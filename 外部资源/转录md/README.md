# 外部资源转录（文老师软考教育 · 软件设计师）

本目录是 `外部资源/*.pdf`（15 份培训机构讲义 PDF，共 314 页 / 约 628 张幻灯片）的 **markdown 全量转录**，便于检索和翻阅。

## 为什么要转录

原 PDF 的中文字体缺 ToUnicode 映射，**机器提取文本只能得到数字和英文，中文全部丢失**（`pdftotext` 类工具无效）。因此本目录内容是**逐页看图人工转录**的，保留原讲义措辞、真题题干与答案。

纯文字的表格已直接转成 markdown 表格，不再重复配图。

## 与本项目 `讲义/` 的关系

- `讲义/`（01–43）是**导师按「定位 → 理解 → 考点」三层结构写的自学讲义**，重理解主线和分步算例。
- 本目录是**外部培训机构的原始材料转录**，重考点罗列 + 真题示例，用作**交叉核对与查漏**，不替代 `讲义/`。
- 已知的覆盖差异（外部有、`讲义/` 目前缺）：
  - **下午题专题**（本目录 15）——`讲义/` 完全空缺，优先级最高
  - **结构化开发方法 / DFD 本体**（本目录 13、15）——`讲义/16` 只讲了内聚耦合与架构风格
  - 数据仓库 / 数据挖掘 / 反规范化 / 分布式数据库（本目录 04）
  - RAID / DAS-NAS-SAN / 综合布线 PDS / 网络规划三层模型（本目录 05）
  - WebApp 分析与设计、逆向工程与再工程、软件产品线（本目录 11、13）
