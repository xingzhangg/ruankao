## 开讲：五件东西装一个包，能不能不把 32 种组合都试一遍

一个具体问题，整课跟着它走。有 5 件东西，价值和重量如下，包只能装 17 斤，每件**要么整件拿走、要么不拿**，问最多能拿走多少价值。

| 物品 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 价值 v | 4 | 5 | 10 | 11 | 13 |
| 重量 w | 3 | 4 | 7 | 8 | 9 |

第一反应人人一样：**全试一遍**。每件拿或不拿，2⁵ = 32 种组合，逐个算总重、剔掉超 17 斤的、在剩下的里挑价值最高的。这办法一定对，只有一个毛病——**候选数量随物品数指数增长**。50 件东西就是 2⁵⁰ ≈ 1.1×10¹⁵ 种，一秒试一亿种也要 130 天。

这一课的全部内容都在回答同一个问题：**怎么不把 32 种试完，还能拿到答案。** 第一节交掉"算法"这个词的定义考点；第二、三节立起量尺（复杂度）和工具（递归），要动手算；第四节是五条路，每条都是上一条不够用时的产物。

### 一、"算法"这个词自己就是考点

**算法**是对特定问题**求解步骤的一种描述**，是指令的有限序列，其中每一条指令表示一个或多个操作。它有五个特性，是纯记忆的送分题：

- **有穷性**：对任何合法输入，必须在执行有穷步之后结束，且每一步都能在有穷时间内完成。死循环不是算法。
- **确定性**：每条指令含义确切、不产生二义；任何条件下**只有唯一一条执行路径**，相同的输入只能得出相同的输出。
- **可行性**：描述的操作都能通过已经实现的基本运算**执行有限次**来实现。"算出圆周率的精确值"就不可行。
- **输入**：有**零个或多个**输入。可以一个都没有——比如一个只负责打印固定字符串的过程。
- **输出**：有**一个或多个**输出，且与输入有特定关系。**一个都没有的不叫算法**。

考题只在最后两条上做手脚，把"输入零个或多个"改成"至少一个"，或把"输出一个或多个"改成"零个或多个"。记一句：**输入可以没有，输出必须有。**

### 二、量尺：时间复杂度是怎么数出来的（这一节要动手算）

衡量一个算法快慢，不数秒表（换台机器结果就变），数**基本操作数**：算法里那条被执行得最多、最能代表工作量的操作（比较、赋值、加法之类）执行了多少次。以输入规模 n 为自变量，把这个次数写成函数 **T(n)**。同一个 n，数据长什么样也会让执行路径不同，所以还要分**最佳情况、最坏情况、平均情况**三种（讲义 12 里快排平均 O(nlog₂n)、最坏 O(n²) 就是这个差别）。

拿培训资料留的那段代码数一遍：

```c
for(i = 0; i < n; i++)
  for(j = i; j < n; j++)
     ......          // 基本操作
```

**先猜一下**：内层 j 从 i 开始而不是从 0 开始，等于只跑了完整双重循环的一半。那它还算 n² 这一档吗？先别往下看。

数：i=0 时 j 从 0 走到 n−1，跑 n 次；i=1 跑 n−1 次；……；i=n−1 跑 1 次。加起来

```
T(n) = n + (n−1) + … + 2 + 1 = n(n+1)/2 = n²/2 + n/2
```

代三个数进去：

| n | 实际执行次数 T(n) | n²/2 | T(n)/n² |
|---|---|---|---|
| 10 | 55 | 50 | 0.550 |
| 100 | 5 050 | 5 000 | 0.505 |
| 1 000 | 500 500 | 500 000 | 0.5005 |

规模从 100 涨到 1000（10 倍），次数从 5050 涨到 500500，涨了 **99.1 倍**——接近 10² 而不是 10。低阶项 n/2 和系数 1/2 谁都没能改变"规模翻十倍、工作量翻一百倍"这件事，能改变它的只有那个指数 2。所以答案是：**还是 n² 这一档，减半减掉的只是常系数。**

于是定下扔东西的规矩：**丢掉低阶项，丢掉最高次项的系数，只留增长量级**，写成 T(n) = **O(n²)**。培训资料原话是"从极限角度看，只关心算法运行时间如何随着输入规模的无限增长而增长"，这就是**渐进**二字的意思。

三个渐进符号，定义抄原文，后面跟一句大白话：

- **O 记号**：O(g(n)) = {f(n)：存在正常数 c 和 n₀，使得对所有 n ≥ n₀ 有 0 ≤ f(n) ≤ c·g(n)}。给的是**渐进上界**——**再坏也坏不过 g(n) 这一档**。培训资料明说：**考试中一般只涉及到 O 符号**。
- **Ω 记号**：不等式反过来，0 ≤ c·g(n) ≤ f(n)，给的是**渐进下界**——**再好也好不过 g(n)**。
- **Θ 记号**：0 ≤ c₁g(n) ≤ f(n) ≤ c₂g(n)，上下界都是 g(n)，叫**渐进紧界**。真题里的 Θ(nW)、Θ(n³) 就是它，考试中和 O 基本通用。

把五段示例代码的档位一次数完（每一格的"次数"栏就是上面那套数法）：

| 代码骨架 | 基本操作执行次数 | 档位 |
|---|---|---|
| `sum = (1+n)*n/2;` 一句算完 | 1 次，和 n 无关 | **O(1)** 常数级 |
| `for(i=0;i<n;i++){…}` 单层 | n 次 | **O(n)** 线性级 |
| `count=1; while(count<n) count*=2;` | count 走 1,2,4,8…，第 k 次后是 2ᵏ，2ᵏ ≥ n 就停，k = ⌈log₂n⌉。n=100 跑 **7** 次（2⁷=128 ≥ 100） | **O(log₂n)** 对数级 |
| 两层都是 `0..n−1` | n × n | **O(n²)** 平方级 |
| 外层 `0..n−1`、内层 `i..n−1` | n(n+1)/2 | **O(n²)** 平方级 |


档位从小到大排成一条链，考试直接问它：

> **O(1) < O(log₂n) < O(n) < O(nlog₂n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)**

唯一真会做错的地方是 nlog₂n 和 n² 谁在前。n = 64 时 nlog₂n = 64×6 = **384**，n² = **4096**，差十倍——**nlog₂n 在 n² 前面**，选项把这两个对调的就是错的。

### 三、递归，和递归式怎么求解（也要动手算）

**递归**是指子程序（或函数）**直接调用自己，或者通过一串调用间接调用自己**。它有两个要素，缺一不可：

- **边界条件**（又叫**递归出口**）：递归到什么时候停；
- **递归模式**（又叫**递归体**）：大问题怎么分解成小问题。

阶乘就是标准样本：`n! = 1（n=0）；n·(n−1)!（n>0）`。第一式给了初值，是边界条件；第二式用较小自变量的函数值表示较大自变量的函数值，是递归体。少了边界条件就永远停不下来，直接违反第一节那条**有穷性**。

递归算法的时间复杂度怎么算？培训资料给的方法叫**展开**：把递归式右边的项按同一个递归式再替换一次，一直展开到得出一个求和表达式为止。

**例**：T(1) = 1，T(n) = T(n−1) + n。

```
T(n) = T(n−1) + n
     = T(n−2) + (n−1) + n
     = ⋮
     = T(1) + 2 + 3 + … + n
     = 1 + 2 + … + n = n(n+1)/2 = O(n²)
```

（代进去核一下：n=10 得 55、n=100 得 5050，与 n(n+1)/2 逐个吻合。）

**再数一个真题里的**：T(n) = 8T(n/2) + n²。意思是解一个规模 n 的问题，要解 **8 个**规模减半的子问题，自己另外还要花 n² 的工。画成一棵树，一层一层数：

| 层 | 子问题个数 | 每个的规模 | 每个的非递归代价 | 这一层合计 |
|---|---|---|---|---|
| 0 | 1 = 8⁰ | n | n² | n² |
| 1 | 8 | n/2 | (n/2)² = n²/4 | 8 × n²/4 = **2n²** |
| 2 | 64 | n/4 | n²/16 | 64 × n²/16 = **4n²** |
| k | 8ᵏ | n/2ᵏ | n²/4ᵏ | **2ᵏ·n²** |

**先猜一下**：这棵树是上面几层贵还是下面几层贵？直觉多半答"上面，因为上面的子问题规模大"。看第四列——每往下一层，这一层的合计就**翻一倍**，所以**最底下那一层最贵**。规模每层减半，减到 1 为止，k 从 0 数到 log₂n，全部加起来是

```
n²(1 + 2 + 4 + … + 2^(log₂n)) = n²(2n − 1) ≈ 2n³  →  Θ(n³)
```

（取 n=1024 逐层累加：总和 2 146 435 072，n³ = 1 073 741 824，比值 1.999，确实落在 n³ 这一档。）

真题第二问：算法 B 是 T(n) = X·T(n/4) + n²，X 最大取多少还能比 A 快？同样数：层 k 有 Xᵏ 个规模 n/4ᵏ 的子问题，这一层合计 Xᵏ·(n/4ᵏ)² = n²·(X/16)ᵏ，共 log₄n 层。X > 16 时底层主导，末层合计是 X^(log₄n) = n^(log₄X)。要它比 A 的 n³ 小，就要 log₄X < 3，即 **X < 4³ = 64**，X 取整数，最大 **63**。（X=63 时指数 log₄63 = 2.9886 < 3；X=64 时正好等于 n³，不算更快。）

数完两次就能提炼出一句直接能用的：**T(n) = aT(n/b) + f(n) 这种式子，把 n^(log_b a) 和 f(n) 摆在一起，谁大听谁的。** 8T(n/2)+n²：n^(log₂8) = n³ 比 n² 大，取 Θ(n³)。

### 四、五条路：每一条都是上一条不够用时的产物

回到开头那个包。

#### 路① 分治：大问题解不动，就切开

最自然的念头是**切小**。分治法的思想就是"将一个难以直接解决的大问题分解成一些规模较小的相同问题，以便各个击破、分而治之"，每一层递归上都是三步：

1. **分解**：把原问题分成若干个规模更小、且**与原问题结构相同**的子问题；
2. **求解**：递归地解各子问题，小到能直接解就直接解；
3. **合并**：把子问题的解**合并**成原问题的解。

要害藏在第 1 步的一个词上：这些子问题必须**互相独立**——解左半边时完全不需要知道右半边解成了什么样。培训资料一句话概括：**凡是涉及到分组解决的都是分治法**。

前几课的现成例子只点一句：归并排序把 n 个元素分成各含 n/2 个的两段、递归排好再归并（三步齐全，最标准的范例）；快速排序按基准划成左右两段各自递归；折半查找每次砍掉一半、只在剩下那半继续。

**那我们的包能不能分治？** 把 5 件东西切成"前 2 件"和"后 3 件"，各求各的最大价值再相加——不行。因为"前 2 件占掉多少容量"直接决定"后 3 件还剩多少容量能用"，两半根本不独立。分治在这里第一次卡住。

卡点分两种，正好通向后面几条路：要么子问题**互相纠缠、同一个被反复索要**（路②），要么**根本不该整块地拆，而该沿路一个一个地做决定**（路③④⑤）。

#### 路② 动态规划：拆开后重叠，那就把算过的记下来

分治的毛病不在"拆"，在**拆完之后同一个小问题被不同分支反复重算**。培训资料写得很直白：适合动规的问题"经分解得到的子问题往往不是独立的"，若用分治来解，"相同的子问题会被求解多次，以至于最后解决原问题需要耗费指数级时间"。

对策只有一句：**算过一次就记下来，下次直接查。** 原话是"用一个表来记录所有已解决的子问题的答案……不管该子问题以后是否被用到，只要它被计算过，就将其结果填入表中"。这就是动态规划的全部秘密。

能用动规的问题要具备两个性质，这两个词是考试原词：

- **最优子结构**：一个问题的**最优解中包含了其子问题的最优解**。装包里就是——如果"5 件、容量 17"的最优方案拿了第 5 件，那么剩下"前 4 件、容量 17−9=8"这一段也必然是那个子问题的最优方案；否则把它换成更好的，大方案就更好了，与"它已是最优"矛盾。
- **重叠子问题**：递归算法会**反复解同一个子问题**，而不是总在产生新的子问题。

⚠️ 培训资料自己插了一句要命的提醒：具有最优子结构时"**贪心策略可能也是适用的**"。所以凡是拿"要不要最优子结构"来区分**动规和贪心**的选项，一律排除——这条两边都要，不是它俩的分水岭。

动规四步（前三步是基本步骤；只求最优值时第四步可省，要求出具体方案才必须做）：①找出最优解的性质并刻画其结构特征；②**递归地定义最优解的值**；③以**自底向上**的方式计算出最优值；④根据算最优值时留下的信息构造出一个最优解。注意第④步的措辞：最优解**可能不止一个，动规只构造出其中一个**——选项写"能求出全部最优解"的是错的。

我们这个包叫 **0-1 背包问题**——"0-1"指每件东西**要么整件拿（xᵢ=1）、要么不拿（xᵢ=0）**，不许拿一部分。第②步的产物就是那个递归式。设 **c[i, w]** 表示"只许动用前 i 件物品、背包容量为 w 时能拿到的最大总价值"：

```
c[i,w] = 0                                      , i = 0 或 w = 0
       = c[i−1, w]                              , wᵢ > w          （第 i 件装不下，只能不拿）
       = max{ c[i−1, w−wᵢ] + vᵢ , c[i−1, w] }   , i > 0 且 wᵢ ≤ w  （拿 / 不拿，取大的）
```

第三行就是"最优子结构"写成算式的样子：**拿**第 i 件，价值 = vᵢ 加上"前 i−1 件在剩余容量 w−wᵢ 下的最优值"；**不拿**，价值 = "前 i−1 件在容量 w 下的最优值"；两者取大。最终要求的是 c[n, W]。

第③步"自底向上"就是从 i=0 那一行、w=0 那一列起，一格一格往右下推，每格只算一次、算完存住。我们这个例子的表是 6 行 18 列共 108 格，末格 **c[5,17] = 24**——对应拿第 4、5 两件，重量 8+9=17 正好装满，价值 11+13=24。（32 种组合穷举与填表两条路互验，都得 24，且最优方案唯一。）

表有 (n+1)×(W+1) 格、每格做一次比较，所以**0-1 背包动规的时间复杂度是 Θ(nW)**——这个数真题直接考过，记住。

（完整填表过程与 C 实现属下午题 4，归讲义 52。上午题只要求你从"填表 + 状态转移式 + 自底向上"这三个特征认出它是动规。）

#### 路③ 贪心：每步直接定，不回头——但它不总对

**先猜一下。** 还是这五件东西、容量 17。最省事的办法是先算每件的"性价比" vᵢ/wᵢ，从高到低往包里塞，塞得下就塞、塞不下就跳过。你觉得这样能拿到最大价值 24 吗？先别往下看。

| 物品 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| v/w | 1.333 | 1.250 | 1.429 | 1.375 | **1.444** |

从高到低是 5、3、4、1、2。拿第 5 件（重 9，还剩 8 斤），拿第 3 件（重 7，还剩 1 斤），第 4、1、2 件都塞不进 1 斤。**结果价值 23，比最优解 24 少 1。**

这就是**贪心法**：原话是"仅根据当前已有的信息做出选择，而且一旦做出了选择，不管将来有什么结果，这个选择都不会改变"；"它并不是从整体最优考虑，它所做出的选择只是在某种意义上的局部最优"，"**并不能保证总能获得全局最优解**，但通常能得到较好的近似最优解"。23 就是那个"较好的近似"。

**为什么会差这 1 分**：贪心拿走第 5 件之后就再也不回头看了，它没机会知道"放弃性价比最高的第 5 件、改拿 4 和 5 这一对"才刚好把 17 斤填满。**每一步都不知道后面会发生什么，而它又不允许自己反悔**——这就是全部原因。

更说明问题的是**度量标准**这件事。培训资料列了三种可选的度量：按最大价值先放、按最小重量先放、按最大单位重量价值先放。同一道题换个度量答案就变（同一实例算三遍）：按最大价值先放拿第 5、4 件得 **24**，**居然对了**；按最小重量先放拿第 1、2、3 件只有 **19**。**三种贪心给出 23、24、19，只有一个碰巧撞上最优。** 贪心的对错取决于度量选得对不对，而"这个度量对不对"贪心自己并不知道。

所以贪心要两个性质：**最优子结构**（和动规同一条，因此不是分水岭），以及**贪心选择性质**——"问题的整体最优解**可以**通过一系列局部最优的选择来得到"。这条才是贪心和动规的真正分界，也是贪心最难的地方，原话："证明一个问题具有贪心选择性质也是贪心法的一个难点"。

**什么时候贪心一定对？** 把 0-1 背包"要么整件要么不拿"这条约束松掉，允许拿一部分（0 ≤ xᵢ ≤ 1），就成了**部分背包问题**。这时按单位重量价值从高到低装、最后一件装个零头把包填满，**必是最优**——因为填满每一单位容量用的都是当时最贵的价值，没有一单位被浪费。练习 2 那道真题就是这么算的，得 16.67，比它自己的 0-1 版本 15 高：**能拆零就一定不比不能拆零差。**

前几课的贪心：哈夫曼编码每次合并权最小的两个结点（讲义 10）、Kruskal 与 Prim 求最小生成树、Dijkstra 求单源最短路每轮锁定当前距离最小的顶点且锁定后不再改（讲义 11）。这几个都**已被证明**具备贪心选择性质，所以给的是真最优解——但那是这几个问题自己的性质，推不到别处。

⚠️ 培训资料第 3-1 节那张部分背包例表（n=5、W=100）把第 5 件的 v/w 标成 1，可 60/40 = 1.5，和它自己那句"已按单位重量价值从大到小排好序"对不上，是抄错了（第 1 件 65/30 也写成了 2.1，实为 2.17）。那张表只用来说明"度量标准有三种选法"，别拿它的数字算题；要练手用练习 2 那道真题，数据自洽。

#### 路④ 回溯：定不下来就试，试错了退回来重选

前三条路都要求你**事先看得出该怎么做**：分治要切得开，动规要写得出状态转移式，贪心要选得出正确的度量。三样都没有时（比如"8 个皇后放棋盘上互不攻击"，根本写不出递推式），只剩最笨也最通用的办法：**把所有可能的选择组合排成一棵树，一条一条走。**

这棵树叫**解空间树**：每往下一层就是做了一个决定（第 i 行的皇后放第几列 / 第 i 件东西拿不拿），从根到叶的一条路径就是一个候选方案。

**回溯法**就是走这棵树的方式，有"**通用的解题法**"之称，可以"**系统地搜索一个问题的所有解或任一解**"。规则：按**深度优先**从根往下搜；搜到任一结点，先判断**这个结点是否肯定不包含问题的解**，若不包含就跳过以它为根的整棵子树、**逐层向其祖先结点回溯**，否则钻进去继续深搜。说人话：**一条路走到黑，撞墙就退回上一个岔路口，换一个还没试过的选择。**

4 皇后（4×4 棋盘放 4 个皇后，两两不同行、不同列、不同对角线）足够看清这个节奏。按行放置，第 1 行先试第 1 列，往下每行挑一个不冲突的列；走到某一行发现四个列全冲突，就退回上一行改试下一个列，改无可改再往上退——一路退回第 1 行，**"第 1 行放第 1 列"这一整支根本无解**。第 1 行改放第 2 列才走通。（把 4 个列号的全部 24 种排列筛一遍就知道：4 皇后只有 **[2,4,1,3]** 和 **[3,1,4,2]** 两组解，方括号里第 i 个数是第 i 行皇后所在的列号，两组首位都不是 1。）

两件事要看出来。一是**回溯不止退一层，可能一路退到第一层**；二是**它撤销过的选择是真的撤销了**——这是五条路里唯一会"反悔"的一条。培训资料还给了一句典型场景：一般用于解决**迷宫类**的问题（走进死胡同就退回岔路口）。同类还有全排列生成、图着色。

上面那句"判断这个结点肯定不含解就跳过整棵子树"有个名字叫**剪枝**——像修树一样，判定没戏的整根枝条连看都不看。代价也清楚：最坏情况仍要把解空间树走完，n 件东西拿不拿是 2ⁿ 个叶子，n 皇后是 n! 量级的路径——**回溯的最坏复杂度就落在 O(2ⁿ)、O(n!) 这一档**，剪枝只是让它少走几支，不改档位。

#### 路⑤ 分支限界：试的路上提前砍掉没希望的支

回溯还差一件事。它判断"这支要不要跳过"，靠的是**约束**——超重了、冲突了，这条路根本不合法。可如果一条路完全合法、只是**再怎么走也不可能比手上已有的答案更好**呢？回溯照样会把它走完。

分支限界补的就是这一条：**再加一把尺子，估一估"这支往下走最好也就这样了"；估出来还不如手头最优解，整支砍掉。**

先说两个词。**活结点**指已经生成、但它的儿子还没全部生成完的结点；把一个活结点拿出来生成儿子，这个动作叫把它变成**扩展结点**。原理原话是：**每一个活结点只有一次机会成为扩展结点**；一旦成为扩展结点，就**一次性产生其所有儿子结点**，其中"导致不可行解或导致非最优解的儿子结点被舍弃，其余儿子结点被加入活结点表中"；此后从活结点表里取下一个结点接着扩展，直到找到所需的解或活结点表为空。

和回溯的区别，考试要的是这两条原文：

1. **求解目标**：回溯要"所有解或任一可行解"；分支限界要"在满足约束条件的解中找出使某一目标函数值达到**极大或极小**的解，即某种意义下的**最优解**"。
2. **搜索方式**：回溯是深度优先；分支限界"以**广度优先或以最小耗费（最大收益）优先**的方式搜索解空间树"。广度优先＝一层一层地铺开，先把同一层的结点全生成完再往下一层，和回溯"一条路走到黑"正好相反。

按"下一个扩展结点怎么挑"分两类：**队列式（FIFO）分支限界法**按队列先进先出取；**优先队列式分支限界法**按优先队列里规定的优先级取，优先级最高的先扩展。

那把尺子的方向别记反：**求最大值**的问题（0-1 背包求最大价值）估的是**上界**，上界 ≤ 当前最优就砍；**求最小值**的问题（**TSP 旅行商问题**：给定若干城市和两两之间的距离，求一条每个城市恰好经过一次再回到起点的最短路线）估的是**下界**，下界 ≥ 当前最优就砍。本质是同一句话：**这支最好也就这样了。**

最后一个常见的错结论：剪枝只让它**期望上**更快，**最坏情况仍是指数级**。选项里写"分支限界法可把时间复杂度降到多项式级"的，一律是错的。

**收口。** 五条路排成一条链，每一条都是上一条在某处不够用时的产物：分治要求子问题切得开、互不相干；动规补的是"切开后彼此重叠、被反复重算"；贪心补的是"根本不必切完、每步直接定"；回溯补的是"定不下来，只能试错重来"；分支限界补的是"试的路上早点砍掉没希望的支"。它们共同的底线是**确定**——同一个输入跑两次，走的路和给的答案都一样；除贪心外的四条还保证**要最优就给最优**（贪心那 23 分就是这条例外）。下面那四类，正是把这两条底线之一当筹码卖掉、或者干脆在回答另一个问题的。

### 五、不在这条链上的四类：认得即可

**概率算法**。允许在某些步骤**随机地选择下一步怎么走**，代价是**结果以较小的概率出错**，换来运行时间的大幅减少。基本特征：**同一个实例用同一个概率算法求解两次，可能得到完全不同的结果**——这一条直接破了第一节那个"确定性"，所以它自成一类。它的输入分两部分：原问题的输入，加一串供随机选择用的随机数序列。还有一条：同一个输入实例，两次运行的**执行时间也可能不同**。四个子类要能对上名字，括号里是培训资料的原话，但这几句字面上极易读反，各配一句大白话：**数值概率算法**（用于数值问题的求解——给的是近似值，多算一会儿就更准）、**蒙特卡洛算法**（求问题的精确解——它总会给你一个答案，但这个答案有小概率是错的）、**拉斯维加斯算法**（不会得到不正确的解——它宁可说"这次没找到"，也绝不给错答案）、**舍伍德算法**（总能求得问题的一个正确解——既不出错也不失败，随机只用来抹平最坏情况）。

**近似算法**。对付**难解问题**（规模一大就没有已知的多项式时间算法可用，比如 TSP）的另一条路：**放弃求最优解，用近似最优解代替**，换算法设计上的简化和时间复杂度的降低。它虽然可能找不到最优解，但**总会给出一个解**，而且必须能说清这个解**与最优解差多远**（差别或比例的界限），差得越少越实用。衡量它只有两个标准：**时间复杂度必须是多项式阶**（基本目标）、**解的近似程度**。

**数据挖掘算法**。它回答的不是"怎么算得快"，而是"从爆炸式增长的数据里挖出隐含的有价值信息"，核心功能是**分类、回归（预测一个数值）、关联规则、聚类**。三个必考名词：**分类**是**有监督的学习过程**——拿带着答案的历史数据（训练数据集）训出模型，再预测未知数据的类别；两步是**学习模型**（用训练集建模）和**应用模型**（用测试集评估好坏，再对未知数据预测）；算法有决策树归纳（自顶向下的递归树算法）、朴素贝叶斯、后向传播 BP、支持向量机 SVM。**关联规则挖掘**先求出数据集中的**频繁模式**（经常一起出现的组合），再由频繁模式产生**关联规则**（"买了 A 的人多半也买 B"，就是啤酒尿布那个故事），用于交叉销售与决策分析；算法有类 Apriori、FP-growth、ECLAT。**聚类**是**无监督学习过程**——事先没有标准答案，只按数据自身的特征把相似的对象归为一类，方法分基于划分、层次、密度、网格、统计模型五种。⚠️ **分类有监督、聚类无监督**是本节唯一稳定的考点，别记反。

**智能优化算法**。以数学为基础求各种工程问题的优化解，全靠"灵感抄自哪儿"来认名字：**人工神经网络 ANN**（抄人脑神经元，是一个以有向图为拓扑结构的动态系统）、**遗传算法**（抄达尔文"优胜劣汰、适者生存"和遗传变异，迭代中保持已有结构同时寻找更好的结构）、**模拟退火 SA**（抄金属退火，分**加温、等温、冷却**三个阶段，求全局最优）、**禁忌搜索 TS**（抄人的记忆，用 **Tabu 表**记下已走过的路，避免绕回局部最优）、**蚁群算法**（抄蚂蚁的**信息素**正反馈，用蚂蚁走过的路径表示可行解，短路径上信息素浓、跟的蚂蚁越来越多）、**粒子群 PSO**（抄鸟群找食，每个解是一只"粒子"，靠追**个体极值 pBest** 和**全局极值 gBest** 更新自己）。

## 考试怎么考

**考点① 给一段描述认策略。** 题干里必有一个标志性短语，对上就完：出现"互不重叠／相互独立／分别求解后**合并**"→分治；"**重叠**子问题／避免重复计算／**存表填表**／自底向上"→动规；"每一步**局部最优**／一旦做出选择**不再改变**／按某种顺序依次选取"→贪心；"**试探**／走不通就**退回**／求**所有**满足条件的解／深度优先"→回溯；"求**最优解**／**界限函数**／提前判断没希望就不再展开／**优先队列**扩展"→分支限界。

**考点② "XX 与 YY 的主要区别是""以下叙述中不正确的是"。** 四个选项里三个抄定义、一个反着写，错项只有三种造法，认出造法就不必逐字比对。一是**对调**：把回溯写成求最优解、把分支限界写成求所有解，把"自底向上填表"安到分治头上、把"自顶向下递归"安到动规头上。二是**把不是分水岭的当分水岭**：拿"要不要最优子结构"来分动规和贪心（两边都要）、拿"是不是递归实现"或"有没有分解子问题"来分分治和动规（两边都有）。三是**把量级吹上去**："分支限界能把复杂度降到多项式级""贪心一定能得到最优解""动规一定比分治快""贪心能求出全部最优解"，全错。三对策略真正的分水岭只有三条，速记里"三条分水岭"那行列全，做题时对着它排除即可。

**考点③ 数字题。** 三种问法：把几个档位排序（唯一真会错的地方是 nlog₂n 和 n² 谁在前）；给一个递归式问复杂度（按第三节的树数法，别只盯着式子里的 f(n)、漏掉子问题个数带来的放大）；给一个具体算法问复杂度（先分清瓶颈在哪一步——部分背包贵在那次排序，不在装包那一遍）。要背的那几个数在速记里。

### 参考答案

**1. D、C**。第一问：n^(log₂8) = n³ 与 f(n) = n² 取大者，得 **Θ(n³)**（推导见第三节那棵递归树）。选 A/B/C 的都是只看见式子里的 n²、漏了 8 个子问题带来的放大。第二问：算法 B 的主导项是 n^(log₄X)，要小于 n³ 就要 X < 4³ = 64，整数最大 **63**。注意是"比 A 快"不是"不慢于 A"，X=64 时两者同为 n³，不算快，所以不选 D。

**2. C、A、D、B**。（62）0-1 背包：穷举与填表双路互验，c[5,10] = **15**（拿第 1、2、5 件，重 2+2+4=8 ≤ 10，价值 6+3+6=15）。（63）填 (n+1)×(W+1) 张表、每格一次比较，**Θ(nW)**。（64）部分背包可拆零：单位重量价值为 3、1.5、0.833、0.8、1.5，从高到低是 1、2、5、3、4；全取第 1、2、5 件用掉 8 斤得价值 15，还剩 2 斤，第 3 件（重 6、值 5）取 1/3 得 5/3，合计 15 + 5/3 = **16.67**。它比 0-1 版本的 15 高，正是"能拆零就不会更差"。（65）这一问考的不是装包本身，而是**这个算法的瓶颈在哪**：装包那一遍只是扫一趟 O(n)，真正贵的是题干指定的**归并排序**，**Θ(nlgn)**。

**3. C、B、B、（第四问两种口径）**。（62）"从左端第一栋开始装一个、去掉被覆盖的、在剩下的里重复"——每一步只看当下、装了不再挪，是**贪心**。（63）房子已按坐标给出，算法只从左到右扫一遍，**O(n)**。（64）半径 20 米，在第一栋房子右侧 20 米处装，覆盖区间就是 [该房, 该房+40]：栓在 30 覆盖 10/20/30/35；剩下最左是 60，栓在 80 覆盖 60/80；剩下 160，栓在 180 覆盖 160；剩下 210，栓在 230 覆盖 210；剩下 260，栓在 280 覆盖 260/300。共 **5** 个。（65）**主流参考答案分两派，不要当成已定论**：信管网真题库给 **A**（肯定可以求得一个最优解），希赛系题库与本课培训资料给 **C**（对有些实例可能得不到最优解）。分歧在问的是谁——题干这个具体做法"在最左边还没被覆盖的房子右侧恰好一个半径处放桩"，对"直线上用最少的点覆盖所有点"这类问题可以证明总能拿到最少桩数，按这个读法选 A；C 说的则是贪心法作为一类策略的通性。**这一问不是可靠得分点**，稳稳能排除的只有 B、D：B 错在"所有最优解"（算法只给一个方案），D 错在"只能得到近似最优解"（那是近似算法的说法）。同类题问"贪心法"就答"不保证全局最优"，问"该算法"则要看这个算法自己站不站得住。

**4. A**。"相互独立、互不重叠 + 分别求解 + 合并"是分治的定义原文；写明"互不重叠"就排除了动规。

**5. A**。"局部最优 + 一旦选择不再回溯或改变"是贪心的定义原文。回溯恰恰相反（会退回改选），排除 B。

**6. B**。A 错：两者都要把问题分解成子问题，"分不分解"不是区别点，区别在分出来的子问题彼此**独立还是重叠**。C **说反了**：动规通常自底向上填表，分治是自顶向下递归分解再合并。D 两头都错：分治不是专为求最优解的（归并排序就没有"最优"可言），求所有解通常是回溯的目标。

**7. D**。剪枝只是期望上更快，最坏仍是指数级——这是"错法三：把量级吹上去"的标准样子。A、B、C 三条都是培训资料原文。

**8. B**。求最大值估上界（上界 ≤ 当前最优就砍），求最小值估下界（下界 ≥ 当前最优就砍），本质都是"这支最好也就这样了"。

**9.** 贪心法。贪心先拿 4，剩 2 只能拿 1、1，共 **3 枚**；最优是 3+3，只要 **2 枚**（填表逐个金额推一遍即可验证）。这就是面额组合不具备贪心选择性质时贪心失手的样子——和课上那个 23 对 24 是同一回事。

**10.** 前者是**分类**，属**有监督**学习（要带标签的训练数据集）；后者是**聚类**，属**无监督**学习（没有标签，只按数据特征分堆）。

**11.** 归并排序＝分治（分解／求解／合并三步齐全）；Dijkstra＝贪心（每轮锁定当前距离最小的顶点，锁定后不改）；n 皇后＝回溯（逐行试探、冲突就撤销上一步重选）；0-1 背包填表＝动态规划（重叠子问题 + 自底向上填表）；TSP 加界限函数的搜索＝分支限界（求最优解 + 提前砍掉没希望的支）。

## 速记

- 算法五特性：有穷、确定、可行、**输入零个或多个**、**输出一个或多个**——输入可以没有，输出必须有；确定性＝同输入同输出，概率算法正好破了这一条
- 档位链 O(1)<O(log₂n)<O(n)<O(nlog₂n)<O(n²)<O(n³)<O(2ⁿ)<O(n!)；O 上界、Ω 下界、Θ 紧界，考试基本只用 O；内层从 i 起只跑一半，仍是 O(n²)
- 递归两要素：边界条件（出口）＋递归模式（体）；T(n)=aT(n/b)+f(n) 比 n^(log_b a) 与 f(n) 取大者；8T(n/2)+n²＝Θ(n³)，X·T(n/4)+n² 要更快则 X<64、最大 63
- 五条路一条链：分治→动规（重叠，记表）→贪心（每步定死不回头）→回溯（试错回退）→分支限界（估界砍支）；分支限界另记：活结点只扩展一次，分 FIFO 式与优先队列式
- 三条分水岭：分治／动规看**重不重叠**；动规／贪心看**贪心选择性质**（最优子结构两边都有，不是分水岭）；回溯／分支限界看**目标（所有解 vs 最优解）＋搜索（DFS vs BFS／最小耗费优先）**
- 必背数字：0-1 背包动规 **Θ(nW)**；部分背包贪心瓶颈是排序 **Θ(nlog₂n)**；回溯／分支限界最坏仍 O(2ⁿ)、O(n!)；界限方向——**求最大估上界、求最小估下界**
- 归档：归并／快排／折半＝分治；0-1 背包填表＝动规；哈夫曼／Dijkstra／Kruskal／Prim／部分背包／消防栓＝贪心；n 皇后／迷宫／全排列／图着色＝回溯；0-1 背包搜索树／TSP＝分支限界
- 链外四类：概率（数值概率／蒙特卡洛求精确解／拉斯维加斯不给错解／舍伍德总正确）；近似（放弃最优，须多项式阶且给出误差界）；数据挖掘（**分类有监督、聚类无监督**，关联规则先频繁模式后规则）；智能优化（ANN、遗传、模拟退火加温—等温—冷却、禁忌 Tabu 表、蚁群信息素、PSO 的 pBest／gBest）
