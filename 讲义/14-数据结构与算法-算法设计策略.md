## 第 0 层 · 定位

**这一课回答**：前 7 课学的算法背后是同几种思路的变形（分治/动态规划/贪心/回溯/分支限界），给一段问题描述能认出属于哪种。

**前后关系**：数据结构板块收官课，把哈夫曼、Dijkstra、快排、折半按「思路」重新归档；只到识别层面，不做完整推导。

**分值与去向**：板块 8–10 分，本课通常 1 道辨析题；下午题 4 常附带问「用了哪种策略、时间复杂度多少」，答案来源就是本课。不用算。

## 第 1 层 · 理解

### 一句话

> 前七课教的是"这道题的解法"；这一课教的是**"没见过的题该从哪下手"**——把工程上反复奏效的五种起手式提炼出来，让你看到一个陌生问题时，能先判断"它属于哪一类"，而不是从零发明。

### 痛点：会背算法 ≠ 会做题

工作里你不会遇到"请实现归并排序"，你遇到的是这种：

> "给你一批订单，每单有耗时和收益，机器只能跑 8 小时，怎么排收益最大？"

这题**没有名字**。你脑子里那些背下来的算法一个都对不上号，于是就开始拍脑袋——**而拍脑袋最典型的翻车方式就是：无脑按"单位时间收益最高"排序，从高到低塞满**。这看着无比合理，但它是**贪心**，而这个问题（0/1 背包的变形）**贪心是错的**——本课第 3 层会用一个 3 行的反例把这种直觉打死。

**这一章真正的价值**：给你一套**问路的顺序**。拿到陌生问题，按顺序问自己三个问题，就能把候选从"我不知道"收窄到"就这一两种"。

### 一条主线

整章只有一个起点：**大问题解不动，就拆**。五种策略是"拆"之后三个岔路口的五个答案。

```
所有算法设计策略的共同起点：问题太大解不动 → 【拆】
   │
   ├─ 岔路① 拆出来的子问题，彼此【重不重叠】？        ← 拆解型（问"重叠吗"）
   │     ├ 不重叠：左右两半各管各的，解完一合并就完事
   │     │         → 【分治】     归并排序、快排、二分查找
   │     └ 重  叠：同一个子问题被不同分支反复索要
   │               硬递归 = 指数级重复劳动（fib 是活教材）
   │               对策：算过一次就【记下来】，查表代替重算
   │         → 【动态规划】  斐波那契、0/1背包
   │            （附带前提：得有【最优子结构】，大解能由小解拼出来）
   │
   ├─ 但有些问题根本【不值得拆完】——拆全了就是 2ⁿ 个子情况
   │  那就别拆全，改成"沿路走，每一步只做一个决定"
   │     岔路② 凭什么做这个决定？                     ← 决策型（问"敢不敢一步定终身"）
   │     └ 凭"当下看着最划算"，定了就不再改
   │         → 【贪心】     找零钱、Dijkstra、Kruskal、哈夫曼
   │            代价：快得多，但【不保证全局最优】
   │                  （{1,3,4} 凑 6 就当场翻车 → 第3层推演B）
   │
   └─ 岔路③ 贪心不敢用（会翻车）、DP 又建不出状态表，怎么办？ ← 搜索型（问"要所有解还是最优解"）
         只剩最笨也最通用的一招：把所有【选择组合】排成一棵搜索树，走一遍
         ├ 目标是"所有解 / 随便一个可行解"：一条路走到黑，撞墙就退回上一步换个选择
         │    → 【回溯】       N皇后、全排列、图着色、迷宫
         └ 目标是"最优解"：再加一把尺子——先估出"这条分支往下走最好也就这样了"，
                            估出来还不如手头已有的最优解，整条分支【连看都不看】直接砍
              → 【分支限界】   0/1背包、TSP
   │
   ↓
最后一根把全章系起来的绳子：为什么非要分这五类？因为它们的【复杂度档位差着数量级】
     分治 / DP  →  多项式级：O(nlog₂n)、O(n²)……（能跑）
     贪心       →  通常最低，常是排序的 O(nlog₂n)（最快，但可能算错）
     回溯 / 分支限界 → 最坏仍是 O(2ⁿ)、O(n!)（剪枝只是让它别真把树走完）
   ↓
所以第 8 节那张复杂度表【不是附录，是这一章的结账单】——
选错策略的代价，就写在这张表的档位差里。
```

**收窄口诀（拿到题先分三类，再五选一）**：
> 题干在说**"分解子问题"** → 拆解型，只在 **分治 / DP** 里选，判据是**重不重叠**
> 题干在说**"每一步选最好的、不回头"** → 决策型，就是 **贪心**
> 题干在说**"试探 / 搜索 / 枚举所有可能"** → 搜索型，只在 **回溯 / 分支限界** 里选，判据是**要所有解还是要最优解**

## 第 2 层 · 考点：考试怎么问

### 考点① 给一段文字描述，选它属于哪种策略（最高频，已核实真题就是这个考法）

**题目长相**：
> "求解某问题时，将其分解为若干子问题，这些子问题相互独立、互不重叠，分别求解后再将子问题的解合并得到原问题的解，该方法属于（ ）。"
> "某算法在求解每一步时，只依据当前状态做出局部最优的选择，一旦做出选择就不再回溯或改变，该算法体现的设计策略是（ ）。"

**怎么解**：题干里必有一个**标志性动词短语**，直接对号入座。这是本课唯一需要"背"的东西——**判别信号表**：

| 策略 | 一句话判别式 | **题干信号（看到就选它）** |
|---|---|---|
| **分治法** | 分解成规模更小、结构相同且**互相独立、互不重叠**的子问题，分别求解后**合并** | "一分为二"、"子问题与原问题结构相同"、"**相互独立/互不重叠**"、"分别求解后**合并**" |
| **动态规划** | 子问题**会重复出现**（重叠子问题），算过就**存表**，用时查表；且需**最优子结构** | "**重叠**子问题"、"避免重复计算"、"**存储中间结果/填表**"、"**最优子结构**"、"分阶段决策"、"求最大/最小/最优值" |
| **贪心法** | 每一步都做**当前看起来最优**的选择，**选完不再更改、不回头** | "**每一步/局部最优**"、"**不再回溯或改变**以前的选择"、"按某种顺序依次选取" |
| **回溯法** | 一步步**试探**构建解，违反约束就**退回上一步**换未试过的选择（DFS + 撤销） | "**试探**"、"**走不通就退回/回退**"、"穷举所有可能的组合/排列并检查约束"、"求**所有**满足条件的解" |
| **分支限界法** | 同样搜索解空间树，但目标是**最优解**，用**界限函数**估出无望分支直接整枝剪掉 | "**求最优解**"、"**上界/下界函数**"、"**提前判断没希望就跳过/不再展开**"、"优先队列按最有希望顺序扩展" |

**陷阱**：
- 最常见的错误选项是拿 **分治** 去顶 **动态规划**——因为两者开头一模一样（都"分解成子问题"）。**只看"重不重叠"这四个字**：题干写"互不重叠"必是分治，写"重复出现/避免重复计算"必是 DP。
- 第二常见是拿 **回溯** 去顶 **贪心**：贪心的题干一定有"**不再回溯/不再改变**"，回溯的题干一定有"**退回/撤销**"——这两个词是互斥的，看到哪个选哪个。
- "求最优解"**不是** DP 的专利。DP、贪心、分支限界都可能求最优解，别看到"最优"就无脑选 DP，要继续看它是"填表递推"（DP）、"每步选最好"（贪心）还是"搜索树+剪枝"（分支限界）。

### 考点② 给一个具体算法名，问它体现哪种策略（送分，前七课的复习题）

**题目长相**："Dijkstra 算法采用的设计策略是（ ）"、"下列算法中采用分治策略的是（ ）"。

**怎么解**：背这张**算法 → 策略**归档表（本板块前七课的算法全在这儿）：

| 具体算法 | 所属策略 | 为什么 |
|---|---|---|
| **归并排序**（讲义12） | 分治 | 从中间切两半，各自排好序（子问题同构），再**合并**两个有序段——"分解→解决→合并"三步的标准范例 |
| **快速排序**（讲义12） | 分治 | 选基准划分成左右两段，两段**独立**递归 |
| **二分查找**（讲义13） | 分治 | 范围切一半，只在剩下那半继续查，另一半直接丢弃 |
| **斐波那契（递推/填表）** | 动态规划 | 重叠子问题 + 记忆化 |
| **0/1 背包（填表解法）** | 动态规划 | 最优子结构，前 i 件的最优解由前 i−1 件推出 |
| **Dijkstra 最短路径**（讲义11） | 贪心 | 每步在未确定顶点里挑**当前已知距离最小**的，确定后不再更改 |
| **Kruskal 最小生成树**（讲义11） | 贪心 | 边按权排序依次尝试加入，**成环就跳过**，不回头调整已选边 |
| **哈夫曼编码构造**（讲义10） | 贪心 | 每步合并**当前权重最小的两个**节点，选完不再拆开重组 |
| **找零钱（按最大面额选）** | 贪心 | 每步选不超过剩余金额的最大面额 |
| **N 皇后 / 全排列 / 图着色 / 迷宫找路** | 回溯 | 试探 + 冲突就撤销上一步重选 |
| **0/1 背包（分支限界解法）、TSP 剪枝搜索** | 分支限界 | 搜索树 + 界限函数剪掉无望分支，求最优解 |

> **补充·0/1 背包问题原型**（DP 和分支限界都拿它当例题，先把题面记牢）：
> n 件物品各有重量和价值，背包容量有限，每件物品**要么整件拿、要么不拿**（不能拿一部分，这就是"0/1"的由来），求能装下的**最大总价值**。
> **DP 解法的子问题定义**：设"用**前 i 件**物品、限重为 w 时能拿到的最大价值"为一个子问题，它的最优解可由"**前 i−1 件**物品在两种限重下的最优解"推出（对应"拿"与"不拿"第 i 件两种决策）——**原问题的最优解由子问题的最优解组合而成，这正是最优子结构**。（完整递推表格属第二轮专项，本课只识别特征。）

**陷阱**：
- **0/1 背包一题多解**——它同时是 DP 的经典例、也是分支限界的经典例，**看题干说的是"填表/递推"还是"搜索树+界限函数"**，不能只看"0/1背包"四个字就选 DP。
- **Dijkstra 是贪心不是 DP**。它每轮"选当前最小并锁定、之后不再改"，是标准贪心。（它之所以正确，靠的是边权非负这个前提。）
- 二分查找有人会犹豫选不选分治——软考口径把它归**分治**（分解成规模更小的同类问题），照这个答。

### 考点③ 两两辨析题（"XX 与 YY 的主要区别是"）

**题目长相**："动态规划与分治法的主要区别是（ ）"，四个选项里三个是似是而非的假区别。

**怎么解**：三组辨析，各自只有**一条**真正的分水岭，其余说法都是干扰：

**A. 分治 vs 动态规划 —— 分水岭：子问题会不会重叠**

| | 分治法 | 动态规划 |
|---|---|---|
| **子问题关系** | **互不重叠**、彼此独立 | **重叠**，同一子问题被反复索要 |
| 处理方式 | 各自递归求解后合并 | **存表/记忆化**，算过就查表 |
| 方向 | 自顶向下递归分解再合并 | 通常**自底向上填表递推** |
| 典型 | 归并排序（左右两半互不相干） | 斐波那契（fib(3) 被多条路径重复用到） |

> ⚠️ **"要不要最优子结构"不是区别点**——分治的子问题（如归并排序的两个半区）往往也具备最优子结构性质。凡是拿"最优子结构"当区别的选项，一律排除。
> ⚠️ **方向别记反**：DP 是自底向上填表，分治是自顶向下递归。选项经常把这两个对调来骗人。

**B. 贪心 vs 动态规划 —— 分水岭：保不保证全局最优**

| | 贪心法 | 动态规划 |
|---|---|---|
| 决策方式 | 每步取当前局部最优，**定了不改** | 穷举所有子问题的最优组合再取最好 |
| 全局最优 | **不保证**（除非问题具备"**贪心选择性质**"） | **保证**（前提是最优子结构成立） |
| 代价 | 快（常是一次排序 O(nlog₂n)） | 慢（要填一张表） |

**C. 回溯 vs 分支限界 —— 分水岭：求解目标 + 搜索方式**

这一组要用**教材权威口径**答（《软件设计师教程》第5版 / 算法设计与分析通行表述）：

| | 回溯法 | 分支限界法 |
|---|---|---|
| **求解目标** | 找出满足约束条件的**所有解**（或任一可行解） | 找出满足约束条件的**一个最优解** |
| **搜索方式** | **深度优先（DFS）**，一条路走到黑 | **广度优先 / 最小耗费（优先队列）优先** |
| **活结点处理** | 一个活结点可**反复**成为扩展结点（回退后再来） | 一个活结点**只有一次**机会成为扩展结点 |
| 数据结构 | 递归 / 栈 | 队列 / 优先队列 |

> 另有一种流传很广的**通俗口径**：回溯只在"违反约束（超重、冲突）"时剪枝，分支限界额外用"界限估计没希望超过当前最优"来剪枝，所以剪得更早更狠。这个说法**方向对但不严谨**——**回溯法本身也可以配限界函数**（教材的回溯法剪枝函数 = 约束函数 + 限界函数）。考试若出现"分支限界用限界函数剪枝"的选项按对处理，但真正稳的判据是上表的**目标 + 搜索方式**。

> **界限函数到底算上界还是下界？**（这是很多资料写混的地方）本质只有一句：**估出"这条分支往下走最好也就这样了"**。
> · **求最大值**问题（0/1背包求最大价值）→ 算**上界**，上界 ≤ 当前最优 就剪
> · **求最小值**问题（TSP 求最短路线）→ 算**下界**，下界 ≥ 当前最优 就剪

**D. 五策略一览总表（辨析题的"总盘"，上面 A/B/C 三组分水岭都能在这张表里对上号）**

| 策略 | 核心思路一句话 | 子问题关系 | 会不会回头改选择 | 求解目标 | 经典例子 |
|---|---|---|---|---|---|
| **分治法** | 分解→独立求解→**合并** | 互不重叠、彼此独立 | 不回头 | 求出解（不专门求最优） | 归并排序、快排、二分查找 |
| **动态规划** | 分解 + **记忆化**避免重复计算 | **重叠**（同一子问题反复出现） | 不回头（自底向上递推） | 最优解（需最优子结构） | 斐波那契、0/1背包填表 |
| **贪心法** | 每步选**当前局部最优** | 不显式划分子问题 | 不回头（选定不改） | 可行解/最优解（**不保证**全局最优，需贪心选择性质） | 找零钱、Dijkstra、Kruskal、哈夫曼 |
| **回溯法** | 试探，走不通就**撤销** | 系统枚举搜索树各分支 | **会回头**（撤销上一步重选） | **所有解**/任一可行解 | N皇后、全排列、图着色 |
| **分支限界法** | 搜索 + **界限函数剪枝** | 系统枚举各分支，按"最有希望"顺序扩展 | 不做"撤销重选"，而是**直接丢弃**无望分支 | **最优解** | 0/1背包分支限界解法、TSP剪枝搜索 |

**陷阱**：
- 选项最爱在**"求解目标"**这一列做手脚：把回溯写成"求最优解"、把分支限界写成"求所有解"——这两个正好对调，看到就是错的。
- **"不回头"不是贪心的专利**：分治、DP 同样不回头（DP 自底向上一次把表填完），**五种里只有回溯会"撤销重选"**。凡是拿"是否回头"来区分贪心和 DP 的选项一律排除——它俩真正的分水岭是**保不保证全局最优**（辨析 B）。
- 别把"**分支限界一定比回溯快**"当成结论：剪枝只是**期望**上更快，两者**最坏时间复杂度仍同在 O(2ⁿ)/O(n!) 这一档**（见考点④）。选项写"分支限界法可把时间复杂度降到多项式级"的，是错的。

### 考点④ 时间复杂度量级排序与归属

**题目长相**："以下时间复杂度从小到大排列正确的是（ ）"、"该算法的时间复杂度为（ ）"。

**怎么解**：记死这条链，剩下的就是对号：

> **O(1) < O(log₂n) < O(n) < O(nlog₂n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)**

| 复杂度 | 读法 | 典型例子 |
|---|---|---|
| O(1) | 常数 | 数组按下标取值、哈希表查找（平均情况） |
| O(log₂n) | 对数 | 二分查找、平衡二叉树查找 |
| O(n) | 线性 | 顺序查找、遍历数组一遍 |
| O(nlog₂n) | 线性对数 | 快速排序（平均）、堆排序、归并排序 |
| O(n²) | 平方 | 直接插入/冒泡/简单选择排序、朴素的双重循环遍历 |
| O(n³) | 立方 | 三重循环，如朴素矩阵乘法 |
| O(2ⁿ) | 指数 | 未优化的斐波那契递归、回溯法穷举所有子集 |
| O(n!) | 阶乘 | 回溯法穷举全排列、TSP 暴力枚举所有路线 |

**和本课主线的接口**：回溯 / 分支限界这类"穷举 / 剪枝穷举"算法的**最坏复杂度落在 O(2ⁿ) 或 O(n!)** 这一档——**剪枝的全部意义，就是尽量别真的把这么大的搜索树走完**。

**陷阱**：**nlog₂n 和 n² 的先后**是排序题里唯一真正的考点，其余档位一眼可辨。记住 **nlog₂n 在 n² 前面**（n=64 时：nlog₂n=384，n²=4096），选项里把这两个对调的就是错的。

### 考点⑤ 衔接下午题 4（算法设计）

**题目长相**（题型规律，**未逐题核实**）：给一段带空的算法代码 + 文字说明，除了填空外，附加问"本题采用的算法设计策略是（ ）""该算法的时间复杂度为（ ）"。

**怎么解**：这两个附加问就是**考点①/④ 的原样搬运**——从代码结构反查策略：

| 代码里看到 | 策略 |
|---|---|
| 递归把区间/数组一分为二，各自递归后再 merge | **分治** |
| 出现二维数组 `dp[][]` / 一维数组从小到大顺推、有状态转移式 | **动态规划** |
| 先排序，然后一个 for 循环依次取、取了不改 | **贪心** |
| 递归里有"选一个 → 递归 → **撤销选择**（回退语句）" | **回溯** |
| 用队列/优先队列存活结点 + 有个 `bound()` 估值函数 | **分支限界** |

**陷阱**：看到递归就填"分治"是最常见的失分点——**回溯和 DP 的记忆化写法也全是递归**。真正的分辨点是：有没有**撤销语句**（回溯）、有没有**查表/存表**（DP）、有没有**merge 合并步骤**（分治）。

## 第 3 层 · 完整推演

> 本课无公式计算，但下面四段推演必须能自己走一遍——考点①②③的所有判据都是从这四段里长出来的。

### 推演 A：fib(6) —— "重叠子问题"到底重叠成什么样

定义式：fib(n) = fib(n−1) + fib(n−2)，fib(1) = fib(2) = 1。

**朴素递归展开 fib(5)**（每一层都在做重复劳动）：

```
fib(5) 需要 fib(4) + fib(3)
fib(4) 需要 fib(3) + fib(2)   ← fib(3) 被算了第2次
fib(3) 需要 fib(2) + fib(1)   ← fib(2) 又被算了第2、3次
```

越往下拆，重复次数越多，朴素递归的时间复杂度**指数级爆炸 O(2ⁿ)**。

**DP 的做法（自底向上填表，每格只算一次）**：

| n | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| fib(n) | 1 | 1 | **2** | **3** | **5** | **8** |

逐格代入，一步不跳：
- fib(3) = fib(2) + fib(1) = 1 + 1 = **2**（代入的是表里已存好的第2、1格）
- fib(4) = fib(3) + fib(2) = 2 + 1 = **3**（fib(3) **查表**得到，不再展开递归）
- fib(5) = fib(4) + fib(3) = 3 + 2 = **5**
- fib(6) = fib(5) + fib(4) = 5 + 3 = **8**

**验算习惯**：填完表反向抽查一格——fib(6)−fib(5) 应等于 fib(4)：8 − 5 = 3 = fib(4)✓。相邻三项恒满足"后 = 前两项之和"，任取一格代入即可自检。

**结论**：每个子问题只算一次、结果存进数组，总代价从 **O(2ⁿ) 降到 O(n)**。这段推演同时坐实了 DP 的两个特征：
① **重叠子问题**——同一个 fib(k) 被多条路径用到；
② **最优子结构（此处是"值"的可组合性）**——fib(n) 直接由 fib(n−1)、fib(n−2) 两个子问题的结果组合（相加）得到，不必重新展开子问题内部。

### 推演 B：贪心失效反例 —— 面额 {1, 3, 4} 凑 6 元

**贪心策略**：每一步选不超过剩余金额的最大面额。

| 步骤 | 剩余金额 | 可选的最大面额 | 选取 | 选后剩余 | 已用枚数 |
|---|---|---|---|---|---|
| 1 | 6 | 4（≤6 的最大面额） | **4** | 6−4 = 2 | 1 |
| 2 | 2 | 1（3 和 4 都 > 2，只能选 1） | **1** | 2−1 = 1 | 2 |
| 3 | 1 | 1 | **1** | 1−1 = 0 | **3** |

贪心解：**4 + 1 + 1 = 6，共 3 枚**。

**穷举核对最优解**：金额 6 的所有凑法中，**3 + 3 = 6 只需 2 枚** —— 比贪心解少 1 枚。

**验算习惯**：面额之和必须等于目标（4+1+1=6✓，3+3=6✓），再比枚数（3 > 2），确认贪心确实**不是**最优。

**结论（本课最重要的一个反例）**：贪心只是一种**启发式策略**，只有问题具备**"贪心选择性质"**时才保证全局最优。Dijkstra、Kruskal、哈夫曼之所以贪心能给出正确的全局最优解，是因为这几个问题**已被证明**具备贪心选择性质（边权非负、贪心子结构等前提）——**不能把"贪心能用"当成理所当然**。

### 推演 C：4 皇后回溯全过程

**问题**：4×4 棋盘放 4 个皇后，任意两个不同行、不同列、不同对角线。按行逐行放置，用"（行,列）"记位置。

> **先记一个结论**：4 皇后**只有 [2,4,1,3] 和 [3,1,4,2] 两组解**（方括号内第 i 个数 = 第 i 行皇后所在的列）。所以**"第1行放第1列"这一整支根本无解**——搜索必须一路回溯到**第1行**换列才能成功。下面按真实搜索顺序走一遍，正好把"回溯不止退一层"这件事看清楚。

**第一支：第1行放第1列**

| 步骤 | 动作 | 结果 |
|---|---|---|
| 1 | 第1行 → 第1列 | 放下 (1,1) |
| 2 | 第2行试第1列 | ✗ 与 (1,1) **同列** |
| 3 | 第2行试第2列 | ✗ 与 (1,1) 行差1、列差1 → **同对角线** |
| 4 | 第2行试第3列 | ✓ 放下 (2,3) |
| 5 | 第3行试第1列 | ✗ 与 (1,1) 同列 |
| 6 | 第3行试第2列 | ✗ 与 (2,3) 行差1、列差1 → 同对角线 |
| 7 | 第3行试第3列 | ✗ 与 (2,3) 同列 |
| 8 | 第3行试第4列 | ✗ 与 (2,3) 行差1、列差1 → 同对角线 |
| 9 | **第3行四列全废 → 回溯到第2行** | 撤销 (2,3)，换下一个没试过的列 |
| 10 | 第2行试第4列 | ✓ 与 (1,1) 行差1、列差3，放下 (2,4) |
| 11 | 第3行试第1列 | ✗ 与 (1,1) **同列** |
| 12 | 第3行试第2列 | ✓（对 (1,1)：行差2列差1 不冲突；对 (2,4)：行差1列差2 不冲突）放下 (3,2) |
| 13 | 第4行试第1、2、3、4 列 | ✗ 第1列同列(1,1)、第2列同列(3,2)、第3列与(3,2)行差1列差1、第4列同列(2,4) → **第4行全废** |
| 14 | **回溯到第3行**，试第3列 | ✗ 与 (2,4) 行差1列差1（与 (1,1) 也是行差2列差2，同样冲突） |
| 15 | 第3行试第4列 | ✗ 与 (2,4) 同列 → 第3行耗尽 |
| 16 | **回溯到第2行** → 第1~4 列已全部试过 | 第2行耗尽 |
| 17 | **回溯到第1行** | **整支宣告无解**，第1行改放第2列 |

**第二支：第1行放第2列 —— 成功**

| 步骤 | 动作 | 结果 |
|---|---|---|
| 18 | 第2行试第1、2、3列 | ✗ 分别是：与(1,2)对角线冲突、与(1,2)同列、与(1,2)对角线冲突 |
| 19 | 第2行试第4列 | ✓ 放下 (2,4) |
| 20 | 第3行试第1列 | ✓（对 (1,2)：行差2列差1；对 (2,4)：行差1列差3）放下 (3,1) |
| 21 | 第4行试第1、2列 | ✗ 第1列同列(3,1)；第2列同列(1,2) |
| 22 | 第4行试第3列 | ✓（对 (3,1)：行差1列差2；对 (2,4)：行差2列差1；对 (1,2)：行差3列差1）放下 (4,3) |

**解：[2, 4, 1, 3]** —— 即 (1,2)、(2,4)、(3,1)、(4,3)。

**验算习惯**：拿到一组解，逐对检查两件事——① **列号互不相同**（2,4,1,3 各不相同 ✓；行号因"逐行放置"天然不同，不必查）；② 任意两皇后的**行差 ≠ 列差**（对角线判据）。抽查 (2,4) 与 (4,3)：行差 2、列差 1，2 ≠ 1 ✓；再抽查 (1,2) 与 (3,1)：行差 2、列差 1 ✓。

**结论**：这段"**试探 → 检测冲突 → 撤销上一步重选**"的节奏就是回溯法的标志性特征；而"回溯不只退一层、可能一路退到第一层"正是它最坏复杂度落在 O(n!) 档的原因。同类例子：全排列生成（试探下一个未用过的数字）、图着色、迷宫找出口。

### 推演 D：0/1 背包的分支限界剪枝（体会"界限函数"在干什么）

**做法**：构造一棵"**选 / 不选**当前物品"的二叉搜索树。每扩展一个节点，就用**放松约束**的方式估一个界——比如允许物品拿一部分（分数背包，用贪心按"单位重量价值"估），算出"从这个节点出发**最多还能拿到多少价值**"作为**上界**。

**剪枝判据**：若这个上界 **≤ 当前已找到的最好答案**，则这整棵子树**再怎么走也超不过手头的解** → 直接砍掉，不必展开。

**和回溯法解同一道题的差别**：
- **回溯法解 0/1 背包**：只有在"**超重**"（违反约束）时才剪枝，剪得晚。
- **分支限界解 0/1 背包**：多了"**上界没希望就剪**"这一层，剪得早、剪得狠，通常效率更高。
- 二者对同一个问题（0/1 背包）的这个差别，就是考点③ 通俗口径的来源。

同类例子：TSP（旅行商问题）的剪枝搜索——**注意 TSP 求最短路线，是求最小值问题，所以算的是下界**：下界 ≥ 当前已知最优路线长度就剪。

## 第 4 层 · 速记

> **五策略辨认口诀**：**"分"要独立不重叠，"动"要重叠靠记忆，"贪"要当下不回头，"回"要撤销再重试，"限"要剪枝求最优**

> **收窄三步**：看到"分解子问题"→ 分治/DP（判**重不重叠**）；看到"每步最优不回头"→ 贪心；看到"试探/搜索/枚举"→ 回溯/分支限界（判**要所有解还是最优解**）

> **五策略一句话**
> · **分治**：子问题**互相独立、不重叠**，分别解决再合并——归并排序、快速排序、二分查找
> · **动态规划**：子问题**会重叠**，算过一次就记下来，靠表格/数组递推——斐波那契、0/1背包
> · **贪心**：每步只选**当前看起来最好**的，选定不再回头——找零钱、Dijkstra、Kruskal、哈夫曼
> · **回溯**：试探着往前走，走不通就**退回上一步**换个选择，穷尽所有可能——N皇后、全排列、图着色
> · **分支限界**：同样是搜索，但目标是**求最优解**，靠界限函数提前砍掉不可能更优的分支

> **三组辨析**
> · 分治 vs DP：子问题**不重叠**用分治，**会重复**必须记忆化（否则指数级重复计算）；"最优子结构"**不是**区别点；DP 自底向上填表、分治自顶向下递归，**别记反**
> · 贪心 vs DP：贪心**不保证**全局最优（除非有贪心选择性质），DP **保证**全局最优
> · 回溯 vs 分支限界：回溯求**所有解/可行解**、**DFS**、活结点可反复扩展；分支限界求**最优解**、**BFS/优先队列**、活结点只扩展一次；通俗口径是"回溯靠违反约束才剪、分支限界靠界限函数早剪"

> **界限函数方向**：求**最大**值算**上界**（0/1背包），求**最小**值算**下界**（TSP）——本质都是"这支最好也就这样了"

> **贪心失效经典反例**：面额 {1,3,4} 凑 6 元，贪心 3 枚（4+1+1），最优 2 枚（3+3）——**贪心不是万能的**

> **4 皇后**：只有 **[2,4,1,3]** 和 **[3,1,4,2]** 两组解；第1行放第1列**无解**（回溯可能一路退到第一层）

> **复杂度口诀**：**"一 log 线性 n 又扛，方立指阶节节高"**
> **O(1) < O(log₂n) < O(n) < O(nlog₂n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)** ——排序题的唯一真考点是 **nlog₂n 排在 n² 前面**

> **算法归档表（下午题反查用）**：归并/快排/二分 = 分治；斐波那契/0-1背包填表 = DP；Dijkstra/Kruskal/哈夫曼/找零钱 = 贪心；N皇后/全排列/图着色/迷宫 = 回溯；0-1背包搜索树/TSP剪枝 = 分支限界

## 考题回顾

**1.【模拟·重现2021上考点】** 求解某问题时，将其分解为若干子问题，这些子问题相互独立、互不重叠，分别求解后再将子问题的解合并得到原问题的解，该方法属于（　）。
A. 分治法　　B. 动态规划　　C. 贪心法　　D. 回溯法

**解答**：抓关键词"子问题相互独立、互不重叠 + 分别求解 + 合并"——正是分治法"分解→解决→合并"的定义。与动态规划的核心区别就在于"是否重叠"：本题明确说"互不重叠"，排除 B。**答案：A**。

**2.【模拟·重现2022下考点】** 某算法在求解每一步时，只依据当前状态做出局部最优的选择，一旦做出选择就不再回溯或改变，该算法体现的设计策略是（　）。
A. 贪心法　　B. 回溯法　　C. 分支限界法　　D. 动态规划

**解答**：核心信号"每一步局部最优 + **不再回溯或改变**以前的选择"——正是贪心法的定义。回溯法恰恰相反（会退回改选择），排除 B。**答案：A**。

**3.【模拟·重现2022下考点】** 动态规划与分治法的主要区别是（　）。
A. 动态规划要求问题具有最优子结构，分治法不要求
B. 动态规划的子问题相互重叠，分治法的子问题相互独立
C. 动态规划自顶向下求解，分治法自底向上求解
D. 分治法只能求最优解，动态规划可以求所有解

**解答**：**B 正确**——如**考点③ 辨析 A** 所述，"子问题是否重叠"是二者最核心的分水岭。A 错误——分治的子问题（如归并排序的两个半区）往往**也**具备最优子结构，这不是区别点。C **说反了**——DP 通常是**自底向上填表递推**（如斐波那契从 fib(1) 推到 fib(n)），**分治**才是自顶向下递归分解再合并。D 无关——两者都不是"求所有解"的策略（求所有解通常是回溯法的目标）。**答案：B**。

**4.【模拟】** 求解迷宫从入口到出口的所有路径时，某算法沿着一条通路不断向前试探，走到死胡同就退回上一个岔路口，改换其他方向继续试探，直到穷尽所有可能的路径，该算法属于（　）。
A. 分治法　　B. 贪心法　　C. 回溯法　　D. 分支限界法

**解答**：核心信号"试探 + 走不通退回换方向 + **穷尽所有可能**"——这是回溯法的标志性特征。若题干改成"只求**一条最短**路径，且用界限函数提前砍掉不可能更短的分支"，则会变成分支限界法。**答案：C**。

**5.【模拟】** 以下时间复杂度从小到大排列正确的是（　）。
A. O(n²) < O(nlog₂n) < O(2ⁿ)　　B. O(nlog₂n) < O(n²) < O(2ⁿ)
C. O(2ⁿ) < O(n²) < O(nlog₂n)　　D. O(n²) < O(2ⁿ) < O(nlog₂n)

**解答**：按标准排序 O(1) < O(log₂n) < O(n) < O(nlog₂n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)，**nlog₂n 排在 n² 前面**，n² 又排在 2ⁿ 前面。A、C、D 都把 nlog₂n 与 n² 或 2ⁿ 的位置搞错了。**答案：B**。

### 参考答案

**1.** 体现**贪心法**——每一步只看"当前剩余金额下能选的最大面额"，选完不回头。这种策略在硬币面额组合不满足"**贪心选择性质**"时会失手，例如面额 {1,3,4} 凑目标 6 时，贪心给出 4+1+1（**3 枚**），但最优解是 3+3（**2 枚**）——贪心解不是全局最优解。（完整分步见第 3 层推演 B。）

**2.** 属于**分支限界法**。关键差异：单纯回溯法是**深度优先**搜索、目标是找出**所有解或任一可行解**，只在"当前路径已经不满足约束"（比如已经绕过了某个必须经过的城市却没经过）时才回退，本质上仍可能把大量"注定不会是最优"的分支走到底才发现不够好；分支限界法目标明确是**求最优解**，采用**广度优先/优先队列**扩展，且额外算出每个分支"往下走最多还能达到多好"的**界限估计**（TSP 求最短路线属**最小值**问题，故算**下界**），只要这个估计已经不如当前已知最优解，就**提前**把整个分支剪掉、根本不必展开，剪枝更早、更狠，通常效率更高。

**3.** 直接递归计算 fib(6) 时，fib(4)、fib(3)、fib(2) 等中间结果会在不同的递归分支里被反复算好几遍，重复次数随 n 增大呈指数级增长（O(2ⁿ)）。改用 DP 的做法：从 fib(1)=1、fib(2)=1 开始，按顺序推 fib(3)=2、fib(4)=3、fib(5)=5、fib(6)=8，每个子问题只计算一次，结果存进数组，后面需要时直接查表，不再重新递归展开，总代价降为 **O(n)**。这体现了 DP 的两个特征：①**重叠子问题**——同一个 fib(k) 会被多条路径用到；②**最优子结构（这里是"值"的可组合性）**——fib(n) 的结果直接由 fib(n−1)、fib(n−2) 这两个子问题的结果组合（相加）得到，不需要重新展开子问题内部的计算过程。
