# 14 · 数据结构与算法：算法设计策略

## 定位

本课回答：碰到没见过的问题从哪下手。第一节是「算法」的定义与五特性；第二、三节立起量尺（时间复杂度）和工具（递归式求解），要动手算；第四节是主干——分治、动规、贪心、回溯、分支限界五条路排成一条链，每一条都是上一条在某处不够用时的产物；第五节收四类不在链上、认名即可的算法。第四节全程跟着同一个装包问题走。

**贯穿例子：0-1 装包。** 5 件东西，包只能装 17 斤，每件**要么整件拿、要么不拿**，求最大价值：

| 物品 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 价值 v | 4 | 5 | 10 | 11 | 13 |
| 重量 wᵢ | 3 | 4 | 7 | 8 | 9 |

每件两种命运，n 件就是 2×2×…×2 = **2ⁿ** 种组合（3 件 8 种，5 件 32 种）。全试一遍一定对，但候选数随物品数**指数增长**：50 件是 2⁵⁰ ≈ 1.1×10¹⁵ 种，一秒试一亿种也要 130 天。整课都在回答：怎么不把组合试完还能拿到答案。

## 一、算法与五特性（概念）

**原话｜** 算法是对特定问题**求解步骤的一种描述**，是指令的有限序列，其中每一条指令表示一个或多个操作。

| 特性 | 是什么 |
|---|---|
| **有穷性** | 对任何合法输入，执行有穷步后结束，且每一步都在有穷时间内完成；死循环不是算法 |
| **确定性** | 每条指令含义确切、无二义；任何条件下**只有唯一一条执行路径**，相同输入只能得出相同输出 |
| **可行性** | 操作都能通过已实现的基本运算**执行有限次**来实现；「算出圆周率的精确值」不可行 |
| **输入** | **零个或多个**；可以一个都没有（如只打印固定字符串的过程） |
| **输出** | **一个或多个**，且与输入有特定关系；一个都没有的不叫算法 |

**易混对：输入 vs 输出**
判据｜输入可以没有，输出必须有。
例子｜只打印固定字符串的过程：零输入、一输出，是算法；把它改成什么都不输出，就不是算法。

## 二、时间复杂度（计算）

**解决什么问题**：衡量算法快慢不数秒表（换台机器就变），数**基本操作数**——执行得最多、最能代表工作量的那条操作（比较、赋值、加法）执行了多少次，写成输入规模 n 的函数 **T(n)**。同一个 n，数据形态不同，执行路径也不同，所以分**最佳、最坏、平均情况**（讲义 12 快排平均 O(nlog₂n)、最坏 O(n²) 就是这个差别）。

**算例**：

```c
for(i = 0; i < n; i++)
  for(j = i; j < n; j++)
     ......          // 基本操作
```

1. i=0 时内层跑 n 次，i=1 跑 n−1 次，……，i=n−1 跑 1 次。
2. T(n) = n + (n−1) + … + 1 = n(n+1)/2 = n²/2 + n/2。
3. 代数验证：n=10 → 55，n=100 → 5 050，n=1000 → 500 500；T(n)/n² 为 0.550、0.505、0.5005，收敛到 0.5。规模涨 10 倍（100→1000），次数涨 **99.1 倍**，接近 10² 而非 10。
4. 结论：内层从 i 起只跑一半，**仍是 n² 这一档**，减半减掉的只是常系数。

**规则**：丢掉低阶项和最高次项系数，只留增长量级，写成 **O(n²)**。能改变「规模翻十倍、工作量翻一百倍」的只有那个指数。原话：「从极限角度看，只关心算法运行时间如何随着输入规模的无限增长而增长」——这就是**渐进**。

| 记号 | 定义 | 大白话 |
|---|---|---|
| **O** | O(g(n)) = {f(n)：存在正常数 c 和 n₀，对所有 n ≥ n₀ 有 0 ≤ f(n) ≤ c·g(n)}，**渐进上界** | 再坏也坏不过 g(n)；一般只用它 |
| **Ω** | 0 ≤ c·g(n) ≤ f(n)，**渐进下界** | 再好也好不过 g(n) |
| **Θ** | 0 ≤ c₁g(n) ≤ f(n) ≤ c₂g(n)，**渐进紧界** | 上下界都是 g(n)；Θ(nW)、Θ(n³) 这类写法就是它，与 O 基本通用 |

五种代码骨架的数法：

| 代码骨架 | 基本操作次数 | 档位 |
|---|---|---|
| `sum = (1+n)*n/2;` | 1 次，与 n 无关 | **O(1)** 常数级 |
| `for(i=0;i<n;i++){…}` | n | **O(n)** 线性级 |
| `count=1; while(count<n) count*=2;` | 第 k 次后 count = 2ᵏ，2ᵏ ≥ n 停，k = ⌈log₂n⌉；n=100 跑 **7** 次（2⁷=128） | **O(log₂n)** 对数级 |
| 两层都是 `0..n−1` | n × n | **O(n²)** |
| 外层 `0..n−1`、内层 `i..n−1` | n(n+1)/2 | **O(n²)** |

**档位链**：**O(1) < O(log₂n) < O(n) < O(nlog₂n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)**

- nlog₂n 在 n² 前面：n=64 时 nlog₂n = 64×6 = **384**，n² = **4096**，差十倍。
- **n 的常数次幂（n、n²、n³）叫多项式阶，2ⁿ、n! 叫指数阶**。「能不能降到多项式级」问的就是跨不跨得过这道界；指数阶规模一大就真算不动（2⁵⁰ 要 130 天）。

## 三、递归与递归式求解（计算）

**递归**：子程序（或函数）**直接调用自己，或通过一串调用间接调用自己**。两要素缺一不可：

- **边界条件**（**递归出口**）：递归到什么时候停；
- **递归模式**（**递归体**）：大问题怎么分解成小问题。

例：`n! = 1（n=0）；n·(n−1)!（n>0）`。第一式给初值，是边界条件；第二式用较小自变量的函数值表示较大自变量的函数值，是递归体。少了边界条件永远停不下来，违反**有穷性**。

**求解方法——展开**：把右边的项按同一递归式反复替换，直到得出求和式。

**算例 1**：T(1) = 1，T(n) = T(n−1) + n。

```
T(n) = T(n−1) + n
     = T(n−2) + (n−1) + n
     = ⋮
     = T(1) + 2 + 3 + … + n
     = n(n+1)/2 = O(n²)          （n=10 得 55、n=100 得 5050，吻合）
```

**算例 2**：T(n) = 8T(n/2) + n²——解规模 n 的问题要解 **8 个**规模减半的子问题，自己另花 n²。按递归树逐层数：

| 层 | 子问题个数 | 每个规模 | 每个非递归代价 | 这一层合计 |
|---|---|---|---|---|
| 0 | 1 = 8⁰ | n | n² | n² |
| 1 | 8 | n/2 | n²/4 | **2n²** |
| 2 | 64 | n/4 | n²/16 | **4n²** |
| k | 8ᵏ | n/2ᵏ | n²/4ᵏ | **2ᵏ·n²** |
| 末层 log₂n | 8^(log₂n) = n³ | 1 | 1 | **n³** |

1. 每往下一层合计**翻一倍**，所以**最底层最贵**（不是上层）。
2. 求和：n²(1 + 2 + 4 + … + 2^(log₂n)) = n²(2n − 1) ≈ 2n³ → **Θ(n³)**。
3. 验算：n=1024 逐层累加得 2 146 435 072，n³ = 1 073 741 824，比值 1.999。

**算例 3**：另一算法 T(n) = X·T(n/4) + n²，X 最大取多少还比 Θ(n³) 快？

1. 第 k 层：Xᵏ 个规模 n/4ᵏ 的子问题，合计 Xᵏ·(n/4ᵏ)² = n²·(X/16)ᵏ，共 log₄n 层。
2. 每层比值 X/16：X 是子问题变多的倍数，**16 = 4²** 是每个子问题变便宜的倍数。X > 16 时越往下越贵，**底层主导**。
3. 末层合计 X^(log₄n) = n^(log₄X)（两边取以 4 为底的对数都是 log₄n·log₄X）。
4. 要 log₄X < 3，即 **X < 4³ = 64**，整数最大 **63**（log₄63 = 2.9886 < 3；X=64 时指数恰为 3，与 Θ(n³) 同档，不算更快）。

**规则**：T(n) = aT(n/b) + f(n)，把 **n^(log_b a)** 和 **f(n)** 比大小——

- n^(log_b a) 大，听它的：8T(n/2)+n² 中 n^(log₂8) = n³ > n²，取 **Θ(n³)**。
- f(n) 大，听 f(n) 的。
- 一样大，再乘 log₂n：归并排序 T(n) = 2T(n/2) + n，n^(log₂2) = n = f(n)，得 **Θ(nlog₂n)**；快排、折半查找也落在这一档。验算：n=1024 每层合计 1024，共 11 层（log₂1024 + 1），总和 11 264，nlog₂n = 10 240，比值 1.1。

## 四、五条路：每一条都是上一条不够用时的产物

### 路① 分治：大问题解不动，就切开（概念）

**原话｜** 将一个难以直接解决的大问题分解成一些规模较小的相同问题，以便各个击破、分而治之。每层递归三步：

1. **分解**：分成若干规模更小、**与原问题结构相同**的子问题；
2. **求解**：递归解各子问题，小到能直接解就直接解；
3. **合并**：把子问题的解合并成原问题的解。

要害：子问题必须**互相独立**——解左半边完全不需要知道右半边的结果。「凡是涉及到分组解决的都是分治法」这句只当**排除**用：分组后子问题还彼此纠缠的，不是分治。

例子：**归并排序**分成各含 n/2 的两段、递归排好再归并（三步齐全，最标准）；**快速排序**按基准划成两段各自递归；**折半查找**每次砍掉一半。

装包不能分治：切成「前 2 件」「后 3 件」各求最优再相加不行——前 2 件占掉多少容量，直接决定后 3 件还剩多少，两半不独立。卡点分两种：子问题**互相纠缠、被反复索要**（→路②），或**该沿路逐个做决定**（→路③④⑤）。

### 路② 动态规划：拆开后重叠，就把算过的记下来（计算）

**解决什么问题**：子问题「往往不是独立的」，用分治解则「相同的子问题会被求解多次，以至于最后解决原问题需要耗费指数级时间」。对策：「用一个表来记录所有已解决的子问题的答案……不管该子问题以后是否被用到，只要它被计算过，就将其结果填入表中」。

两个性质：

- **最优子结构**：问题的**最优解中包含了其子问题的最优解**。装包里：若「5 件、容量 17」的最优方案拿了第 5 件，则「前 4 件、容量 17−9=8」那段也必是该子问题的最优方案，否则换成更好的，大方案更好，矛盾。
- **重叠子问题**：递归算法**反复解同一个子问题**，而不是总产生新子问题。

具有最优子结构时「**贪心策略可能也是适用的**」——最优子结构动规、贪心都要，不是两者的分水岭。

四步（前三步基本；只求最优值时第④步可省）：①找出最优解的性质并刻画其结构特征；②**递归地定义最优解的值**；③以**自底向上**方式计算最优值；④根据计算最优值时得到的信息构造一个最优解。最优解**可能不止一个，动规只构造其中一个**，不能求出全部最优解。

**0-1 背包**（每件 xᵢ=1 整件拿或 xᵢ=0 不拿）的状态转移式：**c[i, w]** = 只许用前 i 件、容量为 w 时的最大价值。w 是「当前剩余容量」，不是物品重量 wᵢ；总容量记 W（此处 17）；也有写成 c(i, j) 的，j 即 w。

```
c[i,w] = 0                                      , i = 0 或 w = 0
       = c[i−1, w]                              , wᵢ > w          （装不下，只能不拿）
       = max{ c[i−1, w−wᵢ] + vᵢ , c[i−1, w] }   , i > 0 且 wᵢ ≤ w  （拿 / 不拿取大）
```

第三行即最优子结构的算式：拿＝vᵢ + 前 i−1 件在 w−wᵢ 下的最优值；不拿＝前 i−1 件在 w 下的最优值。所求为 c[n, W]。自底向上：从 i=0 行、w=0 列起逐格往右下推，每格只算一次、存住。

**算例（三条规则各用一次；第 1 件 v=4 w=3，第 2 件 v=5 w=4）**：

```
c[1,3]  w₁=3 ≤ 3，第三行：拿 4 + c[0,0] = 4；不拿 c[0,3] = 0 → 4
c[2,3]  w₂=4 > 3，第二行：抄上一行同列 → c[1,3] = 4
c[2,7]  w₂=4 ≤ 7，第三行：拿 5 + c[1,3] = 9；不拿 c[1,7] = 4 → 9
```

装不下时不是算不出，是**把上一行原样抄下来**。一路推到右下角：6 行 18 列共 108 格，**c[5,17] = 24**，即拿第 4、5 件，重 8+9=17 正好装满，价值 11+13=24（与 32 种组合穷举互验一致，最优方案唯一）。

**规则**：表 (n+1)×(W+1) 格、每格一次比较 → **0-1 背包动规 Θ(nW)**。认出动规看三个特征：填表、状态转移式、自底向上。（完整填表与 C 实现见讲义 52。）

### 路③ 贪心：每步直接定，不回头——但不总对（计算）

**解决什么问题**：动规的表是 (n+1)(W+1) 格，1000 件、容量 10 万就是一亿格。贪心不填表，一步定一件。

**算例（按单位重量价值 v/w）**：

| 物品 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| v/w | 1.333 | 1.250 | 1.429 | 1.375 | **1.444** |

1. 从高到低：5、3、4、1、2。
2. 拿第 5 件（重 9，剩 8）→ 拿第 3 件（重 7，剩 1）→ 4、1、2 都塞不进。
3. 价值 **23**，比最优 24 少 1：拿下第 5 件后不再回头，不知道「放弃第 3 件、改拿第 4 件」恰好与第 5 件凑满 17 斤。

**原话｜**「仅根据当前已有的信息做出选择，而且一旦做出了选择，不管将来有什么结果，这个选择都不会改变」；「它并不是从整体最优考虑，它所做出的选择只是在某种意义上的局部最优」；「**并不能保证总能获得全局最优解**，但通常能得到较好的近似最优解」。

**度量标准有三种**，同一实例算三遍：

| 度量 | 拿哪几件 | 价值 |
|---|---|---|
| 最大单位重量价值先放 | 5、3 | 23 |
| 最大价值先放 | 5、4 | **24**（碰巧最优） |
| 最小重量先放 | 1、2、3 | 19 |

对错取决于度量选得对不对，而贪心自己不知道。

**两个性质**：**最优子结构**（与动规同）＋**贪心选择性质**——「问题的整体最优解可以通过一系列局部最优的选择来得到」。后者才是贪心与动规的分界，「证明一个问题具有贪心选择性质也是贪心法的一个难点」。

**部分背包**（允许拆零，0 ≤ xᵢ ≤ 1）：按 v/w 从高到低装、最后一件装零头填满，**必是最优**——每单位容量用的都是当时最贵的价值。

1. 同一实例：拿第 5 件（剩 8）、第 3 件（剩 1），此时 23。
2. **第 4 件切 1/8** 装进最后 1 斤，补 11 × 1/8 = 1.375。
3. 总价值 **24.375** > 0-1 最优 24：0-1 的每个方案在部分背包里都合法，能拆零一定不比不能拆零差。

**规则**：排序 Θ(nlog₂n) + 扫一遍 Θ(n)，瓶颈在排序 → **部分背包贪心 Θ(nlog₂n)**，与 0-1 背包动规 **Θ(nW)** 分开记。

已证明具备贪心选择性质、给出真最优解的：哈夫曼编码每次合并权最小的两个结点（讲义 10）；Kruskal、Prim 求最小生成树；Dijkstra 每轮锁定当前距离最小的顶点且不再改（讲义 11）。这是各自问题的性质，推不到别处。

注：常见资料第 3-1 节部分背包例表（n=5、W=100）数字有误——第 5 件 v/w 标成 1，实为 60/40 = 1.5，与「已按单位重量价值从大到小排好序」矛盾；第 1 件 65/30 写成 2.1，实为 2.17。该表只用来说明三种度量，不宜拿来计算。

### 路④ 回溯：定不下来就试，错了退回重选（计算）

**解决什么问题**：分治要切得开、动规要写得出递推式、贪心要选得对度量；三样都没有时（如 8 皇后），把所有选择组合排成一棵**解空间树**逐条走：每往下一层做一个决定（第 i 行皇后放第几列／第 i 件拿不拿），根到叶一条路径是一个候选方案。

**原话｜** 回溯法有「**通用的解题法**」之称，可以「**系统地搜索一个问题的所有解或任一解**」。按**深度优先**从根往下搜；到任一结点先判断**是否肯定不包含问题的解**，不包含就跳过以它为根的子树、**逐层向其祖先结点回溯**，否则继续深搜。即：一条路走到黑，撞墙退回上一个岔路口换选择。

**算例：4 皇后**（4×4 棋盘，两两不同行、不同列、不同对角线），按行放、每行从左试第一个不冲突的列：

```
第1行放第1列
第2行放第3列        （第 1、2 列与第 1 行冲突）
第3行四列全冲突  → 退回第2行
第2行改放第4列
第3行放第2列
第4行四列全冲突  → 退回第3行
第3行已无列可改  → 退回第2行
第2行已无列可改  → 退回第1行 → 这一支无解
```

第 1 行改放第 2 列才走通：2、4、1、3。全部 24 种列排列筛一遍，4 皇后只有 **[2,4,1,3]** 和 **[3,1,4,2]** 两组解（第 i 个数是第 i 行的列号）。

**规则**：

- 回溯**不止退一层**，可能一路退到第一层（上例一次退三层）；撤销的选择是真撤销，五条路里唯一会「反悔」的一条。
- 「判断肯定不含解就跳过整棵子树」叫**剪枝**。最坏仍要走完解空间树：n 件拿不拿 2ⁿ 个叶子，n 皇后 n! 量级 → **最坏 O(2ⁿ)、O(n!)**，剪枝只少走几支，不改档位。
- 典型场景：**迷宫**、n 皇后、全排列生成、图着色。

### 路⑤ 分支限界：试的路上提前砍掉没希望的支（概念）

回溯靠**约束**剪枝（超重、冲突）；一条路合法、但再怎么走也不可能比手上最优解更好时，回溯照样走完。分支限界再加一把尺子——**限界函数**（也写作界限函数），估出「这支最好也就这样」，不如当前最优就整支砍掉。

- **活结点**：已生成、儿子还没全部生成的结点；拿出来生成儿子，就是把它变成**扩展结点**。
- **原话｜** **每一个活结点只有一次机会成为扩展结点**；一旦成为扩展结点，就**一次性产生其所有儿子结点**，「导致不可行解或导致非最优解的儿子结点被舍弃，其余儿子结点被加入活结点表中」；此后从活结点表取下一结点扩展，直到找到所需的解或活结点表为空。
- 按取下一扩展结点的方式分：**队列式（FIFO）分支限界法**（先进先出）、**优先队列式分支限界法**（优先级最高的先扩展）。

**易混对：回溯 vs 分支限界**
判据｜看**求解目标**＋**搜索方式**：回溯求「所有解或任一可行解」，**深度优先**；分支限界求「在满足约束条件的解中找出使某一目标函数值达到**极大或极小**的解，即某种意义下的**最优解**」，「以**广度优先或以最小耗费（最大收益）优先**的方式搜索解空间树」（广度优先＝先把同层结点全生成完再下一层）。
例子｜求 4 皇后全部摆法是回溯；把 0-1 背包画成搜索树、求最大价值并按界砍支，是分支限界。

**易混对：上界 vs 下界**
判据｜求最大值估**上界**，上界 ≤ 当前最优就砍；求最小值估**下界**，下界 ≥ 当前最优就砍。本质同一句：这支最好也就这样。
例子｜0-1 背包求最大价值 → 上界：把剩下未决定的东西**当作可拆零**，用部分背包贪心算一遍，拆零只会更宽松，所以一定不低于真答案。**TSP 旅行商问题**（若干城市两两有距离，求每城恰经过一次再回起点的最短路线）求最小 → 下界。

剪枝只让分支限界**期望上**更快，**最坏仍是指数级**，不能把复杂度降到多项式级。

### 五条路的分水岭（概念）

| 路 | 补上一条的什么缺口 | 典型问题 |
|---|---|---|
| 分治 | — 子问题切得开、互不相干 | 归并、快排、折半查找 |
| 动规 | 切开后**重叠**、被反复重算 → 记表 | 0-1 背包填表 |
| 贪心 | 不必切完，**每步直接定、不回头** | 哈夫曼、Dijkstra、Kruskal、Prim、部分背包、消防栓 |
| 回溯 | 定不下来，**试错回退** | n 皇后、迷宫、全排列、图着色 |
| 分支限界 | 试的路上**估界砍支**，求最优 | 0-1 背包搜索树、TSP |

**易混对：分治 vs 动规**
判据｜子问题重不重叠。
例子｜归并排序左右两半互不相干，是分治；0-1 背包「前 i 件、容量 w」的子问题被多个分支反复索要，是动规。

**易混对：动规 vs 贪心**
判据｜看有没有**贪心选择性质**（最优子结构两边都有，不能用来区分）。
例子｜部分背包能拆零，按 v/w 贪心必最优；改成 0-1 不许拆零，同样的贪心只得 23，要靠动规得 24。

共同底线是**确定**：同一输入跑两次，路径和答案都一样；除贪心外，**用在求最优的问题上时**给出最优（分治本身不一定用在求最优问题上，归并排序无所谓最优）。第五节四类，正是卖掉这两条底线之一、或在回答另一个问题的。

## 五、链外四类（概念）

| 关键词 | 属于 |
|---|---|
| 随机选下一步；**同一实例求解两次可能得到完全不同的结果**；两次执行时间也可能不同；输入＝原问题输入＋随机数序列 | **概率算法**（破了「确定性」，以较小概率出错换运行时间大幅减少） |
| 用于数值问题的求解，给近似值，多算更准 | 数值概率算法 |
| **求问题的精确解**，但有小概率是错的 | 蒙特卡洛算法 |
| **不会得到不正确的解**，宁可说「没找到」 | 拉斯维加斯算法 |
| **总能求得问题的一个正确解**，随机只用来抹平最坏情况 | 舍伍德算法 |
| 对付**难解问题**（规模大时无已知多项式算法，如 TSP）；**放弃最优解，用近似最优解代替**；总会给出一个解，并能说清与最优解差多远（差别或比例的界限） | **近似算法**；两个衡量标准：**时间复杂度必须是多项式阶**（基本目标）、解的近似程度 |
| 从爆炸式增长的数据中挖出隐含的有价值信息；分类、回归（预测数值）、关联规则、聚类 | **数据挖掘算法** |
| 以数学为基础求各种工程问题的优化解，按「灵感来源」认名 | **智能优化算法** |

**易混对：蒙特卡洛 vs 拉斯维加斯**
判据｜蒙特卡洛总给答案、可能错；拉斯维加斯可能不给答案、给了必对。蒙特卡洛的「精确解」是相对数值概率算法的近似值说的——交出一个确定答案（是／否、某个数），代价是有小概率给错。
例子｜素数测试随机抽几个数检验后答「是素数」，有小概率把合数判成素数＝蒙特卡洛；n 皇后随机放前几行、后面放不下就报失败重来，一旦放成必是合法摆法＝拉斯维加斯。

**易混对：分类 vs 聚类**
判据｜分类**有监督**（历史数据带标准答案），聚类**无监督**（事先没答案，按数据自身特征把相似对象归一类）。
例子｜用带标签的历史数据（训练数据集）训模型、判新数据属于哪类＝分类；标签去掉、只按相似度分组＝聚类。

- 分类两步：**学习模型**（用训练集建模）→ **应用模型**（用测试集评估，再对未知数据预测）；算法：决策树归纳（自顶向下的递归树算法）、朴素贝叶斯、后向传播 BP、支持向量机 SVM。
- 聚类方法五种：基于划分、层次、密度、网格、统计模型。
- **关联规则**：先求**频繁模式**（经常一起出现的组合），再产生**关联规则**（买 A 的人多半也买 B，啤酒尿布），用于交叉销售与决策分析；算法：类 Apriori、FP-growth、ECLAT。

智能优化算法按灵感来源：

| 算法 | 抄自 | 要点 |
|---|---|---|
| 人工神经网络 ANN | 人脑神经元 | 以有向图为拓扑结构的动态系统 |
| 遗传算法 | 达尔文优胜劣汰、适者生存与遗传变异 | 迭代中保持已有结构，同时寻找更好的结构 |
| 模拟退火 SA | 金属退火 | **加温、等温、冷却**三阶段，求全局最优 |
| 禁忌搜索 TS | 人的记忆 | **Tabu 表**记已走过的路，避免绕回局部最优 |
| 蚁群算法 | 蚂蚁**信息素**正反馈 | 路径表示可行解，短路径信息素浓、跟随蚂蚁越来越多 |
| 粒子群 PSO | 鸟群觅食 | 每个解是一只粒子，追**个体极值 pBest** 与**全局极值 gBest** |

## 速记

- 五特性：有穷、确定、可行、**输入零个或多个**、**输出一个或多个**；确定性＝同输入同输出，概率算法破了这条
- 档位链 O(1)<O(log₂n)<O(n)<O(nlog₂n)<O(n²)<O(n³)<O(2ⁿ)<O(n!)；O 上界、Ω 下界、Θ 紧界；内层从 i 起仍是 O(n²)；多项式阶 vs 指数阶
- 递归两要素：边界条件（出口）＋递归模式（体）；aT(n/b)+f(n) 比 n^(log_b a) 与 f(n)，相等乘 log₂n；8T(n/2)+n²＝Θ(n³)，X·T(n/4)+n² 要更快则 X<64、最大 63
- 链：分治→动规（重叠，记表）→贪心（每步定死）→回溯（DFS 试错回退）→分支限界（BFS／最小耗费优先，估界砍支，活结点只扩展一次，FIFO 式／优先队列式）
- 分水岭：分治／动规看重叠；动规／贪心看**贪心选择性质**；回溯／分支限界看**所有解 vs 最优解**＋**DFS vs BFS／最小耗费优先**
- 数字：0-1 背包动规 **Θ(nW)**；部分背包贪心 **Θ(nlog₂n)**（瓶颈排序）；回溯／分支限界最坏 O(2ⁿ)、O(n!)；**求最大估上界、求最小估下界**
- 概率：数值概率近似／蒙特卡洛精确解可能错／拉斯维加斯不给错解／舍伍德总正确；近似：多项式阶＋误差界
- 数据挖掘：**分类有监督、聚类无监督**，关联规则先频繁模式后规则；智能优化：ANN、遗传、SA 加温—等温—冷却、TS 的 Tabu 表、蚁群信息素、PSO 的 pBest／gBest
