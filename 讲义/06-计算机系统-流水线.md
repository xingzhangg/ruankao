## 第 0 层 · 定位

**这一课回答**：一条指令的取指、译码、执行几个阶段能不能并起来跑，并起来快多少（流水线周期、吞吐率、加速比、效率）。

**前后关系**：计算机系统板块收尾课；是 02「三步」的展开，也是 03「RISC 便于流水线」的解释。

**分值与去向**：板块 5–7 分，本课 1–2 分，近 5 年仅确认 2023上一次；下午不考。一条源公式加派生式，阶段B刷几组即可。

## 第 1 层 · 理解

### 一句话

> 流水线就是"**洗衣店三台机器同时开工**"——别让 CPU 的取指部件、译码部件、执行部件在同一时刻只有一个在干活，剩下的干瞪眼。

### 痛点：三个直觉全是错的

想象一家洗衣店，一件衣服要经过 **洗 → 烘 → 叠** 三道工序，各占用不同设备，各耗时 1 小时。

- **不用流水线**（串行）：衣服 A 洗完烘、烘完叠，全部搞定要 3 小时，才轮到衣服 B 开始洗。**10 件衣服要 30 小时**，而任何时刻都有 2 台机器闲着。
- **用流水线**（重叠）：衣服 A 进"烘"的时候，洗衣机已经空出来了，衣服 B 立刻开始"洗"。**三个工位同时都在忙**，各自处理不同的衣服。

CPU 完全同构：一条指令要经过 **取指(IF) → 译码(ID) → 执行(EX) → 写回(WB)**，每个阶段占用**不同的部件**。既然部件不同，凭什么要等？

程序员容易踩的三个直觉坑：

- **坑一**："流水线能让单条指令跑得更快。" → **错**。单条指令该走 4 段还是走 4 段，一点没快（加上流水寄存器开销甚至更慢）。快的是**一批指令的总时间 / 吞吐率**。
- **坑二**："段数 k 分得越多越好，加速比无限涨。" → **错**。段数越多控制越复杂、指令相关（冒险）越难处理，还有寄存器开销。
- **坑三**："各段耗时不一样时，也套 (n+k−1)×Δt。" → **错**。这条公式的前提是**各段等长**；不等长时节拍要迁就最慢那一段（木桶效应），且第一条指令的耗时是"各段之和"不是 k×Δt。

### 一条主线

```
一条指令要经过 k 个阶段（IF 取指 → ID 译码 → EX 执行 → WB 写回），
每个阶段占用【不同的部件】
   ↓
串行执行：指令1 走完全部 k 段，指令2 才开始
        → 任一时刻只有 1/k 的部件在干活，其余全闲
   ↓ 既然用的是不同部件，为什么要互相等？
【流水线】= 让不同指令的不同阶段【在时间上重叠】
        指令1 在 EX 时，指令2 在 ID，指令3 在 IF —— 三个部件同时忙
   ↓ 划重点：单条指令一点没变快，变快的是【一批指令的总时间】
   ↓
那这一批到底要多久？画时空图数一数：
        第 1 条指令必须从头走到尾            → k×Δt
        它走完后流水线【满载】，此后每隔 Δt 吐出一条，还剩 n−1 条 → (n−1)×Δt
   ↓
      ★ T = k×Δt + (n−1)×Δt = (n+k−1)×Δt   ← 本课唯一的【源公式】
   ↓
剩下四个指标，全是 T 的派生物，不必单独背：
      串行基准 T0 = n×k×Δt              （每条都老实走完 k 段，作对比用）
      加速比   S  = T0/T = nk/(n+k−1)   （流水线比串行快几倍）
      吞吐率   TP = n/T                 （单位时间流出几条；n→∞ 时 → 1/Δt = 理论上限）
      效率     E  = (n×k×Δt)/(k×T) = n/(n+k−1)
                                        （时空图里"被占用的格子 ÷ 总格子"= 利用率）
   ↓ 白送一条互查关系：S = k × E    （算完两边一对，错了立刻发现）
   ↓
但上面全部建立在【各段等长】这个假设上。
现实里"执行"段就是比"取指"段慢 —— 假设塌了怎么办？
   ↓
流水线是一条【节拍统一】的传送带：所有工位共用一个节拍，
只能迁就最慢的那一个 —— 这就是【木桶效应】
      → 流水线周期 Δt = max(各段耗时)
      → 但第 1 条指令是头一个进来的，没人跟它抢，做完一段【立刻】进下一段，
        所以它的耗时是【各段之和】t1+t2+…+tk，而不是 k×Δt
   ↓
      ★ T = (t1+t2+…+tk) + (n−1)×Δt,   其中 Δt = max(ti)
   ↓
   注意：各段等长时 t1+…+tk = k×Δt，这条式子就退化成 (n+k−1)×Δt
        —— 两条公式【本来就是同一条】，只需记这条通用式即可。
```

**一句话收束**：**"重叠执行" 推出 T，T 推出 S / TP / E，取消等长假设再把 T 改写一次**。全课就这一条链，没有第二块内容。

## 第 2 层 · 考点：考试怎么问

### 考点① 等长流水线的性能指标计算（近 5 年确认命中 1 次：【真题·2023上】，**非每年必考**）

**题目长相**（以下题面为**【模拟】**按考点改写，**非真题原文**）："某指令流水线分为取指、译码、执行、写回 4 段，各段时间均为 1 个时钟周期，连续执行 100 条指令，则流水线的**执行时间 / 加速比 / 吞吐率 / 效率**是（ ）"（四个指标常挑 1–2 个考，或做成两空题）。

**先把时空图看懂**（k=3 段 IF/ID/EX，各段等长，3 条指令）：

```
        t1   t2   t3   t4   t5
指令1:  IF   ID   EX
指令2:       IF   ID   EX
指令3:            IF   ID   EX
```
第 1 条指令走完 3 个阶段用了 3 个时间单位；**从 t2 起每过 1 个单位就流出一条新指令**——这就是"满载"后的节奏。总长 t1~t5 = 5 = (3+3−1) ✓ 与公式对上。

**怎么解**——符号：**k** = 段数，**Δt** = 每段耗时，**n** = 指令条数。

| 指标 | 公式 | 怎么来的 |
|---|---|---|
| 流水线执行时间 **T** | **(n+k−1)×Δt** | 第 1 条走满 k 段，其余 n−1 条各补 1 个 Δt |
| 串行执行时间 **T0** | **n×k×Δt** | 每条都独立走完 k 段（对比基准） |
| 加速比 **S** | **T0/T = nk/(n+k−1)** | 快了几倍 |
| 吞吐率 **TP** | **n/T**；n→∞ 时 **TPmax = 1/Δt** | 单位时间流出几条 |
| 效率 **E** | **(n×k×Δt)/(k×T) = n/(n+k−1)** | 时空图：有效格子 ÷ 总格子(k×T) |

> **互查关系 S = k×E**：算完 S 和 E，用它对一下，能立刻抓出计算失误。
> 顺带（由公式直接取极限可得）：n→∞ 时 **S → k、E → 1**——所以**加速比的理论上限就是段数 k**，永远达不到。

**陷阱**：
- ⚠️ **T 里忘了 −1**，写成 (n+k)×Δt。定位办法：n=1 时 T 必须等于 k×Δt，代进去检验就知道该不该减 1。
- ⚠️ **T 与 T0 搞反**，把加速比算成 T/T0（得到小于 1 的数）。**加速比恒 ≤ k；只要 n>1 且 k>1 就必然 >1**（n=1 时退化成 S=1，考题不会这么出）——结果不落在 (1, k] 区间就是算反了。
- ⚠️ **Δt 不是 1 时忘了乘**：题目给"每段 2ns"就必须乘 2，公式里 Δt 不能默认省掉。
- ⚠️ 把**效率 E 当成百分比忘换算**，或与吞吐率混淆——E 是无量纲利用率（0~1），TP 带单位（条/周期、条/秒）。

### 考点② 不等长流水线：木桶效应（重讲专项）

**题目长相**："某流水线分为取指(2)、译码(1)、执行(3)、写回(1) 四段（单位：时钟周期），连续执行 10 条指令，流水线执行时间是（ ）个时钟周期"，或"该流水线的**流水线周期**是（ ）"。

**怎么解**——三步，一步都别跳：

```
第1步：流水线周期 Δt = max(各段耗时)      ← 木桶效应：最慢的工位卡住整条线
第2步：第 1 条指令总耗时 = t1+t2+…+tk    ← 它没人抢，做完一段立刻进下一段
第3步：T = (t1+t2+…+tk) + (n−1)×Δt

配套：串行基准 T0 = n×(t1+t2+…+tk)      ← 要算加速比时用这个，不是 n×k×Δt
```

**为什么第 1 条按"各段之和"、后面却按 max**：第 1 条进来时整条线是空的，它一路畅通；从第 2 条起流水线满载，每个工位交接都要等最慢那一站腾出来，所以后续**每条只能隔 Δt=max 出一条**。

**陷阱**：
- ⚠️ **直接套 (n+k−1)×Δt**：把 4 段全按 max=3 算，第 1 条会被算成 12 而不是 7，**结果偏大**。等长公式只在等长时成立。
- ⚠️ **Δt 取成平均值或求和**：周期就是 **max**，不是平均、不是总和。
- ⚠️ **算 T0 时仍用 n×k×Δt**：不等长时串行基准是 **n×(各段之和)**。以本课算例为例，n=20、各段 1+1+2+1=5 → T0=100；若误用 n×k×Δt = 20×4×2 = 160 就错了。

### 考点③ 流水线概念辨析（纯文字题）

**题目长相**："关于流水线技术，下列说法**错误**的是（ ）"，四个选项混着放概念断言。

**怎么解**——四条判据，逐条对照：

| 断言 | 对错 | 理由 |
|---|---|---|
| 流水线提高**吞吐率**，但**不缩短单条指令**的执行时间 | ✅ 对 | 单条仍走 k 段，快的是整批 |
| 流水线周期由**耗时最长**的功能段决定 | ✅ 对 | 木桶效应 |
| 段数越多，加速比**一定越大、没有任何代价** | ❌ 错 | 控制复杂度↑、指令相关（冒险）更难处理、寄存器开销；且 S ≤ k 是上限不是保证 |
| 流水线靠**多条指令的不同阶段在时间上重叠**来提效 | ✅ 对 | 这就是定义 |

**陷阱**：⚠️ 凡是带"**一定**""**没有任何代价**""**完全**"这类绝对化措辞的选项，在本考点里**基本就是错项**。

## 第 3 层 · 完整算例

### 算例一：各段等长——五个指标一次算齐

> 某流水线分为 IF/ID/EX/WB 共 **4 段**，各段耗时相同、均为 **1 个时钟周期**，连续执行 **100 条**指令。求 T、T0、S、TP、E。

```
已知：k = 4，Δt = 1，n = 100

第1步 流水线时间 T  = (n+k−1)×Δt = (100+4−1)×1 = 103 个时钟周期
                      （第1条走满 4 段 + 其余 99 条各补 1 个周期 = 4+99 = 103 ✓）
第2步 串行基准 T0   = n×k×Δt     = 100×4×1     = 400 个时钟周期
第3步 加速比 S      = T0/T       = 400/103     ≈ 3.88
第4步 吞吐率 TP     = n/T        = 100/103     ≈ 0.97 条/周期
                      （上限 TPmax = 1/Δt = 1 条/周期，0.97 已很接近）
第5步 效率 E        = n/(n+k−1)  = 100/103     ≈ 0.97

验算①：S = k×E = 4 × 0.97 ≈ 3.88 ✓ 与第3步一致
验算②：S = 3.88 落在 (1, k=4] 区间内 ✓ 合理
```

### 算例二：各段不等长——木桶效应

> 取指 1、译码 1、执行 2、写回 1（单位：时钟周期），共执行 **20 条**指令，求 T。

```
第1步 流水线周期 Δt = max(1, 1, 2, 1) = 2
                      （"执行"段最慢，卡住整条线的出货节奏）
第2步 第 1 条指令总耗时 = 1+1+2+1 = 5
                      （它是头一个，做完一段立刻进下一段，不必凑 Δt）
第3步 T = 5 + (20−1)×2 = 5 + 38 = 43 个时钟周期

对比：不用流水线 T0 = 20×(1+1+2+1) = 20×5 = 100 个时钟周期
      加速比 S = 100/43 ≈ 2.33

反面验算：若错误地套等长公式 (n+k−1)×Δt = (20+4−1)×2 = 46 ≠ 43，
          差的 3 正好是第 1 条被多算的部分（4×2=8 vs 实际 5）✓ 说明必须分开算
```

## 第 4 层 · 速记

> **★ T = (n+k−1)×Δt** —— 先走完第一条（k 段），后面每条只补 1 个 Δt
> T0 = n×k×Δt（串行基准）｜**S = T0/T = nk/(n+k−1)**｜**E = n/(n+k−1)**｜**TP = n/T**
> **S = k × E**（加速比 = 段数 × 效率，算完互相验证）
> **n→∞ 时：TPmax = 1/Δt，S → k，E → 1**（加速比上限就是段数）
> **★ 不等长：Δt 取最长段（木桶效应），第一条按"各段之和"算**
> 　　T = (t1+…+tk) + (n−1)×Δt；不等长时 T0 = n×(各段之和)
> 　　等长是它的特例（各段之和 = k×Δt），**只记这一条通用式也行**
> 概念判据：**提高吞吐率≠缩短单条指令**；周期由**最长段**定；**段数多不是没代价**
> 见到"一定""没有任何代价"这类绝对化措辞，优先怀疑是错项

## 考题回顾

> 以下为 2026-08-13 不等长流水线周期专项重讲后的追加重练题（已讲评）。

**R1.【模拟】** 某流水线分为取指(1)、译码(3)、执行(2)、写回(1) 四段（单位：时钟周期），连续执行 15 条指令，流水线执行时间是多少个时钟周期？
**解**：**49**。
Δt = max(1,3,2,1) = **3**（译码段最慢）；第 1 条指令总耗时 = 1+3+2+1 = **7**；
T = 7 + (15−1)×3 = 7 + 42 = **49**。
（⚠️ 若误套等长公式 (15+4−1)×3 = 54，就是把第 1 条按 4×3=12 算了，多算 5。）

## 自测练习

1. 【模拟】某流水线分为 5 段，各段耗时相同均为 1 个时钟周期，连续执行 50 条指令，流水线执行时间是多少个时钟周期？
2. 【模拟】接上题，加速比 S 约为多少（保留两位小数）？
3. 【模拟】某流水线分为取指(2)、译码(1)、执行(3)、写回(1) 四段（单位：时钟周期），连续执行 10 条指令，流水线执行时间是多少个时钟周期？
4. 【模拟】关于流水线技术，下列说法**错误**的是（ ）
   A. 流水线可以提高指令的吞吐率，但不能缩短单条指令的执行时间
   B. 流水线的周期由各功能段中耗时最长的一段决定
   C. 流水线段数越多，加速比一定越大，没有任何代价
   D. 流水线是通过让多条指令的不同阶段在时间上重叠执行来提升整体效率的

### 参考答案

1. **54**。T = (n+k−1)×Δt = (50+5−1)×1 = **54**。
2. **4.63**。T0 = n×k×Δt = 50×5×1 = 250；S = T0/T = 250/54 ≈ **4.63**。
   （验算：E = n/(n+k−1) = 50/54 ≈ 0.926，S = k×E = 5×0.926 ≈ 4.63 ✓；且 4.63 < k=5 ✓）
3. **34**。Δt = max(2,1,3,1) = 3；第 1 条指令总耗时 = 2+1+3+1 = 7；T = 7 + (10−1)×3 = 7+27 = **34**。
4. **C**。C 错在"**没有任何代价**"——段数越多会带来控制复杂度上升、指令相关（冒险）更难处理等代价，且加速比上限是 k、并非无限增长。A/B/D 均为正确表述。
