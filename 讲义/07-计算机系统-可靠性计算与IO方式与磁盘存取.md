# 07 · 计算机系统：磁盘存取、I/O 方式与系统可靠性

## 定位

计算机系统板块最后一课，走出 CPU 看外设、总线和整机。全课跟着一台文件服务器的一次 `read()`：数据在盘上要等多久（第一节）、多个请求怎么排队（第二节）、CPU 怎么把它弄进内存（第三节）、走哪条线（第四节）、整机靠不靠得住（第五节）。一、二、五节要算，三、四节是概念。

## 一、磁盘存取时间（计算）

读一个扇区要花多久。

**结构术语。** 盘片两面各一个**盘面**；盘面上的同心圆叫**磁道**（track），越外越长；磁道切成小弧叫**扇区**（sector），数据存在扇区里。每个盘面一个**磁头**，全部装在同一根机械臂上**一起横向移动**，半径相同的磁道摞在一起叫**柱面**（cylinder）。柱面号与磁道号在计算上是一回事。

读一个扇区必须经过三段：

1. **寻道时间**：机械臂把磁头挪到目标磁道，一般直接给"平均寻道时间"。
2. **旋转延迟**（又叫等待时间、转动延迟）：等目标扇区转到磁头下。
3. **传输时间**：盘继续转，扇区从磁头下划过被读出。

**算例：** 转速 7200 转/分，平均寻道 8ms，每磁道 12KB，读 4KB。

1. 转一圈 = 60 秒 ÷ 7200 = 1/120 秒 = **8.33ms**
2. 旋转延迟：最好等 0，最差等整整一圈，请求位置随机，平均半圈 = 8.33 ÷ 2 = **4.17ms**
3. 传输：4KB 占磁道 4/12 = 1/3，只需转 1/3 圈 = 8.33 × 1/3 = **2.78ms**
4. 存取时间 = 8 + 4.17 + 2.78 = **14.94ms ≈ 15ms**

```
转一圈时间   = 60 / n 秒            （n = 转速，转/分；×1000 换成 ms）
平均旋转延迟 = 转一圈 ÷ 2 = 30 / n 秒  （"最大旋转延迟"才是整圈）
传输时间     = 转一圈时间 × (数据量 ÷ 每磁道容量)
存取时间     = 寻道 + 旋转延迟 + 传输
```

**第二例：** 6000 转/分，平均寻道 8ms，每磁道 10KB，读 2KB。

```
转一圈 = 60/6000 = 10ms   旋转延迟 = 5ms   传输 = 10 × 2/10 = 2ms
存取时间 = 8 + 5 + 2 = 15ms
```

**口径。** 原话｜"**存取时间 = 寻道时间 + 等待时间**"——教材把"等扇区转来 + 把数据转过去"合称等待时间，所以只有两段。只给转速时按两段算；给了每磁道容量和数据块大小，就单列传输时间加上。培训资料在这句后加了括号"（平均定位时间+转动延迟）"，其中"平均定位时间"就是寻道，塞进"等待时间"会把寻道算两遍，按"寻道 + 转动延迟（+ 传输）"记。

## 二、磁盘调度（计算）

一堆请求落在不同磁道上，三段时间里寻道最慢，服务顺序决定总耗时。调度算法调的是**顺序**，不是单次时间。

### 移臂调度四种算法

**算例：** 磁道 0–49，磁头在 **20**，刚从 15 号过来（正朝大号走），队列按到达先后：**30、8、45、12、38**。

| 算法 | 规则 | 序列 | 移动道数 |
|---|---|---|---|
| **FCFS** 先来先服务 | 按到达顺序；最公平，来回横跳 | 20→30→8→45→12→38 | 10+22+37+33+26 = **128** |
| **SSTF** 最短寻道时间优先 | 每次挑离当前磁头最近的；代价是**饥饿**，近处请求不断来，远处的永远轮不上 | 20→12→8→30→38→45 | 8+4+22+8+7 = **49** |
| **SCAN** 扫描（电梯） | 沿当前方向走到头，顺路服务，到头掉头；无人饿死，最坏等一个来回 | 20→30→38→45→(49)→12→8 | (49−20)+(49−8) = **70** |
| **CSCAN** 单向扫描 | 只朝一个方向服务，到头后不服务地快速退回另一端再重来；解决 SCAN 中间磁道被照顾两次、两端吃亏 | 20→30→38→45→(49)→(0)→8→12 | 29+49+12 = **90** |

- CSCAN 总道数最多，换来各磁道等待时间最均匀；空返是**满程**，从边界回另一端全算。
- SCAN/CSCAN 的掉头点：有的教材算到**磁盘物理边界**（本例 49），有的只算到**最远请求**（本例 45，这种变体叫 **LOOK**，总道数 25+37 = 62）。给出"磁盘共 N 个磁道"时按走到边界算。
- 本例 SSTF 最省只针对这一批请求，它省的是道数，赔的是公平性。

### 移臂调度 + 旋转调度

三层顺序，不能颠倒：

1. **移臂调度**：按**柱面号**决定机械臂往哪挪（用上面的算法）。
2. **旋转调度**：同一柱面的多个请求不用再挪臂，按**扇区号**先后读。
3. 扇区号相同，再按**磁头号**从小到大。

**算例：** 移动臂在 21 号柱面，最短移臂调度。

| 请求 | ① | ② | ③ | ④ | ⑤ | ⑥ | ⑦ | ⑧ | ⑨ |
|---|---|---|---|---|---|---|---|---|---|
| 柱面号 | 17 | 23 | 23 | 32 | 17 | 32 | 17 | 23 | 38 |
| 磁头号 | 8 | 6 | 9 | 10 | 8 | 3 | 7 | 10 | 10 |
| 扇区号 | 9 | 3 | 6 | 5 | 4 | 10 | 9 | 4 | 8 |

```
移臂：21 → 23（距 2）→ 17（距 6，比 32 的距 9 近）→ 32（距 15）→ 38
23 柱面按扇区：②(3) ⑧(4) ③(6)
17 柱面按扇区：⑤(4)，⑦与①扇区同为 9 → 按磁头号 ⑦(7) ①(8)
32 柱面按扇区：④(5) ⑥(10)
响应序列：②⑧③⑤⑦①④⑥⑨
```

### 记录存放顺序优化（单缓冲区）

**单缓冲区**：内存只有一块中转区，磁盘先把记录读进它，CPU 再取走处理，**读和处理不能同时进行**。

**算例：** 一个磁道 11 个物理块，每块 1 条逻辑记录 R0…R10；旋转周期 33ms；磁头在 R0 开头；每条记录处理 3ms。

1. 每块划过磁头 = 33 ÷ 11 = **3ms**
2. 顺序存放（块 1..11 依次放 R0..R10）：读 R0 占 0–3ms，处理占 3–6ms，这期间 R1 已溜过磁头，要再等 30ms 转回来
3. 每条节奏 = 读 3 + 处理 3 + 白等 30 = **36ms**；最后一条读完处理完即结束：10 × 36 + 3 + 3 = **366ms**
4. 优化分布：处理一条正好一个块的时间，就让下一条**隔一个块**存放：`R0 R6 R1 R7 R2 R8 R3 R9 R4 R10 R5`，处理完 R0 磁头刚好到 R1，每条 3 + 3 = 6ms，共 11 × 6 = **66ms**

盘和算法都没换，只换了摆放顺序。

## 三、编址方法与 I/O 方式（概念）

外设通过**接口**（I/O 端口，控制器上放命令、状态、数据的一组寄存器）与 CPU 通信。

### 编址

| 方式 | 是什么 | 优点 | 缺点 |
|---|---|---|---|
| **独立编址** | 内存地址与接口地址是**两个独立的地址空间**，访问接口用专门的 I/O 指令（如 `IN`/`OUT`） | 一眼分清哪句动内存、哪句动外设 | **专用于接口的指令太少、功能太弱** |
| **统一编址**（内存映射 I/O） | 内存与接口**共用一个地址空间**，接口寄存器当作内存单元 | 原则上**所有访存指令都能操作接口**，指令上不再区分 | **地址空间被切走一块，内存地址不连续** |

### 三种 I/O 方式：CPU 越管越少

| 方式 | 关键词 | CPU 做什么 |
|---|---|---|
| **程序控制（查询）** | CPU 循环读状态寄存器 `while (!ready);`，就绪再搬一个数据 | 全程占用，**效率极低** |
| **无条件传送** | 假定外设永远就绪，连状态都不查；用于按键、指示灯等简单设备 | 执行指令传送，与程序查询**并列两种方式** |
| **程序中断** | 设备就绪发**中断**（电信号，逼 CPU 暂停当前指令流去处理），CPU 平时干别的 | **每传一个数据仍要 CPU 介入一次**，读 4KB 要中断几千次 |
| **DMA**（直接主存存取） | **DMA 控制器**在**主存和外设之间建立直接数据通路**；磁盘是典型对象 | **只做初始化**（主存起始地址、字节数、方向），整块搬运不经过 CPU，**搬完中断 CPU 一次** |

```
程序查询 < 程序中断 < DMA        CPU 参与程度递减，效率递增
```

**中断术语：**
- **中断响应时间**：从设备发出中断请求到 CPU 开始执行中断处理程序
- **中断处理时间**：从处理开始到处理结束
- **中断向量**：存各中断源对应处理程序入口地址的表，CPU 据此跳转
- **断点**＝被打断的指令位置；**现场**＝寄存器里的值；多级中断嵌套用**堆栈**保存断点和现场，后进先出正好层层返回

```
中断请求 → 中断响应 →（关中断）→ 保存断点 → 识别中断源 → 保存现场 →（开中断）
→ 中断服务程序 →（关中断）→ 恢复现场 →（开中断）→ 中断返回
```

**易混对**

DMA 与 CPU 的关系
- 判据｜只有中间整块搬运不经过 CPU、CPU 不执行传送指令；传送前 CPU 要初始化控制器，传送后要响应一次中断
- 例子｜读一个 4KB 块：DMA 下 CPU 初始化一次、收中断一次；换成中断方式，每个数据都要 CPU 执行指令搬一次

DMA 响应时机 vs 中断响应时机
- 判据｜**DMA 在一个总线周期结束后响应，中断在一条指令执行结束时响应**。DMA 只要总线使用权，一个总线周期（总线上完成一次数据传输的时间，一条指令通常占好几个）用完就能让出；中断要打断程序流，必须等指令做完，否则寄存器状态残缺
- 例子｜一条指令执行到第二个总线周期时来了请求：DMA 请求在这个总线周期结束就响应，中断请求要等整条指令结束

其余认名即可：DMA 之上还有**通道**和 **I/O 处理机（IOP）**，把 I/O 控制进一步交给专门部件，方向仍是 CPU 越管越少。

## 四、总线（概念）

原话｜总线是"**计算机设备和设备之间传输信息的公共数据通道**"。所有设备**共享**，同一时刻只能有一对设备在用，所以 DMA 搬数据时 CPU 访存会被挤一下。

| 类别 | 级别 / 用途 | 代表 |
|---|---|---|
| **内部总线** | 芯片级，芯片与处理器之间 | — |
| **系统总线** | 板级，连接机器内各部件；分**数据总线**（根数＝并行传的位数）、**地址总线**（位数决定可管理的内存空间，32 根→2³² = 4GB）、**控制总线**（传控制命令） | ISA、EISA、PCI |
| **外部总线** | 设备级，微机与外部设备之间 | RS232（串行）、SCSI（并行）、USB（通用串行总线，即插即用、支持热插拔：不用装驱动、不用关机就能拔） |

**易混对**

并行总线 vs 串行总线
- 判据｜并行多根线同时传，适合**近距离**高速传输，线拉长后线间干扰（串扰）限制速率；串行一根线一位位传，无串扰，**易提高时钟频率**，适合**长距离**
- 例子｜USB、SATA 走串行；把距离从机箱内拉到几米外，并行的串扰就压不住了

单工 / 半双工 / 全双工
- 判据｜单工只能一个方向；半双工两个方向都能传但**不能同时**；全双工同时双向
- 例子｜对讲机轮流说话是半双工；改成两人能同时说就是全双工

其余认名即可：**单总线结构**在一个总线上适应不同种类的设备，设计复杂导致性能降低。

## 五、系统可靠性（计算）

**可靠度 R**＝部件在规定时间内正常工作的概率，0～1。

### 串联与并联

**串联**：所有部件都得好系统才好，独立事件同时发生，概率相乘。

```
串联：R = R1 × R2 × … × Rn        一个设备不可靠，整个系统崩溃
0.9 × 0.9 = 0.81                   不可靠度从 10% 涨到 19%
0.9 × 0.8 × 0.95 = 0.684           比最弱的 0.8 还低，越乘越小，部件越多越不可靠
```

**并联**（冗余备份）：至少一个好即可。正面要枚举，反着算：崩溃当且仅当**全坏**，全坏概率 (1−R1)(1−R2)…，1 减掉即可。

```
并联：R = 1 − (1−R1)(1−R2) … (1−Rn)   所有设备都不可靠，整个系统才崩溃
1 − 0.1 × 0.1 = 0.99                   比单个 0.9 还高：冗余提高可靠性的数学依据
```

### 混合结构：先内后外

**算例：** 网卡（0.9）→ 双电源并联（各 0.8）→ 磁盘（x），要求整机 ≥ 0.85。

1. 内层并联：1 − (1−0.8)(1−0.8) = 1 − 0.04 = **0.96**　（0.96 > 0.8 ✓）
2. 当成一个部件与网卡串联：0.9 × 0.96 = **0.864**　（0.864 < 0.9 ✓）
3. 0.864x ≥ 0.85 → x ≥ 0.85/0.864 ≈ **0.9838**，写成式子即 `0.85 / (0.9 × [1−(1−0.8)²])`

**字母形式：** A 与"B、C 并联"串联，均为 R。

```
内层 1−(1−R)² = 2R−R²
外层 R(2R−R²) = 2R²−R³      （要展开成多项式形状）
```

**自检：** 串联结果 < 最小分量；并联结果 > 最大分量；任何可靠度都在 0 与 1 之间。

### N 模冗余

由 **N 个（N = 2n+1，奇数）相同子系统和一个表决器**组成，表决器输出**占多数**的结果，所以 **n+1 个或以上**正常系统就正常——比并联严（只要 1 个），比串联松（要全好）。

```
3 模（N=3, n=1，至少 2 个好）：R系统 = 3R² − 2R³
R = 0.9：3×0.81 − 2×0.729 = 0.972    介于单模 0.9 与两个 0.9 并联的 0.99 之间
```

### 可靠性指标

| 指标 | 含义 | 公式 |
|---|---|---|
| **MTTF** 平均无故障时间 | 平均连续跑多久坏一次 | 1 / 失效率（单位时间内坏掉的比例） |
| **MTTR** 平均故障修复时间 | 坏一次平均修多久 | 1 / 修复率（单位时间内能修好的比例） |
| **MTBF** 平均故障间隔时间 | 两次故障间隔＝跑的时间 + 修的时间 | MTTF + MTTR |
| **系统可用性** | 任意时刻正在正常服务的比例 | MTTF / (MTTF + MTTR) × 100% |

```
MTTF = 1000h，MTTR = 10h → MTBF = 1010h，可用性 = 1000/1010 = 99.01%
```

可用性 ≠ 可靠度：三天两头坏但五分钟修好的机器，可用性高、可靠度低。

## 速记

- 磁盘：`存取 = 寻道 + 旋转延迟 + 传输`；转一圈 **60/n 秒**（×1000 成 ms），平均旋转延迟**半圈**、最大整圈，传输 = 转一圈 × 数据量/磁道容量
- 调度：先**移臂**（柱面）后**旋转**（扇区，同则磁头号）；FCFS 最慢、SSTF 会**饿死**、SCAN 电梯掉头、CSCAN 单向服务满程空返
- 单缓冲顺序存放每条多等一圈；**优化分布**＝按处理时间隔块摆放
- 编址：独立编址**接口指令少功能弱**，统一编址**内存地址不连续**
- I/O：**查询 < 中断 < DMA**；DMA 只初始化、传完中断一次；**DMA 总线周期结束响应，中断指令结束响应**
- 总线：内部/系统（数据·地址·控制）/外部；32 位地址→4GB；并行近距离、串行长距离；半双工＝双向不同时
- 可靠性：串联连乘、并联 `1−∏(1−Ri)`、混合**先内后外**、N 模需 **n+1 个**正常，3 模 `3R²−2R³`
- 指标：`MTBF = MTTF + MTTR`，`可用性 = MTTF/(MTTF+MTTR)`
