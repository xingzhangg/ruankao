### 一、report.doc 到底是什么：文件与文件系统

**文件**的标准定义：具有符号名的、在逻辑上具有完整意义的一组相关信息项的集合。拆开看三个词——"符号名"就是 `report.doc` 这个名字；**信息项**是构成文件内容的基本单位，可以是一个字符，也可以是一条记录，记录可以等长也可以不等长；"逻辑上完整"是说它对用户是一个整体，哪怕散在几十个盘块上。

一个文件 = **文件体 + 文件说明**。文件体是真实内容；文件说明是操作系统为了管它而额外记的信息：文件名、文件内部标识、类型、存储地址、长度、访问权限、建立时间、访问时间。用程序员的话说，**文件体是数据，文件说明是元数据**——`ls -l` 那一行除了文件名之外全是文件说明。

裸磁盘对外只提供两个操作：**读第 N 块、写第 N 块**。程序直接面对块号会撞三堵墙：代码里得硬编码"我的简历在第 3721～3745 块"，一挪位置全废；两个程序都以为第 3721 块归自己，后写的把前一个覆盖掉，没人拦；想说"这份数据只有我能改"，在块号这一层根本无从说起。

**文件管理系统**（简称文件系统）就是横在中间的那层软件——操作系统中实现文件统一管理的一组软件和相关数据的集合，专门负责管理和存取文件信息。功能正好一一对上：**按名存取**、统一的用户接口、并发访问和控制、安全性控制、优化性能、差错恢复。

文件的四种分类，选择题只认关键词：按性质和用途分**系统文件、库文件、用户文件**；按保存期限分**临时文件、档案文件、永久文件**；按保护方式分**只读、读/写、可执行、不保护文件**；UNIX 分**普通文件、目录文件、设备文件（特殊文件）**——注意 UNIX 把目录和设备也当文件管。

### 二、名字挂在哪：文件控制块与目录的三级演进

操作系统给每个文件单独记的那份文件说明，有个正式名字叫**文件控制块 FCB**（File Control Block）。

它装三类信息：**基本信息类**（文件名、文件的物理地址、文件长度、文件块数）、**存取控制信息类**（存取权限；UNIX 把用户分成文件主、同组用户、一般用户三类，各有一套 RWX）、**使用信息类**（建立日期、最后修改日期、最后访问日期、当前打开该文件的进程数、文件上的等待队列）。

**FCB 的有序集合就叫文件目录**——"目录"不是别的，就是一摞 FCB 排在一起；它自己也存在磁盘上，本身也是个文件。

目录结构是被撞名逼出来的三级演进：**一级目录**全盘只有一张表，两个人都想把文件叫 report.doc 就没辙；**二级目录**给每个用户一张用户文件目录、上面再加一张主文件目录，用户之间能重名了，可一个用户自己的几百个文件仍平铺在一层；**树形目录**允许目录里再套目录、一直套下去，于是 `/usr/work/report.doc` 与 `/home/zhang/report.doc` 同名共存。代价是必须回答"怎么指认树上的一个点"——这就是路径。

**根目录**是树的起点，Linux 记作 `/`（Windows 记作 `\`）。**绝对路径**从根目录写起，不管你在哪，指向永远唯一。**当前工作目录**是进程"此刻站在哪个目录里"（shell 里 `pwd` 打出来的那个），**相对路径**就是从当前工作目录出发写的路径，`.` 表示当前目录、`..` 表示上一级（父）目录。**全文件名 = 绝对路径 + 文件名**；要特别注意，**绝对路径和相对路径都不带最后那个文件名**，只是单纯的路径序列。

先别往下看：当前工作目录是 `/usr/work`，要访问 `c.txt`，相对路径写成 `temp/c.txt` 对不对？

**不对。** `temp/c.txt` 的意思是"当前目录下的子目录 temp"，可 `temp` 和 `work` 是**并列的兄弟目录**，必须先 `..` 退回 `/usr`。三步法：① 把目标的绝对路径写出来；② 和当前目录逐层比，找**最近的共同祖先**；③ 从当前目录退到共同祖先要几级就写几个 `..`，再照抄祖先往下到目标的那一段。

当前目录 `/usr/work` 时，四个目标各自的相对路径：

| 目标（绝对路径） | 共同祖先 | 退几级 | 相对路径 |
|---|---|---|---|
| `/usr/work/report.doc` | `/usr/work`（就是当前目录） | 0 | `report.doc`（写 `./report.doc` 也对） |
| `/usr/work/data/b.txt` | `/usr/work` | 0 | `data/b.txt` |
| `/usr/temp/c.txt` | `/usr` | 1 | `../temp/c.txt` |
| `/home/zhang/report.doc` | `/`（根） | 2 | `../../home/zhang/report.doc` |

**验算习惯**：把写出的相对路径从当前目录一步步走一遍，每个 `..` 上跳一层、每个名字下进一层，最后必须正好落在目标上：`/usr/work` --`..`--> `/usr` --`temp`--> `/usr/temp` --`c.txt`--> ✔。

顺带认两个名词，都是给同一个文件挂第二个名字：**硬链接**是另一个目录项指向**同一份文件说明**，两个名字地位平等，删掉任一个文件都还在，直到最后一个名字也被删（`ln`）；**软链接**（符号链接）是个特殊小文件，里面存的是另一个文件的**路径**，就是 Windows 的快捷方式，原文件一删它就悬空（`ln -s`）。

### 三、名字有了，数据在哪些块：逻辑结构与物理结构

两个词先分层，这一层分不清后面全乱：

- **逻辑结构**是**用户和程序看到的**文件组织形式，和磁盘上怎么摆**无关**。两大类：**有结构的记录式文件**（内容是一条条记录，像数据库表）、**无结构的流式文件**（内容就是一串字节，像 `.txt`、`.bin`，Linux 下几乎全是这类）。
- **物理结构**是文件在**物理存储设备上的存放方法**，也就是它到底占了哪些物理块。

判据一句话：说的是"用户怎么看"就是逻辑结构，说的是"磁盘上怎么摆"就是物理结构；**带"分配"两个字的一定是物理结构**（分配的是磁盘块）。

假设 `report.doc` 有 6 个**逻辑块**（文件自己从 0 数起的第 0～5 块）。三种物理结构是一条被逼出来的演进链（培训资料叫连续结构/链接结构/索引结构，教材常叫连续分配/链接分配/索引分配，一回事）：

**连续结构（顺序结构）**：把逻辑上连续的文件信息依次存放在**连续编号**的物理块上，比如 18～23 号块。目录项只需记"起始块号 18 + 长度 6"，第 i 个逻辑块就在 18+i 号块，一次加法就定位，顺序读写最快。两个死穴：文件要变长而 24 号块已被别的文件占了，就得**整体搬家**；删删建建之后留下一堆装不下东西的小空洞，即**碎片**。

**链接结构（串联结构）**：块散落在**不连续**的物理块上，每个物理块里设一个**指针指向下一个物理块**，18→57→3→99→…。不要求连续空间、随便扩展、无外部碎片。代价是**只能顺着指针从头一块块爬**——读第 5 块必须先读第 0～4 块，**不支持随机访问**；指针占空间，中间断一环后面全丢。

**索引结构**：块照样散落，但系统给每个文件单独建一张**索引表**，记"逻辑块号 → 物理块号"，并把索引表的起始地址放进该文件的目录项。查一次表就能直接跳到目标块，**顺序访问和随机访问都行**——这正是它补上链接结构短板的地方，代价是**多占一张表的空间**。索引表在文件创建时由系统自动建立，与文件存在同一文件卷上；文件大时它本身要占一个或几个物理块。

### 四、索引表自己也放不下：多级索引与最大文件容量

UNIX/Linux 把每个文件的 FCB 和它的索引表合起来做成一个**定长**的小结构，叫**索引结点 inode**（index node）——**inode 就是 UNIX 里 FCB 的实现形式**，但有一处例外要记住：**文件名不在 inode 里**，目录项存的是「文件名 + inode 号」这一对。硬链接就是这么成立的——两个目录项写着不同的名字、却填同一个 inode 号。

定长带来一个硬约束：inode 里的地址项个数是**写死**的（培训资料的图里是 13 个）。先别往下看：块大小 1KB，13 个地址项全部**直接**指向数据块，这个文件系统里最大的文件能有多大？

**13KB。** 荒唐到没法用。所以必须换招：拿出后面几个地址项，让它**不指数据块，改指一个专门用来装地址的块**（间接块，也叫目录块）。13 项就是这么分的：**前 10 个直接 + 第 11 个一级间接 + 第 12 个二级间接 + 第 13 个三级间接**。

**先算 m。** 一个间接块就是一个普通物理块，1KB = 1024 字节；里面装的每个地址（就是一个物理块号）占几字节由题目给，本例 4 字节（32 位，够编 2³² 个块号）。那它能装多少个地址？**1024 ÷ 4 = 256 个**。这个 **m = 块大小 ÷ 地址字节数** 是后面全部计算的种子；题目常常只给块大小和地址长度，不直接给 m。

**单位口径先钉死**：本课 1KB = 1024B、1MB = 1024KB、1GB = 1024MB（严格写法是 KiB/MiB/GiB，软考题面一律写 KB/MB/GB）。**容量题一律按 1024 折算，不用 1000。**

现在**一层层数**。真题多数只给到二级，所以先数前 12 项——**10 个直接 + 1 个一级间接 + 1 个二级间接**，块大小 1KB，地址 4 字节（m = 256）；第 13 项三级最后再补。

- **直接地址项**：每个直接就是一个数据块的块号 → 10 个地址项管 **10** 个块。
- **一级间接**：这个地址项指向 1 个间接块，那块里塞满了数据块地址，共 m 个 → 管 **256** 个块。
- **二级间接**：它指向的块里装的不是数据块地址，而是 **m 个"一级间接块"的地址**；每个一级间接块再各装 m 个数据块地址 → 管 **256 × 256 = 65536** 个块。
- **三级间接**（第 13 项，再套一层）：m 个二级间接块 → **256³ = 16777216** 个块。

公式到这里自己长出来了：

> **最大文件 = (直接块数 + 一级数×m + 二级数×m² + 三级数×m³) × 块大小**

**先全部化成块数相加，最后一次性乘块大小**，中途反复换 KB/MB 最容易出错：10 + 256 + 65536 = **65802 块**，× 1KB = **65802KB ≈ 64.26MB**。

**量级自检**：二级项一定压倒性地大（65536 对 266），结果必然"比 64MB 大一点点"；算出正正好好 64MB 就是漏加了前两项。把第 13 项三级间接也加上，完整的 13 项 inode 合计 10 + 256 + 65536 + 16777216 = 16843018 块 ≈ **16.06GB**——**层数每加一级，容量就乘一个 m**，这才是多级索引真正的威力。

另一个问法是**某个逻辑块号该走哪一级**，把块号按段排队就行：直接块管 0～9，一级间接接着管 10～265，二级间接管 266～65801。

> 培训资料这一节的插图算式抄错了两处，思路没错但数字不能照抄：说 10 个 4KB 直接块"共可存 4KB\*10 = 10KB"，应为 **40KB**；说 4KB 块下一个一级间接块"1024\*4KB = 4098KB"，应为 **4096KB**。它那句"每个地址占 4B 则共有 1024 个地址"也**只在索引块 4KB 时成立**（4096÷4），真题里索引块 1KB 时是 256 个——**1024 不能背下来直接套，m 每题现算**。

### 五、谁能碰 report.doc：权限的三段九位

一台机器多人共用，权限必须细到"是谁在访问"。身份切三段，顺序固定：**属主 u**（owner，文件的所有者，通常就是创建它的人）、**属组 g**（group，组内成员共享同一套权限）、**其他人 o**（既非属主也不在该组里的所有人）。每段各配三个开关：**r 读、w 写、x 执行**。

`ls -l` 打出来的 `-rwxr-x--x` 共 10 位：**开头第 1 位是文件类型**（`-` 普通文件、`d` 目录、`l` 链接），**后 9 位每 3 位一组**，依次是属主、属组、其他人。

那 `chmod 751` 里的数字是怎么来的？**每段的三个开关，有就是 1、没有就是 0，本来就是三个二进制位**：

```
      r w x
      1 0 0 → 4    只有读
      0 1 0 → 2    只有写
      0 0 1 → 1    只有执行
      1 1 1 → 7    全有
```

所以 **r=4、w=2、x=1 不是一张要背的表，就是这三个二进制位的权值 4、2、1**。一段三位正好拼成一个八进制数字（0～7），三段拼成三位数。**751 拆开就是 111 / 101 / 001**：

- 7 = 111 → `rwx`：属主可读、可写、可执行
- 5 = 101 → `r-x`：属组可读、**不可写**、可执行
- 1 = 001 → `--x`：其他人只能执行

即 `chmod 751 report.doc` 之后权限串是 **`rwxr-x--x`**。再练两个常见值：**644** = 110/100/100 = `rw-r--r--`（普通文本文件）；**755** = 111/101/101 = `rwxr-xr-x`（可执行程序和目录）。

**反向换算**同样是三位一段相加：`rw-rw-r--` → 4+2 / 4+2 / 4+0+0 = **664**。正着算完再反着换一遍，两次对得上才算过。

**目录的 rwx 含义要单独记**：`r` = 能不能**列出**目录里有哪些名字（`ls`）；`w` = 能不能在里面**新建/删除/改名**；`x` = 能不能**进入**（`cd`）并按已知名字访问其中的文件。"有 r 没 x"看得见清单却进不去，"有 x 没 r"进得去、按名字读得到，却列不出清单。

顺带一个纯记忆送分点：`/etc` **配置文件**、`/dev` **设备文件**、`/home` **用户主目录**、`/bin` **基本命令的可执行程序**（binary）。

### 六、换个主题：外设怎么管（设备管理）

到这里 report.doc 这条线走完了。下面换主题——**磁盘只是外设中的一种**，与上面那棵目录树无关，别串。外设为什么非要操作系统专门管？

三件麻烦事：型号杂（磁盘、键盘、打印机、网卡的寄存器写法各不相同）、快慢差几个数量级（CPU 论纳秒、磁盘论毫秒、打印机论秒）、还有的东西一次只能给一个进程用。本节三块内容正好一一对应：**分层**屏蔽型号差异、**缓冲**抹平速度差、**SPOOLING** 破独占。

**设备**是计算机系统与外界交互的工具，负责计算机与外部的输入/输出，所以常称**外部设备**（外设）。负责管理设备和输入/输出的那套机构叫 **I/O 系统**，由**设备、控制器**（设备与总线之间那块电路，CPU 靠读写它的寄存器指挥设备）**、通道**（有通道的系统才有）**、总线和 I/O 软件**组成。**通道**是专管 I/O 的小处理部件，有自己的通道程序，CPU 只发一条启动命令，一组 I/O 操作、多台设备都由它管完；常拿来和它对比的 **DMA** 是由专用控制器在主存与外设之间直接搬一块连续数据，**传送过程中数据不经过 CPU**，但每次传送前后仍要 CPU 设定和收尾、一次只管一个数据块——**通道比 DMA 更自治，管的是一组操作而不是一次传送**。（四种 I/O 控制方式的完整对比属计算机组成，在讲义 07。）

**设备的四种分法**，只有两种要真懂：按**数据组织**分**块设备**（信息按固定大小的块存取、能随机定位到任意一块，如磁盘）与**字符设备**（数据是一串字符流、只能顺序来，如键盘、打印机、串口）；按**资源分配角度**分**独占设备**（同一时间只能一个进程用，如打印机）、**共享设备**（多进程可交替使用，如磁盘）、**虚拟设备**（本来独占、用技术手段变成人人有份，就是本节最后的 SPOOLING）。另两种是纯枚举：按功能分输入、输出、存储、网络联网、供电设备；按数据传输速率分低速、中速、高速设备。

**设备管理的任务**是多道程序环境下多个进程竞争使用设备时，按一定策略分配和管理各种设备、控制设备的各种操作、完成 I/O 设备与主存之间的数据交换。它拆成五项**主要功能**，每项都堵一个具体窟窿：不知道谁空着 → **动态掌握并记录设备状态**；抢起来了 → **设备分配与释放**；快慢不匹配 → **缓冲区管理**；寄存器怎么写 → **实现物理 I/O 设备的操作**；上层不该关心这些 → **提供设备使用的用户接口及设备的访问和控制**。

**I/O 软件分四层**，一句话记：越上层越像人话，越下层越像寄存器。

| 层次 | 这一层干什么 |
|---|---|
| 用户进程 | 发起 I/O 调用、格式化 I/O、Spooling |
| 设备无关软件 | 命名、保护、阻塞、缓冲、分配 |
| 设备驱动程序 | 置设备寄存器；检查状态 |
| 中断处理程序 | I/O 结束时唤醒驱动程序 |
| 硬件 | 执行 I/O 操作 |

三个术语首次出现：**设备驱动程序**是唯一知道某个具体型号的设备寄存器该怎么写的那段代码，换块别的牌子的网卡就换个驱动、上层代码一行不改——这正是上面那层叫"设备无关"的原因；**中断处理程序**是 I/O 干完后硬件发出中断信号、CPU 停下手上的活跳过去执行的那段代码；**缓冲**是在内存里开一小块地方暂存数据，抹平"CPU 快、外设慢"的速度差，顺带减少中断次数。

培训资料给的完整实例，考题就考这个流程：用户程序读一个硬盘文件 → **设备无关软件先检查高速缓存里有没有该数据块** → 没有就**调用设备驱动程序**向 I/O 硬件发出请求 → 用户进程**阻塞**等待 → 磁盘操作完成，**硬件产生一个中断**，转入**中断处理程序** → 它认出磁盘读取已完成，**唤醒用户进程**取回数据 → 用户进程继续运行。

一句话结论（真题就考这一句）：**I/O 软件隐藏了 I/O 操作实现的细节，方便用户使用 I/O 设备。** 两个词要咬住——是"隐藏"不是"开放"，是"方便用户使用"不是"提供物理接口"。

最后是 **SPOOLING**（外围设备联机操作，又译**假脱机技术**）。一台打印机是**独占设备**，同一时间只能一个进程用，别的进程只能干等，还不知道它什么时候空闲，外设效率浪费得极狠。

SPOOLING 的做法是在外设上建两个数据缓冲区，叫**输入井**和**输出井**（都在磁盘上）：进程要打印不直接碰打印机，只把命令和数据丢进输出井排队，打印机自动按序取出来打。

于是无论多少进程都能共用这一台打印机，**每个进程都感觉自己在使用一台打印机——这就是物理设备的虚拟化**，虚拟出来的那台叫**虚拟设备**；一句话，它把独占设备变成了共享设备。（作业流程：作业 → 输入设备 → 预输入程序 → 输入井 → 作业调度程序 → 当前运行的作业 → 井管理程序 → 输出井 → 缓输出程序 → 输出设备。）

两条线合起来只做了同一件事：**在裸硬件上盖一层抽象，让上面的人不必知道下面的编号和型号**——文件系统把"第 3721 块"藏成 `report.doc`，I/O 软件把设备寄存器藏成一次 `read()`。

## 考试怎么考

**考点① 相对路径与绝对路径（真题考点，最高频）。** 题面给一棵目录树，再问"当前工作目录为 X，访问文件 Y 的相对路径是（　）"或"全文件名是（　）"，按第二节三步法走。三个高频错法：**漏掉 `..`**（把兄弟目录当成子目录，这是最常设的错项）；**把绝对路径去掉开头的 `/` 冒充相对路径**（`usr/temp/c.txt` 实际指"当前目录下的 usr"）；**把文件名算进路径里**（路径本身不含文件名）。

**考点② Linux 权限与八进制换算（真题考点，2024 上/下核实到考过，751 是典型考法）。** 正问"执行 `chmod 751 file` 后正确的说法是"，反问"`rw-rw-r--` 对应的数字是"，逐位拆成三个二进制位即可。三种错法：**把 5 读成"可读可写"**（5=101 是读+执行，可读可写是 6=110），这是 751 这道题最经典的错项；**三段顺序颠倒**（永远 u→g→o）；**把 `ls -l` 开头那一位文件类型也当成权限**，10 位当 9 位拆。问的若是目录，r/x 要换成"列清单""进得去"。

**考点③ inode 多级索引与最大文件容量【计算，阶段B核心】。** 两种问法：求最大文件长度，或问某个逻辑块号该用哪一级索引。第一步永远是**求 m = 块大小 ÷ 地址字节数**（题目给了 m 就直接用），再按 (直接 + 一级×m + 二级×m² + 三级×m³) 化成块数相加、最后乘块大小。四种错法：**漏加低层的量**（只算最高一级就交卷，选项常故意设成两个相近值）；**二级忘了平方**写成 2×m；**把直接块数和 m 搞混串位**（一个是地址项个数、一个是一块能装几个地址）；只给块大小和地址长度时忘了先做除法求 m。问逻辑块号归哪一级时按段排队数，**注意块号从 0 起**。

**考点④ 三种物理结构辨析。** 问法是"下列说法错误的是"，四条描述里混一条假的。错项只有两种造法，认准就行：**"索引分配和链接分配一样只能顺序访问"**（索引的卖点恰恰是查表就能随机跳）和**"链接分配支持随机访问"**（链接必须从头一块块爬）。

**考点⑤ 逻辑结构 vs 物理结构。** 问"顺序文件属于文件的（　）结构""索引分配属于（　）结构"，选项就是逻辑/物理/存储/目录结构互换，判不准时看有没有"分配"二字。

**考点⑥ 文件与目录的概念题。** 送分点，认关键词即可：FCB 三类信息是基本信息类、存取控制信息类、使用信息类；UNIX 把文件分成普通文件、目录文件、设备文件。目录常识题的标准手法是**把 `/etc` 和 `/bin` 对调**。

**考点⑦ 设备管理。** 四个落点。**I/O 软件的作用**：错项就靠替换两个词造出来——把"隐藏"换成"开放"、把"方便用户使用"换成"向用户提供物理接口"。**四层职责对号**：照第六节那张表反向查即可，错项造法是把相邻两层的职责对调（最常见的是把"置设备寄存器"安给中断处理程序）。**SPOOLING**：认关键词"输入井/输出井""独占设备改造成共享""物理设备虚拟化"；错项常说它"提高了 CPU 主频"或"属于内存管理技术"。另有一种问法考**通道与 DMA 的区别**：通道有自己的通道程序、管一组 I/O 操作，DMA 只搬一个连续数据块。

### 参考答案

1. **C、D**。先求 m = 1KB ÷ 4B = **256**。逻辑块号排队：直接地址管 **0～4**（5 个），2 个一级间接各管 256 个、接着管 **5～516**，二级间接从 **517** 起，故 5 走**一级**、518 走**二级** → C。最大长度 = 5 + 2×256 + 256² = 5 + 512 + 65536 = **66053 块** × 1KB → D。两个干扰项各对应一种典型错法：**517 = 5+2×256** 是把二级间接整项漏掉；**1029 = 5+512+512** 是二级忘了平方、写成 2×m。
2. **D、B**。全文件名从根 `\` 一路读下来即 `\swshare\flash\fault.swf` → D；A 少了整条路径，B 是相对路径加文件名，C 少了开头的 `\` 不算绝对路径。第二空：当前目录是 swshare，目标在它下面的 flash 里，**退 0 级、往下进一层**，相对路径 `flash`、绝对路径 `\swshare\flash\` → B。**路径都不含文件名**，这正是本题真正的考点。
3. **C**。I/O 软件就是隐藏底层细节、只给出方便的接口。A、D 错在"开放"；B 错在"物理接口"——它给的恰恰是**逻辑接口**，物理细节正是被藏起来的那部分。
4. **A**。751 逐位拆：7=111→`rwx`，5=101→`r-x`，1=001→`--x`。B 把属组和其他人对调；C 把属主的 7 误当 6（漏了 x）；D 把 5 读成"可读可写"——5=4+1 是读+执行，可读可写是 6=4+2，这是本考点最经典的错项。
5. **B**。目标绝对路径 `/usr/work/data/b.txt`，与当前目录 `/usr/temp` 的最近共同祖先是 `/usr`，退 1 级写一个 `..` 再照抄 `work/data/b.txt`；回代 `/usr/temp` → `/usr` → `work` → `data` → `b.txt` ✔。A 漏了 `..`（work 是 temp 的兄弟不是子目录）；C 是绝对路径；D 漏了 `work` 这一层，走到的是 `/usr/data/b.txt`。
6. **C**。m = 2048 ÷ 4 = **512**。合计 8 + 512 + 512² = 8 + 512 + 262144 = **262664 块** × 2KB = **525328KB ≈ 513MB** → C。A 是只算直接块（16KB）、B 是只算一级间接（1MB）、D 是量级翻倍的干扰项——**漏算哪一层就正好掉进哪个错项**。
7. **D**。A、B、C 都是标准结论。D 把索引结构和链接结构混为一谈：索引结构**查表就能直接跳到目标块，顺序随机都支持**，这正是它相对链接结构的核心优势。
8. **B**。"输入井/输出井 + 独占设备变成大家共用 + 每个进程都感觉独占"是 SPOOLING 的标志。A 缓冲只是在内存里暂存数据抹平速度差；C 通道是分担 I/O 控制的硬件部件；D 虚拟存储是内存管理，和外设无关（"虚拟设备"≠"虚拟存储"）。
9. **4144KB（约 4.05MB）**。m = 4KB ÷ 4B = **1024**。直接 12 块 = 48KB；一级 1024 块 = 4096KB；**无二级，该项为 0**。合计 12 + 1024 = 1036 块 × 4KB = **4144KB**。
10. **764**。属主 `rwx`=4+2+1=7，属组 `rw-`=4+2=6，其他人 `r--`=4；只有属主能执行，同组能读写、**不能执行**，其他人只能读。反向验算 764 → 111/110/100 → `rwxrw-r--` ✔。
11. 相对路径 **`../../usr/work/report.doc`**：最近共同祖先是根 `/`，从 `/home/zhang` 退 2 级（`../..`）到根，再照抄 `usr/work/report.doc`；回代 `/home/zhang` → `/home` → `/` → `/usr` → `/usr/work` → `report.doc` ✔。全文件名 = **`/usr/work/report.doc`**，**和当前工作目录在哪毫无关系**，这正是它与相对路径最大的区别。
12. **C**。`/bin` 存的是系统基本命令的可执行程序（ls、cp、cat 等，bin = binary），配置文件在 `/etc`。这就是 `/etc` 与 `/bin` 对调的标准手法。

## 速记

- **全文件名 = 绝对路径 + 文件名**；路径本身**不含文件名**。绝对路径从 `/` 起，相对路径从当前工作目录起（`.` 当前、`..` 上级）；退到最近共同祖先几级就写几个 `..`，写完回代走一遍
- **FCB 的有序集合 = 文件目录**；FCB 三类信息＝基本／存取控制／使用信息；**inode 即 UNIX 的 FCB，但文件名在目录项里、不在 inode 里**。目录演进：一级 → 二级（MFD+UFD）→ 树形（不同目录允许同名）
- **逻辑结构＝用户怎么看**（记录式／流式），**物理结构＝磁盘怎么摆**（带"分配"二字的一律是物理）；三种物理结构：**连续快但难扩展有碎片、链接易扩展无外部碎片但只能顺序、索引顺序随机都行但多一张表**
- **m = 块大小 ÷ 地址字节数**（1KB÷4B = 256）；**最大文件 = (直接 + 一级×m + 二级×m² + 三级×m³) × 块大小**；先全化成块数相加、最后一次乘块大小；二级是平方、三项都要加
- **权限 r=4 w=2 x=1 是三个二进制位的权值**；三段 u→g→o，`751` = 111/101/001 = `rwxr-x--x`（5 是读+执行，不是读+写）；`ls -l` 开头第 1 位是类型不是权限；目录的 r＝列清单、x＝进得去
- 设备分类：块／字符（按数据组织）、独占／共享／虚拟（按资源分配）；I/O 系统＝设备＋控制器＋通道＋总线＋I/O 软件；**通道管一组 I/O 操作、DMA 只搬一个数据块**；**SPOOLING ＝ 输入井＋输出井，把独占设备虚拟成人人有份的虚拟设备**
- I/O 软件四层：**用户进程（Spooling）→ 设备无关软件（命名保护阻塞缓冲分配）→ 设备驱动（置寄存器查状态）→ 中断处理（完成时唤醒驱动）→ 硬件**；一句话＝**隐藏细节、方便使用**
