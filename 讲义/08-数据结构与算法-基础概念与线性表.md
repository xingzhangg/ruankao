# 08 · 数据结构与算法：基础概念与线性表

## 定位

这一课讲一堆数据在内存里怎么摆，以及「排成一条线」的数据摆成数组或串成链表各要付出多少搬移、字节和指针步数。第一节把「元素之间是什么关系」和「元素摆在内存哪里」拆成两条独立维度；第二、三节算顺序表的账，第四节算链表的账；第五节把元素换成字符，从朴素匹配推到 KMP 的 next 数组。

全课例子：8 个数 `12 25 33 47 58 61 79 86`。

---

## 一、逻辑结构与存储结构（概念）

**速查表**

| 维度 | 回答的问题 | 分类 |
|---|---|---|
| **逻辑结构** | 元素彼此是什么关系（不涉及内存） | **集合**（同属一堆、无先后，像一袋球）／**线性**（一个挨一个）／**树形**（一对多，像组织架构）／**图状/网状**（多对多，像地铁图） |
| **存储结构**（物理结构） | 元素摆在内存哪里、怎么找到彼此 | **顺序**（连续一整块）／**链式**（散放，每个元素附一个指向下一个的地址）／**索引**（另建「关键字 → 地址」表）／**散列**（用函数把关键字算成地址） |

**数据结构三要素** = 逻辑结构 + 存储结构 + 运算（增、删、改、查、遍历）。

**易混对**

- 逻辑 vs 存储
  判据｜说的是「关系」→ 逻辑；说的是「摆法」→ 存储。两条维度互相独立
  例子｜同一个线性关系，顺序存储得到**顺序表**，链式存储得到**链表**；线性表、栈、树、图永远是逻辑结构，散列、索引永远是存储结构

**线性表定义**｜n 个（n ≥ 0）同类型数据元素组成的有限序列，记作 (a₁, a₂, …, aₙ)；n = 0 为**空表**，也是合法线性表。
原话｜**除第一个元素外每个元素有且仅有一个直接前驱，除最后一个元素外每个元素有且仅有一个直接后继**（直接前驱＝紧挨在前面的那个；序列 12、25、33 里，25 的直接前驱是 12、直接后继是 33）。「除首尾外」不能丢。

## 二、顺序存储的地址计算（计算）

**问题**：元素连续存放，第 i 个在哪个地址？

a₁ 从 2000 开始，每个占 4 字节：

```
元素： a₁    a₂    a₃    a₄    a₅    a₆    a₇    a₈
值：   12    25    33    47    58    61    79    86
地址： 2000  2004  2008  2012  2016  2020  2024  2028
```

1. 求 a₅：前面挡着 a₁–a₄ 共 **4** 个
2. 往后挪 4×4 = 16 字节
3. 地址 2000 + 16 = **2016**

**规则**：第 i 个元素前面挡着 i−1 个。

```
LOC(aᵢ) = LOC(a₁) + (i − 1) × L        L = 每个元素占的字节数（下标从 1 起）
LOC(a[i]) = LOC(a[0]) + i × L          下标从 0 起（C、Java）
```

两式是同一句「前面挡着几个」：1 起时是 i−1 个，0 起时下标 i 本身就是。a₅ 与 `a[4]` 是同一个元素，地址都是 2016。先看首元素写成 a₁ 还是 a[0]，定错结果正好差一个 L。

验证：a₈ = 2000 + 7×4 = **2028** ✓；自查：i = 1 代回得 2000，正是首地址。

变形：已知 LOC(a₁) = 2000、LOC(a₆) = 2020 反求 L：20 = 5L，**L = 4**。单位先换算：「每个元素占 2 个字，1 字 = 2 字节」时 L 取 4。（本课只管一维；二维数组行优先／列优先不在本课。）

**随机存取**：一步算出地址，取第 1 个与取第 800 个代价相同。意思是「取任意位置代价相同」，不是「随便取一个」。

## 三、顺序表的插入与删除（计算）

**问题**：中间不许有洞，插入删除要搬多少个元素？

在第 3 个位置插入 40（n = 8）：

```
原：  12  25  33  47  58  61  79  86
挪：  86→第9格  79→第8格  61→第7格  58→第6格  47→第5格  33→第4格
      （从最后一个倒着挪，从前面挪会覆盖后一个元素）
新：  12  25  40  33  47  58  61  79  86
搬动 a₃..a₈ 共 8 − 3 + 1 = 6 个
```

删除第 3 个（33）：把后面 47、58、61、79、86 各前移一格，共 **5** 个 = 8 − 3。

**规则**：

```
第 i 个位置插入：移动 n − i + 1 个      删除第 i 个：移动 n − i 个
```

插入比删除多搬 1 个：插入要额外腾一个空位，删除只填一个已有的坑。

**平均值**：可选位置数不同——插入可插在第 1 个之前、任意两个之间、最后一个之后，共 **n+1** 个位置；删除只有 **n** 个。n = 8 全枚举：

```
插入 i = 1..9：8 7 6 5 4 3 2 1 0    合计 36，÷9 = 4   = n/2
删除 i = 1..8：7 6 5 4 3 2 1 0      合计 28，÷8 = 3.5 = (n−1)/2

插入平均 = [n + (n−1) + … + 0] / (n+1) = [n(n+1)/2] / (n+1) = n/2
删除平均 = [(n−1) + … + 0]     / n     = [n(n−1)/2] / n     = (n−1)/2
```

两个均值只差 **1/2** 不是 1：每个位置上插入确实多搬 1 个，但插入多出来的那个位置（末尾之后）一个都不搬，把均值拉低了 1/2。

最好/最坏：插入最坏插在第 1 个，挪 n 个；最好插在末尾之后，0 个。删除最坏删第 1 个，挪 n−1 个；最好删最后一个，0 个。

## 四、链式存储（计算 + 对比）

### 4.1 单链表的插入删除（计算）

**问题**：搬家的根源是「连续」，不连续摆就只需改指针。

每个元素单独占一小块内存，叫**结点**：装数据的部分是**数据域**，装地址的是**指针域**；只有一个指向后继的指针域就是**单链表**。**头指针**存第一个结点地址，尾结点指针域为 NULL。

```
head → [12|●] → [25|●] → [33|●] → [47|●] → … → [86|∧]      ∧ = NULL
```

把 40 插到 25 与 33 之间（新结点 s，p 为装 25 的结点）：

```
1. s->next = p->next;    40 指向 33
2. p->next = s;          25 改指 40
共 2 步，没搬任何元素
```

顺序不能反：先执行 `p->next = s`，原来的 `p->next`（33）就丢了，第一句会让 40 指向自己。

删除 33（q = p->next）：

```
1. p->next = q->next;    25 直接指向 47，再释放 q
共 1 步
```

**规则**：插入 2 步、删除 1 步，与表长无关，即 O(1)（步数固定）；**前提是已经握着前驱结点 p**。「删除第 i 个元素」要先从头走到第 i−1 个结点，这段 O(n)（步数与元素个数成正比）省不掉。

### 4.2 双向链表、循环链表、头结点（概念）

单链表指针是单行道，站在 33 上回不到 25，所以需要前驱。

| 结构 | 做法 | 得失 |
|---|---|---|
| **双向链表** | 每个结点加一个**前驱指针域** | 多占一个指针、插入变 4 步；删除给定结点不必先找前驱，就地 2 步（省掉的是「先走到前驱」那一趟） |
| **循环链表** | 尾结点指针从 NULL 改为指回首结点 | 从任意结点出发可遍历全表；遍历终止条件由「走到 NULL」改为「回到起点」；只留**尾指针** rear 时，表尾 = rear、表头 = rear->next，都 O(1)，两条循环链表首尾相接只改两个指针 |
| **头结点** | 第一个数据结点前挂一个不存数据的结点，头指针指向它 | 不省时间也不省空间，只为让「在第 1 个位置插删」与中间插删写成同一段代码（无头结点时改的是头指针本身） |

双向链表在 p 之后插入 s：`s->prior = p; s->next = p->next; p->next->prior = s; p->next = s;`——最后一句必须放最后，前三句还要用原来的 `p->next`。删除 p：`p->prior->next = p->next; p->next->prior = p->prior;`。

### 4.3 存储密度与两种存储对比

**存储密度** = 结点中数据占的字节 ÷ 结点总字节。数据、指针各 4 字节时：顺序表 4/4 = **1**，单链表 4/8 = **1/2**，双向链表 4/12 = **1/3**。

「顺序表更省空间」不是绝对的：顺序表要事先占一整块连续内存，用不满就闲置，估小了要整块重新申请再拷贝（`ArrayList` 扩容）；链表随用随申请。

| 性能类别 | 具体项目 | 顺序存储 | 链式存储 |
|---|---|---|---|
| 空间性能 | 存储密度 | =1，更优 | <1 |
| | 容量分配 | 事先确定 | 动态改变，更优 |
| 时间性能 | 查找运算 | O(n/2) | O(n/2) |
| | 读运算 | O(1)，更优 | O([n+1]/2)，最好情况为 1，最坏情况为 n |
| | 插入运算 | O(n/2)，最好情况为 0，最坏情况为 n | O(1)，更优 |
| | 删除运算 | O([n-1]/2) | O(1)，更优 |

⚠️ 表中 O(n/2) 等**不是渐进复杂度**（严格说都是 O(n)，大 O 会吞掉常数倍率），按「平均动多少次」读：

- 插入 n/2、删除 (n−1)/2：即第三节的两个均值
- 链表读运算 (n+1)/2：按序号取第 i 个平均要走的结点数，(1+2+…+n)/n
- 查找两边相同：**按值**查找两种存法都要挨个比，O(n) 量级；顺序表能算地址的前提是已知序号。表中 n/2 是近似，平均比较次数严格为 **(n+1)/2**

**一句话**：连续 → 地址有规律 → 随机存取快，但增删要搬家、要预占整块空间；不连续 → 只改指针 → 增删快、容量随用随取，但只能顺藤摸瓜、指针占额外空间。

## 五、串与模式匹配

### 5.1 串的概念（概念）

**串**（字符串）是元素全为字符的线性表，记作 S = "a₁a₂…aₙ"，n 为**串长**。结构与前四节相同，只是元素的取值开始参与判断。

| 术语 | 是什么 |
|---|---|
| **空串** | 长度为 0 的串 ""，是任何串的子串 |
| **空格串** | 由一个或多个空格组成，如 " "；空格占一个字符长度，所以**空格串不是空串** |
| **子串** | 串中任意个**连续**字符组成的序列（"abc" 中的 ac 不是）；包含它的串叫**主串**。字符互异时子串共 n(n+1)/2 + 1 个（长度 1 有 n 个、长度 2 有 n−1 个……再加空串） |
| **模式匹配** | 在主串中找给定串（**模式串**）**第一次出现的位置** |

下面把主串看成长纸条、模式串看成短纸条。

### 5.2 朴素模式匹配（计算）

**做法**：短纸条对齐长纸条最左端逐位比；一位不同（**失配**）就整体右移**一格**，从头再比。

```
位置    1 2 3 4 5 6 7
长纸条  A B C A B C D
短纸条  A B C D
        ✓ ✓ ✓ ✗        第 4 位失配
```

依次右移，在第 4 位全中，比较次数 4 + 1 + 1 + 4 = **10**（失配那次也算一次比较）。最坏情况在 n−m+1 个位置各比 m 位，**O(n×m)**（n 主串长，m 模式串长）。

浪费在于：失配时已知长纸条第 1–3 位是 A、B、C，右移一格让 A 对 B、再一格让 A 对 C，结果本可提前算出。

### 5.3 KMP：能滑多远只看模式串（计算）

失配时，已配上的那一段在两张纸条上内容完全相同，所以「挪几格可行」只看短纸条自己。

> ★ **能滑多远是模式串自身的性质，与主串无关。**

因此可以在匹配前把「失配在第几位、滑多远」算成一张表——**next 数组**。**KMP 算法** = 预先算表 + 查表滑动，**主串指针全程不回退**。

**三个动作**（L = 已配上那段中开头与结尾相同的最大长度；此 L 与第二节的字节数 L 无关）：

```
① 数出 L      已配段开头和结尾最多几个字母相同（逐个试完取最大）
② 滑几格      滑格数 = 已配长度 − L
③ 从哪接着比  从短纸条第 L+1 位
```

**算例 1：模式串字符不重复**

```
位置    1 2 3 4 5 6 7
长纸条  A B C A B C D
短纸条  A B C D          第 4 位失配，已配 ABC
试 1 个：A vs C ✗；试 2 个：AB vs BC ✗   → L = 0
滑 3 − 0 = 3 格，从第 1 位比：
短纸条        A B C D    第 4 位全中；KMP 共比 8 次（朴素 10 次）
```

`ABCD` 字母互不重复，失配在哪一位 L 都为 0，直接滑到失配位置重比。

**算例 2：模式串自带重复**

```
位置    1 2 3 4 5 6 7
长纸条  A B A B A B C
短纸条  A B A B C        第 5 位失配，已配 ABAB
试 1 个：A vs B ✗；试 2 个：AB vs AB ✓；试 3 个：ABA vs BAB ✗   → L = 2
滑 4 − 2 = 2 格，短纸条开头 AB 压在已配段结尾 AB 上，自动对齐，从第 3 位接着比：
短纸条      A B A B C    第 3 位全中；KMP 共比 8 次（朴素 11 次）
```

**数 L 的两条规矩**：

1. **两截都不许取整段**：已配长度为 k，最多试到 k−1 个。取整段等于滑 0 格；不加这条，任何串的 L 都等于已配长度。
2. **两截可以重叠**：`aaa` 开头 2 个 `aa` 与结尾 2 个 `aa` 共用中间的 a，L = 2。

另外 L 不单调（算例 2 中试 1 个不成立、试 2 个成立），不能试到第一个不成立就停。

②的减法：已配段结尾 2 个字母在第 3、4 位，短纸条开头从第 1 位挪到第 3 位，挪了 4 − 2 = 2 格。③的加一：前 L 位已自动对上，下一个是第 L+1 位。

### 5.4 next 数组（计算）

> ★ **next[j] = （模式串前 j−1 个字符的最长相等前后缀长度 L）+ 1**，**next[1] = 0**
>
> **前缀**＝开头一截，**后缀**＝结尾一截，都不许取整段——教材称「最长相等**真**前后缀」。

next[1] = 0 是约定：第 1 位失配时一个都没配上，主串指针前进一位、模式串回到第 1 位。next[j] 存的是「接着从第几位比」，所以是 L+1；匹配时令 j = next[j]，等价于右滑「已配长度 − L」格。

教材式（《软件设计师教程》第 5 版）：

```
             ┌ 0                                                        j = 1
next[j] =    ┤ max{ k | 1 < k < j 且 p₁…p_{k−1} = p_{j−k+1}…p_{j−1} }    该集合非空
             └ 1                                                        其他情况
```

`p₁…p_{k−1}` 是开头 k−1 个，`p_{j−k+1}…p_{j−1}` 是结尾 k−1 个，**k = L+1**；约束 `1 < k < j` 就是「不许取整段」。结尾起点 j−k+1：j=5、k=3 时开头 p₁p₂ = `ab`，结尾从第 3 位起 p₃p₄ = `aa`，不等，k=3 不成立。

**算例：P = "abaac"**（j 从 1 起）

```
j=1  特例                                                     next[1] = 0
j=2  已配 "a"     单字符，L=0                                 next[2] = 1
j=3  已配 "ab"    a ≠ b，L=0                                  next[3] = 1
j=4  已配 "aba"   a = a ✓；ab ≠ ba，L=1                       next[4] = 2
j=5  已配 "abaa"  a = a ✓；ab ≠ aa；aba ≠ baa，L=1            next[5] = 2

                                                   next = 0 1 1 2 2
```

**自查**：next[1] 恒为 0、next[2] 恒为 1；相邻两位最多增 1（每次至多多配上一个字符）；除第 1 位外都 ≥ 1。

### 5.5 KMP 匹配过程（计算）

i 为主串指针、j 为模式串指针：相等则都 +1；不等则 `j = next[j]`、**i 不动**；j 变为 0 时 i 前进一位、j 回到 1。

S = "abaabaabaac"，P = "abaac"（next = 01122）：

```
1. i=1..4 j=1..4  abaa 逐位对上
2. i=5 j=5  b ≠ c → j = next[5] = 2，i 留在 5（模式串右滑 3 格）
3. i=5..7 j=2..4  b、a、a 对上
4. i=8 j=5  b ≠ c → j = next[5] = 2，i 留在 8
5. i=8..11 j=2..5  b、a、a、c 对上 → i=12、j=6 越过串尾（m=5），匹配成功
6. 起始位置 = i − m = 12 − 5 = 7（成功时 i 指向匹配段后一位）
```

比较次数：朴素 **21** 次，KMP **13** 次，i 只增不减。KMP 时间复杂度 **O(n + m)**，其中 O(m) 用于预算 next。

## 速记

- 三要素 = 逻辑结构 + 存储结构 + 运算；逻辑四类 **集合/线性/树形/图状**，存储四种 **顺序/链式/索引/散列**，两维独立——线性表、栈、树、图是逻辑，散列、索引是存储
- 一维地址：`LOC(aᵢ) = LOC(a₁) + (i−1)×L`（1 起）／`LOC(a[0]) + i×L`（0 起），L = 每元素字节数；首元素代回自查，单位先换算
- 顺序表插入移动 **n−i+1**、删除 **n−i**；等概率平均插入 **n/2**（n+1 个位置）、删除 **(n−1)/2**（n 个位置），差 1/2
- 指针步数：单链表插 2、删 1；双向链表插 4、删 2；单链表删「第 i 个」要先走到第 i−1 个，整体 O(n)
- 存储密度：顺序表 **1**、单链表 **1/2**、双链表 **1/3**（数据与指针各 4B）；顺序表容量事先定，链表动态
- 循环链表尾指回首，遍历终止改为「回起点」；只留尾指针时找头找尾都 O(1)
- 串：**空格串不是空串**；子串必须连续，字符互异时共 n(n+1)/2+1 个；朴素 **O(n×m)**，KMP **O(n+m)**、主串指针不回退
- next（j 从 1 起）：**next[j] = L + 1**，L = 前 j−1 个字符的最长相等真前后缀长度（逐个试完取最大）；next[1]=0、next[2]=1；k 式中 k = L+1；`"abaac"` → **01122**
