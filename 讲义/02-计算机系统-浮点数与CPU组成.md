# 02 · 计算机系统：浮点数与 CPU 组成

## 定位

小数怎么装进定长的 0/1（阶码尾数、规格化、对阶加法、表示范围），以及这些运算由 CPU 的哪个部件完成（运算器与控制器）。前六节跟着一个数 5.5 走，第七节把它的加法拆开看每一步是谁干的。承接 01 的补码、移码；下一课 03 讲指令怎么找操作数。

---

## 一、定点数的局限

**定点数**：小数点位置事先约定、不占存储位。例：8 位约定成 `xxxx.xxxx`，5.5 = `101.1` → `0101.1000`，装得下。

```
最大值 1111.1111 = 15.9375      → 5500000 装不下
最小间隔 0000.0001 = 1/16 = 0.0625 → 0.001 表示不了
```

范围和精度抢同一批比特，给谁都从对方那里抢——所以要换成浮点。

## 二、浮点表示：N = F × 2^E

照搬十进制科学计数法（85.125 = 0.85125×10²），把小数点挪到最前，挪几位就用 2 的几次方补回：

```
5.5 = 101.1₂ → 小数点左移 3 位 → 0.1011 × 2³
验算：0.1011₂ = 1/2 + 1/8 + 1/16 = 0.6875，× 8 = 5.5 ✓
```

小数点位置由指数决定，所以叫**浮点数**：

- **N = F × 2^E**。E ＝**阶码**（2 的指数，带符号纯整数，管小数点挪几位）；F ＝**尾数**（挪完剩下的有效数字，带符号纯小数）。
- 两者都可能为负（0.0011 = 0.11×2⁻²；−5.5），所以分四段存：

| 阶符 | 阶码 | 数符 | 尾数 |
|---|---|---|---|
| 阶码的符号位，1 位 | 阶码数值部分 | 尾数的符号位，1 位 | 尾数数值部分 |

- **阶码通常用移码**（补码符号位再取反）：正数以 1 开头、负数以 0 开头，阶符 1 是正阶、0 是负阶。好处：两个阶码可当无符号数直接比大小，对阶时不用先判符号。

## 三、阶码定范围，尾数定精度

同样 8 位，两种分法实算：

| | 分法甲 | 分法乙 |
|---|---|---|
| 阶码（含阶符） | 3 位，−4～3 | 5 位，−16～15 |
| 尾数（含数符） | 5 位，最大 `0.1111` = 0.9375 | 3 位，只有 `0.10` = 0.5、`0.11` = 0.75 |
| 最大数 | 0.9375 × 2³ = **7.5** | 0.75 × 2¹⁵ = **24576** |
| 最小正数（尾数最高位为 1） | 0.5 × 2⁻⁴ = **0.03125** | 0.5 × 2⁻¹⁶ ≈ **0.0000076** |
| 5.5 | `0.1011`×2³ ✓ | 2³ 档只有 4、6，**5.5 掉在缝里** ✗ |

位数挪给阶码，范围涨三千多倍，精度塌到连 5.5 都表示不了：

> **数值范围由阶码决定，精度由尾数决定。**

对照：`float` 8 位阶码 + 23 位尾数，`double` 11 位阶码 + 52 位尾数——多的 3 位阶码买范围，多的 29 位尾数买精度。

## 四、规格化

同一个数有多种写法：

```
5.5 = 0.1011 × 2³ = 0.01011 × 2⁴ (0.34375×16) = 0.001011 × 2⁵ (0.171875×32)
```

后两种把尾数高位浪费在存 0 上。规定**尾数小数点后第一位必须是 1**（`0.1xxx`，即 1/2 ≤ |尾数| < 1），叫**规格化**。目的：表示唯一；尾数一位不浪费，精度最大。

- 尾数用补码时：正数 `0.1xxxx`，负数 `1.0xxxx`。统一判据：**符号位与最高数值位相反**。（培训资料与教材第 5 版口径相同）
- **IEEE 754** 不同：写成 `1.xxx × 2^E`，最高位的 1 **隐含、不存储**；单精度 32 位 = 1 位符号 + 8 位阶码（存真实阶码 + **127** 偏移量）+ 23 位尾数。

## 五、浮点加减

**算例 1：5.5 + 1.5**（1.5 = `1.1`₂ = `0.11`×2¹）

尾数不能直接加：`0.1011`×2³ 的各位代表 2²、2¹、2⁰、2⁻¹，`0.11`×2¹ 的各位代表 2⁰、2⁻¹，位权不一致。先让阶码相同，叫**对阶**。

```
① 对阶：小阶 1 → 大阶 3，调大 2，尾数右移 2 位
   0.11 × 2¹ → 0.0011 × 2³     （0.1875 × 8 = 1.5 ✓）
   对照：尾数若左移 → 11.0 × 2³ = 24 ✗
② 尾数相加：0.1011 + 0.0011 = 0.1110
③ 结果规格化：0.1110 已是 0.1xxx，不动
结果 0.1110 × 2³ = 0.875 × 8 = 7 ✓
```

对阶方向为什么定死：

- **E 调大 n，F 必须缩到 1/2ⁿ，即右移 n 位**，乘积才不变（十进制 `0.65×10¹ = 0.065×10²`，指数变大、数字右挪）。
- 反过来大阶向小阶（尾数左移），算式成立但寄存器位数固定，**左移顶掉最高有效位**：`0.1011`×2³ 降到 2¹，4 位尾数左移 2 位剩 `1100`，得 `0.1100`×2¹ = 1.5，5.5 变 1.5，结果作废。右移只丢最低位，损失一点精度。

> **对阶：小阶向大阶看齐，尾数右移。**（"向大"与"右移"绑成一对记）

**算例 2：5.5 + 6.5**（6.5 = `110.1`₂ = `0.1101`×2³，同阶）

```
① 对阶：阶码都是 3，免
② 尾数相加：0.1011 + 0.1101 = 1.1000   ← 进位到小数点左边
③ 结果规格化：尾数右移 1 位、阶码 +1 → 0.11000 × 2⁴
验算：0.75 × 16 = 12 ✓
```

③ 的右移与 ① 的右移目的不同：对阶是让两数可加，规格化是让结果符合 `0.1xxx`。减法可能得到 `0.0011` 这类高位全 0 的结果，此时**尾数左移、阶码减小**，顶出去的是 0，安全。

收尾两步（教材列、培训资料未列）：右移丢掉的低位要不要进位，叫**舍入**；阶码超出位数所能表示的范围，超上界为**上溢**（数太大，报错），超下界为**下溢**（太接近 0，一般当 0 处理），这一步叫**判溢出**。

> **对阶 → 尾数运算 → 结果规格化 → 舍入 → 判溢出**

顺序由逻辑锁定：不对阶不能加；加完才有结果可规格化（参与运算的数本来已规格化）；规格化的右移才产生舍入；阶码调完才知道是否溢出。

## 六、给定格式求表示范围

例：16 位浮点数，阶符 1 位、阶码值 6 位、数符 1 位、尾数 8 位，阶码用移码、尾数用补码。

```
阶码：1 + 6 = 7 位定点整数，移码范围同补码：−2⁶ ～ 2⁶−1 = −64 ～ 63 → 最大指数 63
尾数：1 + 8 = 9 位定点纯小数，补码：−1 ～ 1−2⁻⁽⁹⁻¹⁾ = −1 ～ 1−2⁻⁸
最大值 = (1−2⁻⁸) × 2⁶³
最小值 = (−1) × 2⁶³ = −2⁶³
```

规则（阶码 m 位、尾数 k 位，都含符号位）：

- 位数**把符号位算进去**：阶码 7 位不是 6 位，尾数 9 位不是 8 位。
- 最大指数 **2^(m−1) − 1**：63，不是 64（把 2⁶ 当指数、或按 6 位算都会得到 2⁶⁴）。
- 补码小数负端是 **−1 整**，不是 −(1−2⁻⁸)：补码多出的那个编码给了负端（01 讲的"补码负半边多一个"）。
- 范围 = 阶码极限 × 尾数极限，两端分别相乘。

## 七、CPU 组成

**原话｜** 计算机的基本硬件系统由**运算器、控制器、存储器、输入设备、输出设备**五大部件组成；**运算器和控制器集成在一起就是 CPU**（中央处理单元），是硬件系统的核心，负责数据加工处理和控制。CPU 完整构成：**运算器 + 控制器 + 寄存器组 + 内部总线**（内部总线＝CPU 内各部件间传数据的公共通路）。

存储器分内存（速度高、容量小，临时存放程序数据与中间结果）和外存（容量大、速度慢，长期保存）；输入设备（录入原始数据和命令）与输出设备（输出运行结果）合称**外设**。寄存器＝CPU 内部最快、容量极小的存储单元。

对照 5.5 + 6.5 这次加法：

| 部件 | 属于 | 职责 / 在加法里干什么 |
|---|---|---|
| **ALU** 算术逻辑单元 | 运算器 | 加减乘除、与或非、比较；尾数右移、相加在这里做 |
| **AC** 累加器 | 运算器 | 存源操作数和运算结果（`0.1011`、`1.1000`） |
| **DR** 数据缓冲寄存器 | 运算器 | 内存↔CPU 的中转站，暂存从内存读来的指令或数据 |
| **PSW** 状态条件寄存器（程序状态字） | 运算器 | 存运算结果的条件码：进位、溢出、零；上溢靠它记 |
| **PC** 程序计数器 | 控制器 | 存**下一条指令的地址**，取完自动 +1 |
| **AR** 地址寄存器 | 控制器 | 存 CPU 当前要访问的内存地址；取指时地址经它送上**地址总线** |
| **IR** 指令寄存器 | 控制器 | 存**当前正在执行的指令内容** |
| **ID** 指令译码器 | 控制器 | 分析指令的**操作码**（表示"干什么"的那段） |
| **时序部件** | 控制器 | 产生节拍信号，给全机打拍子（教材列在控制器下，培训资料部件清单未列） |

控制器负责控制整个 CPU 的工作，ALU 做右移还是相加由它决定。

**易混对① PSW 归运算器还是控制器**
- 判据｜看它记的是什么：记运算结果的进位/溢出/零 → 运算器，不看名字里的"程序"。
- 例子｜PSW 与 ALU、AC、DR 同属运算器；PC、IR、AR、ID、时序部件属控制器。

**易混对② PC / IR / AR**
- 判据｜PC 存"下一条指令的地址"，IR 存"指令的内容"，AR 存"本次访存的地址"。
- 例子｜取指第一步送上地址总线的是 PC 的内容（指令地址）；取回来的指令放进 IR；暂存源操作数和结果的是 AC，不是这三个。

**CPU 四项功能**：**程序控制**（按 PC 决定指令执行顺序）、**操作控制**（产生操作信号送对应部件）、**时间控制**（控制每个信号的出现时刻与持续时间）、**数据处理**（算术逻辑运算，最根本的任务）。此外还要**对系统内外的中断（异常）做出响应**（中断＝先放下手头的活，处理更急的事再回来）。

**指令与数据怎么区分**：两者在内存里都是二进制，CPU **靠指令周期的不同阶段区分**——取指阶段取回的当指令，执行阶段取回的当数据。

## 速记

- N = F × 2^E；四段：阶符｜阶码｜数符｜尾数；**阶码定范围、尾数定精度**；阶码用移码（便于直接比大小）
- 规格化 `0.1xxx`（补码负数 `1.0xxx`，符号位与最高数值位相反）；IEEE 754 `1.xxx`，1 隐含，单精度 1+8+23，偏移 **127**
- 加减：**对阶 → 尾数运算 → 结果规格化 → 舍入 → 判溢出**；对阶**小阶向大阶，尾数右移**
- 求范围：阶码、尾数位数都**含符号位**；最大指数 2^(m−1)−1；补码小数 −1 ～ 1−2^−(k−1)；两端相乘
- 五大部件：运算器、控制器、存储器、输入、输出；**CPU = 运算器 + 控制器 + 寄存器组 + 内部总线**
- **算累数状归运算**（ALU/AC/DR/PSW）；**程指译址时序管控制**（PC/IR/ID/AR/时序）
- PC 下一条指令地址，IR 当前指令内容，AR 本次访存地址；CPU 靠指令周期阶段区分指令与数据
