# 52 · 下午题 4：C 算法设计实战

## 定位

下午题 4（15 分）：一段算法原理说明 + 一份挖了 4 个空的 C 代码 + 三问。多数空只需局部推导（循环边界、下标偏移、分支返回值），不必读懂整个算法。第一节是题的结构与作答顺序，第二节是读代码要用的 C 语法，第三节认算法策略与判复杂度，第四节手推给定输入的输出，第五节代码填空，第六节止损与作答要点。C 语言本身归 45，各算法原理与复杂度推导归 14，本课只用结论。

## 二、读代码只需五样 C 语法

- **数组下标与宏**：`a[i]` 取第 i 格；下标从 0 还是 1 开始看循环怎么写，不凭习惯。`#define N 6` 是宏，编译前把后文 `N` 原样换成 `6`，所以 `N`、`n` 这类没写 `int` 的名字是常量。
- **判断与逻辑符号**：`==` 相等（单个 `=` 是赋值），`!=` 不等，`>=` 大于等于；`&&` 两个条件都成立，`||` 成立一个即可。条件空填的多是这类符号。
- **循环三段式**：`for(初值; 条件; 步进)`，`for(i=1; i<j; i++)` 是 i 从 1 走到 j−1。`<` 还是 `<=` 是最常见的边界。
- **递归调用**：函数调自己。看两处：**出口**（某个 `if` 里直接 `return` 常量，不再往下调）和**递推**（自调用那一行，参数比当前小一步）。
- **取值与地址**：`&a` 取地址，`*p` 取 p 所指的值，`p->next` 取 p 所指结构里名为 `next` 的成员（链表、二叉树靠它走），`malloc` 申请内存、`free` 归还；`abs(x)` 取绝对值。

## 三、问题 2：认策略、判方向、判复杂度

**两个术语**：**最优子结构**＝大问题的最优解由小问题各自的最优解拼成（装 5 件的最优装法＝"装/不装第 5 件"两种选择各配上前 4 件的最优装法，取大者）；**递归式**＝把这句话写成的公式，等号右边又出现左边那个量自己（如 `c[i][T]` 右边是 `c[i-1][…]`）。

**关键词速查**（培训资料归纳，非穷举）：

| 说明里出现的问题 / 措辞 | 策略 |
|---|---|
| 0-1 背包（最优子结构性质、递归式） | 动态规划法 |
| RNA 二级结构最优配对（C(i,j) 递归定义） | 动态规划法 |
| 钢条切割（rn = max{1≤i≤n}(pi + rn-i)，自顶向下和自底向上） | 动态规划法 |
| n 皇后（尝试摆放、有冲突则考虑下一列、回溯到上一个皇后）；迷宫 | 回溯法 |
| 假币问题（n 枚硬币分成相等的两部分，用天平称） | 分治法 |
| 集装箱装载（最先适宜 firstfit / 最优适宜 bestfit） | 贪心法：求最优，但没有最优子结构、递归等 |

**四种策略各一句**：

| 策略 | 是什么 | 识别特征 |
|---|---|---|
| 动态规划法 | 拆成子问题，**每个子问题的答案记下来不重算** | 最优子结构、递归式、最优公式 |
| 回溯法 | 试一步，走不通退回上一步换个选择再试 | "回溯""有冲突则考虑下一个" |
| 分治法 | 把问题劈成几部分，各自求解再合并 | "分成两部分""分而治之" |
| 贪心法 | 每步只挑当下最好的，选了不反悔 | "考虑当前情况下"＝局部最优 |

对不上表时按这句口诀判：分而治之是分治法；迷宫问题回溯法；给出"考虑当前情况下"等词是局部最优（贪心）；给出"最优子结构"、递归、最优公式是动态规划法。

**自顶向下 vs 自底向上**（动态规划的实现方向）：

- 判据｜看**第一次调用/第一次计算**的是最大的子问题还是最小的：先大后小＝自顶向下（递归 + 备忘），先小后大＝自底向上（循环逐格填表）。
- 例子｜先用循环把整张表置 −1、再调 `f(n, T)` 往下递归——那个循环一个值都没算，只是标记"未算过"，属自顶向下；函数名带 memoized（带备忘的）同义。若循环体里直接写 `c[i][j] = max(c[i-1][…]+…, c[i-1][j])` 从 i=1 往上填，才是自底向上。

**时间复杂度**：看 for 循环**嵌套的重数**（不是个数）和**每层的循环次数**，逐层抄下上界再相乘；涉及二分必有 O(log n)。

```c
for(x=0; x<=m; x++)
  for(y=0; y<=m; y++)
    for(k=1; k<=n; k++) …     /* m·m·n → O(m²n)，不是 O(n³) */
```

- 三层上界都随 n 走（如 `k`、`i`、`t` 三层都到 n）才是 O(n³)。
- 同一层里先后两段循环是**相加**不是相乘：两段各 O(m²n)，合计仍 O(m²n)。
- 只有一层 `for(j=1; j<=n; j++)`，循环体里只有 `if` 没有别的循环 → O(n)，`if` 不加阶。

## 四、问题 3：给定输入求输出

只拿说明里的算法原理/递归式手推，不碰代码。关键是**系统穷尽**，不随手试几个组合：

1. **求最优值**（背包类）：按某个变量劈成两支——"最后那件装不装"——每支再在剩余容量里取最好，两支取大。
   例：容量 5，（价值, 重量）为 (3,2)(4,3)(5,4)。装第 3 件剩容量 1，别的都放不下，得 5；不装，前两件重 2+3=5 恰好装满，得 7；取 7。
2. **求方案数并列出**（回溯类）：按行/按步逐个试，冲突就试下一个，整步都不行就退回上一步。n 皇后按第 1 行放哪列分 n 支走；解成对出现、互为左右镜像（逐位用 n+1 减），可用来自查。
3. **递推数列**（如"以 a[j] 结尾的最大子段和" b[j]）：从 j=1 起照递归式逐项写出 b 的值，再按说明取最大者。

说明原理十分复杂、推不动时放弃本问，保问题 2。

## 五、问题 1：代码填空

**先后**：每个空的推导成本不同，先做便宜的——

| 空的类型 | 成本 | 做法 |
|---|---|---|
| 返回一个常量 | 最低 | 读注释和前面的 `return` 分支 |
| 注释旁边的空 | 低 | 注释就是答案，照已有调用改参数 |
| 函数里已有同款写法 | 中 | 照抄，改一两处 |
| 从递归式翻译出条件 | 高 | 逐项对照说明里的递归式 |

**四个局部动作**（从循环边界、递推式、边界条件、返回值下手）：

1. **读注释 / 看返回值**。例：
   ```c
   /* 合法返回 1，否则返回 0 */
   for(…){ if(违规) return 0; }
   return ___;        /* 走完循环只剩"合法" → 1 */
   ```
   写 `1`，不写 `true`（没有 `#include <stdbool.h>` 时 `true` 未定义）。
2. **对齐上下文**：函数末尾或同类分支里已出现的表达式，空里多半就是它，照抄改一两处。例：
   ```c
   if(memo[n] != -1) return ___;      /* 末尾是 return memo[n]; → memo[n] */
   memo[n] = fib(n-1) + ___;          /* 照左项改参数 → fib(n-2) */
   ```
3. **对照递推式**：条件、赋值照抄说明递归式的写法。先排除前面分支已挑走的情况（`if(i==0||j==0)` 之后的 `else` 里 i、j 必不为 0，再写 `i>0` 属多写）；"算出另一条路的值再比较"的结构，比较成立后填的就是替换：`if(best<t) best=t;`。
4. **看边界与下标**：
   - 边界｜比较时问一句"两边相等算不算"。例：容量够不够写 `j>=w[i]`；写成 `j>w[i]` 会漏掉"正好装满"的方案，上节背包例的最优解 7 就是恰好装满。
   - 下标｜**刚被赋值的那个变量**才是这一步要处理的对象；同一字母在不同函数里可能换身份。例：`a[k] = x; if(check(___))` 填 `k`，不是 `x`。
   - 条件缺一半｜`||` 一边已写了一种情况，另一边就是说明列出的其余情况中尚未被排除的那种。如 n 皇后冲突有同行、同列、同斜线三种：同行已由"第 i 个放第 i 行"排除；同列是列号相等；同斜线是列差的绝对值等于行差。

**写法要点**：

- 空里填**能直接替换进去的代码片段**，不写解释文字（"这里判断容量够不够"不得分）。
- 只用当前作用域里有的变量；填完把整行连上下文默读一遍，确认能编译。
- 按语义判等价：`j>=w[i]` 与 `w[i]<=j`、`Place(j)` 与 `Place(j)==1` 都行；但整表达式的空（递归调用）函数名、参数个数与顺序必须对。
- 条件等价时也照抄递归式原样（递归式写 `b[j-1] > 0` 就写 `b>0`，不改成 `b>=1`）。

- 25 分钟到、或一个空 3 分钟没头绪，就翻页检查别的题。

- 按点给分，空着必 0 分；整行写不出也写半行（写出形状对的递归调用可能踩到部分点）。
- 答法：策略写名称（"动态规划法""回溯法"），加问方向写"自顶向下/自底向上"；复杂度写 `O(…)`；给输入求输出只写结果数值，不附过程；要求列方案的，**所有方案都写出**，按位列出如 `(2,4,1,3)` 即可。

## 速记

- 顺序倒着做：判策略 → 手推 → 最后填空；先读变量说明，再看代码结构
- 策略：最优子结构/递归式＝动态规划，走不通退回＝回溯，分成两部分＝分治，只看当下＝贪心
- 方向：第一次算的是最大子问题＝自顶向下（备忘），最小＝自底向上（填表）
- 复杂度：逐层抄上界相乘；嵌套才乘，并列相加；二分出 O(log n)
- 填空四动作：读注释、对齐上下文、对照递推式、看边界与下标
- 相等算不算（`>=` 非 `>`）；刚赋值的那个下标才是处理对象
- 空着必 0，写半行也交；25 分钟或卡 3 分钟就翻页
