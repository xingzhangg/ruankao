## 第 1 层 · 理解

### 一句话

> 这一章讲的是"**攒内存条**"：手里只有一堆小容量存储芯片，要拼出一块指定容量、指定位宽的主存——**拼多少片、怎么摆、每片管哪一段地址、该挑哪种料**。

### 痛点：三个"想当然"，每一个都是标准干扰项

你平时看到的内存，是 `malloc` 返回的一个指针指向的、连续平坦的地址空间。硬件上它其实是几十片芯片焊在板子上。凭直觉拍脑袋，会稳定踩这三个坑：

- **想当然一**："16K×8 位，用 1K 的片子，那不就是 16K÷1K = 16 片？"
  → **漏了位宽这一维**。芯片是 1K×**4** 位，只有 4 位宽，还得两片并排才凑够 8 位 —— 实际 **32 片**。
- **想当然二**："4K 的芯片从 A000H 开始，那结束地址就是 A000H+1000H = B000H。"
  → **漏了减 1**。B000H 已经是**下一片的地盘**了，本片最后一个地址是 **AFFFH**。
- **想当然三**："4000H 减 1 是 3999H。"
  → 用十进制的借位习惯做十六进制。**十六进制顶格是 F 不是 9**，正确是 **3FFFH**；3999H = 14745，和 4000H = 16384 差了 **1639**，根本不是前一个数——考试专门设这个干扰项。

### 一条主线

```
手里只有小芯片（比如 1K×4 位），要装一块 16K×8 位的主存
   ↓
【问题1】芯片不够大 —— 但"不够"分两个维度，可能同时缺：
      位宽不够（只有 4 位，要 8 位）  → 横着【并排】拼，同一地址每片各出几位 = 位扩展
      字数不够（只有 1K，要 16K）    → 竖着【摞层】，用地址高位译码选层 = 字扩展
   ↓ 两个方向的倍数一乘，就是总片数
   ↓ （也可以从"总容量 ÷ 单片容量"另一条路算——两条路互为验算）
   ↓
【问题2】拼完了，CPU 甩出一个地址，该由哪一片响应？
      → 必须把地址空间切成一段一段，每片认领一段
      → 一段的边界怎么算：终止地址 = 起始地址 + 容量 − 1
                          （N 个地址占 "起址 ~ 起址+N−1"，从 0 号住起的 8 户，最后是 7 号）
      → 地址一律写十六进制，于是被迫先会两件基本功：
            ① 容量（2 的幂）↔ 十六进制换算
            ② 十六进制减 1 的借位（0 变 F，不变 9）
   ↓ 本课全部算错的地方就集中在这两件基本功上
   ↓
【问题3】拼这块存储，该用哪种芯片？—— 因为需求本来就有两类：
      运行中要反复读写、断电不必保留（程序、变量）→ 要"快、能改" → RAM（易失）
             触发器存数据、不用刷新、快而贵 → SRAM → 拿去做 Cache
             电容存数据、漏电要刷新、慢而便宜密度高 → DRAM → 拿去做主存
      断电后必须还在（开机固件）              → 要"非易失"   → ROM
             按"能不能重写、怎么擦"一路演进：
             掩模ROM → PROM → EPROM → EEPROM → Flash
```

**一句话收束**：**拼多少片（问题1）→ 每片管哪段地址（问题2）→ 用什么料拼（问题3）**。三块内容看着互不相干，其实是"攒一块主存"这**同一件事的三个连续步骤**。

## 第 2 层 · 考点：考试怎么问

### 考点① RAM / ROM 与 SRAM / DRAM 辨析（真题证据最充分，送分题）

**题目长相**：
- "断电后存储内容会丢失的存储器是（ ）　A. ROM　B. RAM　C. Flash　D. EEPROM"
- "关于 SRAM 和 DRAM，描述**正确/错误**的是（ ）"（四个选项互换属性）

**怎么解**——把两张分类记死，一读选项就能对号：

| | 能否写 | 断电 | 存储元件 | 要刷新吗 | 速度/价格 | 典型用途 |
|---|---|---|---|---|---|---|
| **SRAM**（静态 RAM） | 可读可写 | **丢失**（易失） | **触发器** | **不用刷新** | 快、贵、密度低 | **Cache** |
| **DRAM**（动态 RAM） | 可读可写 | **丢失**（易失） | **电容** | **需定期刷新** | 慢、便宜、密度高 | **主存** |
| **ROM** 系列 | 以读为主 | **不丢**（非易失） | — | — | — | 开机固件、U盘/SSD |

**ROM 家族的演进主线**（按"能不能重写、拿什么擦"排）：

```
掩模 ROM （出厂时就固化，永远改不了）
   ↓ 想让用户自己写一次
PROM     （一次性可编程，写完不能改）
   ↓ 想能反复改
EPROM    （紫外线照射擦除，可重复编程；要拆下来照，麻烦）
   ↓ 想不拆机就能擦
EEPROM   （电可擦除，按字节擦）
   ↓ 想更快更大更便宜
Flash 闪存（按块擦除 —— U 盘、SSD、手机存储）
```

**陷阱**：
- ⚠️ **属性对调**：最常见的错项是"SRAM 需要定期刷新、DRAM 不需要"，或"DRAM 速度比 SRAM 快，常用作 Cache"——**全部反了**。
- ⚠️ **把 Flash / EEPROM 划进易失**：它俩姓 ROM，**断电不丢**。问"断电会丢"只能选 RAM。
- ⚠️ **"ROM 完全不能写"**：EEPROM、Flash 都能写，ROM 的定性是**非易失 + 以读为主**，不是"物理上写不了"。

### 考点② 地址范围计算（本课最容易算错的地方）

**题目长相**："某芯片容量为 4K×8 位，起始地址为 3000H，则该芯片的终止地址是（ ）　A. 3FFFH　B. 4000H　C. 37FFH　D. 33FFH"

**怎么解**——固定三步：

```
第 1 步：把位宽扔掉。 "×8 位" 只说明每个地址存 8 位，
        不影响【地址个数】，算地址范围时完全不参与。
第 2 步：容量转十六进制。 4K = 2¹² = 1000H
第 3 步：起址 + 容量 − 1。 3000H + 1000H = 4000H，再 − 1 = 3FFFH
```

**支撑基本功㈠：H 只是标签，不是数字**（2026-08-12 重讲补充）
`800H` 里的 H 是 Hexadecimal 的首字母，意思是"前面这串按十六进制读"，**等价于代码里的 `0x800`**，只是标记位置不同（一个在后一个在前）。**H 不参与任何运算**，作用类似单位。

**支撑基本功㈡：数位 × 权重 —— 为什么 800H = 2048**
任何进位制都是"每个数位有权重，逐位乘权重再相加"。十进制权重是 10 的幂，十六进制权重是 16 的幂（数字表 `0–9 A–F`，注意 **F=15 才是顶格，A 只是 10**）：

```
十六进制 800H：
  位:      8      0      0
  权重:   16²    16¹    16⁰
        (256)   (16)    (1)
  值 = 8×256 + 0 + 0 = 2048 = 2K ✓
```

**支撑基本功㈢：2 的幂转十六进制 —— 二进制分组"笨方法"（必会）**

1. 2ⁿ 的二进制就是"**1 后面跟 n 个 0**"（同十进制 10³=1000）
2. **从右往左每 4 位划一组**（因为 16=2⁴，1 个十六进制位恰好装 4 个二进制位）
3. 每组翻译成 1 个十六进制位

```
4K = 2¹²：1 0000 0000 0000 → 1|0000|0000|0000 → 1000H
2K = 2¹¹：1000 0000 0000  → 1000|0000|0000  → 800H
          （11 不整除 4，多出的 0 和开头的 1 挤同一组，1000b = 8）
```

考场速查表：**背 1K = 400H，逐行翻倍**（十六进制里 4→8→10→20→40→80，逢 16 进位）：

| 容量 | 2 的幂 | 十六进制 |
|---|---|---|
| 1K | 2¹⁰ | 400H |
| 2K | 2¹¹ | 800H |
| 4K | 2¹² | 1000H |
| 8K | 2¹³ | 2000H |
| 16K | 2¹⁴ | 4000H |
| 32K | 2¹⁵ | 8000H |
| 64K | 2¹⁶ | 10000H |

**支撑基本功㈣：减 1 的借位 —— 0 变 F，不变 9**
减 1 借位时，0 要变成**该进制的最大数字**：十进制变 9（4000−1=3999），十六进制变 **F**（4000H−1=**3FFF**H），二进制变 1（1000b−1=0111b）。

**陷阱**：
- ⚠️ **忘了减 1** → 答成 4000H。这是本考点的头号错因（本讲义的三道地址题里，"忘减 1"的那个值都被摆在 B 选项上，可对照文末 R1/R2 与练习 2 自查）。记住：4000H 是**下一片的起始地址**，不是本片的末地址。
- ⚠️ **借位补 9 不补 F** → 答成 3999H。反例警示：3999H = 14745，4000H = 16384，**差 1639**，根本不相邻。
- ⚠️ **把位宽也乘进容量** → 把 4K×8 当成 32K 去转十六进制。位宽不影响地址个数，**直接扔掉**。

> 自查技巧（平时练习用，考场没有终端）：`printf '%X\n' $((0x3000 + 0x1000 - 1))` 即可验算。

### 考点③ 字位扩展片数计算

**题目长相**："用 1K×4 位的存储芯片，组成 8K×8 位的存储器，共需要多少片？"（有时还追问字扩展几层、位扩展几片）

**怎么解**——两条路，互为验算：

```
【路线A · 总账】
总容量(bit)   = 目标字数 × 目标位宽
单片容量(bit) = 单片字数 × 单片位宽
总片数        = 总容量 ÷ 单片容量

【路线B · 分维度】
字扩展倍数 = 目标字数 ÷ 单片字数   （摞几层，用地址高位译码选层）
位扩展倍数 = 目标位宽 ÷ 单片位宽   （每层几片并排，同一地址各出几位）
总片数     = 字扩展倍数 × 位扩展倍数

验算：路线A 与 路线B 结果必须相等
```

**记忆抓手（书架类比）**：
- **位扩展 = 拼宽度**：书架每格能放的书太薄（单片位宽不够），把几个书架**横着并排**，同一地址在每个书架里各出一部分位，拼成完整的字。
- **字扩展 = 拼数量**：书架格子数（地址数）不够，把几个书架**竖着摞起来**，用地址高位当"选哪一层"的开关（**片选/译码**），每层内部地址不变。

**陷阱**：
- ⚠️ **只做字扩展、忘了位扩展**（16K÷1K=16 片）——这是本考点第一大错因。**先看位宽够不够，再看字数够不够。**
- ⚠️ **单位混乱**：算总账时两边都必须换成 bit（1K×4 位 = 4K bit，不是 4K 字节）。
- ⚠️ **把"倍数"当成"片数"**：字扩展 16 只是层数，还要乘以位扩展倍数才是总片数。

## 第 3 层 · 完整算例

### 算例一：字位扩展（拼多少片、怎么摆）

> 用 1K×4 位的芯片，拼出 16K×8 位的存储器，需要多少片？怎么摆？

```
第1步 算总容量：   16K × 8 = 128K bit          （目标字数 × 目标位宽）
第2步 算单片容量：  1K × 4 = 4K bit            （单片字数 × 单片位宽）
第3步 总片数：     128K ÷ 4K = 32 片           （路线A）

第4步 字扩展倍数： 16K ÷ 1K = 16   → 摞 16 层  （字数从 1K 补到 16K）
第5步 位扩展倍数：  8 ÷ 4   = 2    → 每层 2 片并排（位宽从 4 补到 8）

验算：16 × 2 = 32 片 ✓ 与路线A一致
摆法：2 片并排凑成 1K×8 位的"一层"，这样的层摞 16 层，
      地址低位在层内寻址，地址高位送译码器选层。
```

### 算例二：地址范围（每片管哪一段）

> 某芯片容量 4K×8 位，起始地址 A000H，求终止地址。

```
第1步 扔掉位宽：  "×8 位" 不影响地址个数 → 只关心 4K 个地址
第2步 容量转十六进制： 4K = 2¹² = 1 0000 0000 0000b → 1|0000|0000|0000 → 1000H
第3步 起址 + 容量：   A000H + 1000H = B000H
第4步 减 1（借位补 F 不补 9）： B000H − 1 = AFFFH
                      （末位 0 借位变 F，连借三位：000 → FFF，B 减 1 变 A）

结论：该片占用 A000H ~ AFFFH，共 4K 个地址；B000H 属于下一片。
验算：printf '%X\n' $((0xA000 + 0x1000 - 1))  →  AFFF ✓
```

## 第 4 层 · 速记

> **【拼片】** 字扩展摞层数、位扩展拼宽度，**倍数相乘 = 总片数**
> 总容量 = 字数×位宽；总片数 = 总容量 ÷ 单片容量（与倍数相乘互为验算）
> **【地址】** **终止地址 = 起始地址 + 容量 − 1**（位宽不参与）
> **1K = 400H，翻倍往下推**：2K=800H、4K=1000H、8K=2000H、16K=4000H、32K=8000H、64K=10000H
> **减 1 借位补 F 不补 9**（十六进制顶格是 F）；**忘减 1 = 掉进干扰项**
> H 只是标签，`800H` = `0x800`，不参与运算
> **【选料】** RAM 断电就忘（易失）；ROM 断电不忘（非易失，含 EEPROM/Flash）
> 静态 SRAM 用触发器、**不用"刷新"所以"静"** → Cache
> 动态 DRAM 用电容漏电、**必须不断"刷新"所以"动"** → 主存
> ROM 演进：掩模 → PROM → EPROM(紫外擦) → EEPROM(电擦) → Flash

## 考题回顾

> 以下为 2026-08-12 地址计算专项重讲后的追加重练题（已讲评）。

**R1.【模拟】** 某存储芯片容量为 4K×8 位，起始地址为 3000H，其终止地址是（ ）
A. 3FFFH　B. 4000H　C. 37FFH　D. 33FFH
**解**：**A**。4K = 1000H；3000H + 1000H − 1 = 4000H − 1 = **3FFFH**。
B 是**忘减 1**的干扰项（4000H 是下一片起址）；C、D 都是**容量换算错**——C 把 4K 当成了 800H（那是 2K），D 把 4K 当成了 400H（那是 1K）。

**R2.【模拟】** 某存储芯片容量为 8K×8 位，起始地址为 6000H，其终止地址是（ ）
A. 7FFFH　B. 8000H　C. 7999H　D. 67FFH
**解**：**A**。8K = 2000H；6000H + 2000H − 1 = 8000H − 1 = **7FFFH**。
C 正是**"借位补 9"**的典型错误（7999H = 31129，与 8000H = 32768 差 1639，根本不相邻）；B 忘减 1；D 把 8K 错当 800H（那是 2K）。

## 自测练习

1. 【模拟】用 1K×4 位的存储芯片，组成 8K×8 位的存储器，共需要多少片芯片？（并说明字扩展几层、位扩展几片）
2. 【模拟】某芯片的容量为 2K×8 位，起始地址为 2000H，则该芯片的终止地址是（ ）
   A. 27FFH　B. 2800H　C. 21FFH　D. 2FFFH
3. 【模拟】断电后存储内容会丢失的存储器是（ ）
   A. ROM　B. RAM　C. Flash　D. EEPROM
4. 【模拟】关于 SRAM 和 DRAM，描述正确的是（ ）
   A. SRAM 需要定期刷新，DRAM 不需要
   B. DRAM 速度比 SRAM 快，常用作 Cache
   C. SRAM 不需要刷新、速度快，常用作 Cache；DRAM 需要定期刷新，常用作主存
   D. SRAM 和 DRAM 都是非易失性存储器

### 参考答案

1. **16 片**。总容量 8K×8 = 64K bit，单片 1K×4 = 4K bit，64K ÷ 4K = **16 片**；分维度看：字扩展 8K÷1K = **8 层**，位扩展 8÷4 = **2 片并排**，8×2 = 16 ✓ 两条路一致。
2. **A**。2K = 800H；2000H + 800H − 1 = 2800H − 1 = **27FFH**。**B 是漏减 1 的干扰项**。
3. **B**。RAM（含 SRAM/DRAM）易失；ROM、Flash、EEPROM 均属**非易失**家族。
4. **C**。静态不刷新、快 → Cache；动态需刷新、便宜密度高 → 主存。A 属性对调；B 属性对调；D 错在 RAM 都是**易失**的。
