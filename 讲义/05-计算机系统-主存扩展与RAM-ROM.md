# 05 · 计算机系统：主存扩展与地址计算 + RAM/ROM 分类

## 定位

用小芯片拼出指定容量的主存：占哪一段地址、要几片、配几根线、用哪种料。全课跟着一个任务走：**用 2K×4 位的芯片拼一块 16K×8 位的主存，从地址 2000H 开始**。前五节动笔算，第六节认料。承接 04（主存在存储层次中的位置）；"容量 ↔ 十六进制 ↔ 地址范围"是 38 分页地址计算的前置。

---

## 一、芯片规格怎么读

| 术语 | 含义 |
|---|---|
| **存储单元** | 内存里能被单独点名的一个格子 |
| **地址 / 编址** | 格子的编号 / 给格子分配编号 |
| **2K×4 位** | 乘号前＝格子数（字数），乘号后＝每格位宽：2K 个格子，每格 4 位 |
| **K、M、G** | 数量单位，存储器里每级差 1024（1K = 1024，1M = 1024K） |
| **b、B** | 存储单位，b＝bit 位，B＝Byte 字节，**1B = 8b** |
| **按字节编址** | 一个地址对应一个字节（每格 8 位），最常见 |
| **按字编址** | 一个地址对应一个字，字长另给（如按 16 位字编址，一个地址管 16 位） |

2K×4 位 = 2048 × 4 = 8192 bit = **1KB**。

**算地址时位宽完全不参与。** 2K×4 位和 2K×8 位格子一样多（都是 2K 个），占的地址段一样长；位宽只在算总 bit 数、片数时登场。

## 二、一段地址的起止（计算）

**问题**：一层 2K×8 位（两片 2K×4 位并排，见第四节）从 2000H 开始，末地址是多少？

**基本功**

- **H 是标签不是数字**：`800H` 即代码里的 `0x800`，运算时忽略，算完写回：`800H + 1 = 801H`。
- **数位 × 权重**：十六进制权重是 16 的幂，数字 `0–9 A–F`（F=15 顶格，A=10）。
  ```
  800H = 8×16² + 0×16¹ + 0×16⁰ = 8×256 = 2048 = 2K
  ```
- **2ⁿ 转十六进制——二进制分组**：2ⁿ 的二进制是 1 后跟 n 个 0；16 = 2⁴，从右往左每 4 位一组翻成一个十六进制数字，最左不足 4 位前面补 0：
  ```
  2K  = 2¹¹ → 100000000000     → 1000|0000|0000      → 800H
  16K = 2¹⁴ → 100000000000000  → 0100|0000|0000|0000 → 4000H
  ```

**算例**

1. 地址从 2000H 起一格一个号，共发 2048 个号。0 号起的 8 户门牌是 0–7，所以末址 = 起址 + 2048 − 1。
2. 2K = 800H，2000H + 800H = 2800H。
3. 2800H − 1：末位 0 借位变 F，前一位 0 借位变 F，8 变 7 → **27FFH**。
4. 验算：27FFH = 10239，2000H = 8192，10239 − 8192 + 1 = 2048 ✓

**借位规则**：减 1 借位时 0 变成**该进制的最大数字**——十进制 4000 − 1 = 3999，二进制 1000b − 1 = 0111b，**十六进制 4000H − 1 = 3FFFH**。写成 3999H 是把十进制的 9 带进来了：3999H = 14745，4000H = 16384，差 1639，根本不相邻。

> **终止地址 = 起始地址 + 容量 − 1**（容量＝地址个数，位宽不参与）
> **地址个数 = 终止地址 − 起始地址 + 1**（+1 就是"0 到 7 号住 8 户"）

**第二个算例：整块 16K×8 位**

```
16K = 2¹⁴ = 4000H
终止 = 2000H + 4000H − 1 = 6000H − 1 = 5FFFH   （三个 0 借位变 F，6 变 5；5999H = 22937，同样差 1639）
整块主存：2000H ~ 5FFFH
验算：5FFFH − 2000H + 1 = 4000H = 16384 = 16K ✓
```

16K 由 8 层 2K 摞成，每层地盘连着往下切：

| 层 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| 起址 | 2000H | 2800H | 3000H | 3800H | 4000H | 4800H | 5000H | 5800H |
| 末址 | 27FFH | 2FFFH | 37FFH | 3FFFH | 47FFH | 4FFFH | 57FFH | 5FFFH |

接缝处：**2800H 是下一层的起址，不是上一层的末址**；漏掉 −1 得到的正是下一层起址。

**2ⁿ ↔ 十六进制对照**（从 1K = 400H 起逐行翻倍，4→8→10→20→40→80，逢 16 进位）：

| 容量 | 1K | 2K | 4K | 8K | 16K | 32K | 64K | 128K | 256K | 1M |
|---|---|---|---|---|---|---|---|---|---|---|
| 2 的幂 | 2¹⁰ | 2¹¹ | 2¹² | 2¹³ | 2¹⁴ | 2¹⁵ | 2¹⁶ | 2¹⁷ | 2¹⁸ | 2²⁰ |
| 十六进制 | 400H | 800H | 1000H | 2000H | 4000H | 8000H | 10000H | 20000H | 40000H | 100000H |

## 三、给地址段求容量（计算）

**算例**：地址 80000H ~ BFFFFH，按字节编址，容量多少 KB？

1. 按位相减：BFFFFH − 80000H = 3FFFFH（B−8=3，F−0=F，不借位）。
2. 地址个数 = 3FFFFH + 1 = 40000H。
3. 40000H = `0100|0000|0000|0000|0000`b = 2¹⁸ = 2⁸ × 2¹⁰ = 256K 个单元（硬算：4×16⁴ = 4×65536 = 262144）。
4. 按字节编址，每单元 1B → **256KB**。

培训资料原话：**不要硬算，要化简为 2 的幂指数来算**——认出 40000H = 2¹⁸ 比乘 65536 快且不易错。

## 四、要几片：位扩展、字扩展（计算）

| 扩展 | 解决什么 | 做法 | 接线 |
|---|---|---|---|
| **位扩展** | 位宽不够（有 4 位要 8 位） | 两片**横着并排**，同一地址同时送两片，一片出高 4 位、一片出低 4 位 | 地址线、片选线、读写控制线全部并联；只有数据线分开接到数据总线不同位 |
| **字扩展** | 格子数不够（有 2K 要 16K） | 多组**竖着摞**，每组管一段地址 | 低位地址线、数据线并联；高位地址送**译码器**产生**片选信号**，同一时刻只有一组响应 |
| **字位同时扩展** | 两个维度都缺 | 先位扩展凑成一层，再把层摞起来 | — |

**译码器**：把 n 位输入翻成 2ⁿ 根输出线、每次只让一根有效的电路。**片选信号**：告诉某一组"你被选中了，其余别应答"。

**算例**：2K×4 位拼 16K×8 位

```
【分维度】位扩展倍数 = 8 ÷ 4 = 2      → 每层 2 片并排
          字扩展倍数 = 16K ÷ 2K = 8   → 摞 8 层
          总片数 = 2 × 8 = 16 片
【总账】  目标 16K×8 = 128K bit；单片 2K×4 = 8K bit；128K ÷ 8K = 16 片 ✓
```

> **总片数 = (目标字数 ÷ 单片字数) × (目标位宽 ÷ 单片位宽) = 目标总 bit ÷ 单片 bit**

两条路是同一个除法的两种拆法，必须对得上；对不上说明单位混了。全程统一用 bit 或统一用 B，不要中途换。

**第二个算例**：第三节的 256KB 内存，用 16K×4bit 芯片

```
【分维度】字扩展 256K ÷ 16K = 16 层；位扩展 8 ÷ 4 = 2 片 → 16 × 2 = 32 片
【总账】  256K×8 = 2048K bit；16K×4 = 64K bit → 2048K ÷ 64K = 32 片 ✓
【按字节】16K×4bit = 16K×0.5B = 8KB；256KB ÷ 8KB = 32 片 ✓（培训资料的算法）
```

## 五、地址线与数据线（计算）

**地址线**：CPU 说明"访问哪一格"的线，n 根能点名 2ⁿ 个格子。**数据线**：搬运内容的线，一次搬几位就几根。

```
整块 16K×8 位：16K = 2¹⁴ → 地址线 14 根；位宽 8 → 数据线 8 根
单片 2K×4 位： 2K = 2¹¹  → 地址线 11 根；位宽 4 → 数据线 4 根
```

> **地址线条数 = log₂(存储单元数)，数据线条数 = 位宽**

与字扩展互验：14 根里低 11 根接到每片做**片内寻址**，高 14 − 11 = **3 根**进译码器，2³ = **8** 种组合正好选 8 层。片内低位 + 片选高位 = 总地址线。

## 六、用哪种料：RAM 与 ROM（概念）

（培训资料未收录，按《软件设计师教程》第 5 版补。）

| 特征 / 关键词 | 是什么 |
|---|---|
| 可读可写，**断电丢失（易失性）**，装正在运行的程序和数据 | **RAM**（Random Access Memory，随机存取存储器） |
| "随机"＝访问任意地址耗时相同；相对的是**顺序存取**（磁带，读后面须先卷过前面） | 随机存取 |
| **触发器**记一位（常见 6 管），不断电就保持，**不刷新**；快、贵、功耗大、集成度低 | **SRAM**（静态）→ **Cache** |
| **1 电容 + 1 晶体管**记一位，电容漏电须周期性读出再写回（**刷新**）；慢、需刷新电路、便宜、集成度高 | **DRAM**（动态）→ **主存** |
| **断电不丢（非易失）**，存开机固件；也按地址随机存取，"只读"指正常运行时的使用方式 | **ROM**（Read Only Memory） |

**DRAM 三种刷新**（刷新周期传统教科书常写约 2ms）：

| 方式 | 做法 | 代价 |
|---|---|---|
| **集中刷新** | 每个刷新周期里集中一段时间把所有行刷完 | 这段时间不能访存，称"死时间" |
| **分散刷新** | 每个存取周期拆两半，前半读写、后半刷一行 | 无死时间，但每次访存变慢 |
| **异步刷新** | 刷新周期 ÷ 行数得间隔，每隔这么久刷一行 | 兼顾两者 |

**ROM 家族**：演进主线是擦写越来越方便、越来越便宜，每代补上一代短板。

| 类型 | 写入 / 擦除 | 短板 |
|---|---|---|
| **掩模 ROM（MROM）** | 制版时做进电路，出厂定死，用户不可改；大批量极便宜 | 写错整批报废，小批量不划算 |
| **PROM**（可编程） | 空白片，编程器烧断熔丝，**只能写一次** | 烧错即废 |
| **EPROM**（可擦除可编程） | 石英窗口 + **紫外线**照几十分钟，**整片擦除**，可重烧 | 须拔下芯片、专用紫外灯、只能整片擦 |
| **EEPROM / E²PROM**（电可擦除） | **加电压**擦除，不拆机，**按字节**擦写 | 擦写慢、单位容量贵、做不大 |
| **Flash 闪存** | 电擦除，**按块（扇区）**擦除，省掉逐字节擦除电路 → 更便宜、密度更高、擦写更快 | —；用于 U 盘、SSD、手机存储、主板 BIOS |

原话｜闪存的特性介于 EPROM 和 EEPROM 之间。

**易混对**

- **SRAM vs DRAM**
  判据｜要不要刷新：触发器不用（静态），电容漏电要刷（动态）。
  例子｜Cache 用 SRAM；把"要大、要省"的主存换成 SRAM 就贵到做不起，所以主存用 DRAM。
- **RAM vs Flash / EEPROM**
  判据｜看断电后内容在不在：RAM 易失，EEPROM、Flash 属 ROM 家族、非易失。
  例子｜U 盘拔下来数据还在（Flash）；关机后内存里的程序没了（DRAM）。
- **"ROM 只读" vs "ROM 不能写"**
  判据｜ROM 的定性是非易失 + 以读为主；EEPROM 按字节写、Flash 按块写。
  例子｜主板 BIOS 存在 Flash 里，可以刷写固件升级。
- **EPROM vs EEPROM vs Flash**
  判据｜擦除手段和粒度：紫外线整片 / 电擦按字节 / 电擦按块。
  例子｜须拆下芯片照紫外灯的是 EPROM；改成通电擦除、按字节改就是 EEPROM。

回到任务：第四节算出 16 片，第五节配 14 根地址线、8 根数据线，本节决定这 16 片用 DRAM；存开机固件的 Flash 不在这 16 片里。

## 速记

- 规格 `字数 × 位宽`；**算地址只看字数，位宽扔掉**；K/M/G 每级 ×1024，1B = 8b
- **终止地址 = 起址 + 容量 − 1**；**单元数 = 末 − 首 + 1**；漏掉 ±1 就得到下一片起址
- **减 1 借位 0 变 F 不变 9**：4000H − 1 = 3FFFH
- 2ⁿ 转十六进制：1 后跟 n 个 0，从右 4 位一组；或 **1K = 400H 起逐次翻倍**到 1M = 100000H；能化成 2 的幂就别硬乘
- **总片数 = 字数倍数 × 位宽倍数 = 总 bit ÷ 单片 bit**；位扩展并排、字扩展摞层靠高位译码片选
- **地址线 = log₂(单元数)，数据线 = 位宽**；片内低位 + 片选高位 = 总地址线
- **SRAM 触发器不刷新、快贵 → Cache；DRAM 电容要刷新、慢便宜密度高 → 主存**；RAM 易失
- ROM 非易失：**掩模（不可改）→ PROM（一次）→ EPROM（紫外整片）→ EEPROM（电擦按字节）→ Flash（电擦按块）**
