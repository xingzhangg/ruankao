## 定位

**这一课回答**：手里只有小芯片，怎么拼出一块指定容量的主存——要几片、每片管哪一段地址、该拿哪种料来拼。

## 开讲：桌上一堆小芯片，拼一块 16K×8 位的内存

全课跟着同一批器材走：**桌上是一堆 2K×4 位的存储芯片，任务是拼出一块 16K×8 位的主存，装在地址 2000H 开始的位置**。三个问题会依次冒出来——这块内存占哪一段地址、一共要几片、该挑哪种芯片。前两个动笔算，第三个是认料。

### 一、先把"2K×4 位"读懂：哪个数管地址，哪个数不管

**存储单元**就是内存里能被单独点名的一个格子，每个格子有一个编号，这个编号叫**地址**；给每个格子分配地址这件事叫**编址**。"2K×4 位"是芯片的规格写法，**乘号前面是格子数，后面是每格的宽度（位宽）**：这片芯片有 2K 个格子，每个格子装 4 个二进制位。

三个单位先摆清（培训资料原话）：**K、M、G 是数量单位，在存储器里相差 1024 倍**（1K = 1024，1M = 1024K）；**b 和 B 是存储单位，1B = 8b**——小写 b 是 bit 位，大写 B 是 Byte 字节，一个字节 8 位。

所以 2K×4 位 = 2048 × 4 = 8192 bit = **1KB**（8192 ÷ 8 = 1024 字节）。

题目里还会出现**按字节编址**：一个地址对应一个字节，也就是每个格子 8 位。与它相对的是**按字编址**——一个地址对应一个"字"，字长多少位由题目给（比如按 16 位的字编址，一个地址就管 16 位）。考试里绝大多数是按字节编址。

现在是本课最要紧的一句话，后面每道题都要用：

> **算地址的时候，位宽完全不参与。** 2K×4 位和 2K×8 位，格子的宽度不一样，但**格子的个数一样多，都是 2K 个，占的地址段一样长**。位宽只在算"总共多少 bit""要几片"时才登场。

### 二、手算第一段：一片芯片占哪些地址

先把"两片并排拼出更宽的格子"这件事放一放（第五节讲，叫位扩展），假设已经把两片 2K×4 位并排凑成了一"层"2K×8 位，这一层从 **2000H** 开始。

**先别往下看，猜一下：这一层的终止地址是多少？**

不用公式，就数格子。地址从 2000H 开始，一格一个号，2000H、2001H、2002H……一共发 2048 个号。这里有个每次都栽的地方：**从 0 号住起的 8 户人家，门牌是 0 到 7，最后一户是 7 不是 8。**所以末地址不是"起址 + 2048"，是"起址 + 2048 − 1"。

但 2048 是十进制，地址是十六进制，不能直接相加。得先把 2048 换成十六进制，这就要补三件基本功。

**基本功㈠：H 只是个标签，不是数字。** `800H` 的 H 是 Hexadecimal（十六进制）的首字母，意思是"前面这串按十六进制读"，**等价于代码里的 `0x800`**，只是标记写在后面而已。H 本身不是数值的一部分、不参与运算，作用类似单位——算的时候把它当标记忽略，算完再把 H 写回去：`800H + 1 = 801H`。

**基本功㈡：数位 × 权重。** 任何进位制都是"每个数位配一个权重，逐位乘权重再求和"。十进制权重是 10 的幂，十六进制权重是 16 的幂，数字表是 `0–9 A–F`（**F=15 才是顶格，A 只是 10**）：

```
十六进制 800H：
  数位:     8       0      0
  权重:    16²     16¹    16⁰
          (256)   (16)    (1)
  值 = 8×256 + 0×16 + 0×1 = 2048  ✓ 正好是 2K
```

**基本功㈢：2ⁿ 转十六进制的笨方法——二进制分组。** 十进制里 10³ 就是"1 后面跟 3 个 0"；同理 **2ⁿ 的二进制就是"1 后面跟 n 个 0"**。而 16 = 2⁴，**一个十六进制位恰好装下 4 个二进制位**，所以只要**从右往左每 4 位划一组**，每组翻成一个十六进制数字就行（不够 4 位的那一组在最左边，前面补 0 不影响）：

```
2K = 2¹¹ → 1 后跟 11 个 0 → 100000000000
         → 从右每 4 位一组 → 1000|0000|0000 → 8  0  0 → 800H
16K = 2¹⁴ → 100000000000000
         → 100|0000|0000|0000 → 4  0  0  0 → 4000H
         （最左边只剩 3 位 100，补成 0100，就是 4）
```

三件基本功齐了，回到题上：2000H + 800H = **2800H**，还差最后一步减 1。

**又一个先猜：2800H − 1 等于多少？**

这里是本课的头号陷阱。把它换成更露馅的一组：**4000H − 1 等于多少？**很多人第一反应写 **3999H**——那是十进制的借位习惯。查一下就露馅：3999H = 3×4096 + 9×256 + 9×16 + 9 = **14745**，而 4000H = **16384**，两个数差了 **1639**，根本不是前后脚的邻居。

错在哪：**减 1 借位时，0 要变成"该进制的最大数字"**。十进制最大数字是 9，所以 4000 − 1 = 3999；二进制最大是 1，所以 1000b − 1 = 0111b；**十六进制最大是 F，所以 4000H − 1 = 3FFFH**。别把十进制的 9 带进来。

于是 2800H − 1：末位 0 借位变 F，前一位 0 也借位变 F，再前一位 8 减掉那个借位变 7，得 **27FFH**。

```
起始 2000H ── 共 2K(=800H) 个地址 ──→ 终止 27FFH
验算：27FFH = 10239，2000H = 8192，10239 − 8192 + 1 = 2048 = 2K ✓
```

方法从过程里长出来了，写成两条互为逆运算的式子：

> **终止地址 = 起始地址 + 容量 − 1**（容量指地址个数，位宽不参与）
> **地址个数 = 终止地址 − 起始地址 + 1**（那个 +1 就是"住 0 到 7 号的是 8 户"）

### 三、用公式算第二段：整块内存占哪一段（验证）

同一批器材，这回问整块 16K×8 位主存的地址范围。16K = 2¹⁴ = **4000H**（上面刚分组算过）。

```
终止 = 2000H + 4000H − 1 = 6000H − 1
```

**再猜一次：6000H − 1 是多少？**如果脑子里蹦出 5999H，说明借位习惯还没改过来（5999H = 22937，6000H = 24576，同样差 1639）。正确是三个 0 各借位变 F、6 变 5，得 **5FFFH**。

```
整块主存：2000H ~ 5FFFH
验算：5FFFH − 2000H + 1 = 4000H = 16384 = 16K ✓
```

顺便把这块内存内部的分段也摊开——16K 由 8 层 2K 摞成，每层的地盘就是连着往下切：

| 层 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| 起址 | 2000H | 2800H | 3000H | 3800H | 4000H | 4800H | 5000H | 5800H |
| 末址 | 27FFH | 2FFFH | 37FFH | 3FFFH | 47FFH | 4FFFH | 57FFH | 5FFFH |

看第 0 层和第 1 层的接缝：**2800H 是下一层的起始地址，不是上一层的末地址**。考试里"忘了减 1"这个错答，答的正好就是下一片的起址，选项里一定有它等着。

### 四、反过来问：给你一段地址，求容量（培训资料真题）

题目常把上面那条式子倒着用：**地址编号从 80000H 到 BFFFFH、按字节编址，内存容量是多少 KB？**

十六进制减法就按位减，不够再借：

```
  B F F F F H
− 8 0 0 0 0 H
─────────────
  3 F F F F H      （B−8=3，F−0=F，四位都不用借位）

地址个数 = 3FFFFH + 1 = 40000H
40000H = 4×16⁴ = 4×65536 = 262144 = 256K 个存储单元
按字节编址 → 每个单元 1B → 容量 = 256K × 1B = 256KB
```

也可以用分组法反向验：40000H = `0100|0000|0000|0000|0000`b = 2¹⁸，2¹⁸ = 2⁸ × 2¹⁰ = 256K ✓。培训资料在这里专门提醒了一句：**不要硬算，要化简为 2 的幂指数来算**——把 40000H 认成 2¹⁸，比去乘 65536 快得多也不容易错。

### 五、要几片：位扩展、字扩展、字位同时扩展

现在回答第二个问题。手里的芯片是 2K×4 位，目标是 16K×8 位，**两个维度都不够**：

- **位宽不够**：芯片一格只有 4 位，要 8 位。办法是把**两片横着并排**，同一个地址同时送给这两片，一片出高 4 位、一片出低 4 位，拼成完整的 8 位。这叫**位扩展**——接线上是各片的地址线、片选线、读写控制线全部并联（每片收到的地址完全一样），只有数据线分开接到数据总线的不同位上。
- **字数不够**：芯片只有 2K 个格子，要 16K 个。办法是把**八组竖着摞起来**，每组管一段地址，靠地址的高位决定"这次点名点的是第几组"。这叫**字扩展**——接线上是各组的**低位**地址线、数据线并联，剩下的高位地址送进**译码器**（一个把 n 位输入翻译成 2ⁿ 根输出线、每次只让其中一根有效的电路）产生**片选信号**（"你被选中了，其余的别应答"），保证同一时刻只有一组响应。
- 两个方向都缺，就是**字位同时扩展**：先用位扩展凑成一"层"，再把层摞起来做字扩展。

数一数：

```
【分维度算】
位扩展倍数 = 目标位宽 ÷ 单片位宽 = 8 ÷ 4  = 2   → 每层 2 片并排
字扩展倍数 = 目标字数 ÷ 单片字数 = 16K ÷ 2K = 8   → 摞 8 层
总片数 = 2 × 8 = 16 片

【总账算，用来验算】
目标总容量 = 16K × 8 = 128K bit
单片容量   =  2K × 4 =   8K bit
总片数     = 128K ÷ 8K = 16 片  ✓ 两条路一致
```

两条路必须对得上，对不上说明有一步单位混了。公式写出来是同一件事的两种拆法：

> **总片数 = (目标字数 ÷ 单片字数) × (目标位宽 ÷ 单片位宽) = 目标总 bit 数 ÷ 单片 bit 数**

拿上一节那道真题验证公式：256KB 的内存，用 **16K×4bit** 的芯片，要几片？

```
【分维度】字扩展 = 256K ÷ 16K = 16 层；位扩展 = 8 ÷ 4 = 2 片并排 → 16 × 2 = 32 片
【总账】  目标 256K×8 = 2048K bit；单片 16K×4 = 64K bit → 2048K ÷ 64K = 32 片  ✓
【培训资料的算法】单片 16K×4bit = 16K×0.5B = 8KB；256KB ÷ 8KB = 32 片  ✓ 三条路一致
```

第三条是培训资料给的走法：把位宽 4 bit 折成 0.5 B，两边都用字节记，也对。**三种走法算的是同一个除法，选顺手的那种，但别中途换单位**——bit 和 B 混着用是这一题最常见的翻车方式。

### 六、要几根地址线、几根数据线

拼完还有个配套问题：CPU 和这块内存之间要拉多少根线？**地址线**是 CPU 用来说明"我要访问哪一格"的那组线，n 根线能表示 2ⁿ 种不同组合，也就能点名 2ⁿ 个格子；**数据线**是真正搬运内容的线，一次搬几位就要几根。

```
整块 16K×8 位主存：16K = 2¹⁴ 个地址 → 地址线 14 根；每格 8 位 → 数据线 8 根
单片 2K×4 位芯片：  2K = 2¹¹ 个地址 → 地址线 11 根；每格 4 位 → 数据线 4 根
```

> **地址线条数 = log₂(存储单元数)，数据线条数 = 位宽。**

这两个数正好把第五节的字扩展验算了一遍：整块要 14 根地址线，其中低 11 根直接接到每片上做**片内寻址**（在被选中的那片内部找格子），剩下的 **14 − 11 = 3 根高位地址线**送进译码器，2³ = **8** 种组合，正好选 8 层——和字扩展算出来的 8 层严丝合缝。片内低位、片选高位，这就是"地址高位译码选层"的实际含义。

### 七、用哪种料：RAM 与 ROM

> 以下这一节培训资料没有收录，按教材《软件设计师教程》第 5 版补。

前六节一直在说"芯片"，但没说是哪种芯片。选料是被需求逼出来的，从主存自己的活儿说起。

主存要装的是正在跑的程序和数据，特点是**又读又写、访问位置到处跳**。于是第一个词来了：**RAM（Random Access Memory，随机存取存储器）**。

这里的"随机"不是"结果随机"，而是指**访问任意一个地址所花的时间都一样**，跳着访问不吃亏——与它相对的是磁带那种**顺序存取**，要读后面的必须先卷过前面的。RAM 可读可写，但**断电后内容全部消失**，这个性质叫**易失性**。对主存来说这不要紧：程序关机就该退出，下次重新装载。

RAM 内部怎么记住一个 0 或 1，有两种做法，做法不同分出两种芯片：

- **SRAM（静态 RAM）** 用**触发器**记一位。触发器是一个能自己稳定停在 0 或 1 两种状态之一的小电路（常见做法是六个晶体管搭一个），只要不断电就一直保持原状，**不需要任何额外维护**——"静态"就是这个意思。代价是一位要占六个管子，**集成度低、贵、功耗大**，但**速度快**。所以它被拿去做 **Cache**（CPU 和主存之间那层容量很小、速度极快的缓存）：容量小无所谓，快最重要。
- **DRAM（动态 RAM）** 用**一个电容加一个晶体管**记一位，电容里有电荷算 1，没有算 0。电容会漏电，隔一小段时间电荷就漏没了，所以必须周期性地把每一行内容读出来再原样写回去，这个动作叫**刷新**（refresh）——"动态"就是指它得不停地做这件事，也是"动/静"两个名字的由来。刷新有三种排法：**集中刷新**（每个刷新周期里集中一段时间把所有行统一刷完，这段时间不能访存，叫"死时间"）、**分散刷新**（把每个存取周期拆成两半，前半读写、后半顺手刷一行，没有死时间但每次访存都变慢了）、**异步刷新**（用刷新周期除以行数得到间隔，每隔这么久刷一行，均匀插空，兼顾两者）。代价是速度慢、要额外的刷新电路；好处是一位只占一个管子，**集成度高、便宜**。所以它被拿去做**主存**：要的就是大和省。

（刷新周期的具体数值，传统教科书常写"约 2ms"，但软考只考"要不要刷新"，不考这个数，不必背。）

但只有 RAM 机器开不了机——刚上电时内存是空的，谁告诉 CPU 第一条指令在哪？这就需要一种**断电之后内容还在**（**非易失**）的存储器：**ROM（Read Only Memory，只读存储器）**。

注意 ROM 也是**按地址随机存取**的，"只读"说的是使用方式（正常运行时只读不写），不是"物理上写不进去"。ROM 家族的演进主线只有一条：**擦写越来越方便、越来越便宜**，每一代都在补上一代的短板。

- **掩模 ROM（MROM）**：内容在芯片制版时就做进电路里，出厂即定死，用户改不了。好处是大批量摊下来极便宜。短板很硬——内容写错了整批报废，小批量根本不划算。
- **PROM（可编程 ROM）**：出厂是空白片，用户拿编程器烧一次（把片内的熔丝按需烧断）。解决了"必须求厂家定制"的问题，但**只有一次机会**，烧错了这片就废了。
- **EPROM（可擦除可编程 ROM）**：芯片顶上开一个石英窗口，拿**紫外线**照上几十分钟就能把内容整片擦掉，擦完可以重新烧。解决了"只能写一次"。短板是要把芯片从板子上拔下来、专门找紫外灯照，而且**一擦就是全片**。
- **EEPROM（电可擦除可编程 ROM，也写作 E²PROM）**：改用**加电压**擦除，不用拔芯片、不用紫外灯，而且能**按字节**擦写。解决了"要拆机、要设备、只能整片擦"。短板是擦写速度慢、单位容量贵、做不大。
- **Flash 闪存**：同样是电擦除，但把粒度放粗成**按块（扇区）擦除**，省掉了给每个字节配擦除电路的成本，于是**更便宜、密度更高、擦写更快**。今天的 U 盘、固态硬盘 SSD、手机存储、主板 BIOS（开机时最先运行的那段固件）用的都是它。常见的一句定性是"闪存的特性介于 EPROM 和 EEPROM 之间"。

最后收一句这三节的关系：**第五节算出要 16 片，第六节算出配 14 根地址线和 8 根数据线，第七节决定这 16 片买 DRAM——而旁边那颗存开机固件的 Flash 不算在这 16 片里，因为它回答的是另一个问题。**攒一块主存就是这三件事：几片、哪段地址、什么料。

## 考试怎么考

**考点① 求终止地址。** 题干形如"某芯片容量为 4K×8 位，起始地址为 3000H，则终止地址是（ ）"。三步走：先**把位宽扔掉**（×8 位不影响地址个数）；再把容量转成十六进制（4K = 2¹² = 1000H）；最后**起址 + 容量 − 1**（3000H + 1000H − 1 = 4000H − 1 = **3FFFH**）。三个高频错法，选项里通常一次给全：**忘了减 1** 答成 4000H（那是下一片的起址）；**借位补 9 不补 F** 答成 3999H（差了 1639，根本不相邻）；**容量换算错**，把 4K 当成 800H（那是 2K）或 400H（那是 1K）。

**考点② 2ⁿ ↔ 十六进制。** 上面每道题的第二步。考场上没有终端，两个办法：现场用二进制分组法推（1 后跟 n 个 0，从右每 4 位一组），或者直接背下这张表——**记住 1K = 400H，往下逐行翻倍**（十六进制里 4→8→10→20→40→80，逢 16 进位）：

| 容量 | 1K | 2K | 4K | 8K | 16K | 32K | 64K | 128K | 256K | 1M |
|---|---|---|---|---|---|---|---|---|---|---|
| 2 的幂 | 2¹⁰ | 2¹¹ | 2¹² | 2¹³ | 2¹⁴ | 2¹⁵ | 2¹⁶ | 2¹⁷ | 2¹⁸ | 2²⁰ |
| 十六进制 | 400H | 800H | 1000H | 2000H | 4000H | 8000H | 10000H | 20000H | 40000H | 100000H |

**考点③ 给地址段求容量。** 题干形如"地址从 X 到 Y、按字节编址，容量为（ ）KB"。**单元数 = 末 − 首 + 1**，那个 +1 不能丢；按字节编址时单元数就是字节数，除以 1024 得 KB。化简成 2 的幂再报数，别硬乘。

**考点④ 求芯片片数。** 题干形如"用 X×Y 位的芯片构成 M×N 位（或 M KB）的存储器，共需几片"。**总片数 = (M÷X) × (N÷Y)**，或者 **总 bit ÷ 单片 bit**，两条路互相验算。头号错法是**只做字扩展、漏掉位扩展**（16K÷1K = 16 就交卷，漏了 ×2）；第二个错法是**单位混用**，一边算 bit 一边算 B。追问"字扩展几层、位扩展几片"时，别把某一维的倍数直接当成总片数。

**考点⑤ 地址线与数据线条数。** **地址线 = log₂(单元数)，数据线 = 位宽。**字扩展时低位地址片内寻址、高位地址进译码器做片选，两段位数加起来等于总地址线数，可以当验算用。

**考点⑥ RAM/ROM 与 SRAM/DRAM 辨析。** 问法有三种："断电后内容丢失的是（ ）"选 RAM；"关于 SRAM 和 DRAM 描述正确/错误的是（ ）"，四个选项就是把属性互换着摆；"紫外线擦除的是（ ）"选 EPROM。对着这张表逐项核：

| | 存储元件 | 要刷新吗 | 速度/价格/密度 | 断电 | 典型用途 |
|---|---|---|---|---|---|
| **SRAM** | 触发器 | **不用** | 快、贵、密度低 | 丢失（易失） | **Cache** |
| **DRAM** | 电容（单管） | **要** | 慢、便宜、密度高 | 丢失（易失） | **主存** |
| **ROM 系列** | — | — | — | **不丢（非易失）** | 开机固件、U 盘、SSD |

错误选项固定三种造法：**属性对调**（"SRAM 需要刷新、DRAM 不需要"或"DRAM 更快、用作 Cache"）；**把 Flash / EEPROM 划进易失**（它俩姓 ROM，断电不丢）；**说"ROM 完全不能写"**（EEPROM 按字节写、Flash 按块写，ROM 的定性是非易失 + 以读为主）。

ROM 家族的顺序按"擦写方便度"排：**掩模（不可改）→ PROM（写一次）→ EPROM（紫外擦、整片）→ EEPROM（电擦、按字节）→ Flash（电擦、按块）**。

**1.【真题·年份待核实】** 地址编号从 80000H 到 BFFFFH 且按字节编址的内存容量为 (5) KB，若用 16K*4bit 的存储器芯片构成该内存，共需（ ）片

B. DRAM 速度比 SRAM 快，常用作 Cache

**自测**：
7.【模拟】内存地址从 A0000H 到 CFFFFH、按字节编址，共有多少 K 个存储单元？容量多少 KB？
8.【模拟】承上题，若用 16K×8 位的芯片构成这块内存，需要多少片？字扩展几层、位扩展几片？
9.【模拟】某芯片容量 16K×8 位，起始地址 4000H，终止地址是多少？
10.【模拟】一块 64K×16 位的存储器，需要多少根地址线、多少根数据线？
11.【模拟】必须拆下芯片、用紫外线照射才能擦除的只读存储器是（ ）A. PROM　B. EPROM　C. EEPROM　D. Flash

### 参考答案

1. **B、C**。单元数 = BFFFFH − 80000H + 1 = 3FFFFH + 1 = 40000H = 2¹⁸ = 256K；按字节编址每单元 1B，故 256KB，第一空选 B。片数：单片 16K×4bit = 64K bit = 8KB，256KB ÷ 8KB = **32** 片；分维度验算 (256K÷16K) × (8÷4) = 16 × 2 = 32 ✓，第二空选 C。B（16 片）是漏掉位扩展、只算了字扩展；D（64 片）是把芯片位宽 4 直接当成倍数乘了上去（16 × 4），位扩展倍数是"目标位宽 ÷ 单片位宽 = 8 ÷ 4 = 2"，不是单片位宽本身。
2. **A**。2K = 2¹¹ = 800H；2000H + 800H − 1 = 2800H − 1 = **27FFH**。B 是漏减 1（2800H 已是下一片的起址）；C 把 2K 当成 200H；D 把 2K 当成 1000H（那是 4K）。
3. **B**。4K = 2¹² = 1000H；3000H + 1000H − 1 = 4000H − 1 = **3FFFH**。A 就是拿十进制借位习惯做的（3999H = 14745，与 4000H = 16384 差 1639，不相邻）；C 漏减 1；D 把 4K 当成 400H（那是 1K）。
4. **C**。字扩展 8K ÷ 1K = 8 层，位扩展 8 ÷ 4 = 2 片并排，8 × 2 = **16** 片；总账验算：8K×8 = 64K bit，1K×4 = 4K bit，64K ÷ 4K = 16 ✓。A 是只算字扩展漏了位扩展。
5. **B**。RAM（含 SRAM、DRAM）易失，断电就没；ROM、EEPROM、Flash 同属非易失家族，断电内容还在——这正是拿它们存开机固件的理由。
6. **C**。静态 = 不用刷新、快、贵 → Cache；动态 = 电容漏电要刷新、慢、便宜密度高 → 主存。A、B 都是属性对调；D 错在 RAM 全部是易失的。
7. **192K 个单元，192KB**。CFFFFH − A0000H + 1 = 2FFFFH + 1 = 30000H = 3×16⁴ = 196608 = 192K；按字节编址每单元 1B，故 192KB。
8. **12 片，字扩展 12 层、位扩展 1 片**。位宽 8 = 8 已经够了，位扩展倍数 1；字扩展 192K ÷ 16K = 12。总账验算：192K×8 = 1536K bit，单片 16K×8 = 128K bit，1536K ÷ 128K = 12 ✓。这题专门用来提醒：位扩展倍数是 1 时也要过一遍这一维，别默认它一定大于 1。
9. **7FFFH**。16K = 2¹⁴ = 4000H；4000H + 4000H − 1 = 8000H − 1 = **7FFFH**（三个 0 各借位变 F，8 变 7）。写成 7999H 是借位补 9 的老毛病，写成 8000H 是漏减 1。
10. **地址线 16 根、数据线 16 根**。64K = 2¹⁶ 个单元 → 地址线 16 根；位宽 16 位 → 数据线 16 根。两个 16 来源不同、只是巧合，别以为地址线和数据线总是一样多。
11. **B**。PROM 只能写一次、根本不能擦；EEPROM 是电擦除、按字节；Flash 是电擦除、按块。只有 EPROM 靠石英窗口 + 紫外线照射整片擦。

## 速记

- 芯片规格 `字数 × 位宽`；**算地址只看字数，位宽一律扔掉**；K/M/G 每级差 1024，1B = 8b
- **终止地址 = 起址 + 容量 − 1**；**单元数 = 末 − 首 + 1**；忘了这个 ±1 就答成下一片的起址
- **减 1 借位：0 变 F 不变 9**（十六进制顶格是 F）；4000H − 1 = 3FFFH，不是 3999H
- 2ⁿ 转十六进制：1 后跟 n 个 0，从右每 4 位一组；或从 **1K = 400H 起逐次翻倍**（400H→800H→1000H→2000H→…，逢 16 进位），一路数到 1M = 100000H
- **总片数 =（字数倍数）×（位宽倍数）= 总 bit ÷ 单片 bit**，两条路互验；位扩展并排拼宽度、字扩展摞层用高位地址译码片选
- **地址线 = log₂(单元数)，数据线 = 位宽**；片内低位 + 片选高位 = 总地址线
- RAM 断电就忘（易失、随机存取＝访问任意地址耗时相同）；**静 SRAM 触发器不刷新、快贵密度低 → Cache；动 DRAM 电容漏电要刷新、慢便宜密度高 → 主存**
- ROM 断电不忘，按擦写方便度排：**掩模（不可改）→ PROM（一次）→ EPROM（紫外整片擦）→ EEPROM（电擦按字节）→ Flash（电擦按块，U 盘/SSD/BIOS）**
