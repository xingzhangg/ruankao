# 10 · 数据结构与算法：树

## 定位

树存「一对多」的层级关系。一、二节认全术语，说明为什么只研究二叉树；三～五节算性质、存储下标、遍历与还原，都跟同一棵六结点二叉树 T 走；六节反过来由一组权值造哈夫曼树（换成一组字符）；七节是查找用的二叉排序树与平衡二叉树。

## 一、树的术语（概念）

```
            A
         /  |  \
        B   C   D
       / \      |
      E   F     G
```

把它想成项目目录：`A` 是根目录，`C` 是文件（无下级），`B`、`D` 是子目录。

| 词 | 是什么 | 本例 |
|---|---|---|
| 树 | 一个根 + m（m ≥ 0）棵**互不相交**的子树（递归定义；互不相交＝一个文件不会同属两个父目录）；m = 0 时根自己是叶子；n = 0 叫**空树** | — |
| 硬规则 | 除根外每个结点恰有一条边连下来：**只有一个上级、不成环** | — |
| 根结点 | 唯一没有上级的结点 | A |
| 双亲 / 孩子 / 兄弟 | 边的上方 / 下方；同一双亲的互为兄弟 | A 是 B、C、D 的双亲 |
| 子树 | 某结点连同其全部下级 | B、E、F 是 A 的一棵子树 |
| 结点的度 | 孩子个数 | A 3、B 2、D 1、C/E/F/G 0 |
| 树的度 | 所有结点度的最大值 | 3 |
| 叶子（终端结点） | 度为 0 | C、E、F、G |
| 分支结点（非终端结点） | 度不为 0 | A、B、D |
| 内部结点 | 分支结点除掉根 | B、D |
| 层次 | **根是第 1 层**，往下加一 | E、F、G 在第 3 层 |
| 高度（深度） | 最大层数 | 3 |
| 有序树 / 无序树 | 孩子左右次序固定不能交换 / 可交换 | — |
| 森林 | m 棵互不相交的树；树删根得森林，森林加共同根得树 | 删 A 剩 B、C、D 三棵 |

**分支结点 vs 内部结点**
- 判据｜内部结点 = 分支结点去掉根（有的资料把两词当同义词）。
- 例子｜A、B、D 都是分支结点，内部结点只有 B、D。

**根是第 1 层，不是第 0 层。** 本课所有高度公式都建立在这一约定上；按数组下标习惯把根当第 0 层，结果会整体差 1。

## 二、二叉树、满二叉树、完全二叉树（概念）

普通树孩子数不限，「n 个结点有多少层」写不出公式；限死每个结点最多 2 个孩子才能算，所以只研究二叉树。

| 名称 | 是什么 |
|---|---|
| 二叉树 | 每个结点最多 2 个孩子，**左右有别**（交换即另一棵树） |
| 满二叉树 | 每层都住满，无空位 |
| 完全二叉树 | 从上到下、每层从左到右连续编号填格子，填到第 n 个停；即前面各层都满，只有最后一层可不满，且从左连续、中间不跳空 |

把上图的 C（叶子）摘掉，得全课主角 **T**：

```
        A
       / \
      B   D
     / \    \
    E   F    G
```

B、D 是 A 的左、右孩子；E、F 是 B 的左、右孩子；G 是 D 的**右**孩子（D 无左孩子）。

**二叉树 vs 度为 2 的树**
- 判据｜二叉树左右有别，可以是空树或只有一个根；度为 2 的树只有一个孩子时不分左右，且至少 3 个结点。二叉树**不是**度为 2 的树的特例。
- 例子｜根带一个左孩子的两结点树：是二叉树，不是度为 2 的树。

**完全 vs 不完全；满 vs 完全**
- 判据｜按层序编号，出现「前面空着、后面有人」就不完全。满 ⇒ 完全，反之不然。
- 例子｜T 编号 A=1、B=2、D=3、E=4、F=5，6 号（D 的左）空而 G 在 7 号 → 跳空，不完全；补上 6 号成 7 结点满二叉树；只填到 5 号就停 → 完全但不满。

## 三、四条性质（计算）

对照满二叉树：

```
        1
      /   \
     2     3
    / \   / \
   4   5 6   7
```

**性质 1：第 i 层最多 2^(i−1) 个结点。** 每层 1、2、4……，每个结点最多带 2 个孩子，所以逐层翻倍；第 1 层对应 2⁰，故指数是 i−1（「根是第 1 层」的直接后果）。

**性质 2：高度为 h 的二叉树最多 2ʰ − 1 个结点**（满二叉树取到）；**最少 h 个**（单支链）。「最少 2^(h−1) 个」只对完全二叉树成立。

```
h = 3：1 + 2 + 4     = 7  = 2³ − 1
h = 4：1 + 2 + 4 + 8 = 15 = 2⁴ − 1
```

为什么差 1 到整幂：二进制 `111` 加 1 进位成 `1000`。

**性质 3：n 个结点的完全二叉树，高度 h = ⌊log₂n⌋ + 1。** 例：n = 100。

1. 高度 h 的完全二叉树结点数被夹住：最少「前 h−1 层满、第 h 层 1 个」= 2^(h−1)；最多 h 层全满 = 2ʰ − 1，即 `2^(h−1) ≤ n ≤ 2ʰ − 1`。
2. 试 h = 6：上限 63 < 100，不够。
3. 试 h = 7：64 ≤ 100 ≤ 127 ✓，**7 层**（前 6 层装 63 个，第 7 层装 37 个 ≤ 64，自洽）。
4. 提炼：2^(h−1) ≤ n < 2ʰ，取对数得 h − 1 ≤ log₂n < h，所以 h − 1 = ⌊log₂n⌋，

```
h = ⌊log₂n⌋ + 1        验算：64 ≤ 100 < 128，⌊log₂100⌋ = 6，h = 7 ✓
```

夹逼法和公式必须得出同一个数，对不上就是取整或层号错了。边界：n = 63 → h = 6，n = 64 → h = 7。

**性质 4：n₀ = n₂ + 1**（n₀、n₁、n₂ 分别是度为 0、1、2 的结点数）。与形状无关，把边数从两头各数一遍：

1. 入边：除根外每个结点头上一条边 → 边数 = n − 1 = n₀ + n₁ + n₂ − 1。
2. 出边：度为 k 的结点发 k 条 → 边数 = n₁ + 2n₂。
3. 两式相等：

```
(n₀ + n₁ + n₂) − 1 = n₁ + 2n₂
n₀ + n₂ − 1 = 2n₂
n₀ = n₂ + 1
```

n₁ 被消掉，给出 n₁ 也用不上。验 T：n₀ = 3（E、F、G）、n₁ = 1（D）、n₂ = 2（A、B），3 = 2 + 1 ✓；边数 6 − 1 = 5 = 1 + 2×2 ✓。

## 四、存储（计算）

**顺序存储**：一维数组，按层序编号放。结点 i（编号从 1 起）：

```
左孩子 = 2i      右孩子 = 2i + 1      双亲 = ⌊i/2⌋      i = 1 是根，无双亲
（编号从 0 起：左 = 2i+1、右 = 2i+2、双亲 = ⌊(i−1)/2⌋）
```

为什么是 2i：2 号以后全是别人的孩子，前 i−1 个结点各带 2 个孩子占掉 2 ~ 2i−1 号，接着的 2i 号就是第 i 个的左孩子。验：i = 1 左孩子 2，i = 3 左右孩子 6、7 ✓。**2i ≤ n 才有左孩子，2i+1 ≤ n 才有右孩子。**

只对完全二叉树严丝合缝。T 存为 `A B D E F _ G`，6 号必须留**虚结点**空位，否则下标关系乱掉。最坏：10 个结点的右单支链，最深编号 2¹⁰ − 1 = **1023**，开 1023 格装 10 个结点。**顺序存储只适合完全二叉树，一般二叉树用链式存储。**

**链式存储**：`左孩子指针 + 数据 + 右孩子指针` 叫**二叉链表**；再加 `双亲指针` 叫**三叉链表**。

| | 指针槽 | 非空 | 空指针 | T（n = 6） |
|---|---|---|---|---|
| 二叉链表 | 2n | n − 1（每条边一个） | **n + 1** | 7（E 左右、F 左右、D 左、G 左右） |
| 三叉链表 | 3n | 2(n − 1)（向下边 + 双亲指针） | **n + 2** | 8 |

## 五、遍历与还原（计算）

遍历：按固定顺序把每个结点不重不漏访问一遍，把二维的树读成一维序列。左子树永远在右子树前，「前/中/后」指**根的位置**，对每棵子树递归执行：

```
前序（根左右）：A → 左子树 B,E,F → 右子树 D,G         = A, B, E, F, D, G
中序（左根右）：左子树 E,B,F → A → D 无左孩子，D,G     = E, B, F, A, D, G
后序（左右根）：左子树 E,F,B → 右子树 G,D → A         = E, F, B, G, D, A
层次（逐层从左到右）                                   = A, B, D, E, F, G
```

层次遍历非递归，用**队列**（出队一个，把它的孩子排到队尾）；前三种递归，本质借系统**栈**。

**由两个序列还原**：前序首位、后序末位是根；在**中序**里找到根，左边是左子树、右边是右子树——所以中序必须参与。用前序 `A,B,E,F,D,G` + 中序 `E,B,F,A,D,G`：

```
① 前序首位 A = 根
② 中序 A 左边 [E,B,F] 为左子树（3 个），右边 [D,G] 为右子树（2 个）
③ 左子树取前序接下来 3 个 [B,E,F]，B 为根；中序 [E,B,F] 中 E 在左、F 在右
④ 右子树取前序剩下 [D,G]，D 为根；中序 [D,G] 中 D 左边空、G 在右 → G 是【右】孩子
与 T 一致 ✓；层数多时对每一段递归重复 ①–④，直到每段只剩一个结点
```

**前序 + 后序不能唯一确定**：结点只有一个孩子时，前序里它紧跟父结点、后序里紧挨父结点前，分不出左右。把 G 改挂成 D 的左孩子，前序仍 `A,B,E,F,D,G`、后序仍 `E,F,B,G,D,A`；穷举 6 结点二叉树，与这两串同时相符的有 2 棵，换成前序 + 中序只剩 1 棵。**中序 + 前序、中序 + 后序都可以唯一确定。**

### 线索二叉树（概念）

二叉链表只能答「左右孩子是谁」，要找「中序前驱/后继」只能从根重新遍历；另加两个指针域要多花 2n 个，而本来就闲着 **n + 1 个空指针**，拿来存前驱后继。每个结点加两个 1 位标志区分：

```
| ltag | lchild | data | rchild | rtag |
ltag = 0 → lchild 指左孩子      ltag = 1 → lchild 指（该遍历次序下的）前驱
rtag = 0 → rchild 指右孩子      rtag = 1 → rchild 指（该遍历次序下的）后继
```

| 词 | 是什么 |
|---|---|
| 线索 | 指向前驱、后继的指针（教材口径 **0 是孩子、1 是线索**；个别资料反过来，以给定说明为准） |
| 线索链表 / 线索二叉树 | 装了线索的链表 / 对应的二叉树；按哪种遍历穿就叫前序/中序/后序线索二叉树 |

例子｜T 按中序（E, B, F, A, D, G）穿：E 右指针 → 后继 B（rtag = 1）；F 左指针 → 前驱 B（ltag = 1）；G 右指针空，是中序最后一个、无后继，仍指空。

## 六、哈夫曼树（计算）

给一组权值造一棵树，让带权路径最短。下面**小写 a、b、c、d 是字符**，与前面大写结点无关。

**问题**：文件只有 4 种字符，a 2 次、b 4 次、c 5 次、d 7 次。定长编码 2 位（00/01/10/11），共 (2+4+5+7) × 2 = **36 位**；d 与 a 同为 2 位不划算，应常用的编短、罕见的编长（如摩斯电码 E 一个点、Q 四下）。字符放二叉树叶子上，从根往下**左 0 右 1**，沿途 0/1 串即编码，**码长 = 该字符在树中的深度**，于是「高频编码短」＝「权大的离根近」。

| 术语 | 教材定义 |
|---|---|
| 路径 | 一个结点到另一个结点之间的通路 |
| 结点的路径长度 | 路径上的**分支（边）数目** |
| 树的路径长度 | 教材口径：根到**每一个结点**的路径长度之和（也有资料只算根到每个叶子；不影响 WPL） |
| 权 | 结点代表的值（这里是出现次数） |
| 结点的带权路径长度 | 该结点到根的路径长度 × 权值 |
| 树的带权路径长度 WPL（树的代价） | **所有叶子**的带权路径长度之和；WPL 最小的叫**最优二叉树**，即**哈夫曼树** |

⚠️ **本节「深」数边数**，比「根是第 1 层」的层数少 1（第 3 层叶子 = 走 2 条边 = 码长 2）。两套数法同一次计算里不能混用。

同一组权值，形状不同 WPL 不同：

```
(a) 四个字符同层，各深 2            → WPL = 2×(2+4+5+7)        = 36（= 定长编码）
(b) a 深3、b 深3、c 深2、d 深1     → WPL = 3×(2+4) + 5×2 + 7×1 = 35（最小）
(c) a 深1、d 深2、b 深3、c 深3     → WPL = 3×(4+5) + 7×2 + 2×1 = 43（权大的放深，更差）
```

**构造（贪心）**：

1. 所有字符作为独立结点放入待合并集合。
2. 取**权值最小的两个**合并，新结点权值 = 两者之和。
3. **新结点放回集合**参与后续比较（最容易漏）。
4. 重复 2–3 至只剩一个结点，即根。
5. 标边**左 0 右 1**（可反，但同一棵树内统一）；合并时**权小的放左边**得标准形态。

```
初始：{ a(2), b(4), c(5), d(7) }
第1轮：a(2)+b(4) → ab(6)      → { c(5), ab(6), d(7) }
第2轮：c(5)+ab(6) → cab(11)   → { d(7), cab(11) }（d=7 > 6，本轮不选）
第3轮：d(7)+cab(11) → 根(18)

            根(18)
         0 /     \ 1
       d(7)     cab(11)
              0 /     \ 1
            c(5)     ab(6)
                   0 /   \ 1
                 a(2)   b(4)
```

| 字符 | 权值 | 编码 | 码长 |
|---|---|---|---|
| d | 7 | 0 | 1 |
| c | 5 | 10 | 2 |
| b | 4 | 111 | 3 |
| a | 2 | 110 | 3 |

**WPL = 7×1 + 5×2 + 4×3 + 2×3 = 35**，与 (b) 一致。只比定长省 1 位是因为权值差距不大，权值越悬殊越省。

**为什么每次挑最小的两个就最优**：最深一层必站两个叶子（只剩一个就把它上提一层，WPL 更小，与最优矛盾）；最深处码长最大，应由最轻的两个去站；合并后放回等于把它们压成一个虚拟字符，规模减一，重复到底即全局最优。

**验算性质**：

- **WPL = Σ(权 × 码长) = 所有内部结点权值之和**：6 + 11 + 18 = 35 ✓。
- **n 个叶子的哈夫曼树共 2n − 1 个结点，无度为 1 的结点**：合并 n − 1 次、每次多一个结点；n = 4 → 7 个（a、b、c、d、ab、cab、根）✓。每次合并造出的父结点恰有 2 个孩子。
- **权大码短**（并列权值可能等长，严格说是「不长于 / 不短于」）。
- **只有 WPL 唯一**；权值并列时树形、编码串、码长都可能不唯一。

**前缀编码**：若 a = `0`、b = `01`，收到 `01` 有两种读法——一个编码是另一个的前缀就有歧义。字符全放叶子，途经的都是不放字符的分岔点，天然避免。任一编码都不是另一编码前缀的方案叫**前缀编码（前缀码）**，哈夫曼编码是一种前缀编码。

**译码**：从根走，0 左 1 右，**到叶子就输出并回到根**。译 `1111100`：

```
1 → cab；1 → ab；1 → b  ⇒ b，回根
1 → cab；1 → ab；0 → a  ⇒ a，回根
0 → d                   ⇒ d，回根          原文 = "bad"，3 + 3 + 1 = 7 位 ✓
```

串尾停在中间结点（没到叶子）＝ 译错或串被截断。`bad` 定长只要 6 位、哈夫曼用 7 位：哈夫曼只保证**按给定权值统计的整体总长最短**，个别片段可能更长。

## 七、二叉排序树与平衡二叉树

### 二叉排序树（计算）

**二叉排序树**（二叉查找树、查找二叉树、BST）：**左子树上所有结点的值都小于该结点，右子树上所有结点的值都大于该结点**——是整棵子树，不只是直接孩子。查找像翻字典：小往左、大往右。

**建树**（**关键码**＝拿来比大小的值）：空树就当根；比当前结点小往左、大往右；走到空位挂上。依次插 23、17、31、11、19、27：

```
插 23  空树，当根
插 17  17<23 往左，空 → 23 的左
插 31  31>23 往右，空 → 23 的右
插 11  11<23 → 17；11<17 → 17 的左
插 19  19<23 → 17；19>17 → 17 的右
插 27  27>23 → 31；27<31 → 31 的左

              23
            ／    ＼
          17        31
         ／  ＼     ／
       11     19  27
```

**中序遍历得升序序列**：11、17、19、23、27、31 ✓，这是判断是否为二叉排序树最快的办法。

查找每比较一次下降一层，**效率取决于深度**：升序插入会挂成**单支树**（退化成链表），高度 n、比较 n 次，最差；深度最小的形状最快——平衡二叉树就是把深度按住。

### 平衡二叉树（计算）

**平衡二叉树（AVL 树）**：空树，或**左右子树都是平衡二叉树且左右子树高度差的绝对值不超过 1**。**平衡因子 BF = 左子树高度 − 右子树高度**，每个结点只能是 −1、0、+1；**任一**结点 |BF| > 1 整棵树就不平衡。

⚠️ 高度回到层数口径：**空子树高 0，单个结点高 1**。

```
结点 23：左 {17,11,19} 高 2，右 {31,27} 高 2  → BF = 0
结点 17：左 {11} 高 1，右 {19} 高 1            → BF = 0
结点 31：左 {27} 高 1，右空 高 0               → BF = +1（右空按 0，不是 −1）
结点 11、19、27：叶子                          → BF = 0
全部 |BF| ≤ 1 → 是平衡二叉树
```

失衡后靠**旋转**恢复，按失衡结点与新插入结点的相对位置分四型：

| 型 | 哪边太深 | 旋转 |
|---|---|---|
| LL | 左子树的左边 | 一次右旋 |
| RR | 右子树的右边 | 一次左旋 |
| LR | 左子树的右边 | 先左旋再右旋 |
| RL | 右子树的左边 | 先右旋再左旋 |

**三种「有序」的树互不蕴含**
- 判据｜二叉排序树管值的大小关系；平衡二叉树在此基础上再管高度差；完全二叉树管形状连续不跳空。
- 例子｜完全二叉树上的值可以乱放（不是排序树）；平衡二叉树形状可以不完全（T 各结点 BF 为 0、0、−1，高度差达标，但 6 号跳空，不是完全二叉树）。

## 速记

- **根是第 1 层**；度 = 孩子个数，叶子度 0；内部结点 = 分支结点去掉根；高度 = 深度 = 最大层数；森林 = 树删根
- 第 i 层最多 **2^(i−1)**；高 h 最多 **2ʰ − 1**、最少 h；完全二叉树 **2^(h−1) ≤ n ≤ 2ʰ − 1**，**h = ⌊log₂n⌋ + 1**（63→6、64→7）
- **n₀ = n₂ + 1**（边数两头数，n₁ 消掉）；满 ⇒ 完全，反之不成立；二叉树 ≠ 度为 2 的树
- 顺序存储（从 1 起）：左 **2i**、右 **2i+1**、双亲 **⌊i/2⌋**；从 0 起 2i+1 / 2i+2 / ⌊(i−1)/2⌋；只适合完全二叉树
- 二叉链表空指针 **n+1**（线索二叉树用它存前驱后继，tag 0 孩子 1 线索），三叉链表 **n+2**
- 遍历：前/中/后指**根的位置**；层次用**队列**；**中序必须参与才能唯一还原**
- 哈夫曼：最小两个合并、**放回**；字符只在叶子（前缀码）；**WPL = Σ权×码长 = 内部结点权值和**；共 **2n−1** 个结点、无度 1；**只有 WPL 唯一**
- 二叉排序树中序升序、升序插入退化成单支树；AVL：**BF = 左高 − 右高 ∈ {−1,0,+1}**，空树高 0；LL/RR/LR/RL 四种旋转
