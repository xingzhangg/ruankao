# 11 · 数据结构与算法：图

## 定位

图是「多对多、可绕圈」的关系。本课回答四问：怎么存（邻接矩阵／邻接表）、怎么走全（DFS／BFS）、带权后怎么求最短路和最小生成树（Dijkstra／Prim／Kruskal）、怎么排先后（拓扑序列）。第一节认词，第二、三节存和走，第四、五节用边权，第六节把边定向、按入度排序。全课用同一张六个站的地铁图：

```
            A
         6/   \1
         B——3——C
         |     |
        5|     |4
         |     |
         D——8——E
          \   /
          2\ /7
            F
```

六个顶点 A–F，八条边，边上数字是分钟数（权值）。第六节把它改成有向版本。

## 一、基本术语（概念）

| 术语 | 是什么 | 本图 |
|---|---|---|
| **顶点**（vertex）／**边**（edge） | 圆圈／连线；顶点数记 n，边数记 e | n = 6，e = 8 |
| **无向图** | 边无方向，A–B 即 B–A | 本图 |
| **有向图** | 边带箭头，A→B 不代表 B→A（如微博关注）；边叫**弧**，箭尾是起点、箭头是终点 | 第六节 |
| **网** | 边上带数值（权值）的图 | 本图是无向网 |
| **度** | 连着该顶点的边数 | A=2，B=C=D=E=3，F=2 |
| **出度／入度**（有向图） | 指出去／指进来的弧数；**度 = 出度 + 入度** | — |
| **路径** | 顺着边走过的顶点串；无向图 A–C–E–F 与 F–E–C–A 是同一条（写 A→C→E→F 时箭头只表示行进顺序） | A–C–E–F |
| **回路（环）** | 起点与终点相同的路径；树不许有，图可以 | A–B–C–A |
| **子图** | 挑部分顶点和部分边（边的两端须都在所挑顶点中） | — |
| **完全图** | 任意两顶点间都有边 | — |
| **稠密图／稀疏图** | e 接近 n(n−1)/2／e 远小于它 | 8/15 约一半，不算特别稀 |

**易混对：连通分量 vs 强连通分量**
判据｜连通分量只对**无向图**说：任意两点有路径即连通，任意两点都连通是**连通图**，**极大连通子图**（再也拉不进新顶点的连通块）叫连通分量。强连通分量只对**有向图**说：任意 u、v 既有 u→v 又有 v→u 的路径才叫**强连通图**，**极大强连通子图**叫强连通分量。
例子｜本图连通，连通分量 1 个；拆掉 A–B、A–C，A 成孤岛，裂成 {A} 与 {B,C,D,E,F}，变 2 个。第六节的有向版本无环、谁也回不去，强连通分量 **6 个**（每个顶点自成一个）。

### 度与边数（计算）

1. 度之和：2+3+3+3+3+2 = 16 = 2e。每条边两个端点各数一次 → **度之和恒等于 2e**（握手定理）。
2. 有向图：每条弧给起点 1 个出度、终点 1 个入度 → **入度之和 = 出度之和 = e**（第六节 8 条弧，入度和、出度和都是 8），两者相加回到 2e。
3. 6 个顶点的无向完全图：每点连其余 5 个，6×5 = 30，每条边被两端各数一次，÷2 = **15**。另一数法：A 向后连 5、B 再连 4……5+4+3+2+1 = 15。
4. 规则：无向完全图 **n(n−1)/2** 条边；有向完全图任意两点互通两个箭头，不除以 2，**n(n−1)** 条（n = 6 时 30）。

## 二、存储：邻接矩阵与邻接表

**邻接矩阵**：n×n 二维数组，第 i 行 j 列填「i 到 j 有没有边」，有 1 无 0；网则填权值，无边填 ∞。

```
     A B C D E F
  A [0 1 1 0 0 0]
  B [1 0 1 1 0 0]
  C [1 1 0 0 1 0]
  D [0 1 0 0 1 1]
  E [0 0 1 1 0 1]
  F [0 0 0 1 1 0]
```

- 一条无向边在 A 行 B 列、B 行 A 列各填一个 1 → **1 的个数 = 2e = 16**，矩阵**关于主对角线对称**。
- 有向图 A→B 只填 A 行 B 列 → 1 的个数 = e，矩阵**不一定对称**（每条边都成对时照样对称，所以不能说「一定不对称」）。
- 主对角线全 0（无自环）；**某行 1 的个数 = 该顶点的度**（有向图为出度），**某列 1 的个数在有向图里是入度**（B 行 3 个 1，B 的度 3）。
- **矩阵恒为 n 阶方阵**，与边数无关：5 个顶点、7 条弧的有向图，邻接矩阵是 5×5，不是 5×7。

**邻接表**：一维数组存 n 个**顶点头结点**，每个顶点挂一条链表串上邻居（带权顺便存权值），链上的叫**边表结点**。

```
  A → B(6) → C(1)
  B → A(6) → C(3) → D(5)
  C → A(1) → B(3) → E(4)
  D → B(5) → E(8) → F(2)
  E → C(4) → D(8) → F(7)
  F → D(2) → E(7)
```

每条链长 = 该顶点的度，总计 16 = 2e：**无向图边表结点 2e 个**（每条边两端各挂一次），有向图只挂出边，**e 个**。

**空间对比（n = 6）**

| 边数 | 邻接矩阵 | 邻接表（头结点 + 边表结点） |
|---|---|---|
| 本图 e = 8 | 36 格（16 格是 1，20 格白占） | 6 + 16 = 22 |
| 补成完全图 e = 15 | 36 格 | 6 + 30 = 36（结点还要存指针，实际更费） |
| 只剩 5 条边（一棵树） | 36 格 | 6 + 10 = 16 |

规则：**矩阵 O(n²) 只跟顶点数有关；邻接表 O(n+e) 跟着边数走** → **稠密图（尤其完全图）用矩阵，稀疏图用邻接表**，与有向无向无关。

| 查询 | 邻接矩阵 | 邻接表 |
|---|---|---|
| i、j 之间通不通 | 查一格 O(1) | 走 i 的链 O(度) |
| i 的全部邻居 | 扫一整行 O(n) | O(度) |

## 三、遍历：DFS 与 BFS（计算）

**问题**：从某顶点出发，把每个顶点访问一次且仅一次。图有环，须给访问过的顶点**打标记**。图不连通时，一次只走完所在的一块，要另挑未访问顶点重新出发——**出发了几次，就有几个连通分量**。

序列不唯一，取决于**出发点**和**邻居访问次序**；次序由给定的邻接表或矩阵决定，不凭图形位置。下面约定从 A 出发、邻居按字母序（即上面邻接表的挂链次序）。

**DFS（深度优先）：一条路走到底，走不动回退换路。**

```
访问 A                        已访问 {A}
A 的第一个未访问邻居 B，深入    {A,B}
B：A 已访问，下一个 C，深入     {A,B,C}
C：A、B 已访问，下一个 E，深入  {A,B,C,E}
E：C 已访问，下一个 D，深入     {A,B,C,E,D}
D：B、E 已访问，下一个 F，深入  {A,B,C,E,D,F}
F：D、E 都访问过 → 逐级回退，无未访问邻居，结束
序列：A B C E D F
```

**BFS（广度优先）：一圈圈外扩，先访问全部直接邻居，再访问邻居的邻居。** 入队时即打标记，防止重复入队。

```
A 出队访问，B、C 入队        队列 [B,C]
B 出队访问，D 入队           队列 [C,D]
C 出队访问，E 入队           队列 [D,E]
D 出队访问，F 入队           队列 [E,F]
E 出队访问，邻居均已访问     队列 [F]
F 出队访问，无新增           队列 []
序列：A B C D E F
```

规则：
- 回退到上一个岔口是后进先出 → **DFS 用栈**（递归即系统调用栈）；先排队先出来 → **BFS 用队列**。两者只差容器。
- DFS 对应二叉树**前序遍历**，BFS 对应**层次遍历**，图上多了打标记防绕环。
- BFS 只保证**经过的边数最少**，不管权值；带权最短路用 Dijkstra。

## 四、最短路径：Dijkstra（计算）

**问题**：求 A 到其余各站最少花几分钟。A–B 直连权 6，但 A→C→B 只要 1+3 = 4——**直连边只是候选，不是答案**。

**做法**：`dist[]` 记当前已知最短距离，起点 0、其余 ∞。每轮从**未确定**顶点中挑 dist 最小者**确定**（放入集合 S，值冻结），再用它**松弛**邻居：借道它若更近就改小。

| 轮 | 确定谁 | A | B | C | D | E | F | 本轮松弛 |
|---|---|---|---|---|---|---|---|---|
| 初 | — | 0 | ∞ | ∞ | ∞ | ∞ | ∞ | — |
| 1 | **A(0)** | 0 | **6** | **1** | ∞ | ∞ | ∞ | B: 0+6=6 改；C: 0+1=1 改 |
| 2 | **C(1)** | 0 | **4** | 1 | ∞ | **5** | ∞ | B: 1+3=4 **< 6 改**；E: 1+4=5 改 |
| 3 | **B(4)** | 0 | 4 | 1 | **9** | 5 | ∞ | D: 4+5=9 改 |
| 4 | **E(5)** | 0 | 4 | 1 | 9 | 5 | **12** | D: 5+8=13 **不小于 9，不改**；F: 5+7=12 改 |
| 5 | **D(9)** | 0 | 4 | 1 | 9 | 5 | **11** | F: 9+2=11 **< 12 改** |
| 6 | **F(11)** | 0 | 4 | 1 | 9 | 5 | 11 | 无未定邻居，结束 |

各轮挑选：第 2 轮 {B=6, C=1, 其余 ∞} 取 C；第 3 轮 {B=4, D=9, E=5, F=∞} 取 B；第 4 轮 {D=9, E=5, F=∞} 取 E；第 5 轮 {D=9, F=12} 取 D。

结果：**A→B = 4（A→C→B），A→C = 1，A→D = 9（A→C→B→D），A→E = 5（A→C→E），A→F = 11（A→C→B→D→F）**。路径倒着读：谁最后一次把 F 改小，谁就是 F 的前一站（F←D←B←C←A）。

验算（穷举）：A 到 F 有 A-C-B-D-F = 11、A-C-E-F = 12、A-B-D-F = 13、A-C-E-D-F = 15……最小 11，与表一致。

**为什么当前最小的点可以立刻拍板**：设本轮挑中 B，dist[B] = 4。任何别的路要到 B，必先离开 S 踏上某个未定点 v，而 dist[v] ≥ 4，再从 v 到 B 还要加边权；**边权非负**则只增不减，不可能短于 4。一旦有负权边，这个论证就塌了。

规则：
- 每步只挑当前最优、定了不回头 → **贪心法**；硬前提**边权非负**。
- Dijkstra 是**单源**（一个起点到所有点）；**所有点对**之间的最短路径用 **Floyd**，属**动态规划**。

## 五、最小生成树：Kruskal 与 Prim（计算）

**问题**：给六个站铺轨道，全部连通，总里程最少。

从 n 个顶点的连通图挑 **n−1 条边**使全部顶点连通且不成环，得到**生成树**（原图的子图，含全部顶点）。n−1 来自树的性质：少一条必有顶点掉队，多一条必成环。边权和最小的生成树叫**最小生成树（MST）**。

**Kruskal：捡边。** 边按权从小到大，不成环就收，成环跳过，收满 n−1 条停。

```
排序：A-C(1) D-F(2) B-C(3) C-E(4) B-D(5) A-B(6) E-F(7) D-E(8)   目标 5 条
取 A-C(1) ✓   碎块：{A,C} {B} {D} {E} {F}
取 D-F(2) ✓   碎块：{A,C} {B} {D,F} {E}      ← 与 A 那块不挨着，照收
取 B-C(3) ✓   碎块：{A,B,C} {D,F} {E}
取 C-E(4) ✓   碎块：{A,B,C,E} {D,F}
取 B-D(5) ✓   碎块：{A,B,C,D,E,F}，满 5 条，停
MST = {A-C, D-F, B-C, C-E, B-D}，总权 = 1+2+3+4+5 = 15
```

**Prim：长树。** 从任一顶点（这里 A）出发，每次在**一头在树内、一头在树外**的边里取最小者，把树外那头拉进来。

```
树={A}          横跨边 A-C(1) A-B(6)          → 取 A-C(1)，C 入树
树={A,C}        横跨边 B-C(3) C-E(4) A-B(6)    → 取 B-C(3)，B 入树
树={A,B,C}      横跨边 C-E(4) B-D(5)           → 取 C-E(4)，E 入树
树={A,B,C,E}    横跨边 B-D(5) E-F(7) D-E(8)    → 取 B-D(5)，D 入树
树={A,B,C,D,E}  横跨边 D-F(2) E-F(7)           → 取 D-F(2)，F 入树
选边顺序 A-C B-C C-E B-D D-F，总权 = 1+3+4+5+2 = 15
```

验算（穷举）：8 条边取 5 条共 C(8,5) = 56 种，构成生成树的 **30 棵**，最小 15 且唯一，次小 17。

| | Kruskal | Prim |
|---|---|---|
| 做法 | 捡边：全局最小且不成环 | 长树：最小横跨边 |
| 中途形态 | 允许满地碎块（D-F 第二步就收） | 全程一个连通块（D-F 够不着，最后才收） |
| 复杂度 | **O(e log e)**（排序），与顶点数无关 | **O(n²)**，与边数无关 |
| 适合 | **边稀疏**的网 | **边稠密**的网 |

规则：
- 两者**总权一定相同，形状不一定相同**：有等权边时可能挑出不同边集；本图边权互不相同，MST 唯一，所以相同。
- 两者与 Dijkstra 同属**贪心法**。
- **MST 只保证全连通且总造价最低，不保证两点间路径最短**。本图 MST 中 A 到 F 走 A-C-B-D-F = 11，恰等于最短路，属巧合。

## 六、拓扑序列（计算）

**问题**：活动有先后依赖，排一个合法执行顺序。先后关系是单向的，无向边表达不了；依赖成环则谁也开不了工。所以**拓扑排序只对有向无环图（DAG）有意义**。顶点表示活动、有向边表示先后关系的网叫 **AOV 网**（Activity On Vertex）。

把地铁图八条边定向：

```
A→B  A→C  C→B  C→E  B→D  E→D  D→F  E→F
入度：A=0  B=2  C=1  D=2  E=1  F=2
```

**拓扑序列**：把 DAG 全部顶点排成一列，使得**只要有 vi 到 vj 的路径，vi 就在 vj 前面**。

**求法**：输出一个入度为 0 的顶点（没有活动卡在它前面）→ 删去它及其发出的边，被指向的顶点入度减 1 → 重复至全部输出。按字母序打破平局：

```
候选 {A}     → 输出 A，删 A→B、A→C   余下 B=1 C=0 D=2 E=1 F=2
候选 {C}     → 输出 C，删 C→B、C→E   余下 B=0 D=2 E=0 F=2
候选 {B,E}   → 输出 B，删 B→D        余下 D=1 E=0 F=2
候选 {E}     → 输出 E，删 E→D、E→F   余下 D=0 F=1
候选 {D}     → 输出 D，删 D→F        余下 F=0
候选 {F}     → 输出 F
拓扑序列：A C B E D F
```

规则：
- **不一定唯一**：第三步 B、E 同时入度 0，先谁都行。本图共 **2 条**：`A C B E D F`、`A C E B D F`。判断某序列是否合法，逐条检查每条有向边是否「起点在前、终点在后」。
- **排到一半排不动 = 有环**：环上每个顶点都被前一个指着，入度至少 1，永远减不到 0；环若堵住唯一入口，连第一个顶点都输出不了。编译器查循环依赖、Maven 查依赖成环用的就是这一招。

## 速记

- **度之和 = 2e**，有向图**入度和 = 出度和 = e**；无向完全图 **n(n−1)/2**、有向完全图 **n(n−1)** 条边；生成树 **n−1** 条边；连通分量说无向、强连通分量说有向
- **邻接矩阵恒 n²、与边数无关**，无向对称、1 有 **2e** 个，有向**不一定**对称、1 有 **e** 个；**邻接表 n+2e**（无向）/ n+e（有向）结点
- **稠密用矩阵，稀疏用表**；查通断矩阵 O(1)，找全部邻居邻接表快
- **DFS 用栈（递归）、BFS 用队列**；序列随出发点和存储次序变；BFS 只保证边数最少
- **Dijkstra**：每轮确定 dist 最小的未定点再松弛；**单源、边权非负、贪心**；全源用 **Floyd（动态规划）**
- **Kruskal 捡边**（可碎块，O(e log e)，**稀疏**）；**Prim 长树**（一个连通块，O(n²)，**稠密**）；总权同、形状未必同；均为贪心
- **拓扑排序**：入度 0 先输出，删点删边再找；只对 **DAG（AOV 网）**；**通常不唯一**；排不完 = 有环
- 直连边未必最短（A–B 直连 6，A→C→B 只要 4）；MST 不保证两点最短
