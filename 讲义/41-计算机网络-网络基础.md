# 41 · 计算机网络：网络基础

## 定位

一行 `curl` 从本机网卡到另一个城市服务器上的某个进程，要解决八件事：①线怎么布、网多大；②信号怎么表示；③同一根线上谁先发、帧从哪开始、传错怎么办；④跨网走哪条路；⑤包交给哪个进程、丢了要不要重发；⑥会话的开始、结束与恢复；⑦编码、压缩、加密不一致；⑧这次请求到底要干什么。①是布线问题（第一节），②～⑧一层管一件就是 OSI 七层（第二节）；之后是每层的协议（第三、四节）、传输层的两种选择与端口（第五节）、底下的介质（第六节）、介质怎么用（第七节）。全篇概念型，无计算。

---

## 一、网络的功能、分类与拓扑

**原话｜** 计算机网络是计算机技术与通信技术相结合的产物，它实现了远程通信、远程信息处理和资源共享。功能四条：**数据通信、资源共享、负载均衡**（请求分摊到多台机器，如 Nginx 反向代理）、**高可靠性**（一台挂了别的顶上）。

网络**按分布范围和拓扑结构划分**。

| 网络分类 | 分布距离 | 计算机分布范围 | 传输速率范围 |
|---|---|---|---|
| 局域网 LAN | 10m / 100m / 1000m 左右 | 房间 / 楼宇 / 校园 | 4Mbps～1Gbps |
| 城域网 MAN | 10km | 城市 | 50Kbps～100Mbps |
| 广域网 WAN | 100km 以上 | 国家或全球 | 9.6Kbps～45Mbps |

**范围越大，速率越低**：局域网的线是自己的；广域网跨运营商、跨长途链路，带宽是买来的还要与人分享。

| 拓扑 | 形状 | 特点 |
|---|---|---|
| 总线型 | 一条主干线上挂各节点 | 利用率低、干扰大、价格低 |
| 星型 | 中央一个节点向外连 | 交换机形成的局域网、中央单元负荷大 |
| 环型 | 节点串成一个环 | 流动方向固定、效率低扩充难 |
| 树型 | 根往下分级 | 总线型的扩充、分级结构 |
| 分布式 | 任意节点互连 | 任意节点连接、管理难成本高 |

## 二、OSI 七层模型

**OSI**（Open System Interconnection，开放系统互连参考模型）是国际标准化组织出的理论分层标准。自下而上「**物数网传会表应**」，墙②～⑧一层一堵：

| 层 | 职责（原话压缩） | 传输单位 | 典型协议 | 典型设备 |
|---|---|---|---|---|
| 1 物理层 ② | **在链路上透明地传输位**：线路配置、传输模式、信号形式、编码、连接介质；定义建立、维护和拆除物理链路的**机械、电气、功能、规程特性** | 比特 | EIA/TIA RS-232、RS-449、V.35、RJ-45、FDDI | 中继器、集线器 |
| 2 数据链路层 ③ | **把不可靠的信道变为可靠的信道**：比特组成帧、点到点传输、差错控制、流量控制 | 帧 | SDLC、HDLC、LAPB、PPP、STP、帧中继等、IEEE802 | 交换机、网桥 |
| 3 网络层 ④ | 在**源节点-目的节点之间进行路由选择**、拥塞控制、顺序控制、传送包、**保证报文的正确性**；又称**通信子网层** | IP 分组 | IP、ICMP、IGMP、ARP、RARP | 路由器 |
| 4 传输层 ⑤ | 提供**端-端间**可靠的、透明的数据传输，保证报文顺序正确、数据完整 | 报文段 | TCP、UDP | 网关 |
| 5 会话层 ⑥ | 建立通信进程逻辑名字与物理名字的联系，提供进程之间**建立、管理和终止会话**的方法，处理同步与恢复 | — | RPC、SQL、NFS | 网关 |
| 6 表示层 ⑦ | **数据转换**：格式转换、压缩、加密；提供标准的应用接口、公用的通信服务、公共数据表示方法 | — | JPEG、ASCII、GIF、MPEG、DES | 网关 |
| 7 应用层 ⑧ | 「对用户不透明的提供各种服务，如 E-mail」 | 数据 | Telnet、FTP、HTTP、SMTP、POP3、DNS、DHCP 等 | 网关 |

| 术语 | 含义 |
|---|---|
| 四大特性 | 机械（插头形状、尺寸、针脚数，如水晶头 8 针）、电气（多少伏算 1 或 0）、功能（每根针干什么）、规程（信号动作的先后次序） |
| 通信子网层 | 下三层合称通信子网，网络层是其最高层，故得此别名 |
| 帧 / 分组 / 报文段 | 帧＝比特加头尾标记，标出一句话的起止；分组（包）装源、目的 IP，路由器靠它选路；报文段装端口号和序号 |
| 透明 | 感觉不到：物理层不管内容照原样搬；应用层「对用户不透明」＝用户能感知它的服务 |
| 差错控制 / 流量控制 | 发现并处理传错的位 / 让快的一方慢下来，别冲垮接收方 |

**设备判据：能看懂第几层的信息，就工作在第几层。**

| 设备 | 能读懂什么 | 层 |
|---|---|---|
| 中继器、集线器 | 什么地址都不读，只放大、复制电信号到所有端口 | 物理层（1） |
| 网桥、交换机 | 帧里的 **MAC 地址**（网卡出厂烧死的硬件地址） | 数据链路层（2） |
| 路由器、三层交换机 | **IP 地址**，跨网段选路 | 网络层（3） |
| 网关 | 不同体系结构网络之间的协议转换 | **传输层及以上的高层**，不专属某一层 |

**易混对① 交换机 vs 路由器**
- 判据｜只看 MAC、在同一局域网内换个端口送出 → 交换机，二层；看 IP、跨网段选路 → 路由器，三层。
- 例子｜同一办公室两台电脑互传文件经过交换机（二层）；访问另一城市的服务器要经过路由器（三层）；带「交换机」名字但能按 IP 转发的三层交换机归网络层。

**易混对② 三种「之间」**
- 判据｜数据链路层管**相邻结点之间**，网络层管**源节点到目的节点**，传输层才管**端到端**（进程到进程）。
- 例子｜「路由选择、拥塞控制」→ 网络层；「把比特组成帧、差错控制」→ 数据链路层；「进程之间可靠传输」→ 传输层。

排障同样按层：网线松了（1）、交换机端口不通（2）、路由不通（3）、对方端口没监听（4）。

## 三、协议三要素与局域网标准

**原话｜** 网络协议三要素：语法、语义、时序。其中语法部分规定传输数据的格式，语义部分规定所要完成的功能，时序部分规定执行各种操作的条件、顺序关系等。

例子｜HTTP 请求行写成「方法 空格 路径 空格 版本」是语法；`GET` 取、`POST` 提交是语义；先请求后响应是时序。

| 标准 | 名称 | 速率 | 传输介质 |
|---|---|---|---|
| IEEE 802.3 | 标准以太网 | 10Mb/s | 细同轴电缆 |
| IEEE 802.3u | 快速以太网 | 100Mb/s | 双绞线 |
| IEEE 802.3z | 千兆以太网 | 1000Mb/s | 光纤或双绞线 |
| IEEE 802.3ae | 万兆以太网 | 10Gb/s | 光纤 |
| **IEEE 802.11** | **无线局域网 WLAN** | — | 无线 |

后缀 u→百兆、z→千兆、ae→万兆，每档乘十，介质从铜换到光；802.3 是有线，802.11 是无线。同轴电缆＝中间铜芯、外裹金属网（早年有线电视线）；802.3 这一代实际还有粗同轴和双绞线版本，培训资料只写细同轴，记 10Mb/s 即可。

其余认名即可（广域网协议）：**PPP** 点对点协议（拨号和专线上最常用的链路层协议）、**ISDN** 综合业务数字网、**xDSL**（DSL 数字用户线路统称，含 HDSL、SDSL、MVL、ADSL）、**DDN** 数字专线、**x.25**、**FR** 帧中继、**ATM** 异步传输模式。

## 四、TCP/IP 四层与各层协议

OSI 是理论标准，互联网实际跑的是 **TCP/IP 协议族**，四层：

| TCP/IP 四层 | 对应 OSI | 协议（应用层按图上位置分三列） |
|---|---|---|
| 应用层 | 应用 + 表示 + 会话（5/6/7） | 压在 TCP 上：POP3、FTP、HTTP、Telnet、SMTP<br>两框之间空档：Samba、CIFS、NFS（文件共享类，资料未说明走哪个）<br>压在 UDP 上：DHCP、TFTP、SNMP、DNS |
| 传输层 | 传输层（4） | TCP、UDP |
| Internet 层（网际层） | 网络层（3） | IP、ICMP、IGMP、ARP、RARP |
| 网络接口层 | 数据链路层 + 物理层（1/2） | 以太网、令牌环、帧中继、ATM |

**原话｜** 基于 TCP 的 FTP、HTTP 等都是可靠传输。基于 UDP 的 DHCP、DNS 等都是不可靠传输。

| Internet 层协议 | 是什么 |
|---|---|
| **IP** | 网络层核心协议，在源地址和目的地址之间传送数据报，**无连接、不可靠**（尽力送，送不到不补，所以上面要有 TCP） |
| **ICMP** | 因特网控制报文协议，**在 IP 主机、路由器之间传递控制消息**——网络通不通、主机是否可达、路由是否可用等网络本身的消息；`ping` 用它 |
| **ARP** | **将 IP 地址转换为物理地址（MAC）** |
| **RARP** | **将物理地址转换为 IP 地址**（R＝Reverse，反向） |
| **IGMP** | 网络组管理协议，允许计算机参加**多播**（一份数据同时发给一组机器，如视频会议），支持组播 |

| 应用层协议 | 是什么 |
|---|---|
| **FTP** | 可靠的文件传输协议，因特网上控制文件的**双向**传输 |
| **HTTP** | 超文本传输协议，从 WWW 服务器传超文本到本地浏览器；**使用 SSL 加密后为 HTTPS** |
| **SMTP / POP3** | 邮件协议，**邮件报文采用 ASCII 格式**；SMTP 发（Send），POP3 收 |
| **Telnet** | 远程连接协议，因特网远程登录服务的标准协议和主要方式，明文传输不安全 |
| **TFTP** | 不可靠的、开销不大的小文件传输协议 |
| **SNMP** | 简单网络管理协议，由一组网络管理标准协议构成（一个应用层协议、数据库模型和一组资源对象），监测网络设备状况 |
| **DHCP** | 动态主机配置协议，基于 UDP、C/S 模型，为主机动态分配 IP；三种方式：**固定分配、动态分配、自动分配** |
| **DNS** | 域名解析协议，由域名解析出 IP 地址 |

## 五、传输层：TCP 与 UDP、端口、握手与挥手

传输层回答两个问题：要不要保证送达（TCP 还是 UDP），包交给哪个进程（端口号）。可靠要付代价，所以给了两个协议。

| 对比项 | TCP | UDP |
|---|---|---|
| 连接 | **面向连接**（先握手再传） | **无连接** |
| 可靠性 | **可靠**：在 IP 的不可靠数据基础上**采用了重发技术** | **不可靠** |
| 双向性 | **全双工** | — |
| 首部开销 | 20 字节起 | 8 字节 |
| 原话·适用场合 | 传输数据量比较少，且**对可靠性要求高** | 传输数据量大，对可靠性要求不高，但**要求速度快** |
| 典型协议 | FTP、HTTP、SMTP、POP3、Telnet、SSH | **DHCP、DNS、TFTP、SNMP** |

**易混对③ 选 TCP 还是 UDP**
- 判据｜只看能不能容忍丢包：不能 → TCP；能、且要快 → UDP。「数据量少」不作判据（下大文件也用 TCP）。
- 例子｜直播推流丢一帧没人在意、为重传卡半秒不行 → UDP；下载安装包错一位就装不上 → TCP。

**易混对④ OSI 传输层「可靠」vs UDP「不可靠」**
- 判据｜OSI 描述这一层应提供的服务（可靠、透明）；TCP/IP 给了两个实现，TCP 兑现可靠，UDP 放弃可靠换速度。
- 例子｜问 OSI 传输层功能 → 可靠、透明的端到端传输；问 UDP → 不可靠。

**端口**：IP 把包送到机器，端口号指明机器上哪个程序；常用服务端口固定，客户端才不必先问。

| 端口 | 服务 | 端口 | 服务 |
|---|---|---|---|
| 20 | FTP（数据） | 69 | TFTP |
| 21 | FTP（控制） | 80 | HTTP |
| 22 | SSH（加密远程登录，Telnet 的安全替代） | 110 | POP3（邮箱接收） |
| 23 | Telnet | 161 | SNMP（轮询） |
| 25 | SMTP（邮件发送） | 162 | SNMP（陷阱） |
| 53 | DNS | 443 | HTTPS |
| 67 / 68 | DHCP 服务端 / 客户端 | | |

SSH 比 Telnet 安全，号也在它前面（22、23 相邻）。

**三次握手**（TCP 可靠，传数据前先建连接）：
1. 客户端发 **SYN**（同步标志位：「我想建连，初始序号 x」）
2. 服务器回 **SYN+ACK**（ACK 确认标志位：「确认收到 x，我的初始序号 y」）
3. 客户端回 **ACK**（「确认收到 y」）

两次不够：滞留很久的旧 SYN 也能让服务器白建连接干等；第三次 ACK 让服务器确认客户端此刻真的在、且收得到。

**四次挥手**：**FIN**（结束标志位）→ **ACK** → 对方发完剩余数据 → **FIN** → **ACK**。比握手多一次，因为 TCP 全双工、两个方向分别关：收到 FIN 时自己可能还有数据没发完，只能先回 ACK，**ACK 和 FIN 中间隔着数据，合并不成一个报文**。

## 六、传输介质

**双绞线**：多根铜线按规则缠绕以减少干扰，即**网线**；分**无屏蔽 UTP** 和**屏蔽 STP**，都由一对铜线簇组成；**传输距离 100m 以内**，超过要加中继或换光纤。

| 类别 | 速率 / 说明 |
|---|---|
| UTP | 价格低、安装简单、可靠性相对较低 |
| STP | 多一层屏蔽层，可靠性更高、价格高、安装麻烦，用于可靠性要求很高的场合 |
| CAT3 | 10Mbps |
| CAT4 | 与 3 类差不多，无应用 |
| CAT5 | 100Mbps，用于快速以太网 |
| CAT5E（超 5 类） | 1000Mbps |
| CAT6 | 替代 CAT5E，1000Mbps |

水晶头（RJ-45）两种线序（针脚 1～8）：**T568A** 白绿、绿、白橙、蓝、白蓝、橙、白棕、棕；**T568B** 白橙、橙、白绿、蓝、白蓝、绿、白棕、棕。**区别在 1、2、3、6 四根**，4、5、7、8 相同。

**光纤**由**纤芯和包层**组成，光信号在纤芯中传输；PC 出来的是电信号，需先转为光信号。两种光纤的差别都来自纤芯粗细：

| | 多模光纤 MMF | 单模光纤 SMF |
|---|---|---|
| 纤芯半径 | 较大 | 很小 |
| 信号 | **可以同时传输多种不同的信号** | **一般只能传输一种信号** |
| 光源 | **发光二极管 LED** | **激光二极管 LD**，只支持激光信号 |
| 反射 | 全反射（光打到纤芯壁被全部弹回） | 全反射，反射角很大，看起来像直线 |
| 成本与可靠性 | 成本低，效率和可靠性较低 | 成本高，可靠性高 |
| 距离 | 近：100Mbps 时 2KM，1000Mbps 时 550m | 远：可达 5KM |

**易混对⑤ 单模 vs 多模的光源**
- 判据｜细芯只走一束激光 → 单模用 LD；粗芯容多种信号 → 多模用 LED。
- 例子｜「单模光纤采用 LED 作为光源」是错的，应为 LD。

**无线信道**：无线电波（按波长由长到短：长波、中波、短波、超短波、微波；微波分**地面微波**和**卫星微波**）和红外光波（近、中、远红外线）两大类。

## 七、通信方式与交换方式

| 方式 | 是什么 |
|---|---|
| **单工** | 只能 A 发给 B，单向流动（广播电台） |
| **半双工** | 可互相通信，**但同一时刻只能单向流动**（对讲机） |
| **全双工** | **任意时刻都能互相通信**（打电话） |
| **异步传输** | 每个字符首尾插**起始位和停止位**标出边界；资源浪费、效率低 |
| **同步传输** | 以**数据块**为单位：**先发同步帧**，接收方准备好后收数据块，**结束后有结束帧确认**；效率高 |
| **串行传输** | **一根数据线**，1bit 挨个传；低速设备、远距离，一般用于广域网 |
| **并行传输** | **多根数据线**，同时传多个 bit；高速设备，常用于计算机内部各硬件模块之间 |

方向只有单工、半双工、全双工三类，没有「全单工」。画法：单工一个单向箭头，半双工一个双头箭头标「每次一个方向」，全双工两个方向各一箭头。

三种交换方式回答「线是独占还是轮流用」：

| 交换方式 | 怎么走 | 连接 / 可靠 | 特点 |
|---|---|---|---|
| **电路交换** | 一方呼叫、另一方接收后**建立专用电路** | **面向连接** | **实时性高、链路利用率低**；用于语音视频 |
| **报文交换** | **以报文为单位，存储转发**：先存下做差错校验，没错才转发，有错丢弃 | **面向无连接**，可靠性高 | 有延迟 |
| **分组交换·数据报** | 以分组为单位、存储转发，分组较小；**各分组携带地址信息，自由选择不同路由**，接收方按地址重组；现在的主流 | **面向无连接，不可靠** | **时延小于报文交换** |
| **分组交换·虚电路** | 首个分组建立**虚拟通信线路**，后续分组都走它，空闲时这条线也可传别的数据 | **面向连接，可靠** | 同上 |
| **分组交换·信元交换** | **ATM 采用**，按虚电路方式转发；**信元是固定长度分组，共 53B，5B 头部、48B 数据域** | 面向连接，可靠 | 定长 |

**存储转发**＝中间节点完整收下、检查完再发，所以报文交换可靠却有延迟。

**易混对⑥ 电路交换 vs 虚电路**
- 判据｜真独占一条物理线路 → 电路交换；只是双方记着一条约定路径、线仍共享 → 虚电路。两者都面向连接，虚电路利用率更高。
- 例子｜传统电话通话占住整条线路 → 电路交换；ATM 信元沿建好的虚拟路径转发、空闲时线路被别人用 → 虚电路。

## 速记

- 七层「**物数网传会表应**」；单位**比特—帧—IP 分组—报文段—数据**；设备**1 中继集线、2 网桥交换、3 路由（含三层交换）、传输层及以上网关**，看得懂第几层就在第几层
- 四层对七层：**应用=5/6/7，传输=4，Internet=3，网络接口=1/2**；链路层相邻结点、网络层源到目的、传输层端到端
- 功能：数据通信、资源共享、负载均衡、高可靠性；LAN 1Gbps / MAN 100Mbps / WAN 45Mbps，**范围越大速率越低**；拓扑：总线、星、环、树、分布式
- 协议三要素**语法、语义、时序**；802.3 10M、u 百兆双绞线、z 千兆、ae 万兆光纤，**802.11 无线**
- 端口 **20/21 FTP、22 SSH、23 Telnet、25 SMTP、53 DNS、67/68 DHCP、69 TFTP、80 HTTP、110 POP3、161/162 SNMP、443 HTTPS**；**UDP 四个：DHCP、DNS、TFTP、SNMP**
- TCP 面向连接可靠全双工 20B 起，UDP 无连接不可靠 8B；**SYN→SYN+ACK→ACK；FIN→ACK→FIN→ACK**
- **ARP：IP→MAC**，RARP 反向；ICMP 控制消息（ping）；IGMP 组播；IP 无连接不可靠
- 双绞线 **100m**、CAT5 百兆、5E/6 千兆；**单模细芯 LD 5KM，多模粗芯 LED 近**；电路面向连接利用率低、报文无连接有延迟、数据报无连接不可靠、虚电路面向连接可靠、**信元 53B（5+48）**
