# 42 · 计算机网络：IP 地址与子网划分

## 定位

32 个二进制位怎么切成"在哪个网 + 是哪台机"，切完后一个地址属于哪个子网、能装几台、广播地址是几；IPv4 用完后 IPv6 怎么接手。接 41 的分层骨架（网络层负责跨网络送包），本课讲网络层地址本身。全课跟着一段地址走：公司拿到 **192.168.10.0～192.168.10.255** 共 256 个地址，要分给市场、研发、财务、行政四个部门；第三节硬切一遍，公式从切的过程里长出来，第五节再用公式把其中一台 **192.168.10.130** 算透。

---

## 一、IP 地址的写法（计算）

机器里一个 IP 地址就是 **32 位二进制**。每 8 位一段、每段转十进制、点号隔开，叫**点分十进制**（配置文件里的 `192.168.1.1`）。

原话｜「机器中存放的 **IP 地址是 32 位的二进制代码，每隔 8 位插入一个空格**，可提高可读性，为了便于理解和设置，一般会采用**点分十进制**方法来表示」。

```
10000000  00001011  00000011  00011111
   128       11         3         31      → 128.11.3.31
```

- 一段 8 位，权从高到低 128、64、32、16、8、4、2、1；全 1 = **255**，全 0 = 0，所以每段 **0～255**，`192.300.1.1` 这种不合法。（二↔十换算见讲义 01。）
- 总数 2³² = **4 294 967 296**，约 43 亿，第八节 IPv6 要用。

## 二、网络号与主机号；A～E 分类（概念）

地址若是平的一片，路由器（把包从一个网络转到另一个网络的设备）得为 43 亿台机器各记一条路。所以把 32 位劈成两截：

| 部分 | 说什么 | 类比 |
|---|---|---|
| **网络号**（Net-ID） | 这台机器在哪个网络 | 街道 |
| **主机号**（Host-ID） | 在这个网络里是第几台 | 门牌号 |

路由器只按网络号选路，一个网络在路由表里只占一行。**IP 地址有层次，这是它和网卡出厂烧死的物理地址（平的，看不出在哪个网络）最大的不同**（两者转换协议见讲义 41）。

最早的刀口按开头几位**按类别固定切**：

| 类别 | 首位特征 | 首字节范围 | 网络位／主机位 | 默认掩码 | 每网可用主机数 | 用途 |
|---|---|---|---|---|---|---|
| A | `0` 开头 | 1～126 | 8／24 | 255.0.0.0（/8） | 2²⁴−2 = **16 777 214** | 网络极少、每网机器极多 |
| B | `10` 开头 | 128～191 | 16／16 | 255.255.0.0（/16） | 2¹⁶−2 = **65 534** | 中等规模 |
| C | `110` 开头 | 192～223 | 24／8 | 255.255.255.0（/24） | 2⁸−2 = **254** | 网络极多、每网机器少 |
| D | `1110` 开头 | 224～239 | — | — | — | **组播**（一份数据同时发给一组机器） |
| E | `1111` 开头 | 240～255 | — | — | — | 保留作实验 |

掩码与 −2 的来历见第三、四节。

- **A 类到 126 为止**：「首位为 0」圈出的全部范围是 0.0.0.0～127.255.255.255，但首字节 0 被"本网络"占用、127 被环回测试占用（第七节），实际可分配 **1～126**。
- **D、E 类**不切网络号主机号、没有默认掩码——它们不用来标识"某网络里的某台机"。

**分类法的毛病＝子网划分要解决的问题。** 原话｜「一般公司在申请网络时，会直接获得一个范围很大的网络，如一个 B 类地址，因为**主机数之间相差的太大了，不利于分配**，我们一般采用**子网划分的方法来划分网络，即自定义网络号位数**，就能自定义主机号位数，就能根据主机个数来划分出最适合的方案，不会造成资源的浪费」。例：要 300 台，C 类 254 台不够，B 类 65534 台浪费 6 万多；刀口只有三个固定位置，太僵。

## 三、子网划分：256 个地址分四个部门（计算）

192.168.10.0～255 首字节 192，是 C 类，默认刀口在第 24 位。

1. 256 ÷ 4 = 64，按顺序切：

```
市场部  192.168.10.0   ～ .63     末字节 0000 0000 ～ 0011 1111   高 2 位固定 00
研发部  192.168.10.64  ～ .127    末字节 0100 0000 ～ 0111 1111   高 2 位固定 01
财务部  192.168.10.128 ～ .191    末字节 1000 0000 ～ 1011 1111   高 2 位固定 10
行政部  192.168.10.192 ～ .255    末字节 1100 0000 ～ 1111 1111   高 2 位固定 11
```

2. 每块内部末字节**高 2 位不动、低 6 位从全 0 变到全 1**：固定的位决定在哪一块，能变的位决定是块里第几个。
3. 固定段 = 24 + 2 = **26 位**。多固定的 2 位叫**子网号**——从主机号借来当网络号用，地址由两段变成**网络号＋子网号＋主机号**三段。
4. 把界线写下来：造一个 32 位数，固定段写 1、能变段写 0，即**子网掩码**。原话｜「网络号和子网号都为 1，主机号都为 0，这样的地址为子网掩码。」

```
子网掩码  1111 1111 . 1111 1111 . 1111 1111 . 1100 0000
             255         255         255         192       → 255.255.255.192
```

5. 数量：能变 6 位 → 每块 2⁶ = **64** 个地址；借 2 位 → 2² = **4** 块。

**规则**：每块地址数 = 2^主机位数；子网数 = 2^借的位数（把 /a 划成 /b，借 b − a 位）。

## 四、−2：网络地址与广播地址（计算）

财务部 .128～.191 共 64 个地址，能接的机器是 **62** 台：

| 地址 | 末字节 | 主机位 | 名称 | 作用 |
|---|---|---|---|---|
| 192.168.10.128 | `1000 0000` | 全 0 | **网络地址**（子网地址） | 整块的名字，"192.168.10.128/26"就指这一块；不能派给机器 |
| 192.168.10.191 | `1011 1111` | 全 1 | **广播地址** | 原话｜网络号 = Net-ID、主机号全 1：「对 net-ID 上的所有主机进行广播」，往它发包＝对整块喊话；不能派给机器 |

可配到网卡上的：**192.168.10.129～192.168.10.190**。

> **可用主机数 = 2^主机位数 − 2**

原话｜「**要注意的是**：子网号可以为全 0 和全 1，**主机号不能为全 0 或全 1，因此，主机数需要 -2**，而子网数不用。」

**减 2 只减主机数，不减子网数**：借来的 2 位取 `00`、`11` 都算，四个部门都成立；每块的 64 个地址要扣掉两头。

## 五、给地址反推子网：四步（计算）

已知 IP **192.168.10.130**、掩码 **255.255.255.192**，求网络地址、可用主机数、可用范围、广播地址。

0. **掩码转 /n，找要动手的字节**：三个 255 各 8 个 1，末字节 192 = `1100 0000` 再 2 个 → **/26**。前三字节掩码全 1，与运算后不变，照抄 192.168.10，**只算末字节**（提速关键，把 32 位全展开最容易错）。
1. **转二进制**：

```
IP 末字节    130 = 128 + 2  = 1000 0010
掩码末字节   192 = 128 + 64 = 1100 0000
```

2. **按位与得网络地址**（两位都是 1 才得 1，有 0 得 0）：

```
    1000 0010      130
AND 1100 0000      192
  = 1000 0000      = 128     → 网络地址 192.168.10.128
```

为什么：掩码能变段是 0，AND 后主机位归零；固定段是 1，网络位原样保留——**主机位归零、网络位保留，正是网络地址的定义**。130 落在第三节财务部那一块。

3. **可用主机数**：主机位 32 − 26 = **6** → 块大小 2⁶ = 64 → 可用 2⁶ − 2 = **62**。
4. **范围与广播**：主机位从全 0 数到全 1。

```
网络地址   192.168.10.128    1000 0000   主机位全 0
首个可用   192.168.10.129    1000 0001
末个可用   192.168.10.190    1011 1110
广播地址   192.168.10.191    1011 1111   主机位全 1
```

**块大小验算**：块大小 2⁶ = 64，块起点必是 64 的倍数：0、64、128、192；130 在 128～191 之间 ✅；191 − 128 + 1 = 64 ✅，扣两头 62 ✅。答成 .0（把掩码当 /24）或 .192（块归错）都会在这一步露馅。

**反推掩码**：已知要分几个子网、每子网至少几台时，先取满足 2ⁿ ≥ 子网数的最小 n 作借位（够用就停），再验 2^(剩余主机位) − 2 是否够台数——多借一位主机数就砍半。

## 六、CIDR 与超网（计算）

刀口由掩码说了算，A/B/C 类已不重要，叫**无分类编址**。原话｜「即不按照 A B C 类规则，自动规定网络号，无分类编址格式为：IP 地址/网络号，示例：128.168.0.11/20 表示的 IP 地址为 128.168.0.11，其网络号占 20 位，因此主机号占 32-20=12 位，也可以划分子网。」"斜杠 + 数字"叫 **CIDR 记法**（无类别域间路由），数字＝掩码中 1 的个数。

**/n ↔ 点分十进制掩码**：

```
/26 → 26 = 24 + 2 → 末字节高 2 位为 1 → 128+64 = 192          → 255.255.255.192
255.255.255.224 → 224 = 128+64+32 = 1110 0000 → 3 个 1 → 24+3 → /27
```

| /n | /25 | /26 | /27 | /28 |
|---|---|---|---|---|
| 掩码末字节 | 128 | 192 | 224 | 240 |

规律：末字节值 = 256 − 块大小。

**超网**：原话｜「还可以**聚合网络为超网**，就是划分子网的逆过程，将**网络号取出几位作为主机号**，此时，这个网络内的主机数量就变多了，成为一个更大的网络。」

1. 192.168.0.0/24、192.168.1.0/24、192.168.2.0/24、192.168.3.0/24 四个连续 C 类网络，第三字节：`0000 0000`、`0000 0001`、`0000 0010`、`0000 0011`。
2. 前 6 位相同，低 2 位在变 → 把这 2 位还给主机号，前缀 24 − 2 = 22。
3. 聚合为 **192.168.0.0/22**，主机位 10 位，可用 2¹⁰ − 2 = **1022** 台。

规则：聚合后的前缀长度 = 几个网络共同的前导位数。子网划分＝网络号变长、主机数变少；超网聚合＝网络号变短、主机数变多。

## 七、特殊地址（概念）

| 类型 | 原话 / 是什么 |
|---|---|
| **公有地址** | 「**通过它直接访问因特网。是全网唯一的 IP 地址。**」 |
| **私有地址** | 「属于**非注册地址，专门为组织机构内部使用**，不能直接访问因特网」——公司内网、家用路由器后面的地址，各家重复使用互不冲突，因为不出门 |

| 类别 | 私有地址范围 | CIDR | 可容纳的网络数 |
|---|---|---|---|
| A | 10.0.0.0 ～ 10.255.255.255 | 10.0.0.0/8 | 1 |
| B | 172.16.0.0 ～ 172.31.255.255 | 172.16.0.0/12 | 16 |
| C | 192.168.0.0 ～ 192.168.255.255 | 192.168.0.0/16 | 256 |

按"网络号 + 主机号各取什么值"记：

| 地址 | 原话 / 含义 | 能作 |
|---|---|---|
| 0.0.0.0（网络号 0、主机号 0） | 「在本网络上的本主机」，开机还不知道自己 IP 时用 | **只作源地址** |
| 255.255.255.255（全 1） | 「在本网络上进行广播」 | **只作目的地址** |
| Net-ID + 主机号全 1 | 对该网络所有主机广播，如第四节的 192.168.10.191 | **只作目的地址** |
| 127 开头 | 「用作本地软件环回测试之用」，常见 127.0.0.1，包在本机掉头、不上网线；A 类因此只到 126 | — |
| 169.254 开头 | 「Windows 主机 DHCP 服务器故障分配」：开机没从 DHCP（自动派发 IP 的服务，见讲义 41）拿到地址，自己配一个临时地址；`ipconfig` 里看到它基本等于没联上网 | — |

**易混对① 私有 B 段 vs 整个 172.x**
- 判据｜看第二字节是否在 16～31：在 → 私有；不在 → 公网。
- 例子｜172.20.8.1 私有；172.15.8.1、172.32.8.1 都是公网。

**易混对② 0.0.0.0 vs 255.255.255.255**
- 判据｜全 0 是"我自己"，只作源；全 1 是"本网所有人"，只作目的。
- 例子｜刚开机求 IP 的机器发包，源填 0.0.0.0、目的填 255.255.255.255。

## 八、IPv6

### （概念）

原话｜「主要是为了解决 IPv4 地址数不够用的情况而提出的设计方案」；「**IPv6 地址长度为 128 位，地址空间增大了 2^96 倍**」（2¹²⁸ ÷ 2³² = 2⁹⁶）。

| 特性 | 内容 |
|---|---|
| 长度 | **128 位** |
| 头部 | 灵活的报文头部格式：用一系列**固定格式的扩展头部**取代 IPv4 中可变长度的选项字段，路由器可简单跳过选项不做处理；简化报文头部，加快转发、提高吞吐量 |
| 安全 | 原话｜「身份认证和隐私权是 IPv6 的关键特性」 |
| 其他 | 支持更多服务类型；允许协议继续演变、增加新功能 |
| 地址类型（教材补） | 只有**单播、组播、任播**，**取消广播**（由组播接管）；任播＝发给一组机器中离我最近的那一台 |

过渡期「三种基本技术」：

| 技术 | 做法 | 一句话 |
|---|---|---|
| **双协议栈** | 主机同时跑 IPv4、IPv6 两套协议栈 | 两种话都会说 |
| **隧道技术** | IPv6 数据报作为 IPv4 数据报的数据部分封装，加 IPv4 首部，在 IPv4 网络里穿过 | 包在 IPv4 里偷渡 |
| **翻译技术** | 专门的翻译设备（转换网关）在纯 IPv4 与纯 IPv6 网络之间转换 IP 报头地址并做语义翻译 | 翻译官现场改报头 |

### （计算）写法与简写

按教材《软件设计师教程》第 5 版：128 位分 **8 组**，每组 16 位写成 **4 个十六进制数字**，冒号隔开（8 × 16 = 128）。简写：① 每组**前导零可省**；② 连续全零组压成 `::`，**全地址只能用一次**（用两次无法反推各代表几组零）。

```
原地址    2001:0db8:0000:0000:0000:0000:0000:0001
省前导零  2001:db8:0:0:0:0:0:1
压全零组  2001:db8::1
验算：显式 3 组（2001、db8、1），:: 补回 8 − 3 = 5 组全零 ✅
```

## 速记

- 32 位、每 8 位一段 0～255、共 2³² ≈ 43 亿；A 1～**126**（127 环回）、B 128～191、C 192～223、D 组播 224～239、E 保留；默认 /8、/16、/24
- 掩码：网络号与子网号写 1、主机号写 0；**IP AND 掩码 = 网络地址**
- 主机位**全 0 网络地址、全 1 广播地址** → 可用主机 = 2^主机位 − 2；**子网数 = 2^借位数，不减 2**
- 只算掩码有变化的那个字节；块大小 = 2^主机位，块起点是它的倍数
- /25→128、/26→192、/27→224、/28→240（= 256 − 块大小）；超网前缀 = 共同前导位数
- 私有：**10/8、172.16～172.31、192.168/16**；0.0.0.0 只作源、255.255.255.255 只作目的；169.254 = 没拿到地址的自配
- IPv6：**128 位**、8 组×4 位十六进制、前导零可省、`::` 只用一次；**取消广播、有任播**；过渡＝双协议栈／隧道／翻译
