## 第 1 层 · 理解

### 一句话

> 这一章回答一件事：**一个数据包在网络里，究竟靠什么找到目标机器**。答案是"**两套地址 + 三个配套服务 + 一种隔离手段 + 一套划分算法**"——IP 管远、MAC 管近，ARP 负责翻译、DHCP 负责发地址、DNS 负责翻域名，VLAN 负责把广播圈小，子网掩码负责决定"网络号和主机号的分界线画在哪"。

### 痛点：这些你天天用，但说不清

- **配 Docker / K8s 网络时写的 `--subnet 10.244.0.0/16`**——这个 `/16` 到底表示什么？能装多少台？和 `255.255.0.0` 是不是一回事？说不清就只能抄别人的配置。
- **"同网段能 ping 通，跨网段 ping 不通"**——是网关配错了、掩码写错了、还是路由缺一条？不懂"IP 不变 MAC 逐跳变"就无从下手。
- **办公室突然集体断网，运维说"有人 ARP 欺骗"**——为什么随便一台机器就能冒充网关？（因为 ARP 应答不做任何身份验证。）
- **面试老问"有了 MAC 为什么还要 IP"**——回答"一个是硬件地址一个是逻辑地址"是背来的，说不到点上：**MAC 是扁平的，看不出机器在哪个网络，路由器没法据此选路**。

### 一条主线

```
第 38 课的分层图里，网络层的活是"跨网络把包送到那台机器"。
但光靠网卡出厂烧的 MAC 地址，这活干不成 ——
   MAC 全球唯一，可它是【扁平的】：知道一个 MAC，你不知道这机器在世界哪个网络
   类比：身份证号能唯一认人，但快递不能按身份证号送货，得按"省-市-街道"
   ↓
所以另造一套【有层次】的地址：IP = 网络号 + 主机号
   路由器只看网络号，就能一级级把包推向目的网络
   ↓
两套地址并存，立刻冒出三个必须回答的问题：

  ┌ 问题① 一个包同时带着 IP 和 MAC，转发路上它俩各自怎么变？
  │     → 【IP 是端到端的，全程不变；MAC 是逐跳的，每过一个路由器换一对】
  │        （目的 IP = 快递面单的收货地址；MAC = 每一程司机的交接单）
  │
  ├ 问题② 真要把帧发出去必须填对方 MAC，可我手上只有 IP，谁来翻译？
  │     → 【ARP】：本网段【广播去问】，目标主机【单播来答】，结果进 ARP 缓存
  │        （反方向 MAC→IP 是 RARP，早期无盘工作站用，已被 DHCP 取代）
  │        ⚠ ARP 应答不验证身份 → 谁都能喊"我是网关" → ARP 欺骗（第40课）
  │
  └ 问题③ IP 不像 MAC 是烧死的，谁给我配？人记不住的数字串又怎么办？
        → 【DHCP】开机自动下发 IP+掩码+网关+DNS 四件套（Discover→Offer→Request→ACK）
        → 【DNS】域名翻成 IP（客户端对本地服务器【递归】，服务器之间【迭代】）
   ↓
注意问题②的解法是【广播】。网段一大，广播就成灾：
   广播流量挤占带宽（广播风暴）＋ 二层直达无隔离（财务和访客互相可达）
   → 【VLAN】：在交换机上把端口逻辑分组，一组一个广播域
      VLAN 隔的是【二层】，所以不同 VLAN 就相当于不同子网
      → 【跨 VLAN 通信必须经过路由器或三层交换机】（本课最高频结论）
   ↓
既然反复提到"不同子网"，那就必须回答：网络号和主机号的分界线画在哪？
   早期答案：按首字节固定分类 A/B/C/D/E —— 太僵硬，要么不够用要么大浪费
   现在答案：【子网掩码】自由指定分界线
             IP AND 掩码 = 网络地址；主机位全 0 是网络地址、全 1 是广播地址
             → 可用主机数 = 2^主机位数 − 2      ← 本课唯一要动手算的东西
   ↓
可是不管怎么切，IPv4 一共才 2³² ≈ 43 亿个地址，早就分完了（靠 NAT 续命）
   → 【IPv6】128 位，冒号分隔 8 组十六进制，:: 压零只能用一次
      顺带：取消广播、新增任播，报头固定 40 字节，内置 IPSec
```

### 考点① IP 与 MAC 的分工 + 跨网段转发的"不变量"【真题·2024上；相关标注 2022下/2024下】

**题目长相**："主机 A 通过两个路由器向另一网段的主机 B 发送 IP 分组，在整个转发过程中**保持不变**的是（ ）"；或"关于 IP 地址与 MAC 地址的叙述，错误的是（ ）"。

**怎么解**：记住**一条结论 + 一张对照表**。结论就是——**源/目的 IP 全程不变，源/目的 MAC 逐跳更换**。

**场景**（沿用 v1 的具体地址，后面考点② 的 ARP 例子接着用）：主机 **A（192.168.1.10）** 给另一网段的服务器 **B（10.0.0.5）** 发数据，中间经过路由器 **R1、R2**；A 配的默认网关是 **192.168.1.1**，也就是 R1 的入口。

```
A ──帧①──> R1 ──帧②──> R2 ──帧③──> B

帧①  源MAC=A的MAC     目的MAC=R1入口MAC   │ 源IP=A  目的IP=B
帧②  源MAC=R1出口MAC  目的MAC=R2入口MAC   │ 源IP=A  目的IP=B
帧③  源MAC=R2出口MAC  目的MAC=B的MAC      │ 源IP=A  目的IP=B
```

- A 先用**子网掩码**判断出 B 和自己**不在同一网段**，于是把帧发给**默认网关**（R1）——注意此时目的 MAC 填的是 **R1 的**，不是 B 的。
- IP 头里的源/目的 IP 是"从哪来、到哪去"的**端到端**信息，全程不动（不考虑 NAT，考试默认场景不涉及）；MAC 是"**这一跳交给谁**"的逐跳信息，每过一个路由器就换一对。
- 类比：目的 IP = 快递面单上的收货地址（始终不改）；MAC = 每一程承运司机的交接单（换一程换一张）。

| 对比项 | MAC 地址 | IP 地址 |
|---|---|---|
| 所在层 | 数据链路层 | 网络层 |
| 长度 | **48 位**（12 个十六进制数） | IPv4 为 **32 位** |
| 结构 | **扁平**，无位置含义 | **层次化**：网络号 + 主机号 |
| 分配 | 网卡出厂固化 | 手工配置或 DHCP 动态分配 |
| 作用范围 | **同一网段内**相邻设备间寻址 | **跨网络**端到端寻址 |

**陷阱**：
- 错误选项常说"**MAC 地址全程不变**"或"**目的 MAC 一开始就填 B 的**"——都错。同网段才直接填对方 MAC；跨网段第一跳填的是**网关的 MAC**。
- 也有反过来考"整个过程改变的是什么"，答案就是 MAC（源和目的都换）。
- 长度别记混：**MAC 48 位、IPv4 32 位、IPv6 128 位**，三个数字是常见的填空点。

### 考点② ARP / RARP 的方向【真题·2022下】

**题目长相**："ARP 协议的作用是（ ）。A. 将域名解析为 IP B. 将 IP 解析为 MAC C. 将 MAC 解析为 IP D. 动态分配 IP"

**怎么解**：**A**ddress **R**esolution **P**rotocol——**已知 IP，求它的 MAC**。工作方式八个字：**广播去问，单播来答**。

1. A 在本网段**广播** ARP 请求（目的 MAC 填全 1 的 `FF:FF:FF:FF:FF:FF`）："谁是 192.168.1.1？请把 MAC 告诉 192.168.1.10。"
2. 网段内所有主机都收到，只有 IP 匹配的那台（R1）**单播**回复："我是，我的 MAC 是 xx:xx:…"。
3. A 把结果存进 **ARP 缓存**，一段时间内不必重问。

**陷阱**：这道题的四个选项是**四个协议的功能大乱炖**，看清方向就不会错——
- 域名 → IP 是 **DNS**；
- IP → MAC 是 **ARP**；
- MAC → IP 是 **RARP**（早期无盘工作站用，现已被 DHCP 取代，考试只考"方向"辨析）；
- 动态分配 IP 是 **DHCP**。
- 另一个高频延伸：**ARP 应答不做身份验证**，任何机器都能冒充网关应答——这就是 **ARP 欺骗**的原理（第 40 课信息安全展开）。

### 考点③ VLAN 的作用与跨 VLAN 通信【真题·2024下】

**题目长相**："在交换机上划分 VLAN 的主要作用是（ ）"；或"同一交换机上不同 VLAN 的两台主机能否直接通信"。

**怎么解**：先明白**为什么需要它**——交换机组成的局域网默认是**一个广播域**，任何一台主机发广播（比如上面的 ARP 请求），全网都得收。机器一多就三个毛病：①广播泛滥挤占带宽（**广播风暴**）；②财务部和访客机器在二层直接可达，**不安全**；③想按部门隔离就得买多台交换机重新布线，**僵硬**。

**VLAN（虚拟局域网）**：在交换机上把端口**逻辑**划分成若干组，每组是一个独立的广播域，广播只在本 VLAN 内传播。同一 VLAN 的成员即使接在**不同交换机**上也能二层互通（交换机间链路用 **802.1Q 标签**标明帧属于哪个 VLAN）；不同 VLAN 即使插在**同一台交换机**上也二层不通。

- **好处三条**：**隔离广播域**（抑制广播风暴）、**增强安全**（部门间二层隔离）、**灵活管理**（调整分组改配置即可，不动网线）。
- **最高频结论**：VLAN 隔的是二层，**不同 VLAN 相当于不同子网，跨 VLAN 通信必须经过三层设备——路由器或三层交换机**。

**陷阱**：错误选项爱写这三种——
- "VLAN 可以**提高链路传输速率**" → 不能，它管的是广播范围不是带宽速率；
- "VLAN **扩大冲突域**" → 反了，交换机本来就每口一个冲突域，VLAN 缩小的是**广播域**；
- "使不同 VLAN 的主机**无需路由即可通信**" → 正好说反，跨 VLAN **必须**走三层。

### 考点④ 子网掩码计算（本课唯一计算考点，**阶段B 重点**）+ IP 地址分类

**题目长相**："某主机 IP 为 192.168.10.130，子网掩码为 255.255.255.192，其所在子网的**网络地址**是（ ）"；也会问"该子网**可用主机数**"、"**广播地址**"、"某地址属于**哪一类**"。

**怎么解**（三条规则，完整算例见第 3 层）：
1. 掩码是 32 位，**左边连续的 1 对应网络位，右边连续的 0 对应主机位**。`/26` 就是"前 26 位为 1"。
2. **IP 与掩码按位与（AND）= 网络地址**。
3. 主机位**全 0 是网络地址本身、全 1 是广播地址**，两个都不能分给主机 → **可用主机数 = 2^主机位数 − 2**。

**分类地址**（掩码出现之前的老办法，看首字节范围判类别）：

| 类别 | 首位特征 | 首字节范围 | 默认掩码 | 用途 |
|---|---|---|---|---|
| A | **0** 开头 | **1–126** | 255.0.0.0 (**/8**) | 网络少、每网主机极多 |
| B | **10** 开头 | **128–191** | 255.255.0.0 (**/16**) | 中等规模 |
| C | **110** 开头 | **192–223** | 255.255.255.0 (**/24**) | 网络多、每网最多 **254** 台主机 |
| D | **1110** 开头 | **224–239** | — | **组播**地址 |
| E | **1111** 开头 | 240–255 | — | 保留实验用 |

- **127 开头**（如 127.0.0.1）是**环回地址**，本机测试用，**不属于 A 类可分配范围**（所以 A 类到 126 为止）。
- **私有地址**（内网用，公网不路由）：**10.0.0.0/8**、**172.16.0.0–172.31.255.255**、**192.168.0.0/16**。

**陷阱**：
- 算网络地址时**只需处理掩码有变化的那一个字节**，其余字节掩码全 1，直接照抄——很多人整串转二进制反而算错。
- **可用主机数别忘了减 2**（网络地址 + 广播地址各占一个）。C 类默认掩码下是 2⁸−2 = **254**，不是 256。
- **A 类首字节是 1–126 不是 1–127**，127 被环回占了；这是分类题最爱挖的坑。
- 172 开头的私有地址范围是 **172.16–172.31**，不是整个 172.x。

### 考点⑤ IPv6【真题·2021上】

**题目长相**："IPv6 地址的长度为（ ）位。A. 32 B. 64 C. 128 D. 256"；或给一个完整地址让你**写成最简形式**；或"IPv6 相比 IPv4 的改进，错误的是（ ）"。

**怎么解**：先记住**动机**——IPv4 只有 32 位、约 43 亿个地址，早已分完（靠 NAT 勉强续命），所以 IPv6 直接扩到 **128 位**，顺带简化报头、原生支持自动配置。

**表示法**：128 位分 **8 组**，每组 16 位写成 **4 个十六进制数**，冒号分隔。两条简写规则：
① 每组的**前导零可省**；
② **连续的全零组可压缩成 `::`，但整个地址里只能用一次**（用两次就无法反推各代表几组零了）。

| 对比项 | IPv4 | IPv6 |
|---|---|---|
| 地址长度 | **32 位** | **128 位** |
| 表示法 | 点分十进制（192.168.1.1） | 冒号分隔十六进制（2001:db8::1） |
| 地址类型 | 单播、**广播**、组播 | 单播、组播、**任播**（**取消了广播**） |
| 地址配置 | 手工或 DHCP | 支持**无状态地址自动配置** |
| 报头 | 可变长、字段多 | **固定 40 字节**、字段精简 |
| 安全 | IPSec 可选外挂 | **IPSec 是协议体系的组成部分**（内置支持） |

**陷阱**：
- 长度选项里 **64 和 256 是干扰项**，答案恒为 **128**。
- "IPv6 **保留了广播**" → 错，IPv6 **取消广播、新增任播**（广播的功能由组播承担）。
- 压缩题最常见的错法是 **`::` 用了两次**，或把"单个 0 组"和"前导零"混淆——`0db8` 省成 `db8` 是省前导零，不能写成 `::`。

### 考点⑥ DHCP 与 DNS——两个"免人工"服务

**题目长相**："DHCP 的作用是（ ）"；"DHCP 通常一次性下发哪些配置"；"客户端向本地域名服务器发起的查询通常是（递归/迭代）查询"。

**怎么解**：

**DHCP（动态主机配置协议）**：解决"每台机器手工配 IP 又累又容易配重"的问题。主机接入网络后自动申请，获得**四件套：IP 地址、子网掩码、默认网关、DNS 服务器地址**，并附带**租期**（到期续租）。过程四步：
**Discover**（广播找服务器）→ **Offer**（服务器给出候选配置）→ **Request**（客户端申请）→ **ACK**（确认生效）。

**DNS（域名系统）**：解决"人记不住 IP"的问题，把**域名翻译成 IP**。两种查询方式，**辨析是考点**：
- **递归查询**：你问我，我要么直接给最终答案、要么替你一路问到底再把答案给你 —— **客户端 → 本地 DNS 服务器**通常用递归；
- **迭代查询**：你问我，我只告诉你"**下一步该去问谁**"，你自己接着问 —— **本地 DNS → 根 → 顶级 → 权威**服务器逐级查询通常用迭代。

**陷阱**：
- DHCP 的四件套里**最容易漏"默认网关"和"DNS 服务器地址"**，只答"IP 和掩码"不完整。
- 递归/迭代方向常被对调："本地服务器向根服务器发起递归查询" → 通常是**迭代**。记法：**客户端偷懒（递归一问到底），服务器之间只指路（迭代）**。

## 第 3 层 · 完整算例

### 算例一：子网掩码求网络地址、可用主机数、地址范围（**阶段B 必练**）

**题目**：某主机 IP 地址为 **192.168.10.130**，子网掩码为 **255.255.255.192**，求所在子网的网络地址、可用主机数、可用主机地址范围与广播地址。

**第 0 步：先把掩码翻成 `/n` 形式，确认哪个字节需要动手算。**
255.255.255.192 的前三个字节都是 255（二进制全 1，**8+8+8 = 24 个 1**），第四字节 192 = `1100 0000`，再贡献 **2 个 1**，所以这是 **/26**。
→ 前三字节掩码全 1，**网络位照抄原 IP，不必转二进制**；**只需处理最后一个字节**。这一步是提速关键，硬把 32 位全展开最容易算错。

**第 1 步：把有变化的那个字节转成二进制。**
```
IP 末字节    130 = 1000 0010
掩码末字节   192 = 1100 0000     （/26 = 前 24 位 + 这里的 2 个 1）
```
> 130 怎么来的：130 = 128 + 2 = 2⁷ + 2¹ → 第 8 位和第 2 位为 1 → `1000 0010`。
> 192 怎么来的：192 = 128 + 64 = 2⁷ + 2⁶ → 高两位为 1 → `1100 0000`。

**第 2 步：按位与（AND），得网络号。**
```
    1000 0010      （IP 末字节 130）
AND 1100 0000      （掩码末字节 192）
  = 1000 0000  = 128
```
> 按位与的口径：**两位都是 1 才得 1，否则得 0**。逐位看：1&1=1、0&1=0、后六位掩码都是 0 → 结果后六位全 0（主机位被"抹掉"了，这正是求网络号的含义）。

前三字节照抄 → **网络地址 = 192.168.10.128**。

**第 3 步：数主机位，算可用主机数。**
/26 → 主机位 = 32 − 26 = **6 位**（末字节里那 6 个 0）。
可用主机数 = **2⁶ − 2 = 64 − 2 = 62** 台。
> 减 2 的原因：主机位**全 0** 是网络地址本身（.128），主机位**全 1** 是广播地址，都不能分配给主机。

**第 4 步：写出地址范围与广播地址。**
```
网络地址   192.168.10.128   末字节 1000 0000（主机位全 0）
首个可用   192.168.10.129   末字节 1000 0001
末个可用   192.168.10.190   末字节 1011 1110
广播地址   192.168.10.191   末字节 1011 1111（主机位全 1）
```

**第 5 步：验算（养成习惯，5 秒钟）。**
- **块大小校验**：/26 的一个子网占 2⁶ = **64** 个地址，边界必是 64 的倍数 → 0、64、128、192。130 落在 **128–191** 这一块 ✅ 与第 2 步结果一致。
- **总数校验**：128 到 191 共 191 − 128 + 1 = **64** 个地址 = 2⁶ ✅；去掉网络地址与广播地址剩 **62** 个 ✅ 与第 3 步一致。
- **常见错答自查**：选 192.168.10.0（把掩码当成 /24 了）、选 192.168.10.192（把 130 归错块了）——只要做一遍"块大小 64、边界 0/64/128/192"的校验，这两个错都会当场暴露。

### 算例二：IPv6 地址压缩

**题目**：把 `2001:0db8:0000:0000:0000:0000:0000:0001` 写成最简形式。

```
原地址       2001:0db8:0000:0000:0000:0000:0000:0001   （8 组，每组 4 个十六进制数）
第1步 省前导零   2001: db8 :  0  :  0  :  0  :  0  :  0  :  1
              → 2001:db8:0:0:0:0:0:1
第2步 压缩连续全零段（中间连续 5 组全 0）
              → 2001:db8::1
验算：:: 只用了 1 次 ✅；展开时 2001、db8、1 共占 3 组，:: 补回 8−3 = 5 组全零 ✅ 与原地址一致
```

## 第 4 层 · 速记

> **两套地址分工**：**IP 管"到哪去"（端到端全程不变），MAC 管"这一跳交给谁"（逐跳换）**
> **三个长度**：**MAC 48 位，IPv4 32 位，IPv6 128 位**
> **ARP 方向**：**IP 问 MAC 用 ARP，广播去问单播答**；MAC 问 IP 是 **RARP**；域名问 IP 是 **DNS**；发 IP 的是 **DHCP**
> **DHCP 四件套**：**IP、掩码、默认网关、DNS 服务器**（四步 **Discover→Offer→Request→ACK**）
> **DNS 查询**：**客户端递归一问到底，服务器之间迭代指路**
> **VLAN 三大好处**：**隔广播、保安全、易管理**；一句必背：**跨 VLAN 必须过三层（路由器 / 三层交换机）**
> **分类首字节**：**A 到 126，B 到 191，C 到 223，D 组播到 239**；**127 环回**
> **私有地址**：**10.0.0.0/8、172.16–172.31、192.168.0.0/16**
> **子网计算**：**IP 与掩码按位与得网络号；主机位全 0 是网络、全 1 是广播，可用数 2ⁿ−2**
> **算子网的提速法**：**只算掩码有变化的那一个字节，其余照抄**；验算看**块大小 = 2^主机位数**、边界是它的倍数
> **IPv6**：**128 位冒号十六进制，前导零可省，`::` 压零只能用一次；取消广播、新增任播，报头固定 40 字节，内置 IPSec**

## 考题回顾

**1.【模拟·重现2024上考点】** 主机 A 通过两个路由器向另一网段的主机 B 发送 IP 分组，在整个转发过程中保持不变的是（ ）。
A. 源 MAC 地址和目的 MAC 地址　B. 仅目的 MAC 地址　C. 源 IP 地址和目的 IP 地址　D. 所有地址均改变

> **答案：C**。IP 是**端到端**信息，全程不变；MAC 是**逐跳**信息，每经过一个路由器，源/目的 MAC 都换成当前这一跳的一对。A、B 恰好把"变的那个"说成不变。

**2.【模拟·重现2022下考点】** ARP 协议的作用是（ ）。
A. 将域名解析为 IP 地址　B. 将 IP 地址解析为 MAC 地址　C. 将 MAC 地址解析为 IP 地址　D. 动态分配 IP 地址

> **答案：B**。ARP 解决"知道对方 IP、不知道 MAC"的问题，**广播询问、单播应答**。四个选项正好是四个协议：A 是 **DNS**，C 是 **RARP**，D 是 **DHCP**。

**3.【模拟·重现2024下考点】** 在交换机上划分 VLAN 的主要作用是（ ）。
A. 提高链路传输速率　B. 隔离广播域、增强网络安全性　C. 扩大冲突域　D. 使不同 VLAN 的主机无需路由即可通信

> **答案：B**。VLAN 把一个大广播域**逻辑切分**成多个小广播域，抑制广播风暴并实现部门间二层隔离。A 与带宽速率无关；C 说反（缩小的是广播域）；D 说反——跨 VLAN 通信恰恰**必须**经过路由器或三层交换机。

**4.【模拟·重现2021上考点】** IPv6 地址的长度为（ ）位。
A. 32　B. 64　C. 128　D. 256

> **答案：C**。IPv4 为 32 位，IPv6 扩展为 **128 位**，表示法为冒号分隔的 8 组十六进制数（每组 4 位十六进制 = 16 位二进制，8 × 16 = 128 ✅）。

**5.【模拟】** 某主机 IP 地址为 192.168.10.130，子网掩码为 255.255.255.192，其所在子网的网络地址是（ ）。
A. 192.168.10.0　B. 192.168.10.64　C. 192.168.10.128　D. 192.168.10.192

> **答案：C**。掩码末字节 192 = `1100 0000`，与 IP 末字节 130 = `1000 0010` 按位与得 `1000 0000` = 128 → 网络地址 **192.168.10.128**（该子网主机范围 .129–.190，广播地址 .191，可用 2⁶−2 = 62 台）。快速验算：/26 块大小 64，边界为 0/64/128/192，130 落在 128–191 块内 ✅。选 A 是把掩码当 /24，选 D 是块归错了。

## 自测练习

1. 【模拟】DHCP 解决了什么问题？它通常一次性下发给主机哪四项配置？
2. 【模拟】同一台交换机上的两台主机被划入不同 VLAN，它们能否直接二层互通？若要通信需要借助什么设备？
3. 【模拟】把 IPv6 地址 2001:0db8:0000:0000:0000:ff00:0042:8329 写成最简形式。

### 参考答案

1. 解决**每台主机手工配置 IP 繁琐且易冲突**的问题。下发四件套：**IP 地址、子网掩码、默认网关、DNS 服务器地址**（附带租期）。过程四步：Discover → Offer → Request → ACK。
2. **不能**——不同 VLAN 是不同广播域，二层隔离，即使物理上在同一台交换机也不通。要通信必须经过**路由器或三层交换机**做三层转发。
3. `2001:db8::ff00:42:8329`。每组先省前导零（`0db8`→`db8`、`0042`→`42`），中间连续三组全零压缩为 `::`（**只能压缩一处**）。验算：`::` 用了 1 次 ✅；显式写出的组是 2001、db8、ff00、42、8329 共 5 组，`::` 补回 8−5 = 3 组全零 ✅ 与原地址一致。
