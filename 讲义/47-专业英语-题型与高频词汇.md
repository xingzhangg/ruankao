# 47 · 穿插小板块：专业英语（题型与高频词汇）

> 真题：题型 2021上/2022下；固定第 71–75 题，5 分｜无计算｜未讲（穿插小板块，每日 10 分钟）

## 第 0 层 · 定位

**这一课回答**：第 71–75 题的 IT 短文阅读与选词填空怎么拿分：题型套路、高频词汇。

**前后关系**：穿插小板块第 3 课，每日 10 分钟速记的常驻项；它考的东西你在前面各板块已经学过了。

**分值与去向**：固定 5 分，全卷唯一位置固定的题；放弃等于把及格线从 45/75 抬到 45/70。零计算。

## 第 1 层 · 理解

### 一句话

> 这 5 分**不是英语考试**——它是把你前面五周学过的**中文考点换了张英文皮，让你再认一遍**。你需要的不是背单词，是认出"这段在讲我学过的哪个知识点"。

### 痛点：多数人在这 5 分上犯的两个错

- **一看到英文短文就本能地想逐词翻译**，碰到 3 个生词就慌，然后"随便蒙一个下一题"——实际上题目挖的空里，`module`、`coupling`、`cohesion`、`transaction`、`firewall` 这些词，你天天在 IDE、日志、报错信息里见，只是从没把它们和中文考点对上号。
- **另一个极端是直接战略放弃**："英语不好，这 5 分不要了。"——但这 5 分是全卷**唯一保证送到你面前、题型永不变化**的分。放弃它，剩下 70 题必须做对 45 道（正确率 64%）；拿下它，只要 70 题里对 40 道（正确率 57%）。**一放一拿，差的是七个百分点的容错空间。**

### 一条主线

```
先问一个根子上的问题：出题人设这 5 分，到底想验证什么？
   ⇒ 想验证的是【你能不能读懂英文技术文档】——不是你的英语水平
   ↓ 因为要验证"专业能力"而不是"外语能力"，那么：
【推论 1】文章选材必然限定在【大纲里已经讲过的中文知识点】
      （软件维护四分类、ACID、OSI 七层、耦合内聚、设计模式……）
      ⇒ 所以句子结构一定不难，难点全部压在【术语】上
   ↓
【推论 2】挖空的位置必然落在【专业术语】上
      不会去挖 the / of / which 这种功能词——挖了就变成通用英语考试了
   ↓
【推论 3】既然空里填的是术语，四个干扰项就只能这么造：
      【同词性、不同术语】
      （encryption / authentication / authorization / integrity 全是名词，
        语法上填哪个都通顺，只有专业语义能区分）
   ↓ 三条推论倒推出解题动作，顺序固定：
      ① 词性筛  —— 先看四个选项是名词还是动词，排掉语法位置不符的
                    （少数题一步到位；多数题四项同词性，筛不掉，进第②步）
      ② 语境辨  —— 前后句在讲哪个主题？把候选词按语义往场景里代
      ③ 中文考点对号入座 —— "这段在讲软件维护" ⇒ 空里该是"缺陷/可维护性"
                    这一步是【专业能力兜底】：即使个别单词不认识也能推出来
   ↓ 再倒推出备考方式：
      不背通用词汇、不扩词汇量，只背【已学中文考点的英文标签】
      ⇒ 四大阵营词表（软件工程 / 数据结构 / 数据库 / 网络安全）
      ⇒ 术语集中、重复率高、生僻词少 ⇒ 背一次就能一直用
```

**结论：这一章的正确心态是"复习中文考点，顺手把英文标签贴上去"，而不是"临时补英语"。** 你在 W1–W6 已经把内容学完了，本课只是给这些内容配一张英文对照表。

## 第 2 层 · 考点：考试怎么问

### 考点① 短文选词填空（71–75，本板块**唯一**题型）

**题目长相**：一篇约 **200–300 词**的 IT 技术英文短文，文中挖去 **5 个**词或短语（对应 71–75 题号），每题给 **4 个英文选项**，选出最适合填入的一个。文章主题通常围绕软件工程、计算机体系结构、数据库、网络等**大纲已讲过的知识领域**，属于"专业英语"而非"通用英语"。

**怎么解**——固定三步，按顺序走：

1. **先读四个选项，判断词性**：名词、动词、形容词还是副词？空格在句中的语法位置（be 动词后接形容词/名词、动词原形前常需情态动词、冠词 `a/an/the` 后必是名词等）能直接排掉词性不对的选项，**这一步不用先读懂全文**。
2. **结合上下文语境判断语义**：四个选项经常词性相同、术语含义不同（如 encryption / authentication / authorization / integrity 都是名词），要看前后句在说什么，判断哪个术语最贴合场景。
3. **反向利用中文考点知识**：短文主题往往正是某个中文知识点的英文版复述——比如一段讲"软件交付后要分四类维护"的文字，对应的就是"软件维护四种类型"（改正性/适应性/完善性/预防性）这个中文考点。**认出这个考点，即使个别生词不认识，也能靠专业常识推断空里该填哪类词。**
> **配套的备考原则**（不是考场上的第 4 步，是平时的投入方式）：**优先记高频术语，不追求词汇量**——软考专业英语的词汇集中在有限的专业领域（见考点④词表），生僻词很少考，**背熟高频词表比扩充词汇量性价比高得多**。

**陷阱**：
- ❌ **上来就逐词翻译全文**——时间全耗在这里，且用不上。正确做法是先看选项、再回句子定位。
- ❌ **把它当语法题做**——多数题四个选项词性相同，语法筛不出答案，硬用语法感觉去蒙必错，必须靠专业语义。
- ❌ **碰到生词就跳过整题**——空格前后句往往已经把中文考点点明了，生词不影响判断。

### 考点② 同词性干扰项的术语辨析（本题型的真正难点）

**题目长相**：空格处四个选项全是名词（或全是形容词），语法上填哪个都通顺，只有一个在专业语义上说得通。

**怎么解**：把四个候选词的**中文意思**逐个代进句子读一遍，能读出常识矛盾的直接排掉。重点掌握下面这几组"长得像、常同框出现"的对子——它们是最常见的成对干扰项：

| 易混对 | 区别（记中文一句话） |
|---|---|
| **authentication / authorization** | 认证解决"**你是谁**"；授权解决"**你能做什么**"。**先认证、后授权** |
| **confidentiality / integrity** | 保密性 = 信息**不被未授权者获知**；完整性 = 信息**未被篡改** |
| **coupling / cohesion** | 耦合 = **模块之间**的依赖程度（要低）；内聚 = **模块内部**元素的紧密程度（要高） |
| **primary key / foreign key** | 主键 = 唯一标识本表一条记录；外键 = **引用另一张表主键**的字段 |
| **encryption / decryption** | 加密 / 解密，方向相反，看句子里是"保护"还是"还原" |
| **redundancy / reliability** | 冗余 = 重复存储/重复部件；可靠性 = 系统正常运行的能力（冗余是**手段**，可靠性是**目标**） |

**陷阱**：
- ❌ 把 **authorization 当成"认证"**——这是最高频的一对，中文都带"权/证"字，务必按"你是谁 / 你能干什么"来分。
- ❌ 看到 security 相关就无脑选 encryption——防火墙那句要选的是 **intrusion**（入侵），不是加密。

### 考点③ 中英对照死记型（缩写与固定术语组）

**题目长相**：直接考某个中文考点的英文缩写或固定成套术语，例如 "…four properties, commonly abbreviated as ACID: Atomicity, Consistency, Isolation, and ______."

**怎么解**：这类没有推理空间，**属于纯记忆**，但记的量极小，因为都是你已经学过的中文考点：

- **事务 ACID**：**A**tomicity 原子性 / **C**onsistency 一致性 / **I**solation 隔离性 / **D**urability 持久性（讲义 34）
- **软件维护四类**：corrective 改正性 / adaptive 适应性 / perfective 完善性 / preventive 预防性（讲义 20）
- **面向对象三大特征**：encapsulation 封装 / inheritance 继承 / polymorphism 多态（讲义 23）

**陷阱**：ACID 的 D 常被换成 **Availability**（可用性）或 **Portability**（可移植性）做干扰项——这两个都是**质量属性**里的词，不是事务特性。记牢"事务四特性里没有可用性"。

### 考点④ 高频词汇表（四大阵营，本课的弹药库）

**题目长相**：任何一空，填的都是下面表里的某个词，或它的同族变形（`maintain → maintenance → maintainability`）。

**怎么解**：按**中文考点板块**分组记，不要按字母表记——分组记的时候顺便就把中文知识点复习了一遍。

## 第 4 层 · 速记

> **三步解题法**：**先看词性排干扰 → 再看语境辨语义 → 最后回想中文考点对号入座**
> **词汇按四大阵营串记**：软件工程（生命周期类）／数据结构（结构算法类）／数据库（事务规范类）／网络安全（加密攻防类）——按板块记，顺带复习中文考点
> **最易混六对**：认证 authentication「你是谁」／授权 authorization「你能干什么」；保密性 confidentiality「不被看到」／完整性 integrity「不被改」；耦合 coupling「模块间，要低」／内聚 cohesion「模块内，要高」；主键 primary key／外键 foreign key；加密 encryption／解密 decryption；冗余 redundancy 是手段／可靠性 reliability 是目标
> **ACID**：**A**tomicity 原子 / **C**onsistency 一致 / **I**solation 隔离 / **D**urability 持久（**没有** Availability）
> **软件维护四类英文**：corrective 改正 / adaptive 适应 / perfective 完善 / preventive 预防
> **注意同族变形**：maintenance（维护）≠ maintainability（可维护性）
> **心态一句话**：这不是英语考试，是中文考点换了张英文皮——**71–75 固定 5 分、题型稳定、词汇集中，是"保 45"里必须先拿到手的分**

## 考题回顾

> 说明（沿用原文件）：专业英语题的具体选词逐年变化，**暂未检索到可靠的历年真题词汇原文**，以下均为**【模拟】**，用于演示题型与词汇辨析方法，**不代表历年原题**。题型本身（IT 技术短文 + 选词填空）依据【真题·2021上/2022下】。

### A.【模拟】完整短文选词填空（最贴近真实题型的一套，务必整套做）

阅读下面的短文，从每题给出的四个选项中选出最恰当的一项：

> Software maintenance is the process of modifying a software system after (71). It typically accounts for a large (72) of the total cost in the software life cycle. Maintenance activities can be classified into four types. Corrective maintenance fixes (73) discovered after release. Adaptive maintenance modifies the software to work in a new environment, such as a new operating system. Perfective maintenance improves performance or adds new features requested by users. Preventive maintenance restructures the code to make future changes easier and to improve (74). Because maintenance is expensive and risky, a well-documented (75) and a modular design can significantly reduce maintenance cost.

**71.** A. compilation　B. delivery　C. specification　D. requirement

**72.** A. version　B. transaction　C. proportion　D. index

**73.** A. requirements　B. protocols　C. schemas　D. defects

**74.** A. redundancy　B. maintainability　C. concurrency　D. confidentiality

**75.** A. firewall　B. certificate　C. heap　D. specification

> **整篇定位**：这段文字就是中文考点「**软件维护**」（讲义 20）的英文复述——四类维护一句一个，认出这一点，五个空基本都能靠中文常识推出来。这就是"反向利用中文考点知识"的标准示范。
>
> **答案与解析**：
> - **71. B**（delivery，交付）。软件维护发生在"软件交付/发布**之后**"，对应中文考点"软件维护针对已交付投入使用的软件进行修改"；compilation（编译）、specification（规格说明）、requirement（需求）都不是"维护"发生的时间节点。
> - **72. C**（proportion，占比/比例）。"占总成本的很大……"——proportion 语义唯一贴合；version（版本）、transaction（事务）、index（索引）语义不搭。
> - **73. D**（defects，缺陷）。改正性维护"修复发布后发现的……"，对应中文考点"**改正性维护 = 修复已发现的缺陷/错误**"；requirements（需求）、protocols（协议）、schemas（模式）语境不符。
> - **74. B**（maintainability，可维护性）。预防性维护重构代码，是为了让以后的修改更容易、提高"**可维护性**"，对应中文考点"预防性维护"的定义；redundancy（冗余）、concurrency（并发）、confidentiality（保密性）都不是重构代码要提升的目标。注意此处不能填 maintenance——考的是**同族变形**（见考点④陷阱）。
> - **75. D**（specification，规格说明/文档）。"完善的……和模块化设计能显著降低维护成本"，对应"**高质量文档 + 模块化设计有利于维护**"这一中文考点常识；firewall（防火墙）、certificate（证书）、heap（堆）与"降低维护成本"无关。

### B.【模拟】单句词汇辨析三题

**1.【模拟】** In object-oriented programming, a class can acquire properties and methods from another class through ______.
A. encryption　B. inheritance　C. redundancy　D. concurrency

> **答案：B**。题干描述"一个类通过……从另一个类获得属性和方法"，正是面向对象「**继承**」（inheritance）的英文定义；其余三项分别是加密、冗余、并发，与语境无关。这题体现"反向利用中文考点知识"：中文知识点"继承"背得熟，英文词条一眼认出。

**2.【模拟】** A firewall is typically deployed to filter network traffic and protect an internal network from unauthorized ______.
A. compilation　B. redundancy　C. intrusion　D. specification

> **答案：C**。防火墙的作用是过滤流量、保护内网不受"未经授权的**入侵**"——intrusion 在语义上唯一贴合；其余三词词性虽也是名词，但语义（编译/冗余/规格说明）都对不上"防火墙防御的对象"这一语境。**典型的"四项同词性、只能靠语义辨"**（考点②）。

**3.【模拟】** A database transaction must satisfy four properties, commonly abbreviated as ACID: Atomicity, Consistency, Isolation, and ______.
A. Durability　B. Authentication　C. Portability　D. Availability

> **答案：A**。ACID 是事务四特性缩写：原子性 Atomicity、一致性 Consistency、隔离性 Isolation、**持久性 Durability**。这题直接考"事务 ACID 特性"这个中文考点的英文首字母记忆，属于**中英对照死记型**（考点③）；C、D 是质量属性词，不属于事务特性。

## 自测练习

1. 【模拟】请写出以下三组中英对照的正确含义：coupling / cohesion；primary key / foreign key；confidentiality / integrity。
2. 【模拟】短文片段："A ______ is a self-contained unit of a program that performs a specific function and can be developed, tested, and maintained independently." 请从 module（模块）、protocol（协议）、certificate（证书）、topology（拓扑）中选出最贴切的一项，并说明理由。
3. 【模拟】"The process of confirming that a user or system is who/what it claims to be is called ______, while determining what an authenticated user is allowed to do is called ______." 请分别填入 authentication 和 authorization 中的一个到两处空白，并说明两者的中文区别。

---

### 参考答案

1. coupling = 耦合（模块**之间**的依赖程度）／cohesion = 内聚（模块**内部**元素的紧密程度）；primary key = 主键（唯一标识一条记录）／foreign key = 外键（引用另一张表主键的字段）；confidentiality = 保密性（信息不被未授权者**获知**）／integrity = 完整性（信息未被**篡改**）。
2. 选 **module（模块）**。题干定义"一个程序中自包含、执行特定功能、可独立开发测试维护的单元"，正是中文考点「模块」的标准定义；protocol（协议）、certificate（证书）、topology（拓扑）都不满足"可独立开发/测试/维护"这一描述。
3. 依次填入 **authentication**（确认某用户/系统身份是否属实，即"认证"）和 **authorization**（确定已认证用户被允许做什么，即"授权"）。中文区别：**认证解决"你是谁"，授权解决"你能做什么"——先认证、后授权**，二者常被同时考查、最容易混淆。
