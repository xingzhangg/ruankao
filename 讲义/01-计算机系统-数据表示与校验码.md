# 01 · 计算机系统：数据表示与校验码

## 定位

信息怎么装进 0/1（进制、原反补移码），装进去之后怎么保证没被改坏（奇偶校验、CRC、海明码）。全课跟着一个数 45 走：第一节把它变成二进制，第二节装 −45，第三节取它的前 4 位发到网线对面做校验。下一课 02 接着讲浮点数和 CPU。

## 一、进制

内存每格只有通电、断电两种状态，只能用 0 和 1 记数。

**二 → 十：按权展开。** 从右往左权为 1、2、4、8、16、32……，小数点右边接着减半 1/2、1/4、1/8。任何进制都这么读，把 2 换成它的基数：

```
101101  = 32 + 8 + 4 + 1                 = 45
1101.01 = 8 + 4 + 1 + 0.25               = 13.25
(5043)₆ = 5×6³ + 0×6² + 4×6 + 3 = 1080 + 24 + 3 = 1107
```

**十 → 二（整数）：除 2 取余，倒着读。**

```
45 ÷ 2 = 22 …… 余 1   ↑
22 ÷ 2 = 11 …… 余 0   ↑
11 ÷ 2 =  5 …… 余 1   ↑
 5 ÷ 2 =  2 …… 余 1   ↑
 2 ÷ 2 =  1 …… 余 0   ↑
 1 ÷ 2 =  0 …… 余 1   ↑ 从下往上读 → 101101
```

为什么：45 = 2×22 + 1，乘 2 即左移一位、最低位补 0，所以余数就是最低位；依次剥到最高位，所以倒读。别的进制除 R 取余，如 200 转 6 进制：200÷6=33 余 2，33÷6=5 余 3，5÷6=0 余 5，倒读得 **532**。

**十 → 二（小数）：乘 2 取整，顺着读。** 乘 2 把小数点后第一位推到整数位，所以先取出的是第一位：

```
0.625 × 2 = 1.25  取 1
0.25  × 2 = 0.5   取 0
0.5   × 2 = 1.0   取 1   → 0.101（验算 0.5 + 0.125 = 0.625）
```

**八、十六进制是二进制的缩写。** 3 位二进制 = 1 个八进制数字（000–111 → 0–7），4 位 = 1 个十六进制数字（0000–1111 → 0–15，10–15 写 A–F）。**从小数点向两边分组，外侧补 0**：

```
45 = 101101       → 0010|1101 → 2D（十六进制）
                  → 000|101|101 → 55（八进制）
45.25 = 101101.01 → 0010 1101 . 0100 → 2D.4
                  → 101 101 . 010   → 55.2
```

写法：十六进制 `0x18F` 或 `18FH`，二进制 `0b0011`。换算路线：二 ↔ 八、十六直接分组；八 ↔ 十六经二进制中转；其他进制之间经十进制。

## 二、码制：原码、反码、补码、移码

要解决的问题：在固定位数里装负数，并让加法器不分正负直接算对。

术语：**机器字长**＝CPU 一次处理的位数（下面按 8 位）。带符号数最高位是**符号位**（0 正 1 负），无符号数全部位都是数值。机器里的这串 0/1 叫**机器数**，它代表的实际数值叫**真值**。

**算例：−45 装进 8 位**

1. **原码**：符号位置 1，数值位放 45 = `0101101` → `1 0101101`。毛病：`00101101 + 10101101 = 11011010`，按原码读是 −90；要算对得先判符号、比绝对值再定加减，等于另造减法电路。
2. **补码**：找 x 使 45 + x 在 8 位加法器里得 0。8 位加法器丢掉最高进位，2⁸ = 256（1 后跟 8 个 0）对它就是 0，所以 x = 256 − 45 = 211 = `11010011`。验算：`00101101 + 11010011 = 1 00000000`，丢进位得 0。减法变成加法，加法器不必知道谁是负数。
3. **反码**（手算捷径）：256 − 45 = (255 − 45) + 1，255 = `11111111` 减任何 8 位数都不借位，结果就是逐位取反 `11010010`，即反码，再加 1 得补码。对 +45 全部 8 位取反，和对 −45 原码只取反数值位是同一件事（符号位本来就是 1）。
4. **移码**：补码符号位取反。教材写法 [X]移 = 2ⁿ⁻¹ + X：128 + (−45) = 83 = `0101 0011`，结果相同。

```
+45 原码：0010 1101
−45 原码：1010 1101   符号位置 1，数值位照抄
−45 反码：1101 0010   数值位逐位取反，符号位不动
−45 补码：1101 0011   反码 +1（= 256 − 45）
−45 移码：0101 0011   补码符号位取反（= 128 − 45）
```

正数的原码、反码、补码三者相同，只有负数分家。

**0 唯一与取值范围。** 原码 −0 是 `10000000`，反码 −0 是 `11111111`，各有两个 0、浪费一个编码；补码、移码 0 唯一。补码里 `10000000` 当无符号数是 128 = 256 − 128，它是 **−128** 的补码。所以 8 位补码范围 **−128～+127**，负端多一个、不对称；n 位为 **−2ⁿ⁻¹～2ⁿ⁻¹−1**，16 位是 −32768～32767。

**补码 → 真值：把"取反加一"倒过来。** 例：2X 的补码是 90H，求 X。

```
90H = 128 + 16 = 144 = 1001 0000   最高位 1，负数
减 1      → 1000 1111
数值位取反 → 1111 0000（原码）= −1110000 = −112   （或直接 144 − 256 = −112）
2X = −112 → X = −56
```

**移码为什么存在。** 补码负数最高位是 1，当无符号数看反而比正数大；符号位一翻，负数 0 开头、正数 1 开头，顺序就对了：−45 的移码 `01010011` 小于 +45 的移码 `10101101`。浮点数的阶码要频繁比大小，所以用移码（见 02）。正数的移码符号位是 1，1 开头不代表负数。

**定点表示**：小数点不占存储位，只约定位置——约定在最低位之后是纯整数，约定在符号位之后是纯小数。8 位纯小数最大 `0.1111111` = 1/2 + 1/4 + … + 1/128 = 1 − 1/128。字长 n 位时（培训资料原表）：

| 码制 | 定点整数 | 定点小数 |
|---|---|---|
| 原码、反码 | −(2ⁿ⁻¹−1) ～ +(2ⁿ⁻¹−1) | −(1−2⁻⁽ⁿ⁻¹⁾) ～ +(1−2⁻⁽ⁿ⁻¹⁾) |
| 补码、移码 | −2ⁿ⁻¹ ～ +(2ⁿ⁻¹−1) | −1 ～ +(1−2⁻⁽ⁿ⁻¹⁾) |

两行差别就在 0 的个数，负端因此多一个数。移码实际只用来表示整数阶码，小数那格了解即可。

## 三、校验码

线路干扰会让某一位翻转，接收方要发现、最好还能改回来，办法是多带冗余位。本节只发 45 的二进制 `101101` 的前 4 位 **1011**。

### 码距：冗余能买到多少能力

**合法码字**：编码规则允许发出的那些串；收到别的串就说明出了错。

1. **码距**＝任意两个合法码字之间最少相差的位数。
2. **检错**：只有 `00`、`11` 合法时码距 2。`00` 翻 1 位变 `01`，不合法，立刻发现；翻 2 位变 `11`，看不出来。**检出 e 位错，码距 ≥ e+1**。
3. **纠错**：只有 `000`、`111` 合法时码距 3。收到 `001`，离 `000` 差 1 位、离 `111` 差 2 位，判给近的改回 `000`；码距 2 时离两边一样远，没法判。**纠正 t 位错，码距 ≥ 2t+1**，比检错贵一倍，因为还要知道错在哪。

反过来用：码距为 d 时，单独检错最多 **d−1** 位，或单独纠错最多 **⌊(d−1)/2⌋** 位（d = 3：检 2 位或纠 1 位）；要同时纠 t 位、检 e 位（e ≥ t），需 **d ≥ t+e+1**。

### 奇偶校验：1 位冗余

在 1011 后补 1 位，让整串 1 的个数为偶数（偶校验）或奇数（奇校验）。1011 有 3 个 1：偶校验补 1 得 `10111`，奇校验补 0 得 `10110`。

码距变成 2，按 e+1 保证检出 1 位错；实际能发现**奇数个**位翻转，翻偶数个位时奇偶性不变，发现不了。不知道哪位错，**不能纠错**。

### CRC 循环冗余校验：r 位冗余

思路：发送方把整串凑成约定数的倍数，接收方除一遍，余 0 即没错。约定数用多项式 G(x) 写，叫**生成多项式**，收发双方相同，最高位和最低位必须是 1。

三个词：**异或**＝两位相同得 0、不同得 1；**模 2 运算**＝逢 2 归 0、不进位不借位，加和减都是异或；**有效位数**＝去掉前导 0 后的位数。

**算例：信息 1011，G(x) = x³+x²+1**

1. **G(x) 变除数**：从最高次幂到 x⁰ 逐项抄系数，缺项记 0。系数 1、1、0、1 → `1101`（自查：x 当 2 算，8+4+1 = 13 = `1101`）。同理 x³+x+1 → `1011`。
2. **r = 最高次幂** = 3。除数 r+1 位，余数最多 r 位，所以校验位 r 位。信息码后补 r 个 0 占位：`1011000`。
3. **模 2 除法**：除数最高位对齐当前最高位的 1，异或；剩余有效位数 ≥ 除数位数就继续。

```
1011000
1101        ← 对齐最高位的 1，异或
-------
0110000  → 有效位 110000（6 位）≥ 4 位，继续
 1101
 ------
 000100  → 有效位 100（3 位）< 4 位，停
```

4. **余数即校验码**，不足 r 位左边补 0。余数 `100`，发送 `1011100`。为什么能整除：模 2 下减法就是异或，把余数填进末尾的 r 个 0，等于从被除数里减掉余数，剩下的正好是除数的倍数。

停机看**位数**，不看数值大小。程序写法（除数位数 L）：`while value.bit_length() >= L: value ^= divisor << (value.bit_length() - L)`，余数是最后的整个 value。

**第二例：信息 10110，G(x) = x⁴+x+1** → 除数 `10011`（x³、x² 缺项记 0），r = 4，被除数 `101100000`：

```
101100000 ⊕ 100110000 = 001010000   有效 7 位，继续
001010000 ⊕ 001001100 = 000011100   有效 5 位，继续
000011100 ⊕ 000010011 = 000001111   有效 4 位 < 5 位，停
```

余数 `1111`，发送 `101101111`。接收方再除 `10011`，余 0 即没错，不为 0 就要求重传。CRC 检错能力很强，但不知道错在哪，**不能纠错**。

### 海明码：纠 1 位错

思路：每个校验位是一组偶校验，各管一部分位；出错时，各校验位"报警"的组合正好拼成出错位的位号。

1. **定校验位数 k**：k 位有 2ᵏ 种报警组合，要覆盖"全对" 1 种 + "n+k 位中某一位错" n+k 种，所以 **2ᵏ ≥ n + k + 1**（培训资料写成 2ᵏ − 1 ≥ n + k，同一个式子）。右边的 k 和 1 都不能漏。

```
n = 4：k = 2 → 4 < 7 不够；k = 3 → 8 ≥ 8 够
n = 8：k = 3 → 8 < 12 不够；k = 4 → 16 ≥ 13 够
```

2. **定位置**：所有位从右往左从 1 编号，**校验位放在 2 的幂位置**（第 1、2、4、8……位），其余放信息位。校验位下标就是幂次：r₀ 在第 1 位、r₁ 在第 2 位、r₂ 在第 4 位；另一套写法 P1、P2、P3、P4 分别在第 1、2、4、8 位。1011 加 3 个校验位共 7 位：

| 位号 | 7 | 6 | 5 | 4 | 3 | 2 | 1 |
|---|---|---|---|---|---|---|---|
| 放什么 | I₄=1 | I₃=0 | I₂=1 | r₂ | I₁=1 | r₁ | r₀ |
| P 写法 | | | | P3 | | P2 | P1 |

3. **定分组**：把信息位的位号拆成 2 的幂之和，拆出哪些幂就归哪些校验位管。7 = 4+2+1 归 r₂、r₁、r₀；6 = 4+2 归 r₂、r₁；5 = 4+1 归 r₂、r₀；3 = 2+1 归 r₁、r₀。校验位放 2 的幂位置，是因为这些位号的二进制只有一个 1，每个校验位只属于自己那一组，能独立算出。
4. **算校验位**：它管的那几位异或。异或结果就是这几位 1 的个数的奇偶性，填进去后整组 1 的个数为偶数，即偶校验：

```
r₂ = I₄ ⊕ I₃ ⊕ I₂ = 1⊕0⊕1 = 0   （管第 7、6、5 位）
r₁ = I₄ ⊕ I₃ ⊕ I₁ = 1⊕0⊕1 = 0   （管第 7、6、3 位）
r₀ = I₄ ⊕ I₂ ⊕ I₁ = 1⊕1⊕1 = 1   （管第 7、5、3 位）
```

按位号填回，发送 **1010101**。

5. **接收端校验**：每组连校验位一起再异或，偶校验下应全为 0（奇校验应全为 1）。第 p 位出错，只会让位号 p 的二进制里为 1 的那几组报警（p 只归这几组管），所以报警组合 r₂r₁r₀ 就是 p 的二进制。收到 `1011101`（第 4 位 0 翻成 1）：

```
位号：7 6 5 4 3 2 1
收到：1 0 1 1 1 0 1

r₂ ⊕ I₄ ⊕ I₃ ⊕ I₂ = 1⊕1⊕0⊕1 = 1
r₁ ⊕ I₄ ⊕ I₃ ⊕ I₁ = 0⊕1⊕0⊕1 = 0
r₀ ⊕ I₄ ⊕ I₂ ⊕ I₁ = 1⊕1⊕1⊕1 = 0
```

r₂r₁r₀ = `100` = 4，第 4 位出错，翻回即纠正；它正是校验位 r₂ 自己，校验位坏了照样能指出。再如收到 `1000101`（第 5 位 1 翻成 0），三组得 1、0、1，`101` = 5。

三种校验码一路是多花冗余位买更强能力：奇偶 1 位只报奇数个位错，CRC r 位强检错，海明 k 组交叉覆盖能纠 1 位。口诀：奇偶只报错，CRC 除着查，海明能治病。

## 速记

- 十→二：整数除 2 取余倒读，小数乘 2 取整顺读；二↔十六 4 位一组，二↔八 3 位一组，从小数点向两边分
- 负数补码 = 数值位取反加 1（就是 256 − |x|）；补码→真值：减 1 再取反；n 位补码 −2ⁿ⁻¹～2ⁿ⁻¹−1，8 位 −128～127
- 0 唯一：补码、移码；移码 = 补码符号位取反 = 2ⁿ⁻¹ + X，用作浮点阶码
- 码距 d：检 d−1 位 / 纠 ⌊(d−1)/2⌋ 位；检 e 需 ≥ e+1，纠 t 需 ≥ 2t+1，纠 t 同时检 e 需 ≥ t+e+1
- 奇偶只报奇数个位错；CRC 模 2 除、r = 最高次幂、缺项记 0、只检不纠
- 海明：2ᵏ ≥ n+k+1、校验位在 2 的幂位置、位号拆成 2 的幂之和、报警组合 = 出错位号、纠 1 位
