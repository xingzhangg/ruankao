## 定位

**这一课回答**：信息怎么装进 0/1（进制、原反补移码），装进去之后怎么保证没被改坏（奇偶校验、CRC、海明码）。

## 开讲：一个数字从你手里到内存里，再到网线上

我们跟着一个数字走：**45**。前两节看它怎么装进内存（进制）、变成 −45 怎么装（码制）；第三节取它的高 4 位 **1011**，看发到网线对面怎么保证没坏（校验码）。

### 一、把 45 装进内存：进制

内存里每个格子只有两种状态，通电或断电，所以只能用 0 和 1 记数。十进制的 45 是"4 个十加 5 个一"；二进制换成"几个三十二、几个十六、几个八……"。

**从二进制读回十进制：按权展开。** 先别往下看，猜一下 `101101` 是多少？

从右往左，每一位的"权"是 1、2、4、8、16、32。有 1 的位置加起来：32 + 8 + 4 + 1 = **45**。小数点右边的权接着往下减半：1/2、1/4、1/8，所以 `1101.01` = 8 + 4 + 1 + 0.25 = 13.25。

任何进制都是这么读，只是把 2 换成那个进制的基数。培训资料的例子：6 进制的 5043 = 5×6³ + 0×6² + 4×6 + 3 = 1080 + 24 + 3 = **1107**。

**从十进制变二进制：除 2 取余，倒着读。**

```
45 ÷ 2 = 22 …… 余 1   ↑
22 ÷ 2 = 11 …… 余 0   ↑
11 ÷ 2 =  5 …… 余 1   ↑
 5 ÷ 2 =  2 …… 余 1   ↑
 2 ÷ 2 =  1 …… 余 0   ↑
 1 ÷ 2 =  0 …… 余 1   ↑ 从下往上读 → 101101
```

为什么是余数、为什么倒着读：45 = 2×22 + 1。在二进制里乘 2 等于整体左移一位、最低位补 0，所以 2×22 的最低位一定是 0，余数 1 就是 45 的最低位。

接着 22 再除，剥出的是次低位……最后剥出的是最高位，所以要从下往上读。换成别的进制就是"除 R 取余"，例如 200 变 6 进制：200÷6=33 余 2，33÷6=5 余 3，5÷6=0 余 5，倒读得 **532**。

**小数部分反过来：乘 2 取整，顺着读。** 乘 2 还是左移一位，这回是把小数点后第一位推到整数位上，所以第一次取出的整数就是二进制小数点后第一位，顺着读。0.625×2 = **1**.25 取 1；0.25×2 = **0**.5 取 0；0.5×2 = **1**.0 取 1，小数部分归零结束，得 `0.101`。验算：0.5 + 0.125 = 0.625。

**二进制太长看不过来，于是有了八进制和十六进制。** 它们不是另一套体系，只是二进制的缩写：3 位二进制正好是一个八进制数字（000–111 对应 0–7），4 位正好是一个十六进制数字（0000–1111 对应 0–15，10 到 15 写成 A–F）。分组要**从小数点向两边分**，不够的在外侧补 0。还是用 45：

```
45 = 101101       → 0010|1101 → 2D（十六进制）
                  → 000|101|101 → 55（八进制）
45.25 = 101101.01 → 0010 1101 . 0100 → 2D.4
                  → 101 101 . 010   → 55.2
```

题目里的写法：十六进制写成 `0x18F` 或 `18FH`，二进制写成 `0b0011`。二进制和八、十六进制之间直接分组，八和十六之间经二进制中转，其他进制之间走一趟十进制。

### 二、负数怎么装：原码、反码、补码、移码

CPU 一次处理的位数叫**机器字长**，先按 8 位讲。8 个格子里装 −45，最自然的想法是拿最高位当符号：0 正 1 负，剩下 7 位放绝对值。

45 = `0101101`，所以 −45 就是 `1 0101101`。这叫**原码**。带符号数最高位是符号位，无符号数没有符号位，全部 8 位都是数值。机器里这串 0/1 叫机器数，它对应的实际数值叫**真值**。

原码有个致命麻烦。让加法器算 45 + (−45)：`00101101 + 10101101 = 11011010`，按原码读是 −90，明显不对。要让原码算对，得先判符号、比绝对值，再决定做加还是做减，等于另造一套减法电路，成本翻倍。

**换个思路：能不能找一个数 x，让 45 + x 在 8 位加法器里正好得 0？** 2⁸ = 256，二进制写出来是 1 后面跟 8 个 0；8 位加法器只留低 8 位，最高位那个进位被丢掉，所以 256 在它看来就是 0。只要 45 + x = 256 就行：x = 256 − 45 = 211 = `11010011`。这个 x 就是 −45 的**补码**。验算：`00101101 + 11010011 = 1 00000000`，丢掉进位得 0。加法器根本不需要知道谁是负数，减法就变成了加法。

每次都算 256 减太慢，有个手算捷径，而且它不是另一条规则，就是 256 − x 拆开算：256 − x = (255 − x) + 1。

255 = `11111111`，用它减任何 8 位数，每一位都是 1 减 0 或 1 减 1，不用借位，结果正好是把那个数**逐位取反**：`11111111 − 00101101 = 11010010`。这个中间结果叫**反码**。再加 1 就是补码 `11010011`，和上面 256 − 45 算出来的是同一个数。

```
+45 原码：0010 1101
−45 原码：1010 1101   符号位置 1，数值位照抄
−45 反码：1101 0010   数值位逐位取反，符号位不动
−45 补码：1101 0011   反码 +1
−45 移码：0101 0011   补码的符号位取反（下面解释它干什么用）
```

正数的原码、反码、补码三者相同，只有负数才分家。

补码顺带解决了一件事：**0 只有一种写法**。原码里 −0 是 `10000000`，反码里 −0 是 `11111111`，各浪费一个编码；补码里 `10000000` 不再是 −0。先别往下看：**这个空出来的 `10000000` 在补码里代表几？**

它当无符号数看是 128，而 128 = 256 − 128，按"256 − |x| 就是 −x 的补码"，它是 **−128** 的补码。所以 8 位补码能表示 −128 到 +127，负半边比正半边多一个。常见错法是写成对称的 −127 到 127，你 8 月 4 日首答就是这么错的。

推广到 n 位：**−2ⁿ⁻¹ 到 2ⁿ⁻¹ − 1**，16 位是 −32768 到 32767。

**反过来，给你补码求真值。** 培训资料的真题：2X 的补码是 90H，X 是多少？90H = 128 + 16 = 144，二进制 `1001 0000`，最高位是 1，负数。把"取反加一"倒过来做：减 1 得 `1000 1111`，数值位取反得 `1111 0000`，这是原码，读作符号 1、数值 1110000 = 112，即 −112。也可以直接算 144 − 256 = −112。这是 2X，所以 X = **−56**。

**移码**只是把补码的符号位翻过来，教材写成 [X]移 = 2ⁿ⁻¹ + X，两种说法等价。它解决的问题：补码里负数最高位是 1，当无符号数看反而比正数大，没法直接比大小；符号位一翻，负数 0 开头、正数 1 开头，顺序就对了。−45 的移码 `01010011` 小于 +45 的移码 `10101101`。下一课浮点数里有个叫阶码的部分要频繁比大小，所以阶码用移码。注意正数的移码符号位是 1，别看见 1 开头就当负数。移码和补码一样，0 唯一。

**定点表示**：小数点不占存储位，只是约定位置。约定在最低位之后叫纯整数，约定在符号位之后叫纯小数。8 位纯小数最大是 `0.1111111` = 1/2 + 1/4 + … + 1/128 = 1 − 1/128。机器字长 n 位时各码制的范围（培训资料原表）：

| 码制 | 定点整数 | 定点小数 |
|---|---|---|
| 原码、反码 | −(2ⁿ⁻¹−1) ～ +(2ⁿ⁻¹−1) | −(1−2⁻⁽ⁿ⁻¹⁾) ～ +(1−2⁻⁽ⁿ⁻¹⁾) |
| 补码、移码 | −2ⁿ⁻¹ ～ +(2ⁿ⁻¹−1) | −1 ～ +(1−2⁻⁽ⁿ⁻¹⁾) |

差别只在 0 的表示：原码反码分 +0 和 −0，补码移码只有一个 0，所以负端多表示一个数。考试里移码只用来表示整数阶码，小数那格了解即可。

### 三、数在路上会坏：校验码

45 装好了，要从内存发到网卡、从这台机器发到那台机器。线路有干扰，某一位可能从 1 翻成 0。接收方拿到一串 0/1，怎么知道它有没有被改过？为了算例短一点，这一节只发 45 的高 4 位 **1011**，看三种保护方式。

**想发现错，唯一的办法是多带几位冗余。** 冗余带多少，能力就到哪。衡量它的尺子叫**码距**：任意两个合法码字之间最少差几位。只有 `00` 和 `11` 合法时码距是 2，`00` 翻一位变 `01`，不是合法码字，立刻能发现；翻两位变 `11`，就看不出来了。所以**要检出 e 位错，码距至少 e+1**。再看纠错：只有 `000` 和 `111` 合法时码距是 3，收到 `001`，它离 `000` 差 1 位、离 `111` 差 2 位，判给近的那个就把它改回 `000` 了；要是码距只有 2，收到的串离两个合法码字一样远，没法判。所以**要纠正 t 位错，码距至少 2t+1**，比检错贵一倍，因为纠错不光要知道"错了"，还要知道"错在哪"。

**第一种：奇偶校验，1 位冗余。** 在 1011 后面补 1 位，让整串里 1 的个数是偶数（偶校验）或奇数（奇校验）。1011 里有 3 个 1，偶校验补 1 得 `10111`，奇校验补 0 得 `10110`。补了这一位之后，合法码字之间的码距变成 2，套 e+1 只能保证检出 1 位错。实际上它能发现**奇数个**位翻转，翻 1 位、3 位都能发现；翻偶数个位，1 的个数奇偶性不变，发现不了。就算发现了也不知道是哪位，**不能纠错**。

**第二种：CRC 循环冗余校验，r 位冗余。** 先想一个问题：接收方能不能靠"做一次除法"就知道有没有错？可以，只要发送方事先把整串凑成一个约定数的倍数，接收方除一遍，余数为 0 就没错。这个约定数用多项式 G(x) 写，叫生成多项式，收发双方必须用同一个，它的最高位和最低位必须是 1。

先认三个词。**异或**：两位相同得 0、不同得 1。**模 2 运算**：逢 2 归 0、不进位不借位，所以模 2 的加和减都是异或。**有效位数**：去掉前导 0 之后剩下的位数。然后按四步走：

1. **G(x) 变除数**：从最高次幂到 x⁰ 逐项抄系数，缺项记 0。G(x) = x³+x²+1 的系数是 1、1、0、1，除数 `1101`。自查：把 x 当 2 算，8+4+1 = 13 = `1101`。
2. **校验位数 r = 最高次幂**，这里 r = 3。为什么：除数是 r+1 位，除完的余数最多 r 位，所以校验位就是 r 位。在信息码后面补 r 个 0 给它们占位：`1011000`。
3. **模 2 除法**：除数的最高位对齐被除数当前最高位的 1，做异或；看剩下的有效位数还够不够除数的位数，够就继续。

```
1011000
1101        ← 对齐最高位的 1，异或
-------
0110000  → 有效位 110000（6 位）≥ 4 位，继续
 1101
 ------
 000100  → 有效位 100（3 位）< 4 位，停
```

4. **余数就是校验码**，不足 r 位左边补 0。余数 `100`，发送 `1011100`。为什么拼上去就能整除：模 2 下减法就是异或，把余数填进末尾那 r 个 0，等于从被除数里减掉余数，剩下的正好是除数的倍数。

停机条件看的是**位数**，不是数值大小。常见错法是算到 `100` 这种"看起来很小的数"就收工，你 8 月 4 日就错在这里。用程序员的话说，除数位数记作 L：`while value.bit_length() >= L: value ^= divisor << (value.bit_length() - L)`，余数是最后的整个 value。

用培训资料的例子再走一遍：信息 10110，G(x) = x⁴+x+1。除数：x⁴、x³、x²、x¹、x⁰ 的系数是 1、0、0、1、1，即 `10011`（x³ 和 x² 缺项记 0，这是最容易漏的地方）。r = 4，被除数 `101100000`。每步保留全部 9 位：

```
101100000 ⊕ 100110000 = 001010000   有效 7 位，继续
001010000 ⊕ 001001100 = 000011100   有效 5 位，继续
000011100 ⊕ 000010011 = 000001111   有效 4 位 < 5 位，停
```

余数 `1111`，发送 `101101111`。接收方把它再除 `10011`，余 0 就是没错，不为 0 就要求重传。CRC 检错能力很强，但和奇偶一样，**只能说"错了"，不能说错在哪，所以不能纠错**。

**第三种：海明码，能纠 1 位错。** 再想一个问题：给 1011 加 3 个校验位凑成 7 位，3 个校验位怎么指出 7 个位置里是哪一个错了？海明的办法：每个校验位是一组奇偶校验，各管一部分位；出错时，3 个校验位"报警"的组合正好拼成出错位的位号。

先定 k。k 个校验位有 2ᵏ 种报警组合，要覆盖"全对"1 种加"n+k 位里某一位错"n+k 种，所以 **2ᵏ ≥ n + k + 1**；培训资料写成 2ᵏ − 1 ≥ n + k，移项即得，是同一个式子。

n = 4 时，k = 2 不够（4 < 7），k = 3 够（8 ≥ 8）。n = 8 时试 k = 3：8 < 12 不够，k = 4：16 ≥ 13 够。常见错法是只比 2ᵏ 和 n，忘了右边还要加上 k 和那个 1，你 8 月 4 日就是这么选了 3。

再定位置。所有位从右往左从 1 编号，**校验位放在 2 的幂位置**：第 1、2、4、8……位，其余位放信息位。校验位的下标就是幂次：r₀ 在第 1 位，r₁ 在第 2 位，r₂ 在第 4 位；真题里常写成 P1、P2、P3、P4，分别在第 1、2、4、8 位，两套写法一回事。1011 加 3 个校验位共 7 位：

| 位号 | 7 | 6 | 5 | 4 | 3 | 2 | 1 |
|---|---|---|---|---|---|---|---|
| 放什么 | I₄=1 | I₃=0 | I₂=1 | r₂ | I₁=1 | r₁ | r₀ |

哪个校验位管哪些位：把每个信息位的位号拆成 2 的幂之和，拆出哪些幂，就归哪些校验位管。7 = 4+2+1，所以第 7 位归 r₂、r₁、r₀ 三个都管；6 = 4+2 归 r₂、r₁；5 = 4+1 归 r₂、r₀；3 = 2+1 归 r₁、r₀。

为什么校验位要放 2 的幂位置：这些位号的二进制只有一个 1，拆开只有它自己，所以每个校验位只属于自己那一组，可以独立算出来，不用先知道别的校验位。

每个校验位怎么算：它管的那几位做异或。异或的结果就是这几位里 1 的个数的奇偶性，把它填进去，整组 1 的个数就成了偶数，这正是偶校验：

```
r₂ = I₄ ⊕ I₃ ⊕ I₂ = 1⊕0⊕1 = 0   （管第 7、6、5 位）
r₁ = I₄ ⊕ I₃ ⊕ I₁ = 1⊕0⊕1 = 0   （管第 7、6、3 位）
r₀ = I₄ ⊕ I₂ ⊕ I₁ = 1⊕1⊕1 = 1   （管第 7、5、3 位）
```

按位号填回去，发送 **1010101**。

接收方怎么用：把每一组连校验位一起再异或一遍，偶校验下全为 0 才正常，奇校验则应全为 1。培训资料的例子，收到 `1011101`，第 4 位从 0 翻成了 1：

```
r₂ ⊕ I₄ ⊕ I₃ ⊕ I₂ = 1⊕1⊕0⊕1 = 1
r₁ ⊕ I₄ ⊕ I₃ ⊕ I₁ = 0⊕1⊕0⊕1 = 0
r₀ ⊕ I₄ ⊕ I₂ ⊕ I₁ = 1⊕1⊕1⊕1 = 0
```

不全为 0，有错；按 r₂r₁r₀ 排成二进制 `100` = 4，**第 4 位出错**，翻回来就纠正了。注意第 4 位正是校验位 r₂ 自己，校验位坏了照样能指出来。再看一个翻信息位的：收到 `1000101`，第 5 位从 1 翻成了 0，三组重算得 1、0、1，`101` = 5，指向第 5 位。两组报警合起来才拼出 5，这就是"报警组合拼成位号"。

三种校验码放在一起看：奇偶只报错，CRC 除着查，海明能治病。冗余从 1 位、到 r 位、到 k 组交叉覆盖，能力从"检奇数个错"到"强检错"到"纠 1 位错"，一路是"多花冗余位买更强能力"。

## 考试怎么考

**考点① 进制转换。** 很少单独出题，但地址、容量、编码的计算都要先做换算。题型："二进制 1101.01 转十进制"（按权展开，见第一节）、"十六进制 2F 是多少"（2×16+15 = 47）。常见错法：分组从左往右瞎分，正确是从小数点向两边分、外侧补 0；整数余数忘了倒读；把 F 当 16。

**考点② 补码与取值范围。** "8 位补码的范围"答 −128～127，因为那个 −0 编码被拿去表示 −128 了，最诱人的错项是对称的 −127～127。"0 的表示唯一的是"答补码和移码，原码反码各有两个 0。"浮点数阶码用什么码"答移码，因为要比大小。"补码 90H 的真值"先看符号位，负数就减 1 再取反。移码是补码符号位取反，不是原码的。

**考点③ 码距与三种校验码能力。** "码距为 3 能检几位错、纠几位错"，套 e+1 和 2t+1，答检 2 纠 1。"能纠正 1 位错的是"答海明码。常见错项："偶校验能发现所有错"（翻偶数位发现不了）、"CRC 能纠错"（只检不纠）。

**考点④ CRC 求校验码。** 给 G(x) 和信息码，选校验码或整个发送串。按四步走，两个高频错法：G(x) 缺项的 0 漏掉（x³+x+1 是 `1011` 不是 `111`），以及提前收工。余数不足 r 位要补前导 0。

**考点⑤ 海明码。** 三种问法：问校验位至少几位（代 2ᵏ ≥ n+k+1 从小试）；问校验位放哪（2 的幂位置）；问某个数据位由哪几个校验位校验（先从右往左从 1 给整串编号，再把它的位号拆成 2 的幂之和）。

## 练习

**1.【真题·2023上】** 信息位 8 位，海明码要能发现并纠正 1 位错，校验位至少（ ）位。A.1 B.2 C.4 D.8
**2.【模拟】** 8 位补码表示带符号整数的范围是（ ）。A.−127～127 B.−128～127 C.−128～128 D.−127～128
**3.【模拟】** CRC 校验，G(x)=x³+x+1，信息码 1010，校验码为（ ）。A.011 B.100 C.101 D.110
**4.【真题·2016上】** 如果"2X"的补码是"90H"，那么 X 的真值是（ ）。A.72 B.−56 C.56 D.111
**5.【真题·年份待核实】** 数据信息为 1100，生成多项式为 X³+X+1（即 1011），则 CRC 编码是（ ）。A.1100010 B.1011010 C.1100011 D.1011110
**6.【真题·2018上】** 对于 32 位的数据，至少需要加（ ）个校验位才能构成海明码。以 10 位数据为例，其海明码表示为 D9D8D7D6D5D4P4D3D2D1P3D0P2P1，其中 Di 是数据位、Pj 是校验位，数据位 D9 由 P4、P3、P2 校验，则数据位 D5 由（ ）校验。
　　第一空：A.3 B.4 C.5 D.6　　第二空：A.P4P1 B.P4P2 C.P4P3P1 D.P3P2P1

**自测**：
7.【模拟】海明码，信息位 16 位，纠 1 位错，校验位至少几位？
8.【模拟】16 位补码的表示范围？
9.【模拟】CRC，G(x)=x³+x+1，信息码 1101，校验码？
10.【模拟】CRC，G(x)=x³+x²+1，信息码 1110，校验码？
11.【模拟】CRC，G(x)=x³+x+1，信息码 1001，校验码？

### 参考答案

1. **C**。k=3：2³=8 < 8+3+1=12，不够；k=4：16 ≥ 13。选项里没有 3，出题人就是要你把不等式验一遍。
2. **B**。原码浪费掉的那个 −0 编码被补码拿去表示了 −128。
3. **A**。除数 `1011`（x² 缺项记 0），被除数 `1010000`：1010000⊕1011000=0001000 → 有效 4 位，继续 → 1000⊕1011=0011 → 2 位，停，余数 `011`。
4. **B**。90H=`10010000`，负数；减 1 取反得 `11110000`=−112，X=−56。
5. **A**。`1100000` 除 `1011`：1100000⊕1011000=0111000 → 111000⊕101100=010100 → 10100⊕10110=00010 → 余数 `010`，编码 1100010。
6. **D、B**。32 位：k=5 时 32 < 38，k=6 时 64 ≥ 39。D5 从右往左是第 10 位，10=8+2，由第 8 位 P4 和第 2 位 P2 校验。
7. **k=5**。2⁴=16 < 21；2⁵=32 ≥ 22。
8. **−32768～32767**。
9. **001**。1101000→0110000→011100→01010→0001，余数 1 不足 3 位，补成 001。
10. **010**。1110000→0011000→00010，补成 010。
11. **110**。1001000→0010000→00110，余数 110。

## 速记

- 十进制→二进制：整数除 2 取余倒读，小数乘 2 取整顺读；二↔十六 4 位一组，二↔八 3 位一组，从小数点向两边分
- 负数补码 = 数值位取反加 1（就是 256 − x）；补码→真值：减 1 再取反；n 位补码范围 −2ⁿ⁻¹～2ⁿ⁻¹−1，8 位即 −128～127
- 0 唯一：补码、移码；移码 = 补码符号位取反 = 2ⁿ⁻¹ + X，用作浮点阶码
- 码距：检 e 位错需 ≥ e+1，纠 t 位错需 ≥ 2t+1
- 奇偶只报错（奇数个位错）；CRC 模 2 除、r = 最高次幂、缺项记 0、只检不纠；海明 2ᵏ ≥ n+k+1、校验位在 2 的幂位置、位号拆成 2 的幂之和、能纠 1 位
- 口诀：奇偶只报错、CRC 除着查、海明能治病
