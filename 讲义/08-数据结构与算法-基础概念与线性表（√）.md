## 开讲：一排 8 个数，摆进内存，再拿它折腾三件事

全课跟着这 8 个数走：`12 25 33 47 58 61 79 86`。先问它们摆在哪（地址），再问动它们要花多少代价（插入、删除、指针），最后把这条线上装的东西从数字换成字符，看串怎么找串——到那一节会说明为什么必须换。

### 一、动手之前，先把两个问题拆开

这 8 个数要交给程序管起来，其实有两个完全不同的问题，混在一起就会一路错到底。

第一个问题：**它们彼此是什么关系？** 这里的关系是"排成一条线"——每个数最多只有一个紧挨着的前一个、一个紧挨着的后一个。这种只讲关系、一个字都不涉及内存的描述叫**逻辑结构**。

教材把逻辑结构分成四类：**集合**（元素之间只有"同属一堆"这一条关系，彼此没有先后，像一袋子球）、**线性**（一个挨一个排成一条线，本课这 8 个数就是）、**树形**（一对多，一个父亲带若干儿子，像公司组织架构图）、**图状/网状**（多对多，任意两点都可能连边，像地铁线路图）。

第二个问题：**它们实际摆在内存的哪里、彼此怎么找到对方？** 这叫**存储结构**（也叫物理结构），教材列了四种：**顺序存储**（挨着放进一整块连续内存）、**链式存储**（散着放，每个元素额外存一个地址指向下一个）、**索引存储**（元素随便放，另建一张"关键字 → 地址"的表按图索骥）、**散列存储**（用一个函数把关键字直接算成地址）。

**这两个问题是两条互相独立的维度**，考试年年在这上头下套。同一个逻辑关系（线性），换存储结构就得到两样东西：顺序存储的叫**顺序表**，链式存储的叫**链表**。反过来，"散列""索引"永远不可能是逻辑结构，因为它们说的是摆法不是关系；"线性表""栈""树""图"也永远不是存储结构。逻辑结构、存储结构，再加上第三件——这堆数据上**能做哪些操作**（增、删、改、查、遍历），合起来就是**数据结构三要素**。

顺手把线性表的定义钉死：**n 个（n ≥ 0）同类型数据元素组成的有限序列**，记作 (a₁, a₂, …, aₙ)；n = 0 时叫**空表**，空表也是合法的线性表。

定义里最关键的那句是**除第一个元素外每个元素有且仅有一个直接前驱，除最后一个元素外每个元素有且仅有一个直接后继**（直接前驱就是紧挨在它前面的那一个，直接后继是紧挨在它后面的那一个；序列 12、25、33 里，25 的直接前驱是 12、直接后继是 33）——考试的标准错误选项就是把"除首尾外"这几个字抹掉。

### 二、连续摆：地址一步就能算出来

**顺序存储**就是把这 8 个数按逻辑上的先后挨个塞进一整块连续内存，中间不许有洞。设 a₁ 从地址 2000 开始，每个数占 4 字节：

```
元素： a₁    a₂    a₃    a₄    a₅    a₆    a₇    a₈
值：   12    25    33    47    58    61    79    86
地址： 2000  2004  2008  2012  2016  2020  2024  2028
```

**先别往下看：a₅ 的地址是多少，你是怎么得到的？** 过程比答案要紧。手算：a₅ 前面挡着 a₁、a₂、a₃、a₄ 共 **4** 个元素，每个占 4 字节，所以它比起点往后挪了 4×4 = 16 字节，地址 2000 + 16 = **2016**。

把这句话原样翻译成式子，公式就长出来了，要点全在"前面挡着几个"这个数上——第 i 个元素前面挡着 i−1 个：

```
LOC(aᵢ) = LOC(a₁) + (i − 1) × L        L 是每个元素占的字节数
```

用第二个数验证：a₈ 前面挡着 7 个，2000 + 7×4 = **2028** ✓，与上表最后一格对上。再把 i = 1 代回去，2000 + 0×4 = 2000 正是首地址——**这一步自查必做**，公式用反、多减一个 1，一代就露馅。

**换成程序员熟悉的口径。** 上面 a₁ 是"第 1 个"，下标从 1 数起，这是数学记法也是考题的习惯；C、Java 写 `a[0]`，下标从 0 数起。同一个元素两种叫法：**a₅ 就是 `a[4]`**（都是第 5 个），地址都是 2016。0 起时公式里那个减 1 就没有了：

```
LOC(a[i]) = LOC(a[0]) + i × L
```

两个式子不是两条规则，是同一句"前面挡着几个"：1 起时前面挡着 i−1 个，0 起时下标 i 本身就是"前面挡着几个"。**动笔前先看题干把首元素写成 a₁ 还是 a[0]**，这一步定错整题必错，答案正好差一个 L。

一步算出地址这件事有个专门名字：**随机存取**——不管取第 1 个还是第 800 个，代价完全一样。注意它不是"随便取一个"的意思，是"取任意位置代价相同"。

**公式只有一个，未知量换个位置就是变形题。** 已知 LOC(a₁) = 2000、LOC(a₆) = 2020 反求 L：2020 − 2000 = (6−1)×L，20 = 5L，**L = 4** ✓。另一类陷阱藏在单位里：题目说"每个元素占 2 个字，1 个字 = 2 字节"，L 要取 4 而不是 2。（二维数组的行优先／列优先地址公式归讲义 13，本课只管一维。）

### 三、连续的代价：插入删除要搬家

往这排数里插一个 40，让它成为**第 3 个**元素。连续摆的规矩是中间不许有洞，所以第 3 格必须先空出来：

```
原：  12  25  33  47  58  61  79  86                     n = 8
              ↑ 40 要占这一格
挪：  86→第9格  79→第8格  61→第7格  58→第6格  47→第5格  33→第4格
      （必须从最后一个开始倒着挪，从前面挪会把后一个元素覆盖掉）
新：  12  25  40  33  47  58  61  79  86
实际搬动的元素：33、47、58、61、79、86 —— 共 6 个
```

数出来是 6。**它是怎么来的**：第 3 格及其之后的元素全要让位，也就是 a₃ 到 a₈ 这一段，共 8 − 3 + 1 = 6 个。公式于是长成

```
在长度 n 的顺序表第 i 个位置插入：移动 n − i + 1 个元素
```

删除呢？把第 3 个（33）删掉，第 3 格空出来，只需把它**后面**的 47、58、61、79、86 各往前挪一格，共 **5** 个 = 8 − 3 = n − i。**插入比删除多搬 1 个**，因为插入要额外腾出一个空位，删除只是填一个已有的坑。

**现在猜一个**：在长度 n 的顺序表里插入一个元素，**平均**要移动几个？多数人脱口而出 n/2——答案确实是 n/2，但紧接着的一问八成就掉进去：**删除的平均值也是 n/2 吗？**

不是。差别不在减不减 1，而在**可选的位置有几个**：插入可以插在第 1 个之前、任意两个之间、以及最后一个之后，一共 **n+1** 个位置；删除只能删已经存在的元素，只有 **n** 个位置。n = 8 全枚举一遍：

```
插入 i = 1..9，各要移动：8  7  6  5  4  3  2  1  0    合计 36，÷9  = 4
删除 i = 1..8，各要移动：7  6  5  4  3  2  1  0       合计 28，÷8  = 3.5
```

4 = 8/2 = n/2，3.5 = 7/2 = (n−1)/2。写成一般式：

```
插入平均 = [n + (n−1) + … + 0] / (n+1) = [n(n+1)/2] / (n+1) = n/2
删除平均 = [(n−1) + … + 0]     / n     = [n(n−1)/2] / n     = (n−1)/2
```

注意这两个均值只差 **1/2**，不是差 1。每个位置上插入确实比删除多搬 1 个，可插入多出来的那个位置（插在末尾之后）一个都不用搬，正好把均值往下拽了 1/2。

最好最坏顺手记下：插入最坏是插在第 1 个位置，全表 n 个都要挪；最好是插在末尾之后，0 个。删除最坏是删第 1 个，挪 n−1 个；最好是删最后一个，0 个。

### 四、不连续摆：链表，用几步指针换掉一趟搬家

搬家的根源只有一个：**连续**。那就不连续摆——每个数单独找一小块内存住下，再额外存一个地址写着"下一个住哪儿"。

这一小块内存叫**结点**，装数据的那部分叫**数据域**，装地址的那部分叫**指针域**；只有一个"指向后一个"的指针域，就叫**单链表**。整条链靠一个**头指针**（存着第一个结点地址的变量）拎着，最后一个结点的指针域填 NULL 表示到头了。

```
head → [12|●] → [25|●] → [33|●] → [47|●] → … → [86|∧]      ∧ = NULL
```

**把 40 插到 25 和 33 之间**（就是第三节那道"插到第 3 个位置"）。申请一个新结点 s 装上 40，设 p 是装 25 的那个结点：

```
s->next = p->next;    ← 让 40 指向 33
p->next = s;          ← 让 25 改指 40
共 2 步指针赋值，一个数据元素都没搬
```

**这两句顺序不能反**：先写 `p->next = s`，25 后面那条链就断了，`p->next` 已经不是 33，第一句会让 40 指向它自己。**删除 33**（q = p->next 是装 33 的结点）：

```
p->next = q->next;    ← 让 25 直接指向 47，把 33 摘出链条（再释放 q 的内存）
共 1 步指针赋值
```

于是"链表增删快"落到了实处：**插入 2 步、删除 1 步，与表有多长毫无关系**。但这里埋着考试最爱设的半真半假——**这个 O(1) 的前提是你手里已经握着前驱结点 p**（O(1) 指操作步数固定、与元素个数无关；O(n) 指步数与元素个数成正比）。

题目若说的是"删除单链表的**第 i 个**元素"，你得先从头指针出发一个个走到第 i−1 个结点，那一段是 O(n)，省不掉。

**为什么非要前驱？** 因为单链表的指针是单行道：站在装 33 的结点上，你根本回不了头去找装 25 的结点改它。两个补丁：

- **双向链表**：每个结点再加一个**前驱指针域**指向前一个结点，于是能双向走。代价是每个结点多占一个指针、插入变 4 步；换来的是**删除一个给定结点不必事先握着它的前驱**，就地 2 步搞定（步数比单链表的 1 步多，省掉的是"先走到前驱"那一趟）。在 p 之后插入 s 的四句：`s->prior = p; s->next = p->next; p->next->prior = s; p->next = s;`——最后一句必须放最后，因为前三句还要用原来的 `p->next`。删除 p 的两句：`p->prior->next = p->next; p->next->prior = p->prior;`。
- **循环链表**：把最后一个结点的指针从 NULL 改成指回第一个结点，整条链成环。好处是从任意结点出发都能走遍全表，遍历的结束条件也从"走到 NULL"改成"又走回起点"。若只保留**尾指针** rear，找表尾是 rear 本身、找表头是 rear->next，都是 O(1)，把两条循环链表首尾接起来也只改两个指针。

（还有个常见配件叫**头结点**：在第一个数据结点前面再挂一个不存数据的空结点，头指针指着它。它不省时间也不省空间，纯粹为了让"在第 1 个位置插入删除"和在中间插入删除写成同一段代码——没有头结点时改的是头指针本身，有了头结点改的还是某个结点的 next。）

**链表的账单：多出来的指针要占内存。** 衡量它的尺子叫**存储密度** = 结点里真正装数据的字节数 ÷ 结点占用的全部字节数。数据 4 字节、指针 4 字节时，顺序表是 4/4 = **1**，单链表是 4/8 = **1/2**，双向链表是 4/12 = **1/3**。不过**"顺序表更省空间"不能说成绝对**：顺序表要事先占下一整块连续内存，用不满就闲置，估小了还得整块重新申请再拷贝一遍（`ArrayList` 扩容就是这件事）；链表来一个申请一格，容量随用随取。

培训资料把这笔账列成一张表，照抄如下：

| 性能类别 | 具体项目 | 顺序存储 | 链式存储 |
|---|---|---|---|
| 空间性能 | 存储密度 | =1，更优 | <1 |
| | 容量分配 | 事先确定 | 动态改变，更优 |
| 时间性能 | 查找运算 | O(n/2) | O(n/2) |
| | 读运算 | O(1)，更优 | O([n+1]/2)，最好情况为 1，最坏情况为 n |
| | 插入运算 | O(n/2)，最好情况为 0，最坏情况为 n | O(1)，更优 |
| | 删除运算 | O([n-1]/2) | O(1)，更优 |

⚠️ **这张表要按"平均要动多少次"去读，不要按渐进复杂度读。** 严格意义上 O(n/2)、O([n+1]/2) 都该写成 O(n)，因为大 O 记号只描述"规模翻倍时代价怎么涨"，会把 1/2 这种常数倍率吞掉；培训资料这里是拿 O(·) 当"平均次数"的容器用，对上号就好：插入那格的 n/2、删除那格的 (n−1)/2 正是第三节推出来的两个均值；"读运算 (n+1)/2" 是链表按序号取第 i 个平均要走过的结点数（i 等概率取 1..n，平均 (1+2+…+n)/n = (n+1)/2）；"查找运算"两边写成一样，意思是**按值**查找两种存法都得挨个比、都是 O(n) 量级——顺序表并不因为能算地址就查得快，能算地址的前提是你已经知道序号（这一格的 n/2 是抹了零头的近似，挨个比的平均比较次数严格算是 **(n+1)/2**，考题问平均查找长度时按后者答）。

把这一节收成一句：**所有差异都从"连不连续"这一个选择推出来**。连续 → 地址有规律 → 随机存取快，但中间不许有洞 → 增删要搬家、还得预占整块空间；不连续 → 只改指针 → 增删快、容量随用随取，但地址没规律 → 只能从头顺藤摸瓜、还要为指针多付空间。

### 五、把线上装的换成字符：串与模式匹配

**为什么换例子。** 前四节那 8 个数只是"占位的货"，12 换成 99，插入要搬几个、地址怎么算，一个字都不变。这一节要问的是"一段内容在另一段内容里出现在哪"，元素的**取值**开始参与判断，数字讲不出味道，所以换成字符。换掉的只是元素类型，**结构一点没变**——**串**（字符串）就是元素全为字符的线性表，记作 S = "a₁a₂…aₙ"，n 叫**串长**。

四个定义先钉死，全是选择题原料：

```
空串     长度为 0 的串 ""，一个字符都没有
空格串   由一个或多个空格字符组成，如 " "
         空格是正经字符、占一个字符长度 → 空格串的长度不是 0，它不是空串
子串     串中任意个「连续」字符组成的序列；"abc" 的 ac 不算，因为不连续
         包含它的那个串叫主串；空串是任何串的子串
模式匹配 在主串里找一个给定的串（叫模式串）「第一次出现的位置」
```

串上唯一要考算法的运算就是**模式匹配**。下面用两张纸条来讲：长纸条是主串，短纸条是模式串，要回答的是**短纸条上那串字符，在长纸条上从第几位开始整段出现**。

#### 5.1 最笨的找法：朴素模式匹配

把短纸条放在长纸条最左边，一位一位对着比；只要有一位不同（这叫**失配**），就把短纸条整个往右挪**一格**，从头再比一遍。

```
位置    1 2 3 4 5 6 7
长纸条  A B C A B C D
短纸条  A B C D
        ✓ ✓ ✓ ✗        第 4 位失配：短纸条要 D，长纸条是 A
```

挪一格重比，如此反复，直到全部对上或挪出头。这个例子挪到第 4 位才全中，答案是 **4**，全程比了 **10** 次。最坏情况下短纸条要在长纸条的 n−m+1 个位置各试一遍、每次比 m 位，所以是 **O(n×m)**（n 为主串长，m 为模式串长）。

**它浪费在哪？** 盯住上图失配那一刻：我们**已经知道长纸条第 1、2、3 位就是 A、B、C**，这是刚刚一位一位比出来的。可朴素法照规矩只挪一格，让短纸条开头的 A 去对长纸条第 2 位——而第 2 位是 B，A ≠ B，**不用比就知道不行**。再挪一格去对第 3 位的 C，同样白比。这两次比较的结果本来是可以提前算出来的。

#### 5.2 关键立足点：能滑多远，只看短纸条自己

失配时，**已经配上的那一段，长纸条上的内容和短纸条上的内容是一模一样的**——这就是"配上了"的定义。上图里已配上的是前 3 位，两张纸条上都是 `A B C`。

于是判断"挪 1 格行不行"根本不用回头看长纸条，看短纸条自己就够：短纸条开头的 A，挪 1 格后会落在已配段的第 2 个字母上，那是 B，不行；挪 2 格落在第 3 个字母 C 上，也不行。

> ★ **能滑多远，是模式串自身的性质，跟主串长什么样没有关系。**

既然跟主串无关，就可以**在开始匹配之前**把"失配在第几位、该滑多远"全部算好存成一张表，匹配时查表就走。这张表就是 **next 数组**，**KMP 算法**（三位作者姓氏的首字母）＝ 事先算好这张表 ＋ 查表滑动，**主串指针全程一步不回退**。

#### 5.3 先看简单的：模式串字符全不重复

```
位置    1 2 3 4 5 6 7
长纸条  A B C A B C D
短纸条  A B C D
        ✓ ✓ ✓ ✗        第 4 位失配，已配上 = 前 3 位 = A B C
```

在已配上的 `A B C` 里找**开头几个字母和结尾几个字母相同**，把这个"最多能相同几个"记作 **L**：

```
试 1 个：开头 A    结尾 C     不同 ✗
试 2 个：开头 A B  结尾 B C   不同 ✗
                              L = 0
```

`ABCD` 四个字母互不重复，开头第一个是 A，而 A 在后面再没出现过，两头永远凑不出相同的一截，**所以不管失配在第几位，L 恒为 0**。

L = 0 意味着一位都占不到便宜，**短纸条直接滑到失配的那个位置，从第 1 位重新比**：

```
位置    1 2 3 4 5 6 7
长纸条  A B C A B C D
短纸条        A B C D
              ✓ ✓ ✓ ✓    答案：第 4 位；KMP 共比 8 次（朴素法 10 次）
```

即便如此也比朴素法强——朴素法要一格一格挪过去挨个试，KMP 一步到位。

#### 5.4 再看难的：模式串自带重复

```
位置    1 2 3 4 5 6 7
长纸条  A B A B A B C
短纸条  A B A B C
        ✓ ✓ ✓ ✓ ✗      第 5 位失配，已配上 = 前 4 位 = A B A B
```

同样在已配上的 `A B A B` 里数 L：

```
试 1 个：开头 A      结尾 B      不同 ✗
试 2 个：开头 A B    结尾 A B    相同 ✓
试 3 个：开头 A B A  结尾 B A B  不同 ✗
                                L = 2
```

注意试 1 个不成立、试 2 个反而成立，**所以不能试到第一个不成立就停，要逐个试完取最大的**。

L = 2 是什么意思？把纸条错开摆出来看：

```
滑 1 格
   已配上   A B A B
   短纸条     A B A B C
              ↑ 短纸条的 A 压在已配段的 B 上        A ≠ B  ✗

滑 2 格
   已配上   A B A B
   短纸条       A B A B C
                ↑ ↑
                A 压在 A 上，B 压在 B 上          两个都对 ✓
```

**滑 2 格之后，短纸条开头的 `A B` 正好压在已配段结尾的 `A B` 上。因为这两截内容相同，它们自动对齐，一次都不用比**，直接从短纸条第 **3** 位接着往下比：

```
位置    1 2 3 4 5 6 7
长纸条  A B A B A B C
短纸条      A B A B C
            ✓ ✓ ✓ ✓ ✓    答案：第 3 位；KMP 共比 8 次（朴素法 11 次）
```

把这一节压成三个可以直接算的动作：

```
① 数出 L      已配上那段，开头和结尾最多几个字母相同（逐个试完取最大）
② 滑几格      滑格数 = 已配上的长度 − L
③ 从哪接着比  从短纸条第 L+1 位
```

代进本例：已配上 `ABAB` 长 4，L = 2 → 滑 4−2 = 2 格 → 从第 2+1 = 3 位比。

**② 那个减法**是这么来的：已配段结尾的 2 个字母在第 3、4 位上，短纸条开头的 2 个字母原本在第 1 位，要挪到第 3 位，就是挪了 2 格 = 4 − 2。**③ 那个加一**纯粹是数数：前 L 位已经自动对上、跳过不比，下一个自然是第 L+1 位。

#### 5.5 把每个失配位置的 L 提前算好：next 数组

失配可能发生在模式串第 1 位到第 m 位的任何一处，每处对应一个已配上的前缀，也就对应一个 L。全部算好列成一张表，就是 next 数组：

> ★ **next[j] = （模式串前 j−1 个字符里，最长相等前后缀的长度 L）+ 1**，特例 **next[1] = 0**

next[1] 取 0 是约定：失配在第 1 位意味着一个字符都没配上，无处可滑，主串指针只能前进一位、模式串回到第 1 位重来。

**教材（也是真题里给的那个式子）写作**：

```
             ┌ 0                                                        j = 1
next[j] =    ┤ max{ k | 1 < k < j 且 p₁…p_{k−1} = p_{j−k+1}…p_{j−1} }    该集合非空
             └ 1                                                        其他情况
```

它和上面那句是同一件事：`p₁…p_{k−1}` 就是"开头 k−1 个"，`p_{j−k+1}…p_{j−1}` 就是"结尾 k−1 个"，式子里的 **k 就是 L+1**。考场上给你的是这个形式，但脑子里该装的是纸条往右滑。

**手算真题那个模式串 P = "abaac"（j 从 1 起数）**，只需逐行看"已配上那段"的两头：

```
j=1  没有已配上的东西，特例                                  next[1] = 0
j=2  已配上 "a"     只有一个字符，谈不上两头各取一截，L=0     next[2] = 1
j=3  已配上 "ab"    开头 a，结尾 b，不同，L=0                 next[3] = 1
j=4  已配上 "aba"   开头 a = 结尾 a ✓；开头 ab ≠ 结尾 ba，L=1 next[4] = 2
j=5  已配上 "abaa"  开头 a = 结尾 a ✓；开头 ab ≠ 结尾 aa，L=1 next[5] = 2

                                                   next = 0 1 1 2 2
```

写成选项里的样子就是 `01122`。**三条自查**：next[1] 恒为 0、next[2] 恒为 1（第 2 位失配时只配上一个字符，L 必为 0）；相邻两位最多增 1（每次至多多配上一个字符）；除第 1 位外所有值都 ≥ 1。

#### 5.6 用这张表跑一遍，看它省在哪

记 i 是主串指针、j 是模式串指针：相等就双双 +1；不等就令 `j = next[j]` 而 **i 原地不动**，若 j 变成 0 则 i 前进一位、j 回到 1。取主串 S = "abaabaabaac"、模式串 P = "abaac"（next = 01122）：

```
i=1..4 j=1..4  abaa 逐位对上
i=5 j=5  S[5]=b ≠ c  → j = next[5] = 2，i 留在 5     ← 主串一步没退，模式串右滑 3 格
i=5 j=2  S[5]=b = P[2]=b ✓
i=6 j=3  a=a    i=7 j=4  a=a
i=8 j=5  S[8]=b ≠ c  → j = next[5] = 2，i 留在 8
i=8 j=2  b=b    i=9 j=3  a=a    i=10 j=4  a=a    i=11 j=5  c=c → 成功
起始位置 = i − m = 12 − 5 = 7
```

比较次数从朴素法的 **21** 降到 **13**，且 i 全程只增不减。KMP 的时间复杂度是 **O(n + m)**，其中 O(m) 花在预先算 next 上。

（说明：培训资料 1-3 只给了 KMP 的文字描述和这道真题，真题题干写着"其定义如下式所示"，但那个式子在转录本里既没抄下来、也没留 `> [图]` 标记，上面那个三行式子是按教材《软件设计师教程》第 5 版补的；逐位代入 "abaac" 得 01122，与真题标答完全一致。）

**收口。** 这一课从头到尾只做一件事：把"元素之间是什么关系"和"它们摆在哪"拆成两个独立问题，然后在最简单的那条线上，把第二个问题的两个答案各算一遍账。串则给这条线加了一道新运算——朴素法为此付出重复比较，KMP 用一张事先算好的表把主串指针的回退整个抹掉。

## 考试怎么考

**考点① 逻辑结构与存储结构的归属。** 问法：「下列属于**物理（存储）结构**的是」「关于逻辑结构与存储结构，叙述错误的是」。解法：一句话判——回答"元素之间什么关系"的是逻辑结构（集合、线性、树形、图状，具体到线性表、栈、队列、串、树、图），回答"摆在内存哪里、怎么找到彼此"的是存储结构（顺序、链式、索引、散列）。三种错法：把栈、队列、串当成存储结构（它们是线性逻辑结构，各自都有顺序、链式两种存法）；把散列、索引当成逻辑结构；选"同一逻辑结构只能有一种存储结构"。

**考点② 顺序表地址计算。** 问法：给首元素地址与元素长度求第 i 个的地址，或给两个元素的地址反求 L，地址常写成十六进制。解法：认下标基准 → 套"首地址 + 前面挡着几个 × L" → 把首元素代回自查。两种错法：下标基准弄反——把"第 i 个元素"和"下标为 i 的元素"当成同一个，(i−1)×L 写成 i×L，答案正好差一个 L，最高频；单位没换算（"2 个字"在 1 字 = 2 字节时是 4 字节）。

**考点③ 插入删除要移动的元素个数。** 问法：「长度 n 的顺序表在第 i 个位置插入需移动几个」「等概率下平均移动几个」。解法：插入 n−i+1、删除 n−i；平均插入 n/2、平均删除 (n−1)/2。拿不准就用小例子当场数一遍。三种错法：把插入删除的公式记混（差 1）；两个平均值都答 n/2（漏掉了"插入有 n+1 个位置"）；把 i 当成从 0 起算。

**考点④ 顺序表与链表的两两辨析。** 问法：「相对于顺序存储，链表的**缺点**是」「下列叙述正确的/错误的是」。解法：回到"连不连续"现场推，别背结论。四种典型错项：「链表也支持随机存取」（只能顺序存取）；「顺序表的插入删除效率高于链表」（说反了）；「顺序表的空间利用率**一定**高于链表」（两边各有各的浪费，带"一定"先警惕）；「单链表删除第 i 个结点是 O(1)」（按序号走到第 i−1 个那段仍是 O(n)）。指针步数常单独出一问：单链表插入 2、删除 1，双向链表插入 4、删除 2。

**考点⑤ 串的概念与 KMP 的 next 数组。** 问法：给一个模式串问 next 函数值（四个选项都是数字串）；或考空串/空格串/子串的定义。解法：先写死 next[1] = 0、next[2] = 1；从 j = 3 起，看「已配上那段」（即前 j−1 个字符）**开头几个字母和结尾几个字母相同**，逐个试完取最大的那个长度记作 L，则 **next[j] = L + 1**，一个都不相同就是 L = 0、记 1。题干给的 k 式是同一件事，`p₁…p_{k−1}` 是开头 k−1 个、`p_{j−k+1}…p_{j−1}` 是结尾 k−1 个，**k 就是 L+1**。三种错法：把 next[1] 写成 1（题干声明 j 从 1 开始时它必须是 0，有的资料用另一套下标口径、整张表的值差 1，别串口径）；**试到第一个不成立就停**（L 不是单调的：`ABAB` 试 1 个不成立、试 2 个反而成立，必须试完取最大），漏掉成立的那一个就一律记 1，真题选项 D 的 01111 正是这么来的；**结尾那一截的起点数错**，选项 C 的 01211 从第 3 位起就偏了。定义题那一路只有一个坑：**空格串不是空串**，别答反。

### 参考答案

1. **A**。链表的指针域存的是"元素之间的关系"而不是数据本身，结点里真正装数据的比例小于 1，这正是存储密度低的定义。B 说反了——必须占用地址连续单元的是顺序表，链表恰恰不要求连续。C、D 的诱饵是"链表增删要遍历"：只要已经握着待操作结点的前驱，插入 2 步、删除 1 步就完事，与表长无关；即便按序号定位那一步是 O(n)，也不是"遍历整个链表"。

2. **B**。next[1] = 0；j = 2 时 1 < k < 2 无解取 1；j = 3 时 k 只能为 2，p₁ = a ≠ p₂ = b，取 1；j = 4 时 k = 2 满足（p₁ = a = p₃）、k = 3 不满足，取 2；j = 5 时只有 k = 2 满足（p₁ = a = p₄），取 2。合起来 01122。A 是把 next 当成序号 j−1 递增来蒙；C 从第 3 位起就偏；D 只错在第 4、5 位。

3. **C**。先换单位：L = 2 个字 × 2 字节 = 4 字节。下标从 0 起，`LOC(a[35]) = 1000 + 35×4 = 1140`。自查：i = 0 代回得 1000 ✓。A 是忘了字与字节的换算（1000 + 35×2）；B 是把下标 35 当成"第 35 个"套 1 起公式（1000 + 34×4）；D 是认成"第 36 个"又套 0 起的 i×L（1000 + 36×4），等于调了两遍。

4. **B、B**。插入：n − i + 1 = 10 − 4 + 1 = **7**（第 4 到第 10 共 7 个元素各后移一位）。删除平均：(n−1)/2 = 9/2 = **4.5**。第二空的 C（5）正是把删除也按 n/2 算的错法——删除只有 n 个位置可选，不是 n+1 个。

5. **C**。散列是"用函数把关键字算成地址"的摆法，属存储结构。线性表、栈、图都是逻辑结构，各自都可以顺序存也可以链式存。

6. **C**。A 错，链表地址无规律，只能从头指针一步步走，没有随机存取能力。B 错在"一定"：链表每结点多存指针是浪费，顺序表预分配的连续空间用不满同样是浪费。D 错，"第 i 个"意味着要先从头走到第 i−1 个结点，整体是 O(n)；只有已经握着前驱指针时那一步才是 O(1)。

7. **D、A**。双向链表在 p 后插 s 要改 4 个指针：`s->prior`、`s->next`、`p->next->prior`、`p->next`，且最后一句必须放最后（前面还要用原来的 p->next）。单链表删除 p 的后继只改 1 个指针：`p->next = p->next->next`。常见错法是把双向链表的插入也答成 2——那是单链表的数。

8. **B**。空格串由空格字符组成，空格是占一个字符长度的正经字符，`" "` 的长度是 1 而不是 0。A、C、D 都是定义原文。

9. **3028；L = 4**。LOC(b₁₅) = 3000 + (15−1)×2 = 3000 + 28 = 3028，自查 i = 1 代回得 3000 ✓。反求：3040 − 3000 = (11−1)×L，40 = 10L，L = 4。

10. 插入平均 **6**（= 12/2）、删除平均 **5.5**（= 11/2）、插入最坏 **12**（插在第 1 个位置，全表都挪）、删除最坏 **11**（删第 1 个）。

11. `"aaab"` → **0123**；`"abcabaa"` → **0111232**。前者每多一位就多配上一个 a，所以逐位加 1；后者的 j = 6 处 `p₁p₂` = ab 与 `p₄p₅` = ab 相同，取 k = 3 得 3，是全串最大的一位。

12. 朴素：对齐主串第 1、2、3 位各比 3 次（前两个 a 都对、第三位 a ≠ b），对齐第 4 位比 3 次全中，共 **12** 次，匹配位置 **4**。next("aab") = **012**。KMP：失配时 j 由 3 退到 2、i 不回退，总比较 **9** 次，位置同样是 4。

13. **2/3 ≈ 0.67**。存储密度 = 8 ÷ (8 + 4) = 2/3。对照数据 4 字节、指针 4 字节时的 1/2，可见数据域越大、指针那点开销占比越小。

## 速记

- 三要素 = 逻辑结构 + 存储结构 + 运算；逻辑四类 **集合/线性/树形/图状**，存储四种 **顺序/链式/索引/散列**，两条维度正交——线性表、栈、树、图是逻辑，散列、索引是存储
- 一维地址：`LOC(aᵢ) = LOC(a₁) + (i−1)×L`（1 起）／`LOC(a[0]) + i×L`（0 起）；算完把首元素代回自查；单位先换算
- 顺序表插入移动 **n−i+1**、删除 **n−i**；等概率平均：插入 **n/2**（n+1 个位置）、删除 **(n−1)/2**（n 个位置），两者只差 1/2
- 指针步数：单链表插 2、删 1；双向链表插 4、删 2；单链表删「第 i 个」仍要先走到第 i−1 个，整体 O(n)
- 存储密度 = 数据字节 ÷ 结点总字节：顺序表 **1**、单链表 **1/2**、双链表 **1/3**（数据与指针各 4B）；容量：顺序表事先定死，链表动态改变
- 循环链表尾结点指回首结点，遍历终止由「到 NULL」改成「回起点」；只留尾指针时找头找尾都 O(1)
- 串：空串长度 0，**空格串不是空串**；子串必须连续，字符互异时子串共 n(n+1)/2+1 个；朴素匹配最坏 **O(n×m)**，KMP **O(n+m)**、失配时**主串指针不回退**
- next（j 从 1 起）：**next[j] = L + 1**，L = 前 j−1 个字符里「最长相等前后缀」的长度（逐个试完取最大，不单调）；next[1] = 0、next[2] = 1；等价的 k 式里 **k = L+1**；`"abaac"` → **01122**
