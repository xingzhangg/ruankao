## 考试怎么考

**考点① 求工期和关键路径（2021 上、2022 下考的都是这一类）。** 给表或给网络图，问"项目工期为（ ）天""关键路径是（ ）"。**枚举法最快**：从起点到终点把所有路径列全，各自求和取最长，不必做正推倒推。别漏路径——按第一个活动分组穷举。看到一条就收工是常见错法，关键路径可能有多条。

**考点② 求某活动的总时差/松弛时间。** 快法直接套"总工期 − 经过该活动的最长路径"。但题目若问"活动 C 最迟应在第几天开始/完成"，只能正推倒推走两遍，此时"正推 max、倒推 min"绝不能记反。

**考点③ 总时差 vs 自由时差。** 看清问的是哪一个。总时差 = LS − ES = LF − EF；自由时差 = min(紧后的 ES) − 本活动 EF。错法是拿总时差的公式去答自由时差，两者只在"紧后活动本身也有富余"时才不相等。

**考点④ 延期/提前后重算工期。** 把受影响的每条路径都重算再取最大。三个错法：只算原来的关键路径；以为非关键活动延期一定不影响工期（超出总时差就影响）；以为关键活动提前多少工期就缩多少（第二长的路会顶上来）。

**考点⑤ 甘特图与 PERT 图对比（送分，反着背）。** 固定问法是"Gantt 图不能清晰地反映（**各任务之间的依赖关系**）""PERT 图不能清晰地表达（**各任务之间的并行关系**）"。甘特图能看清起止时间、持续时间、并行关系和实际进度；PERT 图能看清依赖关系、关键路径和时差。另外要认得虚活动：**虚线箭头、历时为 0、不占资源，只表达依赖约束或区分同起止节点的两个活动**，只出现在 AOA 画法里。

**考点⑥ 概念送分题。** 进度管理六过程按顺序问哪个在前（活动定义 → 活动排序 → 资源估算 → 历时估算 → 计划编制 → 进度控制）；活动资源估算五方法（专家判断、替换方案的确定、公开的估算数据、估算软件、自下而上的估算），常见干扰项是把成本估算的"自顶向下""差别估算法"混进来。

**关于教材的节点图**：教材把四个时间和总浮动画成一个三行的方框（上行"最早开始｜工期｜最早完成"，中行活动名，下行"最迟开始｜总浮动｜最迟完成"），培训资料指出教材这张原图有误。别死记格子位置，按"**上行早、下行迟，左列开始、右列完成，中列上工期下总浮动**"理解，任何画法都读得出来。

　　A. 一个项目的关键路径有且只有一条　B. 关键路径上各活动的自由时差一定为 0
　　C. 压缩任何一个活动的工期，都能缩短项目总工期　D. 某活动总时差为 3 天，则它推迟 3 天开工，项目工期一定延长 3 天

### 参考答案

1. **D、D**。三条路径：A→B→E→G = 2+4+4+3 = 13；A→C→E→G = 2+5+4+3 = 14；A→D→F→G = 2+6+6+3 = **17**。工期 17 天（第二空 D），关键路径 A→D→F→G。C 的总时差 = 17 − 14 = **3** 天（第一空 D）。验算：ES(C)=2、EF(C)=7，LF(C)=LS(E)=10、LS(C)=5，LS−ES = 3 ✓。

2. **12 天，A→D→F**。五条路径：A→C→E = 9；A→D→E = 11；A→D→F = **12**；B→D→E = 10；B→D→F = 11。

3. **3 天、1 天**。C 的总时差：经过 C 的最长路径是 A→C→E = 9，12 − 9 = 3；验算 ES(C)=3、EF(C)=7，LF(C)=LS(E)=12−2=10、LS(C)=6，6−3 = 3 ✓。B 的自由时差：B 的紧后只有 D，ES(D) = max(EF(A), EF(B)) = max(3, 2) = 3，自由时差 = 3 − EF(B) = 3 − 2 = **1**，与 B 的总时差 1 相等（因为 D 是关键活动）。

4. **D**。非关键活动只能在**总时差范围内**推迟，超出同样拖累工期。A、B、C 三句都是关键路径的直接定义或推论。

5. **(1) B，(2) C**。甘特图有时间轴没有依赖箭头，PERT 图有依赖箭头没有时间轴。

6. **B**。虚活动历时为 0、不占资源，只表达依赖约束（或区分起止节点相同的两个活动），它不可能自己构成"辅助工作"，也和关键路径、时差没有定义上的关系。

7. **C**。差别估算法属于**成本估算**的三类基本方法（自顶向下、自底向上、差别估算法），不在活动资源估算的五种方法里。这是本考点最常见的干扰项造法：拿隔壁小节的方法名来凑。

8. **10 天，关键路径 B→D→E**。三条路径：A→C→E = 2+3+4 = 9；B→D→E = 4+2+4 = **10**；B→D→F = 4+2+3 = 9。

9. **总时差 1 天，自由时差 1 天**。ES(C)=EF(A)=2，EF(C)=5；E 的 LF = 10、LS = 6，C 的紧后只有 E，故 LF(C)=6、LS(C)=3，总时差 = 3−2 = 1。快法验算：经过 C 的最长路径 A→C→E = 9，10−9 = 1 ✓。自由时差 = ES(E) − EF(C) = 6 − 5 = 1，两者相等，因为紧后的 E 是关键活动。

10. A 拖 1 天，项目仍是 10 天完工（总时差 1）；但 A 只要拖，紧后 C 的 ES 就立刻从 2 被顶到 3（自由时差 0）。也就是说 A 拖得起，但拖的代价由 C 承担——C 自己那 1 天余地被吃掉了。这正是"不拖累项目，但吃掉下游余地"。

11. **12 天，关键路径变成 A→C→E**。三条路径重算：A→C→E = 5+3+4 = **12**；B→D→E = 3+2+4 = 9；B→D→F = 3+2+3 = 8。两处陷阱都在这题里：A 原本不是关键活动，但它的总时差只有 1 天（见第 10 题），实际多拖了 2 天，工期就从 10 天涨到 12 天；B 是关键活动，提前的那 1 天却一点没换成工期，因为瓶颈已经换到 A 这条路上了。**受影响的路径必须全部重算再取最大**，只盯原来那条 B→D→E 会答成 9。

12. **B**。A 错，关键路径可能不止一条；C 错，只有压关键活动才有用；D 错，总时差 3 天推迟 3 天恰好不影响工期；B 对——关键活动总时差为 0，而 0 ≤ 自由时差 ≤ 总时差，所以自由时差也只能是 0。
