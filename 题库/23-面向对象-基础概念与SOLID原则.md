## 考试怎么考

**考点① 给定义句式认名词。** 题干几乎照抄教材原句，认句式就够：出现"把数据和操作**封装**成整体""只能通过对外接口访问"选封装；"在已存在的类的基础上创建新类""父类与子类的层次关系"选继承；"不同对象收到同一消息产生不同结果"选多态；"不同类的对象之间**通信**"选消息。错项造法只有两种：把三大特性互换（把"通信"答成继承），或塞一个不是特性的词（"信息""聚合""组合"）。

**考点② 覆盖与重载、动态与静态绑定。** 最常见的错误选项是"**重载在运行时根据对象的实际类型确定调用哪个方法**"——重载在编译时就按参数表定了。反向的错项是"覆盖后的方法在编译时确定"，同样错。记法：**同类不同参＝重载＝编译期；父子同签名＝覆盖＝运行期。**

**考点③ 多态四形式。** 题干给一句描述让你填形式名。"操作具有相同的名称、在不同的上下文中含义不同"是过载；"父子类关系、同一消息不同响应"是包含；"同一段代码作用于多种类型"是参数；"类型转换后才能运算"是强制。过载与包含对调是最常见的错法。

**考点④ 实体类／接口类（边界类）／控制类。** 判据是这个类**站在哪儿**：代表现实世界里真实存在的人或物，实体类；跟用户或外系统打交道的入口（屏幕、窗体、菜单、二维码、对外收发数据），接口类；不代表任何实物、只负责把流程串起来，控制类。

**考点⑤ SOLID 及其外围，给描述选原则。** 这是本课分值最集中的一处，判别词是封闭清单：

| 题干里出现 | 选 |
|---|---|
| 修改的原因有且只有一个／只做一种类型责任 | 单一责任 |
| 可以扩展但不可修改／对扩展开放对修改关闭 | 开放—封闭 |
| 子类必须能替换基类型／父类出现处都能换成子类 | 里氏替换 |
| 抽象不依赖细节、细节依赖抽象／高层不依赖低层／针对接口编程 | 依赖倒置 |
| 不应强迫客户依赖它们不用的方法／接口属于客户 | 接口分离 |
| 优先使用组合聚合而不是继承来复用 | 合成复用 |
| 重用了包中一个类就要重用包中所有类 | 共同重用 |
| 包中的类对同一类变化共同封闭 | 共同封闭 |
| 对其他对象了解尽可能少／不和陌生人说话 | 最少知识（迪米特） |

两个坑要单独记：**接口分离的题干后半截也会写"依赖于抽象，不要依赖于具体"**，别被带去选依赖倒置，只认前半句；**共同重用与共同封闭**只差"重用/封闭"两个字，看题干问的是复用还是变化。

### 参考答案

1. **A**。继承是"在已存在的类的基础上创建新类"，得到的是一个**新类**。B、C 说的是往老类里加方法或属性，那是改老类，不是继承；D 把类换成了状态。
2. **C**。"相同的名称、不同上下文含义不同"是过载多态的定义原句。包含多态强调的是父子类关系下同一消息不同响应，参数多态强调同一段代码吃多种类型，强制多态强调类型转换。
3. **B、A**。客户是现实世界中真实的人，实体类；二维码是用户与系统交互的入口（属于人机接口那一类），接口类（边界类）。控制类只负责协调流程，本题没有这样的角色。
4. **C**。只认前半句"不应该强迫客户依赖于他们不用的方法"——这是接口分离的定义原句。后半句"依赖于抽象，不要依赖于具体"读着像依赖倒置，是本题最大的陷阱。
5. **C、D**。第一空：cat、bird、parrot 各自是 Animal 某个子类的对象，都可以当作 Animal 的对象；parrot 是 Parrot 的对象、Parrot 又是 Bird 的子类，所以 parrot 也可以看作 Bird 的对象。只有 C 把方向反过来了——bird 是 Bird 的对象，而 Bird 是 Parrot 的**父类**，父类的对象顶不了子类的位置（是鸟不一定是鹦鹉）。这正是里氏替换那句话的反面：能替换的方向只有"子类替父类"。第二空：不同对象收到同一条 move() 消息给出各自不同的结果，是多态的定义句；B 继承是支撑多态的机制而不是这个现象本身，C 消息传递说的是通信手段。
6. **A、D**。(37) 鸭子类实现公共的呱呱叫和游泳、把显示颜色留给野鸭和红头鸭各自实现，这是父类子类的层次关系，即继承；聚合和组合是"整体—部分"关系，不是"是一种"。(38) 一组不同对象收到同一条显示颜色消息、各显各的色，正是多态的定义句。动态绑定是多态在运行时的实现机制，题干问的是"这种现象称为"，答多态。
7. **A**。"修改的原因有且只有一个""只做一种类型的功能"是单一责任的定义原句。
8. **A、C**。(37) 姓名、成绩这些数据连同"查看成绩"这个操作一起装进对象，是封装的定义。(38) 对象之间的通信手段叫消息；继承和多态是机制不是通信手段，重载只是同名不同参。
9. **B**。"重用了一个类就要重用整包"是共同重用原则。A 共同封闭讲的是同一类变化封闭在一个包内，问的是变化不是重用。
10. **C**。同一个类里同名不同参，是方法重载；方法覆盖要求子类与父类同名同参，题干里根本没有父子类。
11. **D**。"抽象不应该依赖于细节，细节应该依赖于抽象""针对接口编程而不是针对实现编程"是依赖倒置的定义原句。C 最少知识讲的是对象之间了解越少越好。
12. **C**。调用方一行代码没改，是被"换进来的子类不守父类承诺"坑的，属里氏替换。答开闭是最常见的错法——开闭问的是"加新东西时老代码改没改"，这里老代码没改。
13. **B**。重载在**编译时**按参数表就能定，属静态绑定；运行时按实际类型定的是覆盖。
14. **B**。把"继承来复用"改成"持有对象来复用"，正是合成复用原则（优先用组合聚合而非继承）。选依赖倒置的常见理由是"都在讲别写死"，但 DIP 讲的是高层别依赖低层的**具体实现**，本题压根不涉及抽象层。
15. 前者是**抽象**（抽取共同特征、忽略次要特征），后者是**封装**（信息隐蔽，只能通过对外接口访问）。判据：抽象在造类时决定留哪些特征，封装在类造好后决定露哪些接口。
16. `b.type()` 走 **TravelBill** 的实现，看的是对象的**实际类型**，属**动态绑定**；`route(b)` 走 **`route(Bill)`**，看的是引用的**声明类型**，属**静态绑定**。同一个 `b`，覆盖看实际是什么，重载看声明成什么。
