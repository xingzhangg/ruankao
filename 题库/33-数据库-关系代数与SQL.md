## 考试怎么考

**考点① 自然连接的属性列数（上午第一高频）。** 题目长相："关系 R(A,B,C,D) 和 S(C,D,E) 自然连接后的属性列为（ ）个"，或换成中文表问"几元关系"（部门 3 列 + 员工 5 列、公共属性部门代码 1 个 → 7 元）。常见错法：直接相加（那是笛卡尔积/等值连接的列数，正是干扰项来源）；减 1 而不是减公共属性的**个数**；把"几元关系"当行数去数。

**考点② 关系代数 ↔ SQL 互译，含把 R⋈S 展开成 π(σ(R×S))。** 给一句 SQL 问等价代数式，或给 π/σ 式让你填 SELECT / FROM / WHERE 三个空。先看**下标装的是什么**——σ 装条件、π 装列名，装反的直接排除，通常砍掉一半；再看**嵌套顺序**，σ 在里 π 在外。列号是这类题唯一的机关：**编号永远相对括号里那张表**——σ(R×S) 按 a+b 列编（R 的列在前、重复列各占一号），σ(R⋈S) 按 a+b−公共属性 列编，同一个"第 6 列"在两种基准下不是同一列（练习 1 用前者、练习 2 用后者）。剩下三个动作固定：**π 的下标 → SELECT 的列**（展开成 R×S 时就是把 S 侧的重复列号排除掉），**FROM 后是逗号分开的两张表**，**WHERE 要写全"等值条件 + 额外的 σ 条件"并用 AND 连**。常见错法：用 OR 连；给列号加引号写成 σ<sub>'2'>'7'</sub>——**加引号就成了字符串常量而不是列号**，是本题型的招牌干扰项；只写 σ 忘了外层 π。

**考点③ WHERE 与 HAVING、执行顺序。** 给一条含 WHERE + GROUP BY + HAVING 的 SQL 问结果有哪几行。照队伍走：**先删行、再分堆、再删堆**。常见错法：拿原始表数 COUNT/算 AVG，忘了 WHERE 已先删过行；以为两者可互换。

**考点④ GROUP BY 分组聚合的 SQL 填空（下午题 2 的主力）。** 一条 SQL 挖 1–3 个空，按空计分。判定套路：**带聚合函数的条件只能是 HAVING，不带就是 WHERE**；"按各种 X 分别统计"必有 `GROUP BY X` 且 X 要进 SELECT；`AS` 的格式是"表达式 AS 别名"，写反是标准错误项。常见错法：自造表名列名（题干里全给了，必须原样抄，写错一处该空不得分）；多表连接漏写连接条件；SELECT 里写了非聚合列却没进 GROUP BY。

**考点⑤ GRANT / REVOKE 与视图索引叙述题。** 权限题按零件逐个判。常见错法：把 `WITH GRANT OPTION` 当成"授予全部权限"（那是 ALL PRIVILEGES，它只管转授）；看见 `GRANT SELECT` 就选"能做任何操作"；介词写反。叙述题的错误项只有三种造法：给视图安上"存了一份数据副本"，给索引安上"越多越好/不占空间"，把并交差的相容条件改成"列名必须相同"（只要求个数相同、对应属性同域）。

### 参考答案

**1. B、D**。第一空：公共属性 C、D 共 2 个，4+3−2 = **5**。第二空：R×S 的 7 列从 1 编号 → 1=A、2=B、3=R.C、4=R.D、5=S.C、6=S.D、7=E。等值条件 R.C=S.C、R.D=S.D 即 3=5 ∧ 4=6；去重复列靠外层 π 只取 1,2,3,4,7（排除 S 侧的 5、6）；附加条件 R.B>S.E 即 2>7，合起来正是 D。A、C 缺外层 π；B 给列号加了引号，**'2'>'7' 比的是两个字符串常量而不是列**，与 D 只差这对引号。

**2. C、A、D、B**。(51) 公共属性 B、C 共 2 个，5+4−2 = **7**。(52) 七列按 A B C D E F G 编号，π<sub>1,3,6,7</sub> 取 **A、C、F、G**，写成 `A,R.C,F,G`（C 两表都有必须加前缀）。(53) 查两张表，写 `R,S`。(54) WHERE 要用 **AND** 连两部分：等值条件 `R.B=S.B AND R.C=S.C`，加上 σ<sub>3<6</sub> 即第 3 列 C 小于第 6 列 F 得 `R.C<S.F`。用 OR 的 C、D 一眼排除；A 把第 6 列错当成 S.B。

**3. A、A、D**。54 属讲义 31 的考点：主键是 (零件号,供应商)，而"零件号→零件名称"只用半个码，存在部分函数依赖，卡在 **1NF**。55 语法是"表达式 AS 别名"，B、D 把两边写反，C 的 `AVG 库存量` 漏括号。56 要"各种零件"分别统计就按零件号分组；ORDER BY 只排序不分组，不分组时聚合函数会把整表压成一行。

**4. B**。C、D 的下标装反，直接排除；A 顺序反了，先投影就把年龄列扔了，外层无从比较。

**5. B**。自然连接去重复列：4+3−2 = **5**；干扰项 7 是笛卡尔积/等值连接的列数。

**6. B**。动词 GRANT 排除 D；权限只有 SELECT 而非 ALL PRIVILEGES，排除 C；带 WITH GRANT OPTION 可转授，排除 A。

**7.** R×S = 3×4 = **12 行**、2+3 = **5 列**。R⋈S 也是 **12 行 5 列**——**没有公共属性时等值条件是空的，谁都跟谁匹配，自然连接退化成笛卡尔积**，减号那项减 0。

**8.** 只有 **C01 一行，平均 76.67**（(85+90+55)/3）；C02 平均 65，被 HAVING 整组删掉。

**9. π<sub>课程号</sub>(σ<sub>成绩>=85</sub>(SC))**。成绩≥85 的是 S01-C01-85、S02-C01-90，投影出课程号得 C01、C01，π 去重 → **{C01}，1 行**，正对应 DISTINCT。

**10.** 填 **HAVING**（`… GROUP BY 学号 HAVING COUNT(*)>=2`）。条件里有聚合函数 COUNT(*)，而 WHERE 排在 GROUP BY 之前，那时还没分堆、COUNT 无从算起；按聚合值筛掉整个"堆"正是 HAVING 的职责。本讲表上得张三、李四。

**11.** 不能——没有 `WITH GRANT OPTION` 只能自己用，无权转授。第二问：U1 已转授给 U2，不加 CASCADE 的 REVOKE 会被拒绝（U2 那份会成无源之水）；要连 U2 一起收得写 `… FROM U1 CASCADE;`。
