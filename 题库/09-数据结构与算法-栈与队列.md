## 考试怎么考

**考点① 出栈序列合法性。** 问法：「元素 1,2,3,4 依次入栈，出栈序列**不可能**是（ ）」，或给一个入栈序列问某串是否合法。解法走第三节四步操作规程，先用「后面比它小的必须递减」这条判据秒掉明显不合法的选项，再对留下的做模拟。三种错法：以为必须全压完才能弹（那样出栈序列只能是完全逆序，一道也做不对）；凭直觉判断（n ≥ 4 时直觉基本失效）；模拟时不写栈的内容，全靠脑子记。变式（培训资料未收，频率待核实）问「共有多少种出栈序列」用卡特兰数 C(2n,n)/(n+1)，n = 4 是 14。

**考点② 栈/队列的基本特性与操作复杂度。** 问法：「入队、出队的时间复杂度」「插入删除只能在同一端进行的结构是」。解法：只要维护了队头队尾指针（栈是栈顶指针），两端都不用遍历，**全是 O(1)**，四种实现一样。常见错项：「入队 O(1)、出队 O(n)」（想象成要挪元素）、「队列只能顺序存储」「栈必须用数组」（两者都可顺序、可链式）。还要分清：不循环的顺序队列确实会浪费前段空间，但那是**空间**问题（假溢出），不是时间复杂度问题。

**考点③ 循环队列的判空、判满与元素个数。** 问法：「队满条件是」「当前元素个数是」「容量 MaxSize 的循环队列最多存几个」。解法：牺牲一个单元的约定下，空 `front == rear`、满 `(rear+1) % MaxSize == front`、个数 `(rear − front + MaxSize) % MaxSize`、最多 **MaxSize − 1** 个。三种错法：把队满只写成 `(rear+1) % MaxSize`（漏了 `== front`）；忘了「牺牲一个单元」导致最多只能装 MaxSize−1 个；算个数时漏掉 `+ MaxSize`，rear 绕回后算出负数。若题目改用 front + size 描述，队尾下标是 `(front + size − 1) % MaxSize`。

**考点④ 后缀表达式求值与栈内操作数个数。** 问法：给后缀式求值；给中缀式选后缀式；「运算数栈中最多同时保存几个操作数」。解法走第五节三条规则加四条防粗心规程。三种错法：左右操作数弄反（只在减、除上暴露）；把「栈内最多同时存放的操作数个数」和「表达式里操作数的总个数」当成一回事（主例里是 3 和 4）；把后缀式当中缀读。

**考点⑤ 双端队列。** 问法：给一个两端都能进出的队列加各种限制，问哪个出队序列可能/不可能。解法：先把限制翻译成栈还是队列——「同一端进出」就是栈（该端后进先出），「一端进另一端出」就是队列（先进先出）；再把每一端各自能产生的出队顺序写死，最后看选项是不是这几串的合法交错。常见错法：直接凭「队列就是先进先出」下结论，没注意题目已经把它限制成了两个栈。

### 参考答案

1. **D**。「同一端口进出」把每一端各自变成了一个栈：A 端压入 e1、e2，弹出必然是 e2 在 e1 之前；B 端压入 e3、e4，弹出必然是 e4 在 e3 之前。于是出队序列只能是 (e2, e1) 与 (e4, e3) 这两串的交错。逐项查：A 里 e1 在 e2 前 ✗；B 里 e3 在 e4 前 ✗；C 两条都违反 ✗；D 是 e4→e3→e2→e1，两串各自的相对顺序都对 ✓。

2. **D**。只要 k ≥ 2，最后出来的既可能是 1、也可能是 n。以 n = 4、k = 2 为例：`push1 push2 pop2 pop1 push3 pop3 push4 pop4` 得到 2,1,3,4，最后是 4；`push1 push2 pop2 push3 push4 pop4 pop3 pop1` 得到 2,4,3,1，最后是 1。同一个 k 能导出不同的末位，所以答案只能是「不确定」。选 B 的思路是「1 在栈底，一定最后出」——错在 1 弹出之后栈就空了，后面的元素还能继续压进来再弹。

3. **B**。front 指着队头元素，从队头往后数 size−1 格就是队尾，所以队尾下标 = `(front + size − 1) % M`。按题图代入 front 编号为 1、size = 3，得 1 + 3 − 1 = 3，正是队尾元素 Z 的位置。四个选项没有一个直接写成这个样子：A 少了 `% M`（rear 绕回时会越界），C、D 方向反了。B 多出来的 `+ M` 不改变余数（加上模数的整数倍余数不变），所以 B 与 `(front + size − 1) % M` 等价。

4. **C**。维护了队头指针和队尾指针之后，入队是往队尾那一格写、出队是把队头指针往后挪，**两个操作都不遍历**。A、B 的诱饵是「出队后要把后面的元素整体前移一格」——有队头指针就不用移。

5. **C**。用判据先筛：C 里取 x = 3，排在它后面又比它小的是 1、2，呈「先小后大」→ 不合法。再用模拟坐实：push 1,2,3 → pop 3，栈剩 [1,2]，下一个要弹 5，于是 push 4、push 5 → pop 5，栈剩 [1,2,4]；接着要弹 1，栈顶却是 4，待入栈的也压完了 → 卡住。另三项模拟均可走通：A 是全压完再全弹；B 为 push1,2→pop2, push3→pop3, push4,5→pop5→pop4→pop1；D 为 push1→pop1, push2,3,4,5→pop5→pop4→pop3→pop2。

6. **38；3 个**。逐步：压 5 → [5]；压 6 → [5,6]；压 2 → [5,6,2]（栈深 3，最大）；`+` 弹 2（右）、弹 6（左），6+2=8 → [5,8]；`×` 弹 8、弹 5，5×8=40 → [40]；压 8 → [40,8]；压 4 → [40,8,4]（栈深 3）；`÷` 弹 4、弹 8，8÷4=2 → [40,2]；`−` 弹 2（右）、弹 40（左），40−2=38 → [38]。还原中缀验算：5×(6+2) − 8÷4 = 40 − 2 = 38 ✓。表达式里操作数共 5 个，但栈内同时最多只放 3 个，两者不同。

7. **6 个；7 个**。个数 = (rear − front + MaxSize) % MaxSize = (1 − 3 + 8) % 8 = 6 % 8 = 6；手工点一遍，占用下标 3、4、5、6、7、0 共 6 格 ✓。最多能存 MaxSize − 1 = 7 个，那被牺牲的一格是用来区分队空与队满的。

8. **`a b × c d ÷ +`**。加满括号：`(a × b) + (c ÷ d)`；把每对括号里的运算符移到括号右边：`(a b ×) (c d ÷) +`；去括号即得。验算：从左到右扫一遍，`a b ×` 压回一个结果、`c d ÷` 压回一个结果，最后 `+` 把两个结果相加，与中缀语义一致 ✓。

9. **42 种**。C(2n,n)/(n+1)，n = 5 时 C(10,5)/6 = 252/6 = 42。对照 5! = 120，被后进先出挡掉了 78 种。

10. **值 9，最大栈深 3**。压 2 → [2]；压 3 → [2,3]；压 4 → [2,3,4]（栈深 3）；`×` 弹 4、弹 3，3×4=12 → [2,12]；`+` 弹 12、弹 2，2+12=14 → [14]；压 5 → [14,5]；`−` 弹 5（右）、弹 14（左），14−5=9 → [9]。还原中缀：2 + 3×4 − 5 = 9 ✓。

11. **3 个；rear = 0**。个数 = (4 − 1 + 6) % 6 = 9 % 6 = 3，占用下标 1、2、3 ✓。判满条件 `(rear + 1) % 6 == front = 1`，解得 rear = 0；此时占用下标 1、2、3、4、5 共 5 个 = MaxSize − 1 ✓。

12. **不合法**。判据：取 x = 4，排在它后面又比它小的是 1、3，出现了「1 在 3 前面」这种先小后大 → 不合法。模拟坐实：push 1、push 2 → pop 2，栈剩 [1]；push 3、push 4 → pop 4，栈剩 [1,3]；下一个要弹 1，栈顶却是 3，而待入栈的元素已经压完 → 卡住。
