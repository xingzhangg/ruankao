## 考试怎么考

**考点① 折半查找的比较次数与过程。** 两种问法。问"n 个元素最多比较几次"，套 `⌈log₂(n+1)⌉`，实操是**找第一个 ≥ n+1 的 2 的幂，指数就是答案**（1000 → 10）。问"被比较的元素依次是哪些"，就老实走 low/high/mid 三列表格。常见错法：mid 忘了向下取整；下一轮区间又把 mid 算进去（应该是 mid−1 / mid+1）；算树高时把 ⌈log₂(n+1)⌉ 错成向下取整（13 个元素答成 3，正确是 4）；被 n/2 这种干扰项骗走（那是顺序查找的量级）。

**考点② 折半的前提与适用性（辨析）。** 只认两条硬前提——**顺序存储 + 关键字有序**，并由此推出只适合**静态表**。错误选项的三副面孔："折半可以在**有序链表**上高效进行"（取中点就 O(n)）、"**只要有序**，任何存储结构上都是 O(log₂n)"（漏了顺序存储）、"折半适合**频繁插删**的动态表"（搬移代价太大，该用二叉排序树）。

**考点③ 哈希表线性探查的手工模拟。** 四步：先把此前所有键按插入顺序落位摆全 → 对新键算 key mod p → 被占就 (H+1) mod m、(H+2) mod m 顺延，**到表尾绕回表头** → 记下探查次数。问 ASL 就是**各键探查次数之和 ÷ 键数**（分母是键数，不是表长）。最大的错法是算新键时**只看谁和它同余**——因冲突顺延占位的键同样挡路。

**考点④ 冲突处理方法辨析。** 记住分类：开放定址法（线性探测／二次探测／随机探测再散列）、链地址法、再哈希法、公共溢出区。高频问法："哪种方法不会产生堆积"（链地址法；二次探测也能缓解）、"线性探测的增量序列是什么"（1,2,3,…,m−1）。错项常见："冲突可以通过设计好的哈希函数完全避免"（抽屉原理，不可能）、"哈希查找的时间复杂度恒为 O(1)"（那是平均）。

**考点⑤ 特殊矩阵的下标公式。** 两种问法：一种给 n、给 aᵢⱼ，问它存在 B 的第几个位置；另一种直接给四个式子，问"k 与 i、j 的对应关系"是哪一个（三对角矩阵最常这么问）。都别背公式，现场数"前面还有几个元素"，或者拿角上那一两个元素代进四个选项一一排除。**普通二维数组**（不压缩）也常单独出一题：行优先 LOC = a+(i×n+j)×len、列优先 LOC = a+(j×m+i)×len，认准"行优先看行长 n、列优先看列长 m"就不会串。**动笔前先确认行优先／列优先、下标从 0 还是从 1、数组从 B[0] 还是 B[1]**——四个选项里往往有两个只差 1，就是拿这个坑人；三对角的三种口径分别是 2i+j−2（都从 1）、2i+j（都从 0）、**2i+j+1（矩阵从 0、数组从 1，真考过）**。用 a[1][1]（或 a[0][0]）代入自查最快。

**考点⑥ 稀疏矩阵三元组。** 问"三元组**不需要**包含的信息"，答矩阵的行数／列数／非零元个数（那是头信息）；问存储单元数，压缩前 = 行×列，压缩后 = 非零元个数×3 + 头信息 3。

**考点⑦ 广义表的长度、深度与 head/tail。** 长度只数最外层元素个数，深度数括号嵌套的最大重数。head 取第一个元素（可能是原子），tail 取剩下的**并且一定带括号**。常见错法：把长度当成所有原子的总个数；tail 结果忘了加括号；把只剩一个元素的表尾写成原子。

**考点⑧ 顺序查找（送分）。** 平均比较次数 **(n+1)/2**（不是 n/2），最坏 n，O(n)。它是唯一"对存储结构和有序性都无要求"的查找法。注意别把"顺序**查找**"（从头挨个比，链表也能用）和"顺序**存储**"（数组，那是折半的前提）搞混。

### 参考答案

1. **A**。low=1,high=13,mid=7 → 目标在 M[4]，4<7 故 high=6；mid=⌊7/2⌋=3，4>3 故 low=4；mid=⌊(4+6)/2⌋=5，4<5 故 high=4；mid=4 命中。依次比 M[7]、M[3]、M[5]、M[4]，共 4 次，恰好等于判定树高度 ⌈log₂14⌉=4。B、C、D 都少了一步，是把某一轮的 mid 算错（没有向下取整或没把 mid 排除出下一轮区间）造成的。
2. **A**。四个选项都是一次代入就能排掉三个的：三对角矩阵的第一个元素 a₁,₁ 必须落在 B[1]，代 i=j=1——A 得 2+1−2 = **1** ✓，B 得 2−1+2 = 3 ✗，C 得 3+1−1 = 3 ✗，D 得 3−1+2 = 4 ✗。再拿最后一个 aₙ,ₙ 复核 A：2n+n−2 = 3n−2，正好是数组最后一格 ✓。B、D 是把 j 的符号写反，C 是把"中间每行 3 个"错当成"整体乘 3"（真按行数乘 3 就会给第 1 行也留 3 个坑，可第 1 行只有 2 个元素）。
3. **C**。**同一个三对角矩阵，口径一换答案就变**：这里矩阵下标从 0、压缩数组从 1，属于混搭。先代 A[0,0]，它必须落 B[1]——A 得 −1 ✗，B 得 0 ✗，C 得 1 ✓，D 得 1 ✓，**一个测试点排不完，C 和 D 都活着**。再代第 2 个元素 A[0,1]，它该落 B[2]——C 得 0+1+1 = **2** ✓，D 得 0−1+1 = 0 ✗。（用题干给的 A[n−1,n−1] → B[3n−2] 复核也行：C 得 2(n−1)+(n−1)+1 = 3n−2 ✓，D 得 2n−1 ✗。）教训是**代入自查至少取两个点**，最好一个在角上、一个在旁边。
4. **B**。⌈log₂1001⌉：2⁹=512 < 1001，2¹⁰=1024 ≥ 1001，答 10。C 是顺序查找的平均量级、D 是顺序查找最坏次数，都是干扰项。
5. **D**。先摆已占位：26 mod 11 = 4 → 4 号；38 mod 11 = 5 → 5 号；15 mod 11 = 4 → 4 占、5 占 → 落 **6 号**（探查 3 次）。再插 49：49 mod 11 = 5 → 5 占(38)、6 占(15) → 落 **7 号**。关键在 15 因冲突顺延占了 6 号，它和 49 并不同余却照样挡路。
6. **D**。三元组 = (行号, 列号, 值)，"在哪 + 是多少"缺一不可，A、B、C 都要有。矩阵的总行数／总列数／非零元个数是整张表的头信息，只存一份。
7. **B**。链表不能按下标随机访问，取中点本身 O(n)，A、C 错；维持有序数组插删要大量搬移，折半只适合静态表，D 错。
8. **B**。i=2 < j=4，用对称位置 a₄,₂：k = 4×3/2 + 2 = 6 + 2 = **8**。自查：前 3 行共 1+2+3=6 个元素，a₄,₂ 是第 4 行的第 2 个，6+2=8 ✓。若题目改成 B[0..14]（数组从 0 起），答案就变成 7——先看口径再动笔。
9. **A、C**。长度只数最外层：(a,b) 和 (c,d) 共 2 个元素。深度：最外 1 层，(a,b) 与 (c,d) 各再嵌 1 层，最大 2。取 d：tail(LS) = ((c,d)) → head 得 (c,d) → tail 得 (d) → head 得 **d**，正是 head(tail(head(tail(LS))))。
10. low=1,high=9,mid=5,a[5]=41 <90 → low=6；low=6,high=9,mid=7,a[7]=78 <90 → low=8；low=8,high=9,mid=8,a[8]=90 ✓。依次比 41、78、90，共 **3 次**（上限 ⌈log₂10⌉=4，3 ≤ 4 合理）。
11. 14 mod 7 = 0 → 0 号，1 次；22 mod 7 = 1 → 1 号，1 次；8 mod 7 = 1 → 1 占 → 2 号，2 次；15 mod 7 = 1 → 1 占、2 占 → 3 号，3 次。**ASL = (1+1+2+3)/4 = 7/4 = 1.75**。三个同义词堆在 1–3 号，探查次数逐个递增，典型堆积。
12. 压缩前 100×100 = **10000** 单元；压缩后 60×3 + 3 = **183** 单元，约为原来的 1.8%。
13. 23→1、40→7、91→3、17→6、19→8、10→10、31→9 均一次落位；**65 mod 11 = 10，10 号被占，绕回表头落 0 号（2 次）**；26 mod 11 = 4 → 4 号，1 次。表为 `0:65  1:23  2:—  3:91  4:26  5:—  6:17  7:40  8:19  9:31  10:10`。**ASL = (1×8 + 2)/9 = 10/9 ≈ 1.11**。这道题专考绕回表头，忘了取模就会答"放不下"。
14. k = 2i + j − 2 = 2×4 + 3 − 2 = **9**。自查：第 1 行 2 个、第 2 行 3 个、第 3 行 3 个共 8 个，a₄,₃ 是第 4 行的第一个（j−i+2 = 1），8+1 = 9 ✓。
