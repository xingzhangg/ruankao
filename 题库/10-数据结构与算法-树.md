## 考试怎么考

**考点① 完全二叉树的高度与结点数互推（本课最高频）。** 问法：「n 个结点的完全二叉树，高度（深度）为（ ）」，或反问「高度 h 最多/最少多少个结点」「第 i 层最多几个」。解法：`h = ⌊log₂n⌋ + 1`，再用 `2^(h−1) ≤ n ≤ 2ʰ − 1` 复核。三种错法：把根当第 0 层，答案整体差 1；把 2ʰ − 1 当成完全二叉树的结点数（那是**满**二叉树的，完全二叉树只被它当上界夹住）；栽在 2 的整幂边界上——**n = 63 → h = 6，n = 64 → h = 7**，最常被做成陷阱。

**考点② n₀ = n₂ + 1。** 问法：「某二叉树中度为 2 的结点有 15 个，则叶子结点有（ ）个」，题干常附「度为 1 的结点有 8 个」。解法：直接套得 16；反问「叶子 16 个，度为 2 的几个」就反解成 15。常见错法：拿 n₁ 加加减减（它在推导里已被消掉，必是干扰项）；把「度为 2 的结点」读成「有 2 个结点的层」。

**考点③ 顺序存储的下标关系。** 问法：「结点 i 的左孩子编号为（ ）」「某二叉树顺序存储，数组至少要多大」。解法：编号从 1 起时左孩子 2i、右孩子 2i+1、双亲 ⌊i/2⌋；数组大小 = 最深最右那个结点的编号（空位也占格）。常见错法：**没看清从几开始编号**——从 0 起则是 2i+1 / 2i+2 / ⌊(i−1)/2⌋。另一种问法给编号 m、n 问关系，如 n = 2m+1 即 n 是 m 的右孩子（练习 1）。

**考点④ 空指针数与线索二叉树。** 问法：「n 个结点的二叉链表中空指针有（ ）个」「三叉链表呢」。解法：二叉链表 n+1、三叉链表 n+2，现推法是「总槽数 − 非空槽数」。线索二叉树多考概念：**它利用的正是这 n+1 个空指针**，存某种遍历次序下的前驱和后继，靠 ltag/rtag 区分指针含义。常见错法：以为它是额外加了两个指针域（那正是它要避免的）。

**考点⑤ 遍历。** 三种问法：给树求某种遍历序列；给前序+中序求后序（或中序+后序求前序）；问「哪两种遍历能唯一确定二叉树」。解法：先定根、用中序切左右、再递归。常见错法：把中序当成「按图上位置从左往右读」；**答「前序+后序可以确定」**（必须有中序参与）；把层次遍历和前序搞混（层次用队列，前序用栈）。

**考点⑥ 哈夫曼树。** 四种问法：给权值求 WPL；求某字符的编码或编码总长；给编码表把 0/1 串译回原文；问结点总数。解法走第六节五步，算完用「WPL = 非叶结点（含根）权值和」和「2n−1 个结点」双路验算。常见错法：合并后忘记把新结点放回集合；把字符放到中间结点上（造出非前缀码）；以为哈夫曼树唯一——**权值出现并列时，树形、编码串、甚至各字符的码长都可能不唯一，唯一确定的只有 WPL**（例如权值 4,2,2,1,1，最优方案有码长 1/2/3/4/4 和 2/2/2/3/3 两套，WPL 都是 22）。所以问 WPL 可以放心答；问某字符的编码或码长，必须走「每次取最小的两个、并列时按题目给的先后、左小右大」这一套标准做法，才和标答对得上。

**考点⑦ 二叉排序树与平衡二叉树。** 问法：给树问是不是二叉排序树（中序看是否升序）；给几组插入序列问哪组建不出图上这棵树（逐个插入、比根小往左大往右，画出来比对）；给树问是不是平衡的、某结点 BF 是多少。解法：BF = 左子树高 − 右子树高，全部结点 |BF| ≤ 1 才平衡。常见错法：算子树高度时「层数」和「边数」混用（同一题里统一即可，差值不变）；以为二叉排序树一定平衡（升序插入会退化成单支树）。

**1.【真题·年份待核实】** 一个高度为 h 的满二叉树的结点总数为 2^h-1，从根结点开始，自上而下、同层次结点从左至右，对结点按照顺序依次编号，即根结点编号为 1，其左、右孩子结点编号分别为 2 和 3，再下一层从左到右的编号为 4、5、6、7，依此类推。那么，在一棵满二叉树中，对于编号为 m 和 n 的两个结点，若 n=2m+1，则（ ）
A. m 是 n 的左孩子　B. m 是 n 的右孩子　C. n 是 m 的左孩子　D. n 是 m 的右孩子

**10.【模拟·重现真题考点·年份待核实】** 某二叉树如下图所示，若进行顺序存储（用一维数组元素存储该二叉树的结点，对于下标为 i 的结点，其左孩子下标为 2i、右孩子下标为 2i+1），则该数组的大小至少为（ ）；若采用三叉链表存储（每个结点包括数据、父结点指针、左孩子指针、右孩子指针），则该链表所有结点中空指针的数目为（ ）。

```
        A
      /   \
     B     C
          / \
         F   D
              \
               E
```
第一空：A. 6　B. 10　C. 12　D. 15
第二空：A. 6　B. 8　C. 12　D. 14

### 参考答案

1. **D**。n = 2m+1 正是「右孩子 = 2i+1」的形式，把 m 代进 i，n 就是 m 的右孩子。验证：m = 3 时左孩子 6、右孩子 7 = 2×3+1 ✓。选 A、B 的是把父子方向读反了。

2. **C**。先定根：前序首位 `c`，中序里 `c` 左边 [a,b]、右边 [d,e,f,g]；递归还原出 c 的左孩子 a（a 只有右孩子 b）、右孩子 f（f 的左孩子 e、右孩子 g，e 只有左孩子 d）。逐个算平衡因子：c 为 2−3 = −1、a 为 0−1 = −1、f 为 2−1 = +1、e 为 1−0 = +1，b、d、g 均为 0，全部 |BF| ≤ 1 → **平衡二叉树**。排除另三项：树高 4 却只有 7 个结点，不满（h=4 的满二叉树要 15 个）；a 无左孩子却有右孩子 b，格子编号 4 号空、5 号有人，跳空了，不完全；题目没给权值，谈不上最优二叉树。

3. **C**。按各序列逐个插入（比当前结点小往左、大往右）：A、B、D 三组建出的都是图中这棵树。C 组第三个数 27 比根 23 大，会成为 23 的**右孩子**，而图中 23 的右孩子是 31，矛盾。技巧：只看**根的两个孩子**——序列中第一个大于 23 的数必须是 31，C 组是 27，直接排除。

4. **A；C**（第二空的公布答案是 C，但按题目给出的串**四个选项都对不上**，见下）。构造：5+9=14 → 12+13=25 → 14+16=30 → 25+30=55 → 45+55=100，得编码 a=0、b=101、c=100、d=111、e=1101、f=1100。所以 "bee" = 101+1101+1101 = **10111011101**（11 位），第一空选 A。第二空：给出的串 `11001001101` 只有 11 位，从根译得 1100→f、100→c、1101→e = "fce"，不在选项里；补成 `110001001101`（12 位）才译出 1100→f、0→a、100→c、1101→e = **face**，即公布答案 C。**转录的串少抄了一个 0**，答题以官方原卷为准，本题记住方法即可：译码从根走、到叶子就回根，末尾必须正好落在叶子上。

5. **B；64 → 7；63 → 6**。⌊log₂70⌋ + 1：2⁶ = 64 ≤ 70 < 128 → ⌊log₂70⌋ = 6，h = 7；夹逼复核 h=7 要求 64 ≤ 70 ≤ 127 ✓、h=6 要求 n ≤ 63 ✗。n = 64 时 64 号结点正是第 7 层的第一个，h = 7；n = 63 = 2⁶−1 恰好填满 6 层，h = 6。**63/64 这一对是最典型的边界陷阱。**

6. **C**。n₀ = n₂ + 1 = 15 + 1 = 16。「度为 1 的有 8 个」是干扰项，推导时 n₁ 被消掉了。（顺带可算总结点数 n = 16+8+15 = 39，边数 39−1 = 38 = n₁+2n₂ = 8+30 ✓。）

7. **码长 a=3、b=3、c=2、d=1，WPL = 25。** 合并：1+2=3 → 3+4=7 → 7+8=15，于是 d 深 1、c 深 2、a 和 b 深 3。WPL = 8×1 + 4×2 + 2×3 + 1×3 = 25；双路验算：非叶结点（含根）权值和 3+7+15 = 25 ✓。对照定长 (1+2+4+8)×2 = 30 位，省 5 位。

8. **13 个；14 个**。别背结论，现推：二叉链表 2×12 = 24 个指针槽，非空的等于边数 12−1 = 11，空的 24−11 = 13 = n+1。三叉链表 3×12 = 36 个槽，非空的是 11 条向下的边加 11 个非根结点的双亲指针共 22 个，空的 36−22 = 14 = n+2。

9. **C B E F D A；不能唯一确定。** 还原：前序首位 A 是根，中序里 A 左边 [C,B] 是左子树、右边 [E,D,F] 是右子树；左子树前序 [B,C] 定根 B，中序 [C,B] 说明 C 在 B 左边 → C 是 B 的**左**孩子；右子树前序 [D,E,F] 定根 D，中序 [E,D,F] 定出 E 左 F 右。后序按「左右根」读出 C, B, E, F, D, A。若只给前序 `A B C D E F` 和后序 `C B E F D A`，把 C 改挂成 B 的右孩子，这两串一字不变（穷举可知符合的树恰好 2 棵），所以无法唯一确定——必须有中序参与。

10. **D；B。** 第一空按「填格子」编号：A=1，B=2，C=3，C 的左孩子 F=6、右孩子 D=7，D 只有右孩子，编号 2×7+1=**15**。数组必须一直开到最深最右那个编号，中间 4、5、8～14 的空位也得占格，所以至少 15 个单元——**6 个结点要 15 格**，正是「顺序存储只适合完全二叉树」的直接后果。第二空：n=6，三叉链表空指针 = n+2 = **8**；现推 3×6 = 18 个槽，非空的是 5 条向下的边加 5 个非根结点的双亲指针共 10 个，18−10 = 8。（本题取自培训资料第 5 节【考试真题】第 2 题的考法，公布答案 D／B；**原题配图未随转录收录**，此处按这两个答案还原了一棵满足条件的树，故标【模拟·重现】而非【真题】。）
