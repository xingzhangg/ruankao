## 试题四（算法：回溯法求子序列和）

【说明】（原文缺）回忆：用回溯法，求一个有序数组中是否存在子序列之和等于指定值。

【C 代码】（原卷代码缺）

【问题 1】补充代码。

【问题 2】输入数组 [1,2,3,4,5] 和 5，问输出什么。

【问题 3】算法在最坏情况下的时间复杂度。

（问题提纲取自希赛；分值缺。）

### 参考答案与解析

CSDN 给出了一段**回忆者事后重构的完整代码**（不是原卷代码，变量名、空的位置都可能与原卷不同），照录如下，注释中的“空（N）”是回忆者标的空位：

```c
#include <stdio.h>
#include <stdlib.h>
// 全局变量
int *A; // 输入数组
int M; // 目标和
int *remaining_sum; // 剩余和数组
int n; // 数组长度
int found = 0; // 是否找到解
// 打印数组函数
void printArray(int path[], int path_len) {
    printf("[");
    for(int i = 0; i < path_len; i++) {
        printf("%d", path[i]);
        if(i < path_len - 1) printf(",");
    }
    printf("]");
}
// 回溯函数
void backtracking(int index, int current_sum, int path[], int path_len) {
    // 找到一个解
    if(current_sum == M) {//空1，填写找到解的条件
        found = 1;
        printArray(path, path_len);
        return;
    }
    // 剪枝条件1：如果当前和加上剩余所有元素和小于M，返回
    if(current_sum + remaining_sum[index] < M) return;
    // 边界检查
    if(index >= n) return; // 空（2）括号里的条件判断
    // 单层if判断，满足条件则选择当前元素
    if(current_sum + remaining_sum[index] >= M) { //空3，填写括号内判断
        path[path_len] = A[index];
        backtracking(index + 1, current_sum + A[index], path, path_len + 1);
    }
    // 尝试下一个元素 if(current_sum + remaining_sum[index+1] >= M) {
    backtracking(index + 1, current_sum, path, path_len);}
}
int main() {
    printf("请输入数组长度: ");
    scanf("%d", &n);
    // 动态分配内存
    A = (int*)malloc(n * sizeof(int));
    remaining_sum = (int*)malloc(n * sizeof(int));
    printf("请输入数组元素:\n");
    for(int i = 0; i < n; i++) {
        scanf("%d", &A[i]);
    }
    // 计算remaining_sum数组
    remaining_sum[n-1] = A[n-1];
    for(int i = n-2; i >= 0; i--) {
        remaining_sum[i] = remaining_sum[i+1] + A[i]; // 空（4）整行代码
    }
    printf("请输入目标和M: ");
    scanf("%d", &M);
    int *path = (int*)malloc(n * sizeof(int));
    printf("\n查找和为 %d 的所有子序列:\n", M);
    backtracking(0, 0, path, 0); // 空（5）整行代码
    if(!found) {
        printf("没有找到符合条件的子序列\n");
    }
    // 释放内存
    free(A);
    free(remaining_sum);
    free(path);
    return 0;
}
```

（缩进由伴读整理，内容照录。倒数第二个 `}` 前的注释行把一个 `if(...) {` 注释掉了，导致多出一个右括号，原文如此。按原文，当 index == n 时会先读 remaining_sum[n]，越界；这是重构代码的问题，与原卷无关。）

**问题 1**

CSDN 给出两组回忆答案：
- 第一组：（1）`current_sum == M`；（2）`return`；（3）`current_sum + remaining_sum[index] >= M`；（4）`remaining_sum[i] = remaining_sum[i+1] + A[i]`；（5）`backtracking(0, 0, path, 0);`
- 第二组：（1）`A[index] == M`；（2）`backtrack(index, crruent_sum+A[index], path, path_len+1)`；（3）`current_sum + A[index] > M`；（4）`(int*)malloc((i)*sizeof(int))`；（5）`backtrack(0, current_sum, *path, *path.length)`

两组差别很大，说明原卷的空位和代码结构记不清了，存疑，以原卷为准。

**问题 2**

CSDN 回忆：结果为 [1, 4][2, 3][5]。（CSDN 第一组答案列表里另有一行“6、[1,2,3,4,5]”，意思不明。）

校验：{1,2,3,4,5} 中和为 5 的子集只有 {1,4}、{2,3}、{5}。回溯时先“选当前元素”再“不选”，按字典序依次找到 [1,4]、[2,3]、[5]，与回忆一致。

**问题 3**

CSDN 回忆：O(nlogn)。

存疑，伴读补判为 O(2ⁿ)：子集和的回溯要在一棵 n 层的二叉决策树（每个元素选或不选）上搜索，剪枝只在部分输入上有效，最坏情况下要遍历全部 2ⁿ 个子集，时间复杂度 O(2ⁿ)（算上打印每个解，为 O(n·2ⁿ)）。O(nlogn) 是排序的复杂度，不是这类搜索的复杂度。

### 参考答案与解析

CSDN 给出两组几乎相同的回忆答案：
