### 第 1 题
计算机中，系统总线用于（1）连接。
- A. 接口和外设
- B. 运算器、控制器和寄存器
- C. CPU、主存及外设部件
- D. DMA 控制器和中断控制器

**答案：C**

**解析：** 总线是计算机设备和设备之间传输信息的公共数据通道，分为内部总线、外部总线和 I/O 总线。内部总线是 CPU 内部连接各寄存器及运算器部件之间的总线。系统总线也称外部总线，是 CPU 和计算机系统中其他高速功能部件相互连接的总线，即 CPU 与主存及外设部件之间相互连接的总线，所以选 C。I/O 总线是中低速 I/O 设备相互连接的总线。I/O 接口与外设之间通过数据信号线、联络信号线、时钟脉冲等进行数据交互；运算器、控制器和寄存器是 CPU 的组成部分；DMA 控制器和中断控制器属于输入输出系统中对外设进行管理的部件。

### 第 2 题
在由高速缓存、主存和硬盘构成的三级存储体系中，CPU 执行指令时需要读取数据，那么 DMA 控制器和 CPU 发出的数据地址是（2）。
- A. 高速缓存地址
- B. 主存物理地址
- C. 硬盘的扇区地址
- D. 虚拟地址

**答案：B**

**解析：** 输入输出系统的工作方式有四种：程序查询、程序中断、DMA 和通道。DMA 方式下，DMA 控制器获得总线控制权，使数据在 I/O 设备和主存之间直接传输，所以 DMA 控制器发出的数据地址是主存的物理地址。CPU 执行指令时读取数据，数据在主存中，因此 CPU 发出的数据地址也是主存物理地址。

### 第 3 题
设信息位是 8 位，用海明码来发现并纠正 1 位出错的情况，则校验位的位数至少为（3）。
- A. 1
- B. 2
- C. 4
- D. 8

**答案：C**

**解析：** 海明码是一种多重奇偶校验码，具有检错和纠错的功能。数据位 n，校验位 k 的关系应满足 n + k + 1 ≤ 2ᵏ。代入 n = 8，即 9 + k ≤ 2ᵏ，k 的最小值为 4。

### 第 4 题
中断向量提供的是（4）。
- A. 中断源的设备地址
- B. 中断服务程序的入口地址
- C. 传递数据的起始地址
- D. 主程序的断点地址

**答案：B**

**解析：** 中断向量表用来保存各个中断源的中断服务程序的入口地址。在程序中断方式下，当 CPU 响应中断时，由硬件直接产生一个固定的地址（即向量地址），由向量地址指出每个中断源设备的中断服务程序入口，这种方法通常称为向量中断。（原题：2013 年上半年第 2 题、2020 年下半年第 6 题）

### 第 5 题
计算机系统中，定点数常采用补码表示，以下关于补码表示的叙述中，错误的是（5）。
- A. 补码零的表示是唯一的
- B. 可以将减法运算转化为加法运算
- C. 符号位可以与数值位一起参加运算
- D. 与真值的对应关系简单且直观

**答案：D**

**解析：** 定点数的表示有原码、反码、补码和移码，计算机中常采用补码表示，最高位为符号位，其余为数值位。补码零的表示是唯一的，符号位可以与数值位一起参加运算，而且可以将减法运算转化为加法运算，这些都是补码的特点。但补码与真值的对应关系并不简单直观：正数的补码与原码相同；负数的补码是原码符号位不变、数值位取反末尾再加 1，需要进行额外的转换才能得到真值。

### 第 6 题
设指令流水线将一条指令的执行分为取指、分析、执行三段，已知取指时间是 2ns，分析时间是 2ns，执行时间是 1ns，则执行完 1000 条指令所需的时间为（6）。

<!-- 原 PDF 第 4 页 -->
- A. 1004ns
- B. 1998ns
- C. 2003ns
- D. 2008ns

**答案：C**

**解析：** 流水线的操作周期按各步操作的最大时间考虑，即 τ = max{τᵢ} = 2ns。第一条指令的执行时间为 2 + 2 + 1 = 5ns，剩下 n − 1 条指令的执行时间为 (1000 − 1) × 2 = 1998ns，所以共需 1998 + 5 = 2003ns。

### 第 7 题
在 OSI 参考模型中，负责对应用层消息进行压缩、加密功能的层次为（7）。
- A. 传输层
- B. 会话层
- C. 表示层
- D. 应用层

**答案：C**

**解析：** 表示层为应用层进程提供能解释所交换信息含义的一组服务，即将要交换的数据从适合于某一用户的抽象语法转换为适合于 OSI 系统内部使用的传送语法，提供格式化的表示和转换数据服务。数据的压缩、解压缩、加密和解密等工作都由表示层负责。

### 第 8～9 题
在 PKI 体系中，由 SSL / TSL 实现 HTTPS 应用。浏览器和服务器之间用于加密 HTTP 消息的方式是（8），如果服务器证书被撤销那么所产生的后果是（9）。

（8）
- A. 对方公钥 + 公钥加密
- B. 本方公钥 + 公钥加密
- C. 会话密钥 + 公钥加密
- D. 会话密钥 + 对称加密

（9）
- A. 服务器不能执行加解密
- B. 服务器不能执行签名
- C. 客户端无法再信任服务器
- D. 客户端无法发送加密信息给服务器

**答案：（8）D　（9）C**

**解析：** SSL（Secure Socket Layer）和 TLS（Transport Layer Security）是建立在 TCP 传输层上的安全协议，最常见的使用场景是 HTTPS：在 HTTP 和 TCP 之间加了一层 SSL/TLS，使不安全的 HTTP 成为安全的 HTTPS。HTTPS 采用混合加密方式，即非对称加密算法和对称加密算法相结合。整个握手过程中，服务器和客户端通过非对称加密算法进行通信，确认彼此身份后，再生成一个会话密

<!-- 原 PDF 第 5 页 -->
钥，采用对称加密算法对后续的通信数据进行加密传输。因此，浏览器和服务器之间用于加密 HTTP 消息的方式是会话密钥 + 对称加密，（8）选 D。

在 PKI 体系中，为了避免证书被恶意使用或泄露造成损失，引入了证书吊销机制：当证书被撤销时，应及时向证书颁发机构（CA）发起吊销请求，将该证书列入证书吊销列表（CRL）中；此外，还可以使用在线证书状态协议（OCSP）查询证书是否被吊销。客户端在建立 SSL/TLS 连接时，会验证服务器证书的有效性，如果证书被撤销，则无法验证证书的合法性，此时可能会出现安全漏洞、导致网络攻击，那么客户端无法再信任服务器，（9）选 C。

### 第 10 题
以下关于入侵防御系统功能的描述中，不正确的是（10）。
- A. 监测并分析用户和系统的网络活动
- B. 匹配特征库识别已知的网络攻击行为
- C. 联动入侵检测系统使其阻断网络攻击行为
- D. 检测僵尸网络，木马控制等僵尸主机行为

**答案：C**

**解析：** 入侵防御系统是在入侵检测系统的基础上发展起来的，不仅能够检测到网络中的攻击行为，同时能主动对攻击行为发出响应，对攻击进行防御。
- A 正确：入侵防御系统可以监测并记录所有用户和系统的网络活动，然后进行分析，以便及时发现可疑的行为。
- B 正确：入侵防御系统通常会维护一个特征库，包含各种已知网络攻击行为的特征信息，检测到可疑行为时与特征库匹配，及时发现和阻断已知攻击。
- C 不正确：入侵防御系统本身就是一种入侵检测系统，不需要与其他入侵检测系统进行联动，其主要功能之一就是阻断网络攻击行为。
- D 正确：入侵防御系统可以检测并阻断各种僵尸网络、木马控制等僵尸主机的行为。

### 第 11 题
Web 应用防火墙无法有效保护（11）。

<!-- 原 PDF 第 6 页 -->
- A. 登录口令暴力破解
- B. 恶意注册
- C. 抢票机器人
- D. 流氓软件

**答案：D**

**解析：** Web 应用防火墙是一种安全工具，可以在 Web 应用程序和互联网之间建立一道屏障，防止恶意攻击者利用已知或未知的漏洞进行各种攻击。登录口令暴力破解（用暴力破解工具尝试不同的用户名和密码组合登录 Web 应用）、恶意注册（利用漏洞或自动化工具批量注册大量虚假账号）、抢票机器人（用自动化工具模拟人工操作实现快速抢票）都可以通过 Web 应用防火墙有效防护。但流氓软件不属于 Web 应用防火墙的防护范畴：它是没有明确安装许可的不良软件或广告软件，常通过欺骗、搭便车等方式侵入用户计算机，窃取用户信息或推送广告，需要通过杀毒软件、反恶意软件等安全工具来检测和清除。

### 第 12 题
著作权中（12），的保护期不受限制。
- A. 发表权
- B. 发行权
- C. 展览权
- D. 署名权

**答案：D**

**解析：** 开发者的身份权（署名权）不随软件开发者的消亡而丧失，且无时间限制。发表权有保护期限，一般是作者终生及其死亡后五十年，截止于作者死亡后第五十年的 12 月 31 日。

### 第 13 题
国际上为保护计算机软件知识产权不受侵犯所采用的主要方式是实施（13）。
- A. 合同法
- B. 物权法
- C. 版权法
- D. 刑法

**答案：C**

<!-- 原 PDF 第 7 页 -->
**解析：** 计算机软件作为一种创造性的产品，具有明显的知识产权属性，需要在国际上采取相应的保护措施。其中最常用的方式是实施版权法，通过登记、授权、许可等手段保护软件作者的知识产权，维护市场秩序和公平竞争。另外，也可以采用技术保护手段，如数字签名、加密等技术来防止软件被盗版或篡改。

### 第 14 题
以下关于计算机软件著作权的叙述中，不正确的是（14）。
- A. 软件著作权人可以许可他人行使其软件著作权，并有权获得报酬
- B. 软件著作权人可以全部或者部分转让其软件著作权，并有权获得报酬
- C. 软件著作权属于自然人的，该自然人死亡后，在软件著作权的保护期内，继承人能继承软件著作权的所有权利
- D. 为了学习和研究软件内含的设计思想和原理，通过安装、显示、传输或者存储软件等使用软件的，可以不经软件著作权人许可，不向其支付报酬

**答案：C**

**解析：** 《计算机软件保护条例》第十五条规定：“在软件著作权的保护期内，软件著作权的继承者可根据《中华人民共和国继承法》的有关规定，继承本条例第八条规定的除署名权以外的其他权利。”所以 C 错（不能继承“所有权利”）。第十七条规定：“为了学习和研究软件内含的设计思想和原理，通过安装、显示、传输或者存储软件的方式使用软件的，可以不经软件著作权人许可，不向其支付报酬。”第六条规定，除计算机软件的程序和文档外，著作权法不保护计算机软件开发所用的思想、概念、发现、原理、算法、处理过程和运算方法；这些属于社会公有领域，不能被个人专有。

### 第 16 题
以下关于好的软件设计原则的叙述中，不正确的是（16）。
- A. 模块化
- B. 提高模块独立性
- C. 集中化
- D. 提高抽象层次

**答案：C**

**解析：** 系统设计的基本原理有抽象、模块化、信息隐蔽和模块独立。模块化是指将整个软件系统划分为若干个功能模块，每个模块具有完整的功能结构，便于开发和维护；提高模块独立性是指让每个模块尽可能独立，降低模块之间的耦合度，从而提高系统的可扩展性和可维护性；提高抽象层次是指使用抽象的设计方式，将问题抽象成更加通用、高层次的概念或模块，使系统更加灵活和可扩展。集中化不是好的软件设计原则，过于集中的设计可能导致单点故障、性能瓶颈等问题，降低系统的可靠性和可扩展性。

### 第 19 题
由 8 位成员组成的开发团队中，一共有（19）条沟通路径。
- A. 64
- B. 56
- C. 32
- D. 28

**答案：D**

**解析：** 团队中每个人都可能需要和其他成员沟通，n 个成员的团队内部沟通路径数 P = n(n − 1)/2。8 个成员时 P = 8 × 7 / 2 = 28。

### 第 20 题
对布尔表达式 “a or ((b < c) and d)” 求值时，当（20）时可进行短路计算。
- A. a 为 true
- B. b 为 true
- C. c 为 true
- D. d 为 true

**答案：A**

**解析：** 直接计算是指布尔表达式中每个因子都进行运算，短路计算是指只要表达式的值能够确定下来，就停止计算。在 “a or ((b < c) and d)” 中，如果 a 为 true，整个表达式的值已确定为 true，后面不再需要计算；如果 a 为 false，则需继续计算后面的部分。因此当 a 为 true 时可以进行短路计算。

### 第 22 题
设函数 foo 和 hoo 的定义如下图所示，在函数 foo 中调用函数 hoo，hoo 的第一个参数采用传引用方式（call by reference），第二个参数传值方式（call by value），那么函数 foo 中的 print(a, b) 将输出（22）。

```
foo( )                    hoo( int &x, int m )
  int a = 8, b = 5;         m = x * m;
  hoo(a, b);                x = m - 1;
  print(a, b);              return;
```

- A. 8, 5
- B. 39, 5
- C. 8, 40
- D. 39, 40

**答案：B**

**解析：** 传值调用将实参的值传递给形参，形参的改变不会影响实参；引用调用相当于实参存储单元的地址引用，形参改变的同时实参也跟着改变，实参只能是变量或表达式，不能是常量。foo 调用 hoo 时，第一个参数 a 按引用传递：m = 8 × 5 = 40，x = 40 − 1 = 39，即 a 被改为 39；第二个参数 b 按值传递，hoo 中对 m 的修改不影响 b。所以输出 39, 5。

### 第 23 题
某文件管理系统采用位示图（bitmap）来记录磁盘的使用情况，若计算机系统的字长为 64 位，磁盘容量为 512GB，物理块的大小为 4MB，那么位示图的大小为（23）个字。

<!-- 原 PDF 第 11 页 -->
- A. 1024
- B. 2048
- C. 4096
- D. 9600

**答案：B**

**解析：** 物理块大小为 4MB，整个磁盘共有 512GB / 4MB = 2¹⁷ 个物理块。每一位记录一个物理块的使用情况，字长 64 位，所以位示图大小为 2¹⁷ / 64 = 2¹¹ = 2048 个字。

### 第 24 题

### 第 40 题
在面向对象系统设计中，如果重用了一个包中的某个类，那么就要重用该包中的所有类，这属于（40）原则。
- A. 共同封闭
- B. 共同重用
- C. 开放—封闭
- D. 接口分离

**答案：B**

**解析：** 本题考查面向对象设计原则。
- 共同封闭原则：包中的所有类对于同一类性质的变化应该是共同封闭的。一个变化若对一个包产生影响，则将对该包中的所有类产生影响，而对于其他的包不造成任何影响。
- 共同重用原则：一个包中的所有类应该是共同重用的。如果重用了包中的一个类，那么就要重用包中的所有类。
- 开放—封闭原则：软件实体（类、模块、函数等）应该是可以扩展的，即开放的；但是不可修改的，即封闭的。
- 接口分离原则：不应该强迫客户依赖于它们不用的方法。接口属于客户，不属于它所在的类层次结构。

- （73）A. medern　B. hands-off　C. generic　D. labor-free

**答案：（71）A　（72）B　（73）B　（74）B　（75）C**

（参考译意：低代码是一种快速应用开发方法，通过拖放、下拉菜单等**可视化**构件自动生成代码；这种**自动化**让用户专注于差异化部分。无代码则是完全**放手（hands-off）**的方式，100% 依赖可视化工具。低代码平台含有带**内置**功能（API、代码模板、可复用插件、图形连接器）的 IDE。专业开发者用它自动化通用部分，把精力放在**开发**的最后一公里上。）
