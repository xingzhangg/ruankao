### 第 1～2 题
以下流程图中，要进行语句覆盖和路径覆盖测试，则需要的最少测试用例数分别为（1）；采用 McCabe 度量法计算该程序的环路复杂度为（2）。

【按原图转写】流程图：Start → S1 → 判断 J1：Y → S2，N → S3；S2、S3 汇合 → 判断 J2：Y → S4 → 判断 J3（Y → S6 → S8；N → 直接到 S8）；J2 为 N → S5 → 判断 J4（Y → S8；N → S7 → 回到 J4 之前，再次判断 J4）；S8 → End。

- （1）A. 2和6　B. 2和8　C. 4和8　D. 4和6
- （2）A. 4　B. 5　C. 6　D. 3

**参考答案（第 1～2 题）**｜B B
解析：语句覆盖：用例① J1=Y、J2=Y、J3=Y 走 S1、S2、S4、S6、S8；用例② J1=N、J2=N、J4 先 N 后 Y 走 S3、S5、S7、S8。2 个用例覆盖全部语句。路径覆盖：J1 两条分支 × J2 之后的路径数；J2=Y 时 J3 有 Y/N 两条，J2=N 时 J4 有“直接 Y”与“先 N 经 S7 再 Y”两条（循环按执行 0 次、1 次计），共 2 × (2 + 2) = 8 条。环路复杂度 V(G) = 判定结点数 + 1 = 4（J1～J4）+ 1 = 5。来源未给答案，参考答案为伴读补判，解析为伴读补写。校验：路径 2×4=8，V(G)=4+1=5。

Beyond simple visualization, LLMs now act as advanced "reasoning partners" that help technical leaders select the most suitable（5）patterns, such as Microservices or Event-Driven systems, based on specific project constraints like scalability and budget. While these AI tools significantly enhance the（6）between high-level design documents and actual code implementation, human oversight remains indispensable. ### 第 16 题
若 C 类地址每个子网主机数是 30 台，则子网掩码是（16）。
- A. 255.255.255.192
- B. 255.255.255.0
- C. 255.255.255.224
- D. 255.255.255.248

**参考答案（第 16 题）**｜C
解析：**存疑：CSDN·blog_programb 作 A**，但它自己的推导写的是“/27”，而 /27 对应的是 255.255.255.224，不是 .192（.192 是 /26），答案与推导自相矛盾。按伴读复算取 C：要容纳 30 台主机，主机位 n 满足 2^n − 2 ≥ 30，n = 5；网络前缀 32 − 5 = 27 位，最后一字节为 11100000 = 224。解析为伴读补写。校验：2^5 − 2 = 30，恰好够用；.248 只剩 3 位主机位，最多 6 台。
