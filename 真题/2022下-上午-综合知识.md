## 逐题解析

> 补充来源：《软件设计师真题精析与命题密卷》扫描件（2022 年下半年 上午试卷解析，共 8 页），2026-09 人工看图转写。原卷只给了答案，没有解析。

### 第 1 题

RISC（Reduced Instruction Set Computer）的主要特点：①指令数量少；②指令的寻址方式少；③指令长度固定，指令格式种类少；④以硬布线逻辑控制为主；⑤单周期指令执行，有利于采用流水线技术；⑥优化的编译器；⑦CPU 中的通用寄存器数量多；⑧对存储器操作有限制，从而使得控制更简单；⑨使用频率较高的指令是设计的重点，以提高其执行速度。

### 第 2 题

系统总线是计算机系统内部各部件（包括 CPU）之间进行连接和传输数据的信号线，位于 CPU 之外。

### 第 3 题

该部件的千小时可靠度 R（Reliability）为 (2000−4)/2000 = 0.998。

### 第 4 题

DRAM（Dynamic RAM）一般用于主内存，属于易失性存储器，掉电会丢失信息，使用的是电容存储（电容存在自放电，数据需周期性刷新维持）。SRAM（Static RAM）、ROM、EPROM（Erasable Programmable ROM）、EEPROM（Electrically EPROM）都用于保存非易失性数据（如计算机的二级高速缓存、自检系统、存储卡等），使用的都是晶体管。

### 第 5 题

一个二进制数 N 的一般表示形式为 N = 2^E × F，其中 E 称为阶码，F 称为尾数。阶码的大小决定了 N 的大小，尾数的长短决定了 N 的精度。用阶码和尾数表示的数称为浮点数，这种表示数的方法称为浮点表示法。

### 第 6 题

在补码表示中，最高位为符号位，0 表示正号，1 表示负号。正数的补码与反码都与其原码相同；负数的补码则等于其反码（负数的反码等于"符号位不变其余位求反"）的末位加 1。有了补码之后，可以证明 A−B = A+(−B) 的补，通过这个公式就可以把减法运算转化为加法运算，从而不必再单独设计运算器的减法逻辑。

### 第 7 题

口令认证是基于用户所知道的秘密而进行的认证技术，优点是简单、易于实现。但是口令认证只认口令而不考虑其它因素（如监听、盗用、重放攻击、猜测、暴力破解、中间人攻击等），因此安全性较低。

### 第 8～9 题

（网工与软设在本次都考到了本题）X.509 是国际密码学里公钥证书的格式标准，推荐使用的密码算法是 RSA。而国密 SM2 数字证书采用的公钥密码算法是 ECC（基于椭圆曲线的公钥密码算法）。ECC 算法与 RSA 算法相比具有加密强度高、计算速度快的优点。

### 第 10 题

数据库审计通常是监控并记录用户对数据库服务器的各种操作，并可以对数据库操作命令进行回放。包过滤是在 IP 层实现的防火墙技术，可根据包的源／目的 IP 地址、源／目的端口等包头信息判断是否允许包通过。可见，包过滤防火墙技术决定不让包通过并不是基于包中的负载数据，而是基于包中的控制数据，因此无法拦截对应用层的攻击。Web 应用防火墙是一种用于保护 Web 服务器和 Web 应用的网络安全机制，其技术原理是根据预先定义的过滤规则和安全防规则，对所有访问 Web 服务器的 HTTP 请求和服务器响应，进行 HTTP 协议和内容过滤，进而对 Web 服务器和 Web 应用提供针对性的安全防护功能。入侵检测通过收集操作系统、系统程序、应用程序、网络包等信息，发现系统中违背安全策略或危及系统安全的行为，入侵检测系统简称为 IDS，它能发现入侵行为并报警，但不能阻止恶意攻击。

### 第 11 题

### 第 12 题

《中华人民共和国著作权法》第十九条规定，受委托创作的作品，著作权的归属由委托人和受托人通过合同约定。合同未作明确约定或者没有订立合同的，著作权属于受托人。

### 第 13 题

在有些情况下，数据流图中某个加工的一组动作依赖于多个逻辑条件的取值。这时，用自然语言或结构化语言都不易于把多个条件的组合全面地描述出来，而判定表是解决这类问题的有力工具。

### 第 16 题

模块的规模大小应该在考虑到各种具体情况的前提下，力争做到高内聚、低耦合、深度和宽度合理、扇入和扇出系数合理、模块规模适中等，仅根据模块功能确定规模大小肯定是不恰当的。

### 第 19 题

风险可划分为已知风险和未知风险，已知风险是可以管理的，未知风险是风险的一种但不可管理（比如某些自然灾害，不可预测、不可控制、不可避免，因此也谈不上管理）。因此，我们不可能同时管理所有风险。

### 第 20 题

栈帧是用来执行被调用函数的一段专用空间。调用者通过实参向被调用函数传递参数，被调用函数通过形参来接收调用者传递过来的实参，然后在函数体内执行各种操作。被调用函数执行完毕后，应该知道返回将子的地址。全局变量是指整体程序都可使用（当然包括所有函数）的变量，因此全局变量定义在函数体外，所以在栈帧中无需包括全局变量。

### 第 21 题

编译器是先编译后执行，它对源代码进行编译的结果是可以直接在电脑上运行的机器码，但该机器码可在这种操作系统下运行、不能在另一种操作系统下运行，要想移植，需要改源代码并使用不同的编译器，因此编译型语言开发的程序可移植性是比较差的。而解释器是边解释边执行，只要有相应的解释器，解释型程序就可运行在各种系统上，因此可移植性好。

### 第 22 题

语法分析的任务是在词法分析的基础上将单词序列组合成各类语法短语，如程序、语句、表达式等。语法分析主要有两种：自上而下分析法和自下而上分析法。递归子程序法又叫递归下降分析法，可见它是一种自上而下的语法分析方法。

### 第 23 题

调度方式分为可剥夺和不可剥夺两种。可剥夺式是指当有更高优先级的进程到来时，强行将正在运行进程的 CPU 分配给高优先级的进程；不可剥夺式是指当有更高优先级的进程到来时，必须等待正在运行进程自动释放占用的 CPU。

### 第 24～26 题

用 PV 操作控制进程的同步与互斥时，应该在进程执行前执行 P 操作；进程执行后执行 V 操作。因此①、②、④、⑤处都应为 V 操作；③、⑥处应分别为 P 操作。

### 第 27 题

由图可知，段号占 10 位，因此最多可有 2^10 = 1024 个段；页号也是 10 位，因此每段最多可包含 2^10 = 1024 个页；页内地址为 12 位，因此页的大小为 2^12 = 4×2^10 = 4K。

### 第 28 题

硬盘的存取时间主要包括三个部分：一是磁头从原先位置移动到目的磁道所需要的时间，一般称为寻道时间；二是在到达目的磁道后等待被访问的记录块旋转到磁头下方的时间，称为旋转延迟或旋转起始时间；三是信息的传输时间（含读写时间）。本题读取一个 100 块的文件需要时间 = (2×5+10+1)×100 = 2100ms。

### 第 29 题

快速原型模型比较适合于用户需求不清、需求经常变化及系统规模不是很大也的项目。开发大型软件系统适用螺旋模型或者 RUP 模型。

### 第 30 题

三层 C/S 结构是将软件在逻辑上分成表示层、功能层和数据层三部分。系统的各层独立部署，可以并行开发，也可以选择各自最适合的开发语言。

### 第 31 题

低耦合、高内聚是模块设计的基本原则。模块之间的耦合性由低到高依次为：非直接耦合、数据耦合、标记耦合、控制耦合、外部耦合、公共耦合、内容耦合。公共耦合是指多个模块都访问同一个公共数据环境，公共数据环境可以是全局数据结构、共享的通信区、内存的公共覆盖区等。模块 A 和模块 B 通过外部变量来交换输入、输出信息，显然属于公共耦合。

### 第 32 题

Dijkstra 算法属于贪心算法策略。首先选中一个结点作起始节点，然后再从其相邻结点中找出一个距离最近的，并记住这两个顶点及其最短距离（非最重结果）；然后再遍历这两个结点的所有邻接结点，并从中选择距离最小的顶点加入到已有集合中，计算并更新已有顶点间的最小距离。依此类推，最终得出任意两点间的最短距离。
