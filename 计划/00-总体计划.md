# 总体计划（2026 下半年）

制定日期：2026-08-03。距考试（预计 11 月上旬）约 **14 周**。每天 1–2 小时。

## 目标

上午、下午各稳过 45 分。不追高分，性价比优先。

**下午·应用技术**（5 大题各 15 分，1–4 必答，5/6 二选一）：

1. 数据流图 DFD（结构化分析）
2. 数据库设计（ER 图 + 关系模式）
3. UML 建模（用例图/类图/顺序图等）
4. 算法设计（C 语言填空，常配时间复杂度）
5. C++ 设计模式 / 6. Java 设计模式（二选一，建议 Java）

下午题套路性极强，是「保 45」的关键，必须尽早开始练。

## 三轮计划

### 第一轮：基础 + 同步下午题（W1–W6，8/3–9/13）

每周一个主题章节，节奏：前 5 天学知识点 + 章节配套刷题，周末小结 + 下午题入门。

| 周 | 日期 | 上午知识点 | 下午衔接 |
|---|---|---|---|
| W1 | 8/3–8/9 | 计算机系统（进制/校验码/CPU/存储/流水线） | — |
| W2 | 8/10–8/16 | 数据结构与算法（线性表/树/图/排序查找/复杂度） | 下午题 4 初识 |
| W3 | 8/17–8/23 | 软件工程（过程模型/需求/测试/项目管理） | 下午题 1（DFD）初识 |
| W4 | 8/24–8/30 | 面向对象 + UML + 设计模式 | 下午题 3、6 初识 |
| W5 | 8/31–9/6 | 数据库（关系代数/范式/SQL/ER） | 下午题 2 初识 |
| W6 | 9/7–9/13 | 操作系统 + 网络与信息安全 | 第一轮总复盘 |

程序语言与编译、标准化/知产、专业英语三个小板块不占整周，从 W3 起以「每日 10 分钟速记 + 穿插刷题」处理。

### 第二轮：真题轮（W7–W10，9/14–10/11）

- 每周 1 套上午真题（限时 150 分钟或分两次），逐题订正入错题本
- 下午题按题型逐个击破：W7 数据流图 → W8 数据库设计 → W9 UML → W10 算法 + 设计模式，每周 2–3 道真题精练
- 周复盘看正确率曲线，弱项板块回炉

### 第三轮：冲刺（W11–W13，10/12–11/1）

- 全真模拟：上午 + 下午各至少 2 次限时整卷
- 错题本清零：全部重刷，仍错的写进「考前必看」清单
- 速记卡背诵：口诀、公式、协议端口、设计模式意图
- **机考适应**：用官网模拟作答系统熟悉界面（画图题、代码填空的机考操作）

### 考前周（11/2–考试日）

只看速记卡和「考前必看」清单，不学新内容，调整作息。
