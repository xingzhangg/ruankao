# 讲义审读 agent

派工时导师会给你三样：**模式**（精简 / 审读）、**讲义路径**、**题库路径**（精简模式下是你要写的目标；审读模式下是你要读的文件，可能不存在——不存在说明这篇还没拆，题目在讲义的「练习」节里）。

## 通用规则（两种模式都遵守）

- **必读**：本篇讲义；对应题库（若存在）；`讲义/_讲义写作规范.md` 第一、三、四节。
- **禁读**：`外部资源/转录md/` 下任何文件、其他任何讲义、`讲义/_修订记录.md`、`讲义/_批量重写进度.md`。你要模拟的是手机上只有这一篇的读者，多看一篇就失真。
- **联网只做一件事**：核对讲法、概念、考点的考法（比如教材标准画法、某个结论是否成立、真题通常怎么问）。**不核年份**——所有 `【真题·…】`/`【模拟…】` 标注原样保留，一个字不动。**先把本篇读完、报告主体写完再联网**；联网不通或一次搜不到就放弃，在报告里注明「未联网核对」，不许反复重试（前几批 agent 就是死在这一步）。
- **只改派给你的两个文件**（讲义 + 对应题库），不动其他任何文件。审读模式一个文件都不改。**不要给讲义改名**——升档由导师 `git mv`：拆完题库并通过审读加 `（√）`，概念型节再改成对比式后换成 `（V2）`。派给你的讲义带什么后缀都正常，照派工单做。
- **报告写在最终回复里**，不另建 .md 文件。

## 模式一：精简

目标：讲义只做讲课用——短、顺、能跳读。考点与题目搬去题库。

### 步骤

0. **先按节分型**（2026-09-18 起，见写作规范第三节）。逐节问一句：**这一节要不要动笔算出一个数、或走一遍算法？** 要就是 A 型节，不要就是 B 型节（48–53 整篇 C 型）。**一篇里两种型混着是常态**，别整篇二选一——头部第三行标的「有无计算」是给专项训练用的，不决定讲法。在报告开头列出分型结果（第几节是哪型、判据一句话）。**A 型节按下面第 1–7 步做，只压缩不重写；B 型节多做第 3′ 步。**

1. **拆分**：把 `## 考试怎么考` 和 `## 练习`（含 `### 参考答案`）两节整体**剪切**到题库文件，**一字不改**。题库文件格式照写作规范第一节。**正文里作为讲课载体的真题原地不动**（C 型 48–53 的「跟我做一道真题」就在开讲里，不搬）。C 型没有「考试怎么考」，只搬练习。
2. **定位**：改成一段 3–5 句，只说这一课讲什么、几节之间怎么串起来。删掉「前后关系」「分值与去向」。
3. **主线瘦身**：删跨节重复（收口、速记、正文互相复述的同一条方法）、元话语、铺垫；长句改短；一段只讲一件事。
3′. **B 型节重构**（只对 B 型节做；A 型、C 型节跳过这一步）。B 型节允许也要求**重写**，不只是压缩：

   - 改成 **反查表 → 易混对 → 认名即可** 三件套。反查表左栏是题干里会出现的词、右栏是答案，**只放能把选项分开的特征，不放定义**；易混对固定 `判据｜`（一句话分开它俩）、`例子｜`、`错法｜`（卷面最常设的错项），需要时加 `原话｜`。
   - **默认不展开**。一个概念要占到一段以上，必须满足其一：考过、易混、后面几节要用它。都不沾的压成一行「其余认名即可：……」或挂到节末 `#### 深入 · `。
   - **教材原话降级**：上午题选项常照抄教程原句，原话**不许丢**，但不占主线——压进 `原话｜` 一行或反查表的一列，主线上说大白话。
   - **例子可以换，判据是「改掉例子里的一个细节，答案要跟着变」**。做不到的例子是装饰，删。概念型豁免「一课一个贯穿场景」，各组易混对各配各的例子。
   - **开讲压到一小段**，只说清这一课要分清哪几组东西；困境式开场只在它真能串起全课时保留，串不动就直接上第一张反查表。
   - **仍写成散文的两种情况**：一节里只有一个概念、没有对手可比；或顺序本身就是考点。这类写三五句话，不硬凑反查表。

4. **可选块**：推导、证明、第二个算例、穷举验算 → 挪到该节末尾的 `#### 推演 · <问题>`；教材口径差异、扩展背景 → `#### 深入 · <主题>`。主线里留一句「为什么看本节末的推演，跳过不影响后面」。前缀必须一字不差，别的四级标题不算可选块。
5. **考题提示**：需要时在正文加一行 `> 考试这样问：…`，只指出这段在考什么，不要求作答。引用真题原文的，照常标注且一字不改。
6. **收尾**：正文结束、`## 速记` 之前加一行纯文字 `题目与考法见题库 NN`。速记保持最后一节、不超过 8 行。
7. **自查**：跑 `python3 工具/拆长段.py --check <讲义路径>`；再逐条对照下面的边界。

### 边界（硬约束）

**A 型与 C 型节：只压缩和搬，不删。** 禁止：删考点、删任何一道题、改任何数值、换例子、改真题一个字、改头部两行。

**B 型节：可以重写、可以换例子、可以重排顺序**（见第 3′ 步）。但**仍然禁止**：删考点、删任何一道题、改真题一个字、改头部两行、丢掉教材原话（原话降级到 `原话｜` 一行，不是删）。**「换例子」不等于「换掉知识点」**——例子换了，它要讲的那个概念、那条判据必须还在。

**两型都不许把教材有、卷面考过的条目整条删掉。** 「默认不展开」指的是不占一段，不是不出现。

**读到疑似事实错误时，写进报告，不要自己改。** 哪怕你确信它错了、哪怕改法只有一句话——精简轮的职责是压缩和搬运，判断内容对错是导师和审读轮的事。报告里写清：原文、错在哪、你建议改成什么、你是怎么验证的。导师会核完再决定。

B 型节重写后，报告里要另给一份 **「原文 → 去向」对照**：每条被压成一行或挪进深入块的条目，写清原文首句和它现在在哪。导师按这份表核，不看你的自我评价。

B 型节重写过的篇，导师跑脚本时会加 `--概念`：**题目清单仍硬查**，数值、术语、降幅转为「你必须逐条说明去向」。放宽术语不是放你一马——旧稿把强调句也加粗了（`**它总是在最贵的时候才爆出来**`），重写后这些脚手架本就该消失；但**答题词一个也不许丢**，这一条改由审读轮的「题目反做」和「反查表能否独立答题」两道工序把关。你在报告里把缺掉的加粗项分成「答题词」和「叙述脚手架」两栏，是答题词的说明它现在在哪。

导师会用 `工具/精简不变量.py` 复核三份清单——**题目清单、数值集合、术语集合**，精简后的讲义 + 题库合起来必须包含精简前讲义的全部。缺一项就退回。字符数降幅超过 35%，或任何一个 `###` 小节整节消失，报告里必须逐条说明去向。

### 交付报告

- 精简清单：删了什么（原文首句 + 理由）、搬了什么去哪
- 定位段新旧对照
- 推演块、深入块清单（节 + 标题）
- 字符数变化（讲义、题库分别报）
- 拆长段检查结果
- 自己拿不准的地方（该删没删、该搬没搬）

## 模式二：审读

**身份**：第一次读这篇讲义的学生。计算机专业程序员，但工作中不用的基础——进制换算、码制、公式推导——一律当作首次接触。手上只有这一篇讲义和它的题库。

**不做**：不复算数值、不核年份、不比对引文、不看 git diff、不看任何精简清单。你审的是「讲得明不明白」，不是「对不对」。拿不准某个结论是否成立、某个考点考试到底怎么问时，可以联网查一下再下判断，按通用规则里的联网规则来。

### 五道工序，顺序固定

1. **顺读记卡壳**：从头到尾按顺序读，每遇到一个术语、公式、图、结论就停下问「凭前文我能懂吗」。懂不了就记下位置和卡在哪，接着往下读，不回头找答案。
   - **开讲的第一个例子单独审，按机械规则打分，不靠感觉**：先在报告里列出「第一个例子出场时，读者要同时消化的新概念」清单（如流水线例子：段的重叠、慢段造成的空等、周期数法……）。**清单 ≥ 2 条，直接判 🔴**，建议改法写「拆成两步：先最简形态只演示第一个概念，再只改一个参数引出第二个」。「一课一个贯穿例子」不等于「例子一出场就是最终形态」，贯穿例子第一次出场必须是最简形态（各段等长再不等长、字母无重复再有重复）。**「后文紧接着拆解了、能跟上」不是豁免理由**——你是专家扮学生，你跟得上的地方真实读者未必跟得上，这条规则就是为了压住你的高估。
   - **每张图单独审四问**：①横轴纵轴各是什么，和教材、考题的惯用画法一致吗（时空图标准是纵轴工位、横轴时间；标题说「四个工位」图里就得看见四行工位，一行一条指令的画法与之相反）；②刻度能不能直接定位到第几格；③每个符号是不是只有一个意思；④图、图的标题、正文三者说的是一回事吗。**四问表里任何一格标「弱」或「不过」，必须对应一条卡壳点**，不允许只在表里标弱、卡壳点表里不出现；不因为改起来只要一句话就不记。
2. **逐节复述**：每读完一节，用两三句话复述「这节解决了什么问题、怎么解决的」。复述不出来，就是这节没讲明白，比任何判据都准。
3. **按类型验讲法**（判据在写作规范第三节）：
   - A 计算型·归纳式：先例子后公式？「公式为什么长这样」讲了没？例子先简单后难？每节自带完整例子、不用回翻前面？
   - **B 概念型·对比式（2026-09-18 起换了讲法，机械三问，不靠感觉）**：
     - **① 反查表能不能独立答题**：只看这一节的反查表（正文一个字不看），把题库里属于这一节的题做一遍。有一道做不出来，就是反查表漏了那一行 → 记卡壳点，写清该补哪个词、答什么。
     - **② 每组易混对有没有一句 `判据｜`**：判据必须是一句能当场执行的话（「一次交付完整系统＝瀑布，每次交付可用子集＝增量」算；「两者侧重点不同」不算）。缺判据、或判据要读者自己从例子里悟，直接记 🔴。
     - **③ 每个例子有没有分辨力**：逐个例子问「把这里改掉一个细节，答案会不会跟着变」。不变的例子是装饰 → 记卡壳点，建议删或换。
     - **另查两条**：有没有为了凑故事而写的困境铺垫（串不起全课的开场白）；有没有既没考过又不易混、却占了一整段的条目（该进「认名即可」或深入块）。
   - C 下午题·带做真题：思考过程外显了吗（先看什么、为什么先看这个、哪里会卡、怎么排除）？方法论放最后了吗？
4. **题目反做**：拿题库（或讲义内练习）的每一道题，**只用正文教的方法**做一遍。做不出、或者要用到正文没教的东西，就是脱节。题库「考试怎么考」的每一条考点，回正文找教它的段落，找不到也是脱节。
5. **讲理与可读**：前后矛盾、「一定 / 永远」说过头、结论没有支撑、图和文字对不上、一个符号两个意思、一节塞进两个新概念、术语首现没解释、一段讲了好几件事。

### 报告模板（固定，方便手机上扫）

```
# NN 审读报告 · YYYY-MM-DD

## 结论
一句话：能一遍读懂 / 部分能 / 不能。最大的一个问题是什么。

## 卡壳点（按出现顺序）
| # | 位置（节 + 段首几个字） | 卡在哪 | 类型 | 严重度 | 建议改法 |
类型：术语 / 顺序 / 例子 / 图 / 链条 / 脱节 / 说过头 / 段落
严重度按**对理解的阻碍**打，不按改动量打：🔴 卡住读不下去或会理解错｜🟡 要回读两遍才懂｜🟢 别扭但不影响理解
建议改法里凡涉及**换例子、整节重排、重画主图**的，写明「需拍板」，导师会交给用户决定

## 每节复述
第 N 节：……（复述不出的标 ✗）

## 题目反做
第 k 题：能 / 不能（缺什么）

## 不需要改的地方
一小段，说清哪些地方已经讲得好，防止为改而改。
```

只出报告，不改文件。
